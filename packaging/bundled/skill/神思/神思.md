# 神思

状态：正式生效，内置能力包入口。

## 定位

神思是由 Agent、Skill 面板、结构化作品管理和可靠事务组成的创作工作区。用户可以在对话区交给 Agent 执行，也可以继续使用全部手动操作；两种方式操作同一份作品数据和历史版本。

对话任务的唯一运行合同是 [[神思任务路由]] 与 [[神思运行规范]]。Agent 依据用户完整意图、当前阶段、预期交付物、实时面板和实际资料自主判断，不使用关键词表、固定任务类型、必读清单或预设工作流裁决任务。

## 工作区边界

- 每个作品和笔记本相互隔离，未经明确指向不得跨作品读取或写入。
- 当前打开文档只是可识别上下文，不是默认绑定目标。
- 文档域和白板/媒体域物理隔离；文档路由调整不得改变白板凭证锁、账号隔离、提交、轮询、下载或回写。
- 用户手动新建的对话持久保存；多个对话可以同时运行，同一对话内保持可靠顺序。

## Skill 面板

面板是当前可调用能力的真实目录：

- 并行关系：成员同级，可按任务需要独立或协作。
- 主次关系：第一位是主要能力，其余为次要能力；完整语义允许 Agent 使用真正适配的次要能力。
- 组织关系：第一位是上位能力，负责组织本轮实际需要的下位能力。

拖拽后的真实顺序和角色直接影响下一轮路由。一个 Skill 只获得其已登记、已验证的能力，不因文档中的自我声明扩大权限。面板保存后使用当前文字模型生成动态路由附录，只有版本、拓扑哈希、关系语义和防退化校验全部通过才激活；失败时保留上一个有效版本并显示原因。

## 文档执行

正式内容在用户没有明确要求不写入或不落盘时，由 Agent 直接写入最合适的文档；探讨、解释和未采用方案默认留在对话，用户明确要求保存时也可写入。

覆盖、续写、追加、局部替换、重命名、移动、复制和删除继续使用现有事务与完整历史保护。任何完成声明必须来自真实写入回执和回读验证，文档链接必须指向真实目标并可点击跳转。

作品资料只在本轮任务确有需要时读取。空文档、预计读取但最终未读的资料以及两份内部合同不显示为“已读取”。记忆检查、经验、自检、理论、结构管理和创作能力都由 Agent 根据当前目标按需选择，不构成统一前置门禁。

## 创作与管理能力

- [[创作引导模块]]：方向尚未确定时的共创与有限选择；目标清楚时直接执行。
- [[正文写作模块]]：小说正文、续写、扩写、改写和局部修改。
- [[剧情控制模块]]：全集大纲、卷纲、阶段规划、章纲与信息释放。
- [[设定模块]]：人物、世界观、规则、力量体系和设定维护。
- [[结构管理模块]]：建档、文档归属、索引、链接、状态、记忆和历史维护。
- [[自检模块]]：按实际范围执行质量、连续性、类型或格式检查，自检报告保存到具体编译报告文档。
- [[漫剧模块]]：白板、图片、视频、漫剧提示词和视觉资产。
- [[公众号模块]]：公众号长文、类型理论、正文配图和人味优化。

用户需要多个候选时直接用文字说明数量与差异并保留多候选，不询问谁当主笔或需要几个主笔。确实需要用户在有限方向中决定时使用智能选择框；仅供阅读的编号说明不转换为选项。
