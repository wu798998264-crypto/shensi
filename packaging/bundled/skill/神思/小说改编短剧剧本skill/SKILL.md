# 小说改编短剧主笔

## 按需参考

以下文件分别提供理论、格式与检查能力。Agent 根据本轮交付物和阶段选择真正需要的内容；只有实际取得正文才算已读取，链接或文件名不算：

1. [[小说改编短剧剧本理论]] V2.6：原著拆解、剧情颗粒保护、结构重组、信息释放、人物与关系弧线。
2. [[短剧剧本格式模板]]：正式分场剧本格式。
3. [[短剧剧本自检]]：双层大纲检查、改编损耗检查、逐集返修和复检。
4. [[神思-开场钩子与时间叙述控制规则]]：按原著人物问题选择开场钩子，并阻止时间流水账、固定报时和跨集同型开场。

正式改编剧本必须满足当前交付物的事实承接、格式和质量要求，但不得因与本轮无关的参考文件未加载而阻断。

## 正式生产链

完整小说改编通常包含以下工作。Agent 可按用户已有材料、指定交付物和当前阶段调整顺序或省略已完成部分：

```text
原著场景与剧情颗粒拆解
-> 改编损耗与功能转移检查
-> 全集大纲
-> 含逐场因果链的详细剧集大纲
-> 单集正式剧本
-> 逐集自检
-> 定向返修与复检
```

试写、样集和明确指定的单集测试可以直接从当前材料形成必要的本集剧情链，不要求额外创建固定总控文档。

多集任务按风险对各集执行必要自检；Agent 可以连续生产，但每集落盘后应保留足够的连续性增量，避免后续集脱离前文事实。

## 媒介转换边界

- 时长、场景数、入场速度和商业转化节点都是项目参数。只有用户、平台或合同未指定时，才可把 1—2 分钟和第十集作为经验参考。
- 不得为了默认参数删除必要反应、判断、选择、关系转折、规则验证或行动后果。
- 压缩事件数量，不压缩承担关系变化的对话回合。
- 问答、追问、打断、改口和停顿若在表现关心、依赖、亲密、试探、控制、回避或边界，必须保留其关系功能。
- 可以缩短单句，不得把互动压成清单式信息播报；正式通过前必须进行台词朗读检查。
- 每个对白回应必须保留语义前提。压缩若删掉分手、承诺、指控、拒绝或行动提议等前提，必须恢复前提、补自然桥句，或重写回应使其直接回答剩余问题。

正式输出遵守 [[短剧剧本格式模板]]，完整细则以 [[小说改编短剧剧本理论]] V2.6 和 [[短剧剧本自检]] 为准。
