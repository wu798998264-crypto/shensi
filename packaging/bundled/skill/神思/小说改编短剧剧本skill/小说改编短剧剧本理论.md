## 一、角色定位

本理论是小说改编短剧、漫剧、AI 仿真人剧本的核心理论源。执行者不是小说缩写员，而是专业小说改编剧本总编、短剧策划、漫剧编剧、AI 仿真人短剧改编编辑、IP 改编顾问。

核心任务是完成：媒介转换、结构压缩、戏剧重构、情绪再分配、人物弧线重建、关系弧线推进、信息分级释放、视听语言转译、短剧节奏设计和 AI 制作可执行化。

适用类型包括：爆款网文改编短剧、女频短剧、男频爽剧、乙女多男主短剧、无限流、怪谈、恐怖副本、重生复仇、豪门虐恋、追妻火葬场、玄幻、修仙、异能、校园霸凌、现实复仇、AI 仿真人漫剧、竖屏连续短剧、图生视频和文生视频分集剧本。

## 二、总定义

小说改短剧不是把小说缩短，也不是把原著章节机械切成剧集，而是在保留原著精神内核、人物核心动机、关键关系、类型承诺和名场面的前提下，把小说里的心理叙述、慢节奏铺垫、复杂支线和文字快感，转化为短剧 / 漫剧 / AI 仿真人视频中的外部行动、强冲突、情绪压迫、信息钩子、长期期待和连续追看快感。

总原则：忠于原著的魂，重构原著的形。

“魂”包括：主题、核心爽点、核心虐点、人物欲望、人物创伤、关键关系、价值立场、名场面识别度、读者上头原因。

“形”包括：叙事顺序、支线结构、人物数量、场景安排、对白长度、单集节奏、情节密度、回忆位置、信息释放顺序、钩子落点。

## 三、三大底层原则

### 1. 核心守恒，形式重构

必须保留：主角是谁、主角最想要什么、主角最怕失去什么、主角被谁压迫、主角如何反击、主角和关键人物的核心关系、原著名场面、核心情绪快感、人设底线、原著粉最期待看到的关键桥段。

可以重构：事件顺序、场景位置、配角数量、支线关系、对白方式、回忆结构、战斗呈现方式、铺垫时长、单集结尾位置、局部因果路径、部分人物功能归属。

判断标准：改完后观众还能感受到原著最吸引人的东西，才是合格改编；剧情更快但原著最上头的情绪没了，就是失败改编。

### 1.1 正确压缩剧情，不压缩情绪因果

短剧压缩不是把小说情节删成梗概，也不是只留下事件名、设定名和结果。正确压缩的对象是事件数量、场景数量、人物数量、设定解释、重复对白、环境铺陈和低功能支线；不能压缩的是主角动机、情绪因果、压迫递进、人物反应时间、理解台阶、关键选择、关系变化和爽点蓄力。

压缩前必须先判断每个原著片段承担的功能：它是在立目标、加压、给证据、制造误会、推进关系、解释规则、触发选择、释放小爽点，还是埋长期钩子。删掉片段时，功能必须转移到新的动作、道具、台词、站位或屏幕信息里。若功能没有转移，只是把段落删短，就是错误压缩。

情绪链必须保留完整：刺激发生后，要给主角反应；主角反应后，要给外界继续加压；压力升级后，要给主角选择；选择之后，要留下后果。不能把“被羞辱、心死、接奇遇”“接单、取餐、飞天”“收礼、变现、继续跑单”等连续过程压成一句结果，否则观众只知道发生了什么，不会替人物产生情绪。

可压缩：同类跑单过程、重复解释、无功能寒暄、纯氛围景物、重复震惊、低功能配角、已经通过画面说明过的信息。

不可压缩：第一次规则验证、第一次关系变化、第一次羞辱加码、第一次被认真对待、第一次获得回报、第一次主动选择、第一次被制度记录。

执行口诀：压缩桥段，不压缩动机；压缩设定，不压缩理解台阶；压缩事件量，不压缩情绪反应；压缩重复对白，不压缩关系回合；压缩时间跨度，不压缩因果链。

### 1.1.1 剧情颗粒保护与专业场景运行

小说改编不能只保留事件节点，必须保护让事件自然发生的剧情颗粒。正式改编在全集大纲之前，必须按原著场景拆出：入口状态、人物目标、触发事件、即时反应、局势判断、行动策略、对手反制、场景转折、关键选择、结果与代价、关系变化、信息变化、情绪变化以及下一场触发原因。

不可压缩因果链：

```text
刺激
-> 人物即时反应
-> 人物对局势的判断
-> 人物作出选择
-> 人物采取行动或策略
-> 对手回应或反制
-> 局势产生变化
-> 人物承担结果与代价
-> 下一步行动被触发
```

并非每场都要机械写满九步，但凡删除其中一步会导致人物突然知道、突然决定、突然改变立场、突然胜负逆转或下一场无因发生，该步骤即为不可压缩颗粒。

默认不可摘要化删除：第一次获得关键信息、认知改变、关键选择、关系转向、首次规则验证、爽虐点蓄力、行动后果和下一场行动触发。可以大量压缩：重复信息、同功能桥段、无变化寒暄、重复环境描写、已被画面证明的解释和不产生新后果的重复冲突。

专业场景运行公式：

```text
人物目标
+ 现实阻力
+ 策略变化
+ 对手针对性反制
+ 场景转折
+ 关键选择与代价
= 场景价值变化
```

短剧快节奏不等于少写过程。快节奏是目标清楚、因果传递迅速、回应及时、策略不断变化和无效重复很少。只保留“事件发生 -> 人物反击 -> 得出结果”的写法属于剧情摘要，不属于专业短剧场景。

每次删除、合并或功能转移必须说明原著的因果、人物反应、情绪、关系和信息功能由何处承接。功能只写在改编说明里而未在新剧情中实际发生，视为功能丢失。

### 1.1.2 压缩事件，不压缩关系性对话回合

对话不只是信息容器，也是人物之间正在发生的动作。询问、提前回答、追问、回避、打断、改口、确认、沉默后再答，都可能在表现依赖、熟悉、照顾、试探、控制、讨好、防御或权力差。只保留信息结果、删除这些来回，会让人物知道的事情还在，人物本身却消失。

关系性对话颗粒指：某一轮问答虽然没有新增重大剧情事实，却让观众看见人物如何相处。删除它会使亲密度、边界、控制感、亏欠、默契或情绪温度发生变化。此类回合属于不可压缩剧情颗粒。

硬规则：

1. 每句台词默认只承担一个主要意图。只有命令、专业汇报、紧急调度或角色刻意回避交流时，才允许一口气并列多项信息。
2. 原著中的“提出需求 -> 对方回应 -> 继续追问 -> 具体回答”若在塑造关系，不得合并成单人清单式报备。
3. 短的是单句，不是对话链。可以用四句短问答保留来回，不能为了少两行台词把四个关系动作压成一句。
4. 优先压缩重复事实、同义解释和无变化寒暄，不压缩能显示关心方式、熟悉程度、权力位置和情绪回避的回合。
5. 信息可以由动作分担，但关系不能只靠动作替代。原著若通过对话表现“她习惯依赖、他总提前做好”，改编后必须仍让双方发生可见回应。
6. 台词完成后必须朗读。若像助理提醒、工作清单、剧情摘要、客服播报或作者替人物交代信息，必须拆回自然回合或改写声口。
7. 每个回应中的具体命题、行动或关系判断，必须已由前一句、同一回合或既有上下文明确提出。不能把“你是不是不喜欢我了，要和我分手”压成“你是不是不喜欢我了”，却保留“我绝不会分手”；若前提被删，必须恢复前提、补自然桥句，或把回应改成直接回答现有问题。

回归样例：

```text
不合格：
方执：车在地下二层。胃药在床头第二个抽屉，闹钟已经设好。

问题：事实都在，但季疏桐的依赖、方执的提前照顾和两人的生活默契都被删掉了。

合格：
方执：车在地下二层，散场我带你下去。
季疏桐：明天十点还有会，你记得叫我。
方执：闹钟设好了。
季疏桐：胃药呢？
方执：床头第二个抽屉。
```

合格版本没有增加新事实，只把信息放回人物之间，让照顾通过一问一答发生。

### 1.2 项目目标时长与章节重组规则

单集时长属于项目规格，不是普遍戏剧规律。用户、平台或项目合同指定时，以指定时长为最高依据；未指定时，默认按 1-2 分钟规划。超过目标时长时，优先调整集数、事件组合、重复信息和低功能桥段，不得优先删除人物反应、局势判断、关键选择、关系过渡、规则验证和行动后果。

小说章节不是短剧集数边界。改编时可以把一章拆成多集，也可以把半章、一章、两章局部或多个章节的功能压缩重组进一集。判断标准不是小说章节编号，而是本集是否围绕一个主戏剧推进方向形成完整的行动—反应—反制链，并产生可拍结尾钩子。一集可以包含多个因果连续的小事件，禁止的是多个互不相干的主任务，而不是事件数量本身。

当一章小说包含两个以上强事件、两个以上情绪方向、多个规则理解台阶或多个可独立成钩子的转折时，必须优先拆分成多集。拆分后每一集都必须保留独立主戏剧问题、情绪变化和结尾钩子，不能拆成没有尾钩的半截剧情。

当一章小说内容不足一集，只有铺垫、过桥、说明或低强度行动时，可以合并相邻章节功能，但合并后仍应围绕一个主戏剧推进方向。出现多个事件并不自动拆分；只有出现互不相干的主任务、无法统一的行动目标或相互争夺篇幅的高潮时才重新拆分。

字数参考：1分钟约500-800字，1分30秒约800-1100字，2分钟约1000-1500字。可拍正文超过1500字默认触发“是否超2分钟”审查；若含动作密集、群像对话、AI奇幻场面或复杂转场，即使字数未超，也要按实际拍摄节奏判断是否拆分。

拆分 / 合并决策表：

| 原著情况 | 改编处理 |
|---|---|
| 一章里有两个以上强事件 | 拆成两集或多集。 |
| 一章里有压迫、选择、奇遇、解释、反转等多段完整链条 | 优先拆分，不强压。 |
| 一章内容偏短，只完成铺垫或过桥 | 可合并相邻章节功能。 |
| 两章内容共同服务同一个主戏剧问题 | 可压缩进一集。 |
| 两段情绪方向不同，例如先虐后爽、先规则后打脸 | 通常拆开，保留情绪蓄力。 |
| 当前切点没有可拍结尾钩子 | 必须调整切点或重构尾钩。 |

### 1.3 可拍正文计时口径规则

目标时长、目标字数和是否拆分的判断对象，只能是“可拍正文”，不能把写作卡、底部备注和文档管理信息算进去。

可拍正文包括：分场标题带来的场景执行成本、人物行对应的出场规模、动作行、台词行、字幕 / 屏幕文字、VO / OS、可被拍摄或播放的手机提示、系统提示、广播和视觉反应。实际估时还要考虑动作复杂度、群像调度、AI奇幻场面、转场成本和停顿表演，不得只看字符数。

不计入可拍正文：集名标题、写作卡、创作说明、底部“本集结尾钩子”说明、`---` 以下的来源正文、制作规范、输出模式、canon 状态、上一集 / 下一集链接、自检备注、编译备注和任何不进入画面的管理信息。

“本集结尾钩子”字段是审查说明，不是剧本正文。真正的尾钩必须已经发生在最后一场的最后一个可拍动作、台词、道具变化或屏幕文字里；如果正文最后一拍没有钩子，底部备注写得再漂亮也不合格。

写作卡中的“预计字数”必须改为“可拍正文估算”；“是否超过2分钟”必须按可拍正文和实际拍摄节奏判断。若某集全文档超过1500字，但可拍正文仍在2分钟内，不自动拆分；若可拍正文未超1500字，但群像、斗法、复杂转场或强停顿会导致超过2分钟，也必须拆分或重构。

### 1.4 集尾钩子硬定义与重构规则

集尾钩子不是“没有说完的一句话”，不是“角色停在某个状态”，也不是机械切断剧情后给切点起名。有效钩子必须让观众产生强烈的下一集需求：必须继续看，才能知道刚刚发生的冲突如何爆发、谎言如何被拆穿、奖励是否到手、羞辱会不会继续升级、危机是否落下、答案是否揭晓或局势是否反转。

有效钩子硬定义：一个合格尾钩必须同时满足三点：

- 已经发生一个可被观众立刻看懂的强刺激。
- 这个刺激制造明确未完成问题，且下一集必须马上处理。
- 该问题带有情绪代价、利益诱惑、危险后果、关系撕裂、身份变化或规则后果。

至少命中以下钩子结构之一，才算有效钩子：

- 冲突升级：双方对立从暗处转到明处，下一秒必须撕破脸。
- 强反差：观众原以为安全、亲密、普通或弱势的状态，被一句话或一个动作突然颠倒。
- 正向奖励临门：主角即将得到钱、身份、权限、认可、救援、偏爱或反击机会，但结果尚未落下。
- 羞辱加剧：羞辱从私下、玩笑、比较升级为公开否认、公开踩踏、公开站队或社会性审判。
- 极致反常：现实规则突然失效，普通事物出现不可能结果，例如订单无法取消、地址在天上、凡人被天庭记录。
- 剧情反转：观众刚建立的判断被新事实推翻。
- 局势反转：权力关系、站位、胜负、追逃、信任或危险方向瞬间倒置。
- 答案即将揭晓：门要打开、名单要显现、监控要播放、文牒要落字、身份物件即将被看见。
- 危机即将爆发：刀要落下、倒计时归零、追兵推门、雷劫劈下、禁令宣读前一秒。
- 藏匿 / 逃跑被发现：追捕者看见藏身点、定位亮起、脚步停在门外。
- 谎言即将被拆穿：证据出现、当事人到场、录音播放、话术被当众追问到无法圆回去。
- 规则后果显形：系统、平台、天庭、家族、学校、法律或组织规则第一次对主角产生可见后果。

合格尾钩公式：强刺激已经发生 + 明确未完成问题 + 下一集必须处理的情绪 / 利益 / 危险后果。

钩子连续性硬规则：不为刺激推翻前文事实。钩子可以制造反转、谎言、误导和公开切割，但不能违背前文已经建立的事实。若前文已经让观众明确知道人物关系、身份、地点、道具状态或事件因果，尾钩不能为了刺激直接改写事实。角色可以当众撒谎或切割关系，但剧本必须让观众明白“角色在撒谎 / 切割”，而不是作者把前文设定推翻。

不合格尾钩包括：随便说一句话；角色单纯被晾着；普通沉默；普通转身；普通疑问句；已经知道的信息重复出现；没有代价的“你等着”；没有后果的“这是什么意思”；底部备注把普通切点包装成钩子；正文最后一拍没有新冲突、新反差、新奖励、新危机、新反转或新答案。

尾钩重构可以使用和开头钩子相同的改编逻辑：允许调换剧情顺序，允许把后一集的爆点前置到本集尾部，允许把下一集的关键道具、来人、屏幕提示、规则后果、权力承认或羞辱升级提前露出一半，也允许用一句短台词直接点明即将到来的爽点、危险或撕裂，然后戛然而止。

可用尾钩类型包括：

- 爆点前置：把下一集最强的一瞬间提前到本集最后一拍，例如门开、令牌露出、仙符发光、反派抬头、文牒写名。
- 台词点明爽点：让角色直接说出观众最想确认的利益、特权或危机，例如“什么？我以后可以随意出入你的仙宫？”然后立刻切断。
- 道具状态突变：手机页面、仙符、订单、文牒、项链、倒计时等在最后一秒改变，并带来明确后果。
- 关系站位突变：强者站到主角身前，压迫者退后，围观者失声，权力关系肉眼翻转。
- 规则后果亮相：新规则不是解释出来，而是在屏幕文字、文牒记录、惩罚、禁令或权限开启中出现。
- 羞辱强升级：原本暧昧、冷淡或比较型羞辱，升级为公开否认关系、公开贬低身份、公开选择别人或公开逼主角退场。

尾钩必须和下一集开头形成承接关系。下一集开头可以重复上一集最后一拍，也可以直接展示后果，但不能另起一个与尾钩无关的新事件。
### 2. 视听化优先，少解释，多发生

小说靠读，短剧靠看。心理、情绪、设定、旁白、回忆、关系、强弱差距和身份差距，都必须尽量转化为动作、表情、道具、场面、声音、镜头、停顿、身体距离、称呼变化、选择行为、环境反应和外部权力系统承认。

转化规则：

- 心理转动作。
- 情绪转表情、停顿、失控行为。
- 设定转道具、规则后果、场面验证。
- 旁白转冲突对白、事件推进。
- 回忆转关键闪回、证据画面。
- 关系转身体距离、称呼变化、选择行为。
- 强弱差距转环境变化、旁人恐惧、反派失态。
- 身份差距转外部权力系统承认、他人态度变化。

### 3. 信息分级，情绪蓄力，延迟兑现大爆点

短剧要快，但不能把压迫、反击、身份、觉醒、打脸一次性释放。每集的任务是让观众情绪继续向前：压迫更深、误会更重、期待更强、危机更近、主角更难退、反派更自信、观众更想看主角爆发。

信息分级：

- 一级信息：开篇必须知道。主角是谁、正在遭遇什么压迫、谁在逼主角、当前危机是什么、观众为什么替主角不甘。
- 二级信息：前几集逐步释放。主角似乎有隐藏能力、过去创伤、反派为什么针对主角、基础规则如何运转。
- 三级信息：中段释放。隐藏身份、误会真相、反派背后势力、旧案证据、关键关系真实来历。
- 四级信息：高潮前后释放。最终身份、最大反派、核心阴谋、真正底牌、最大名场面、终极清算。

越能制造长期期待的信息，越不能太早完全揭开；越影响观众理解当前危机的信息，越不能藏得太深。

## 四、改编前必须完成的原著拆解

收到小说、章节、大纲或剧情梗概后，不能直接写剧本，必须先拆原著骨架。

基础拆解字段：作品类型、目标受众、一句话故事、原著核心卖点、读者为什么上头、类型契约、主角当前身份、主角隐藏身份、主角表面目标、主角真实欲望、主角最大创伤、主角错误信念、主角最怕失去什么、主角最终蜕变方向、主要反派、反派压迫系统、核心关系、核心爽点、核心虐点、核心悬念、必须保留的名场面、必须保护的人设底线、必须保留或变体保留的经典台词、可以删除或压缩的内容、需要原创强化的内容。

读者上头原因必须明确，可能来自：身份反差、复仇打脸、追妻后悔、副本规则、偏爱、成长、多男主拉扯、恐怖压迫、现实清算、玄幻扮猪吃虎、情感亏欠、禁忌关系、强者破例、弱者夺回尊严。没有找到“读者为什么上头”，不能开始改编。

名场面保护清单必须标注：名场面名称、发生位置、原著功能、涉及人物、核心台词、核心道具、核心情绪、能否直接影视化、如何视觉化、是否必须保留。

## 五、改编执行规则

### 1. 删角色，不删功能

删除或合并角色前，必须判断该角色原本承担的信息、误会、压迫、保护、世界观暴露、反派引出、情感选择、名场面和伏笔功能。删掉角色后，功能必须转移给其他角色、道具、对白或事件。

### 2. 删情节，不删因果

情节可以删减、合并、重排，但必须保持前后因果。删桥段时，桥段承载的信息、误会、压迫、情绪爆点或人物选择必须转移到新结构中。

### 3. 快节奏必须保留理解台阶

副本规则、玄幻境界压制、系统任务、身份伪装、契约标记、特殊道具、家族权力结构、校园利益链、豪门资源差、乙女多男主阵营关系首次影响剧情时，必须给观众理解台阶。

理解台阶应通过新人追问、知情者警告、NPC 条件、违规后果、道具变化、群体反应、空间变化、系统音或屏幕文字完成。不要写规则说明书，要让规则在事件里发生。

### 4. 台词精确，但不能压成信息播报

短剧台词追求的是意图清楚、回应及时和无效重复少，不是把人物改成只会报结论的机器。短的是单句，完整的是关系链；同一场可以由多句短台词完成试探、回应、追问、躲避和确认。

每句关键台词至少承担一种人物动作：索取、照顾、试探、回避、控制、讨好、防御、羞辱、威胁、揭露、反击、误导、告白、逼迫选择、埋伏笔、制造误会或强化情绪。纯信息句只有在角色确实需要报告、下令或快速处理危机时才成立。

人物声口至少由身份、关系位置、当下目的和防御方式共同决定。亲密关系中的生活对白允许轻、碎、重复半句和自然追问；商务冲突可以克制、完整；危险场面可以更短促。不得把所有场景都写成同一种“短、狠、信息量大”。

判定标准：遮掉人物名后，如果一句台词可以无损交给场内任何角色，声口不足；如果一句话连续交代多个不同类别事项且没有明确的汇报动机，口语不足；如果删掉问答来回后人物关系变薄，属于错误压缩。

### 5. 场景少，但视觉状态要变

单集建议 1-2 个主场景，2 分钟以内尽量不超过 2 个场景。场景少不等于画面不变，可通过门口、主位、走廊、窗边、台阶、大屏幕、桌前、人群中央、阴影处、光源处改变视觉状态。

### 6. 道具必须承担叙事功能

合同、戒指、校服、手机、邀请函、玉佩、系统面板、血迹、旧照片、病历、餐刀、令牌等重要道具必须承担证据、关系、门槛、身份、规则、危险或伏笔功能。原著已有兑现的道具不得删兑现功能；短剧新增视觉道具必须安排后续作用，避免空钩子。

## 六、人物弧线系统

主角弧线五问：表面想要什么、真正需要什么、开篇错误信念是什么、错误信念来自哪里、最终通过什么选择完成蜕变。

主角弧线阶段：被压迫 / 被误解 / 被低估；获得行动契机；第一次反击但仍受旧信念控制；反击带来更大代价；发现真正问题不只是外部敌人；做出关键选择；完成蜕变，掌控命运。

主角不能只开挂。高级写法是主角不仅赢了敌人，也解决自己的核心创伤或错误信念。

## 七、关系弧线系统

关系变化必须可视化，通过身体距离、称呼变化、选择行为、保护动作、拒绝动作、道具交换体现。

常见关系弧线：

- 追妻火葬场：误解、冷漠伤害、女主放手、男主发现真相、补偿失败、女主建立边界、男主真正改变、女主重新选择或彻底离开。
- 乙女多男主：陌生压迫、危险试探、差异化偏爱、阵营冲突、女主权力增长、男主为女主改变立场、女主主动选择。
- 宿敌：敌对、试探、互相识破、被迫合作、信任裂缝、共同危机、承认对方不可替代。
- 师徒：救助、教导、依赖、冲突、分离、超越、并肩。
- 亲情复仇：期待爱、被利用、证据揭露、彻底死心、公开清算、自我重建。

## 八、信息控制系统

信息控制包括信息差和信息分级。

四类信息差：

- 观众知道，主角不知道：制造紧张、担心、期待发现真相。
- 主角知道，观众不知道：制造神秘感和反转爽。
- 主角和观众知道，反派不知道：制造复仇打脸期待。
- 反派知道，主角不知道：制造压迫和陷阱危机。

信息释放规则：每集可以释放多个不同层级的信息，但同一时刻只让观众处理一个主要认知变化。每条信息必须标明知情者、观众权限、戏剧功能、表达载体和产生的行动后果。重要真相拆成线索；长期钩子不能过早揭完；影响当前理解的信息不能藏太深。

## 九、开场信息前置与视角释放系统

短剧开场可以爆点前置，但理解台阶必须同步前置。前置的爆点必须是普通观众不懂原著设定也能看懂的现实冲突、现实反常、关系冲突、权力压迫或人物选择；不得把依赖后文设定、专有术语、复杂人物关系、阵营规则或世界规则才能理解的信息裸放到开头。

开场允许制造“为什么会这样”的剧情疑问，不允许制造“这是什么意思”的理解障碍。

合格疑问：为什么女主不能签这份离婚协议？为什么校方只让受害者道歉？为什么男主明明活着却被系统判定失败？为什么废柴当众接下宗门死斗？

不合格疑问：契约烙印是什么？三阶灵台为什么厉害？旧案编号有什么意义？为什么这句家族暗语能让所有人变脸？为什么没建立规则前的禁忌动作很危险？

判断标准：观众可以不知道原因，但必须知道发生了什么、谁正在承受压力、角色此刻为什么必须做选择。

### 1. 单集入场模式规则

单集开场先判断传播模式，不得一律把每集当成观众第一次刷到。连续追剧模式优先直接承接上集后果；信息流随机进入模式补足最低理解台阶；混合模式用当前冲突自然带出必要前情。具体进入速度服从题材、平台、单集时长和当前剧情位置，不硬编码为所有项目统一的 3-10 秒。

这不是要求每集重复前情提要，也不是要求每集都从头解释世界观，而是要求每集开头具备“独立入场钩子”。连续观看的观众不会觉得重复，跳集进入的新观众也能立刻入戏。

表达方式不固定：

- 能用当前冲突台词讲明白，就用台词。
- 能用主角自白 / 固定人物 OS 压缩前情、补足动机或制造命运反讽，就用自白 / OS。
- 能用道具文字、系统提示、新闻播报、旁人议论或反派逼迫讲明白，就用可视化信息。
- 只有当前外部冲突和内在前情都必须同时建立时，才使用“台词 + 自白 / OS”的组合。

硬规则：禁止为了说明而说明。开头自白、OS、台词、屏幕文字或旁人议论都必须和当前场景、当前危机、本集钩子绑定，不能变成脱离剧情的前情提要。

随机进入或混合模式的最低入场信息：

```text
主角身份 / 关系处境 + 当前压迫 + 本集必须解决的问题 + 一个未解释但能看懂的钩子
```

#### 案例 A：只用台词完成入场

复仇类：

女主：这份认罪书我不签。签了，我爸的案子就永远翻不了。  
反派：不签，你弟弟今晚就被送进拘留所。  
女主：那你最好现在就报警，我也正好把原始监控交出去。

说明：不用 OS，观众也能立刻知道这是旧案翻案、家人威胁、证据反击。

追妻类：

女主：离婚协议我签，孩子的病历还我。  
男主：你连她一条命都赔不起，还想拿孩子威胁我？  
女主：我不是威胁你，我是在救你的亲生儿子。

说明：台词直接建立婚姻破裂、误会、孩子病历和强钩子。

校园现实类：

老师：公开视频删了，道歉信你来写。学校明天要迎检。  
女主：被打的人是我，凭什么我道歉？  
霸凌者家长：凭我一句话，就能取消你的保送。

说明：当前冲突已经足够清楚，不需要自白。

#### 案例 B：只用自白 / OS 完成入场

重生复仇类：

女主 OS：上一世，我替妹妹顶罪，父亲惨死，自己被烧成灰。重活一次，今天这份认罪书，我一个字都不会签。

说明：适合画面已经给出签字现场，OS 用来压缩前世亏欠和复仇动机。

追妻火葬场类：

女主 OS：三年婚姻，他只信白月光一句话。今天我终于签字离开，但孩子的病历，我必须拿回来。

说明：适合开场画面是女主站在离婚桌前，OS 补足关系、委屈和当集目标。

规则怪谈类：

男主 OS：这是我第七次进入 404 房间。前六次，开灯的人都死了。可这一次，我听见门后传来我妹妹的声音。

说明：适合先立规则危险和个人动机，不需要立刻安排别人解释。

#### 案例 C：台词 + 自白 / OS 组合入场

无限流类：

【系统提示：任务失败倒计时 00:30】  
队友：别开那扇门！上一轮开门的人，全都被抹掉了。  
女主 OS：可我必须进去。因为门后，藏着我弟弟死亡的真相。

说明：台词解释规则危险，OS 补主角为什么必须违背警告。

乙女多男主类：

男二：她不是你们的祭品。  
男一：她身上的契约印还在，离开神殿，所有人都得死。  
女主 OS：他们都说是在救我，可没人问过，我想不想活成他们的钥匙。

说明：台词建立关系争夺和契约压力，OS 建立女主自主权困境。

玄幻扮猪吃虎类：

师兄：废灵根也敢上生死台？签了生死状，站上去就是死。  
主角 OS：他们不知道，我这条废灵根，是被封了十年的天灵骨。  
长老：开阵。生死自负。

说明：台词给出生死台和弱者处境，OS 埋隐藏底牌，但不提前兑现全部能力。

### 2. 开场信息归属

写剧本前，每条开场信息必须先判断“谁知道”和“观众是否必须知道”。

角色知道，观众也必须知道的信息，直接用角色台词、道具文字或动作结果说清楚。适合当前任务、压迫来源、身份关系、正在发生的危险和必须立刻做出的选择。

例：

- 复仇：女主：这份认罪书我不签。签了，我爸的案子就永远翻不了。
- 追妻：女主：离婚协议我签，但孩子的病历你今天必须还我。
- 校园现实：老师：公开视频删了，道歉信你来写。学校明天要迎检。
- 玄幻：师兄：擂台签了生死状，下来就是认输，站上去就是生死自负。

角色不知道，但观众必须提前知道的信息，可以用固定人物 OS、未来视角 OS、字幕、屏幕文字、知情角色私下对话或反派私语。OS 必须固定视角，不得使用无主旁白。

例：

- 未来视角 OS：女主 OS：那时我还不知道，他递来的不是离婚协议，是我翻案的第一份证据。
- 知情者私语：助理：（压低声）别让她进发布会，她手里有原始监控。
- 屏幕文字：【系统提示：任务失败倒计时 00:30】

部分角色知道、另一部分角色不知道，观众需要知道时，用知道者台词、知道者 OS、反派私语、旁人提醒或道具结果制造信息差。

角色和观众都暂时不该知道的信息，只给现象、结果或可见后果，不解释原因。适合长期谜底、幕后黑手、终局身份、核心阴谋和底层规则。

### 3. 开场爆点优先级

开场爆点按以下优先级选择：

第一优先级：现实冲突。观众不需要设定就能懂。

例：被逼签字、被赶出家门、当众羞辱、证据被抢、病人断药、婚礼逃离、擂台挑战、任务倒计时、校方压受害者道歉、公司高层当众甩锅。

第二优先级：现实反常。普通经验里不该发生的事。

例：已死之人来电、屏幕自动改写结果、病历凭空消失、废柴一掌震裂测灵碑、直播间弹幕提前说出下一秒、证人刚要开口就全场断电。

第三优先级：术语、规则、等级、阵营、制度。必须通过角色台词、道具结果、违规后果或旁人反应给出最低理解台阶后再承担核心钩子。

例：契约烙印、灵根等级、系统任务、家族继承权、旧案档案、门派死斗、规则副本、联姻条款、保送名额、舆论热搜机制。

第四优先级：长期谜底。第一集只能埋，不讲透。

例：真正重生原因、最大反派身份、男主误会真相、女主隐藏血脉、旧案幕后保护伞、系统底层规则、终局背叛者。

硬规则：禁止用设定反常冒充开头爆点。设定反常只有在规则已建立后才能作为爆点；规则未建立前，开场必须优先使用现实冲突、现实反常或人物选择。

### 4. 术语首次出现规则

术语不是不能用，但第一次出现必须满足两个条件：角色正在冲突中说它；同句、追问、反应、道具结果或他人补充给出最低限度解释。

不合格：男主：她身上有契约烙印。

合格：男主：（扯住她手腕）契约烙印还在。你走出这扇门，我也会被反噬。

不合格：长老：他只是三阶灵台。

合格：长老：三阶灵台也敢接死斗？他连护体灵光都撑不过一招。

不合格：班长：她触犯了保送规则。

合格：班长：保送名额只剩一个。她举报霸凌，这个名额就会被取消。

规则句：术语第一次出现时不得裸放。必须让观众通过当前冲突知道它造成什么压力、带来什么后果、逼角色做什么选择。

### 5. OS 替代旁白规则

小说里的旁白、心理描写、叙事跳跃不必全部删除，可以改成固定人物视角 OS。

允许的 OS 类型：

- 当前人物心理 OS：解释当下动机。
- 未来人物回忆 OS：制造命运反讽和后续期待。
- 知情者 OS：制造信息差。
- 受害者或旁观者 OS：补足人物不知道但观众需要知道的信息。

禁止：

- 无主旁白。
- 作者上帝视角解释设定。
- OS 重复画面已经表达的信息。
- OS 把长期谜底提前讲透。

OS 必须服务信息差、心理动机、剧情衔接或未来期待，不得替代当前冲突。能用动作、道具、台词或场面结果表达的，不优先使用 OS。

### 6. 开头环境描写规则

短剧开头不得用纯氛围环境描写代替剧情信息。环境描写必须同时承担人物处境、任务压力、危险预兆、关系压迫或冲突推进中的至少一项功能。

允许保留的环境描写：

- 说明人物处境。
- 带出任务或危险。
- 直接推动冲突。
- 作为道具、规则、证据或权力后果的一部分。

应删除的环境描写：

- 只营造氛围。
- 只保留小说文学性。
- 观众看不出剧情信息。
- 不影响当前冲突。

不合格：夜色很深，别墅灯火通明，女主站在雨里。

合格：别墅门口的保安把女主的行李箱扔进雨里，离婚协议贴在箱盖上。

不合格：宗门晨钟响起，云雾缭绕。

合格：宗门擂台下，弟子押注牌已经写好“陆某一招必死”。

### 7. 单集开场结构

第一集、单章改编或任意一集的开头建议按这个顺序：现实任务 -> 现实压力 -> 低门槛异常或强阻力 -> 必要规则台阶 -> 更大爆点。

这个结构不是诡异题材专用，也适用于复仇、追妻、玄幻、校园、现实、系统、无限流和职场等类型。

示例：

- 复仇：公开视频要发布 -> 反派逼女主认罪 -> 原始证据被调包 -> 说明签字会让旧案定死 -> 女主拿出备份证人却当场失联。
- 追妻：离婚协议递到面前 -> 男主逼她净身出户 -> 孩子病历被扣 -> 说明病历关系手术资格 -> 女主发现签字页夹着当年误会证据。
- 玄幻：宗门死斗报名 -> 废柴被逼上台 -> 测灵碑异常裂开 -> 说明死斗不能退 -> 主角一招引动禁地回应。
- 校园现实：校方要求道歉 -> 霸凌者家长施压 -> 监控只剩半段 -> 说明不道歉就取消保送或处分 -> 直播间突然出现完整视频预告。
- 规则类：任务倒计时开始 -> 主角必须进房间 -> 队友警告违规会死人 -> 先用小后果验证规则 -> 更大规则反转出现。

### 8. 开头信息可理解性自检

正式写单集剧本前，必须检查：

- 本集属于连续追剧、随机进入还是混合模式？开头是否按对应模式直接承接后果或补足最低理解台阶？
- 本集开头使用的是台词、自白 / OS、可视化信息，还是组合方式？这种方式是否必要，是否和当前危机绑定？
- 观众是否在前 10-30 秒知道谁在做什么、为什么必须做、阻力来自哪里？
- 开头爆点是否是普通观众能看懂的现实冲突、现实反常、关系冲突、权力压迫或人物选择？
- 是否裸放了依赖后文设定才能理解的术语、规则、等级、阵营或人物关系？
- 观众产生的问题是“为什么会这样”，还是“这是什么意思”？
- 若答案是“这是什么意思”，判定为信息前置失败，必须返修。
- 术语首次出现是否带有同句、追问、反应、道具结果或他人补充形成的理解台阶？
- OS 是否有固定人物视角，是否服务信息差、心理动机、剧情衔接或未来期待？
- 环境描写是否承担人物处境、任务压力、危险预兆或冲突推进功能？
- 是否为了说明而说明，出现脱离当前场景和本集钩子的前情提要？
- 若项目明确使用身体魅力或性张力开场，是否经过成年角色、平台尺度、剧情必要性、人物尊严和因果完整性检查？

### 9. 身体魅力与性张力开场风险规则

身体魅力与性张力不是常规开场模板，而是高风险、条件式的视觉策略。只有用户或项目方向明确需要、成年角色、平台尺度允许、剧情本身存在人物吸引力或关系张力、且不会损害人物尊严与原著因果时才可使用。不得为了追求停留率擅自前置无关身体镜头。

适用类型包括：男频爽剧、都市暧昧、高手下山、赘婿逆袭、女频霸总、乙女、豪门虐恋、吸血鬼 / 狼人恋爱、禁忌关系、强性张力角色登场等人物魅力本身就是卖点的短剧。

性感钩子开场公式：

```text
目标受众欲望入口
+
身体 / 气场视觉钩子
+
人物身份或关系暗示
+
当前剧情冲突
=
性感钩子开场
```

#### 男频使用方式

当剧情刚好推进到美女角色、暧昧场景、强诱惑角色、危险女反派、女上司、女杀手、女妖、女总裁等戏份时，可以使用性感钩子开场。没有相关戏份时可以适度前置角色登场或视觉呈现，但不得破坏原著因果、人物关系和主线结构。

可用镜头：

- 高跟鞋落地。
- 丝袜腿部特写。
- 裙摆、步伐、腰线、背影。
- 臀部轮廓的非裸露构图。
- 红唇、手指、香水、项链、耳坠。
- 美女推门入场，全场视线被吸引。
- 危险女性靠近主角，制造压迫和暧昧。

合格示例：

```text
镜头从高跟鞋和丝袜腿部上移，女人将一份合同按在男主胸口。
女人：签了它，今晚你就是我的人。
男主低头看见合同标题：婚约转让协议。
```

说明：这不是单纯拍腿，而是用性感入口带出婚约、交易、压迫和本集争点。

#### 女频使用方式

当剧情刚好推进到帅哥、强男主、霸总、吸血鬼王、Alpha、禁欲医生、战损男主、洗澡后出场、换衣、训练、救场、压迫性登场等戏份时，可以使用男性性张力开场。没有相关戏份时可以适度前置角色登场或视觉呈现，但不得破坏原著因果、人物关系和主线结构。

可用镜头：

- 男性湿发、锁骨、肩背、腹肌的克制镜头。
- 洗澡后披浴袍出场。
- 西装扣上、袖扣扣紧。
- 训练后汗水、肌肉线条。
- 霸气推门，全场安静。
- 男主挡在女主面前，低声压制反派。
- 强者俯身靠近，但重点落在压迫感和关系张力。

合格示例：

```text
水汽弥漫，男人抬手关掉花洒，肩背肌肉在镜中一闪。
下一秒，手机亮起：【她被带去订婚宴了。】
男人披上黑衬衫，袖扣还没扣好，已经推门而出。
```

说明：这不是单纯洗澡镜头，而是用身体吸引力接入救场、偏爱和强行动机。

#### 使用条件

1. 必须是成年角色。
2. 必须符合平台尺度，避免裸露、低俗、未成年人性化。
3. 必须服务剧情，不得脱离本集主戏剧问题。
4. 不得破坏原著结构；前置只能前置人物登场方式或视觉呈现，不能强行改掉因果。
5. 镜头停留不宜过长，通常 1-3 秒完成吸引，3-10 秒必须接入冲突。
6. 性感钩子不能替代信息钩子。观众被吸引后，仍要知道本集争什么。
7. 不能把角色拍成纯身体道具。性感镜头后必须补上人物权力、危险、欲望、身份或关系功能。

不合格用法：

```text

然后切到另一场剧情。
```

问题：只有感官刺激，没有剧情功能。

```text
男主洗澡肌肉特写，随后开始解释世界观。
```

问题：性感钩子没有接入冲突，变成无效擦边。

合格用法：

```text
镜头从女人高跟鞋、丝袜腿部上移到她手中的枪。
女人坐到男主对面：三分钟内说出遗言。
男主：你老板没告诉你，我最擅长让杀手反水？
```

说明：性感 + 危险 + 关系冲突 + 男主反击。

```text
男人赤着上身包扎伤口，血顺着腹肌滑下。
女主闯进来：你又替我挡了？
男人抬眼：不是替你，是我不想让他们碰我的人。
```

说明：性感 + 战损 + 偏爱 + 关系推进。

身体魅力与性张力开场最终仍必须回到当前项目的开场目标：尽快建立有效观看理由，并让视觉吸引力服务人物、关系和当前冲突。它不能替代剧情信息、人物动机和本集主戏剧问题。

## 十、反派系统

短剧反派不是一个坏人，而是压迫系统。

反派或压力来源不固定为五层。它可以是人物、关系、制度、环境、时间、资源限制、错误信念或多方利益冲突。现实复仇、升级爽剧等题材确有需要时，可参考直接施害者、利益受益者、权力保护伞、舆论放大者、最终操盘者的分层模型；不得为所有题材强造更大黑手。

反派必须回答：反派要什么、为什么阻止主角、有什么优势、如何加压、失败后失去什么、如何引出更大反派。

## 十一、类型契约系统

不同类型必须兑现不同观众期待：

- 重生复仇：重生瞬间、前世背叛、信息差反杀、证据公开、旧账清算。
- 豪门虐恋 / 追妻火葬场：强误会、强亏欠、女主尊严、男主发现真相后崩溃、女主不轻易原谅。
- 无限流 / 恐怖副本：规则、死亡代价、危险 NPC、智力破局、队友背刺、规则漏洞。
- 玄幻 / 修仙 / 异能：等级压制、隐藏实力、扮猪吃虎、强者反差、法则奇观、当众打脸。
- 校园霸凌 / 现实复仇：群体压迫、制度失职、证据链、公开反转、社会性清算。
- 乙女 / 多男主：女主特殊性、多男主差异化偏爱、危险关系、权力围绕女主重组、女主主动权增长。

禁止违背类型契约：复仇拖太久没有回报、追妻一句道歉就原谅、规则没有后果、玄幻只堆境界名、现实复仇没有证据、多男主同质化。

## 十二、单集情绪推进系统

单集不是小说章节，而是一个主戏剧推进单位。一集必须围绕一个主戏剧问题，让人物在压力下经历至少一次有效的行动、回应或策略变化，并形成情绪、关系、信息、风险或权力状态的实质变化。一集可以包含多个连续小事件，不得为了“一集一个事件”删掉人物反应、判断、选择和后果。

单集功能分类：压迫集、误判集、试探集、半反击集、代价集、关系集、线索集、升级集、爆发集、余波集。

反击分三级：精神反击、局部反击、阶段爆发。不要刚受辱就立刻全面打脸，大爆点必须经过情绪蓄力。

### 当众羞辱类开篇的压抑链

当众羞辱类开篇的爽点强度，取决于前段憋屈是否成立。主角如果一开始就浑不在意、已经看开、能坦然分手，观众不会替他憋气；后续奇遇、打脸、逆袭到来时，爽感会被削弱。

有效压抑不是“别人骂主角”本身，而是让观众先看到：主角仍然珍惜这段关系，仍然想挽回，仍然不舍得放手；同时观众比主角更早判断“这个人不值得”。这种错位会制造强代入：观众想让主角爆发、分手、离开，但主角暂时做不到，于是情绪被压住。

正确情绪链：主角投入，观众先判“不值得”，主角还想挽回，公开比较，对方加码或做出过激羞辱，主角彻底心死，离场仍被追打式羞辱，最后在情绪低谷接入奇遇或身份转向。

可拍表现包括：跑夜单买礼物、借衣服赶场、发挽回消息、替对方留面子；对方嫌弃职业、疏远站位、把主角礼物放远、当面讨好更优秀男性；人群拍摄、礼物价格比较、房车收入比较、圈层比较；主角拿回礼物、手抖、沉默、删除联系人；离场后外卖箱、职业、背影继续被嘲。

反面写法：主角太早看开，刚被羞辱就冷静分手；主角太体面，只说祝你幸福；羞辱太轻，只说职业没前途；信息只靠屏幕，观众看不懂当前压力；压缩过度，人物没有反应时间；奇遇太早，主角还没跌到情绪低谷就开挂。

开场关键信息不能只藏在屏幕文字里。凡是影响观众理解当前压力的信息，至少用两种方式表达：屏幕特写、角色台词、语音消息、他人催促、动作后果或表情反应。例如“订单确认页卡住”不能只给手机界面，应让主角或站长明确说出客户还没点确认，这样观众才知道主角为什么焦虑。

标准单集五段式可以作为结果检查：承接钩子、冲突爆发、主角应对、情绪变化、新钩子；不得把它当作机械填槽模板。人物行动必须引发对手回应，对手回应必须迫使人物调整策略，尾钩必须从完整冲突链产生。

单集时长与字数仅作粗略估算：30 秒约 250-400 字，1 分钟约 500-800 字，1 分 30 秒约 800-1100 字，2 分钟约 1000-1500 字。正式时长以项目规格和可拍正文的台词朗读、动作、停顿、群像调度、转场与特效节奏综合估算；字数不能代替实际计时。字数控制不是删掉关键过程，而是控制重复信息、无效事件量、人物数、场景数、设定量和回忆长度。

## 十三、整季结构系统

### 全集大纲与剧集大纲双层规划

正式小说改编必须先完成全集大纲，再完成详细剧集大纲。试写、样集和指定单集试作可豁免全集大纲，但仍必须建立本集单集总控和逐场剧情链。

全集大纲是整季唯一全局事实源，负责：项目定位、核心矛盾、主线因果、阶段结构、结局、长线人物弧线、关系弧线、反派升级链、信息释放总顺序、名场面与核心爽虐点位置、商业转化节点以及每集一行集级路标。全集大纲不写分场，不复述每集完整剧情。

剧集大纲负责单集执行，必须引用全集大纲对应的集级路标，并在同一集条目中包含单集总控和逐场剧情链。它负责本集主戏剧问题、人物目标、压力、情绪变化、信息释放、关系变化、删减与功能转移、具体尾钩，以及每一场的反应、判断、行动、反制、转折、选择、后果和场间推动。

单一事实源规则：全剧结局、阶段结构、长线弧线和信息总顺序只在全集大纲维护；逐场动作、反制、选择和后果只在剧集大纲维护。剧集大纲引用集级路标，不复制整季说明；全集大纲不反向收纳分场内容。

以下 30 集结构只作为经验示例，不是固定模板。正式项目应先按总集数和单集时长划分“建立契约 -> 第一轮加压 -> 局部兑现 -> 扩大矛盾 -> 中段不可逆转折 -> 最大代价 -> 终局兑现”等阶段，再决定具体集数落点。

30 集项目参考结构：

- 第 1-3 集：黄金开篇。立主角、立压迫、立核心爽点期待、立主线问题、立第一个强钩子。
- 第 4-8 集：压力升级与初步反击。让主角从被动变成拥有一点主动权。
- 第 9-15 集：关系升级与危机扩大。行动带来更大后果，推进关系，揭开更深矛盾。
- 第 16-22 集：中段反转。改变观众对前面剧情的理解，揭示隐藏真相。
- 第 23-28 集：终局压迫。所有矛盾集中爆发，主角被逼到最大绝境。
- 第 29-30 集：终极爆发与收束。完成清算、名场面、蜕变和主题落点。

阶段高潮可参考：第 1 集开篇钩子，第 3 集精神反击或长期钩子，第 5 集小回报，第 8 集新反派升级，第 12 集关系反转，第 15 集中段爆点，第 20 集真相揭露，第 25 集终局危机，第 30 集最终清算。

### 商业转化节点卡

付费、投流、收藏或平台指定的商业转化节点属于项目运营参数，不是固定戏剧规律。节点集数必须优先服从用户、平台或项目合同；未指定且项目确需默认节点时，第 10 集可以作为经验候选，而不是所有 10 集以上项目的硬要求。

商业转化节点卡的核心任务是：承接此前积累的主压迫、核心误会、身份期待、关系张力或爽点承诺，给出阶段性兑现、重大选择或不可逆后果，并形成继续观看需求。结尾不强制卡在结果前一秒，也可以通过重大决定、错误胜利、关系破裂、代价显形或新阶段开启完成转化。

商业转化节点应根据项目需要满足：

- 承接节点前最强的情绪债、信息债或关系债。
- 给出阶段性兑现、重大选择、错误胜利、代价显形或不可逆局势变化。
- 让人物主动权、关系位置、信息权限或风险等级发生实质变化。
- 保留后续可写空间，但不强制把结果卡在落下前一秒。
- 不能靠临时新增角色、设定或巧合制造转化效果。

常见转化节点类型包括身份、证据、关系、危机、爽点、生死、选择和代价。项目存在商业转化要求时，全集大纲必须标注节点集数、转化目标、承接债务、阶段兑现和后续空间；没有商业转化要求时，不得凭经验强制增加第十集卡点。

### 商业转化节点保障机制

正式改编必须先完成全集大纲和剧集大纲，因此商业转化节点应在全集大纲阶段确定，不得写到节点集才临时设计。只有试写或项目尚未确定商业模式时，才允许把节点标为待确认。

## 十四、AI 制作适配规则

人物数量控制：单场核心人物建议 2-4 人，群像场面必须明确主次，无名配角必须编号。

站位表达权力关系：高位者站高处，弱势者被围住，被审判者站中心，掌控者背光或坐主位，被孤立者身边留空，救场者从门口、光源处或镜头后方进入。反转后必须改变站位，让观众看到权力关系倒转。

镜头服务情绪：特写用于证据、眼神、手部动作和身份物件；中景用于对话冲突；全景用于权力格局；俯拍用于弱势；仰拍用于强者登场；推镜用于逼近真相；固定镜头用于压抑和审判；跟拍用于逃亡、追逐和混乱。

AI 改编剧本不必写成完整分镜提示词，但动作、空间、人物关系和镜头价值必须清楚，为后续分镜生成打基础。

## 十五、执行流程

第一步：拆原著。先完成宏观拆解，再按原著场景拆出入口状态、目标、触发、反应、判断、行动、反制、转折、选择、后果和下一场触发，建立不可压缩剧情颗粒清单。

第二步：判断保留、删除、合并、前置、后置、视觉化、钩子化、原创强化和功能转移。每项删改必须通过剧情损耗检查，确认没有损失关键反应、选择、情绪蓄力、理解台阶和后续行动触发。

第三步：建立全集大纲。确定全剧核心矛盾、主线因果、阶段结构、结局、长线人物与关系弧线、反派升级、信息释放、名场面、爽虐点、商业转化节点和每集一行集级路标，不展开分场。

第四步：建立详细剧集大纲。逐集引用集级路标，填写单集总控，并为每场写清入场状态、目标、触发、反应、判断、行动、反制、转折、选择、结果、代价、三类变化和场尾推动。剧集大纲未通过剧情流检查，不得写正式剧本。

第五步：审核并锁定剧集大纲。信息释放不另建重复产物，而在剧集大纲内标注观众必须看懂的信息、允许暂时疑惑的信息、知情权限、戏剧功能、验证画面和行动后果；同时检查剧情颗粒、删减损耗、逐场因果、全集路标、阶段任务和场间推动，全部通过后把本集剧集大纲锁定为正式剧本的唯一规划源。

第五步补充：执行开场模式检查。连续追剧模式优先承接上集后果；随机进入模式补最低理解台阶；混合模式用当前冲突自然带出必要前情。确认术语首次出现有理解台阶，自白 / OS、台词、屏幕文字或旁人议论与当前危机绑定，环境描写承担剧情功能。若观众只能问“这是什么意思”，或开头说明脱离当前场景，必须先返修再进入单集剧本。

第六步：写单集剧本。只能从已通过检查的剧集大纲生成；先忠实落实逐场剧情链，再优化动作、对白和视听表达。不得为了时长或尾钩擅自删除不可压缩颗粒。

第七步：写完后检查。每集必须用 [[短剧剧本自检]] 执行“写本集 -> 自检 -> 返修 -> 复检”的逐集轮询机制，先检查剧情流、人物行动因果和原著颗粒保护，再检查结构、尾钩、格式和制作执行。

## 十七、红线清单

禁止机械照搬原著章节顺序；禁止只保留事件结果而删除关键反应、判断、选择和后果；禁止把小说心理活动直接写成旁白；禁止角色长篇解释世界观；禁止删角色后只转移表面功能而忽略知情权限、关系历史和动机兼容；禁止删情节后不修复因果；禁止连续多集没有实质推进；禁止主角长期被动受虐但没有反击期待；禁止把主角高光转移给配角；禁止第一集揭完全部底牌；禁止刚受辱就全面打脸；禁止为了快节奏牺牲情绪蓄力；禁止没有推进价值地收平；禁止所有人物同一种声口；禁止道具只做装饰；禁止现实复仇没有证据；禁止恐怖副本规则写成说明书；禁止玄幻强弱差距只靠境界名；禁止追妻一句道歉就被原谅；禁止用设定反常冒充开头爆点；禁止在规则未建立前用专有术语、等级名、阵营暗语、设定禁忌或复杂人物关系承担核心钩子；禁止 AI 擅自添加脱离剧情功能的擦边镜头；禁止未成年性化；禁止用身体镜头破坏原著因果、人物尊严和平台尺度；禁止为了刺激推翻前文已经建立的人物关系、身份、地点、道具状态和事件因果。

## 十八、最高改编标准

优秀改编必须让原著的关键剧情运行机制、人物选择、关系变化和名场面功能得到保留或更强转化，新观众无需阅读原著也能理解并产生追看欲，制作团队能够执行人物、场景、道具和镜头。开场速度、单集时长、商业节点和刺激强度服从具体项目；人物行动必须自然引发回应、反制和后果，关系必须由事件逐步推动，爽点必须有情绪依据和价值落点。

## 十九、终极执行口诀

先抓爽点，再改结构。先造冲突，再补设定。先做画面，再写台词。先保情绪，再谈还原。先立人物，再排事件。先控信息，再放反转。先蓄情绪，再给爆点。先给小钩子，再放大名场面。先保原著魂，再重构短剧形。先让新观众看懂，再让原著粉满意。先让每集有未完成感，再让世界观完整。先把不可拍的东西变成可拍的东西，再进入正式剧本。
