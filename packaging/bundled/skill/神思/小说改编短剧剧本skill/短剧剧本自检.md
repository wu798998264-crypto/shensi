# 短剧剧本自检

关联：[[神思]]、[[小说改编短剧剧本skill]]、[[小说改编短剧剧本理论]] V2.6、[[短剧剧本格式模板]]、[[神思-短剧与视觉资产规则]]、[[神思-正文质量净增益与防退化规则]]、[[神思-正文高频表达限制与语境裁决规则]]、[[神思-开场钩子与时间叙述控制规则]]

## 定位

[[短剧剧本自检]] 是小说改编短剧、原创短剧、漫剧前置剧本、AI 仿真人剧本的质量闸门。它以 [[小说改编短剧剧本理论]] V2.6 为核心标准，检查对象不是小说章节，也不是小说章纲，而是全集大纲、剧集大纲、单集剧本和连续多集剧本。小说 `分集细纲/` 已废止，不再作为检查对象。

目标不是让剧本照搬小说，而是确保原著魂没有丢、短剧形成立、每集有观看快感、上下集衔接连续、格式可执行、AI 制作可落地。

## 适用场景

- 小说改短剧剧集大纲审稿。
- 原创短剧全集大纲、样集、单集剧本审稿。
- 顶级人类编剧水平、爆款、投流、投稿、平台重点项目的终稿前检查。
- 单集短剧剧本审稿。
- 第一集、样集、核心爆点集检查。
- 多集短剧连续生成时逐集轮询自检。
- 短剧剧本转漫剧提示词之前的前置检查。
- 用户指出剧情不连贯、格式不对、台词意思丢失、闪回接不上、配角混乱、信息释放过早或钩子无效时。

## 合格线

每集必须同时通过三条合格线：

1. 内容质量合格线：原著核心、类型契约、人物弧线、关系弧线、单集情绪推进、视听化、台词、道具、集尾钩子均达标。
2. 内容衔接合格线：上集钩子、人物情绪、关系后果、道具状态、信息释放和下一集接力均连续。
3. 制作执行合格线：格式、场景、人物数量、站位、镜头价值、AI 制作可执行性均达标。
4. 表达原创合格线：前三个实际剧情节拍 / 台词回合零命中受控高频表达，固定模板零命中，正文词族配额与逐条语境裁决通过，近期跨集无未登记复用。
5. 质量净增益合格线：改编和返修保住人物动机、关键选择、关系回合、因果桥、情绪蓄力、理解台阶、类型承诺和后续空间；指标变好但这些资产下降时必须回退。

任一硬项不合格，本集不得通过。

原创短剧项目必须先通过 [[skill/神思/original-short-drama/references/original-short-drama-audit|原创短剧专项自检]]；当目标包含“顶级”“人类编剧水平”“爆款”“投流”“投稿”“平台重点”“满血终稿”时，还必须追加 [[skill/神思/original-short-drama/references/top-tier-benchmark|顶级短剧样本标尺]] 与 [[skill/神思/original-short-drama/references/rewrite-ladder|短剧四轮重写机制]]。未完成这些前置闸门时，不能只用本表判定通过。

检查顺序固定为：

```text
剧情流与人物行动因果
-> 原著剧情颗粒与删减损耗
-> 全集 / 阶段 / 集级路标承接
-> 场景策略、反制与场间推动
-> 人物、关系、情绪和信息
-> 单集节奏与结尾需求
-> 内容衔接
-> 格式与制作执行
```

格式正确、尾钩明显或字段齐全，不能覆盖剧情链断裂、人物行为突兀和原著关键过程丢失。

## 双层大纲自检

正式小说改编必须先检查全集大纲与详细剧集大纲：

- 全集大纲是否只维护全剧核心、阶段结构、长线弧线、信息释放总序、商业转化节点和每集一行路标，没有复制逐场内容。
- 剧集大纲是否引用全集路标，没有另写冲突的结局、阶段任务和长线弧线。
- 每集是否同时包含单集总控与逐场剧情链。
- 每场是否写清触发、反应、判断、行动、反制、转折、选择、结果、代价和场尾推动中的必要项。
- 是否存在“事件发生 -> 直接得出结果”的剧情摘要，导致人物突然知道、突然决定、突然改变立场或下一场无因发生。
- 试写、样集和指定单集试作虽可豁免全集大纲，是否仍建立本集单集总控和逐场剧情链。

双层大纲未通过时，不得进入正式剧本。

## 核心自检表

| 维度 | 自检问题 | 不合格表现 |
|---|---|---|
| 原创项目前置检查 | 原创短剧是否已通过专项自检；顶级目标是否已完成样本标尺对照与四轮重写？ | 只有通用格式检查，没有确认原创辨识度、故事发动机、中段续航和重写质量。 |
| 原著核心 | 是否保留原著精神内核、主角动机、关键关系、名场面和核心爽点？ | 只保留表面事件，原著最上头的情绪没了。 |
| 剧情颗粒保护 | 关键反应、判断、选择、关系转向、首次规则验证、爽虐蓄力、行动后果和下一场触发是否保留？ | 只留下事件节点和结果，人物过程被摘要化。 |
| 关键过程戏剧化 | 调查、证据确认、争辩、失败、关系翻面、惩罚和不可逆选择若是本集核心看点，是否在场面中发生？ | 一段汇报宣布调查完成、反派受罚；或用蒙太奇/旁白跳过观众最该亲历的过程。 |
| 剧情损耗 | 每项删除、合并和功能转移是否有明确新承载位置，并检查人物与因果损耗？ | 改编说明写“功能已转移”，实际剧情没有承载；人物合并后知情权限或动机冲突。 |
| 场景运行 | 人物行动是否引发对手针对性回应，并迫使人物调整策略或承担后果？ | 双方轮流放话，事件由大纲推动，没有策略与反制。 |
| 场间推动 | 下一场是否由本场结果通过具体原因触发？ | 本场结束后机械跳转，人物突然出现在下一任务。 |
| 读者上头原因 | 原著读者为什么上头是否被转成观看快感？ | 没有身份反差、复仇期待、规则压迫、偏爱、关系拉扯或尊严反击等核心吸引力。 |
| 类型契约 | 是否兑现对应类型观众期待？ | 重生无清算、追妻轻易原谅、恐怖无规则代价、玄幻只堆境界名、现实复仇无证据。 |
| 改编功能 | 删除、合并、前置的内容是否有功能替代？ | 删掉角色或桥段后，信息来源、误会、压迫、伏笔或情绪爆点断掉。 |
| 剧情压缩 | 是否压缩事件量而保留主角动机、情绪因果、理解台阶、关键选择和选择后果？ | 只留下事件结果，删掉人物反应、规则验证、关系变化和爽点蓄力。 |
| 单集时长 | 是否服从用户、平台或项目合同；未指定时是否按默认时长规划并结合朗读、动作、停顿、转场实际估算？ | 把经验时长当绝对上限；仅按字数裁切；为时长删除关键过程。 |
| 正文计时口径 | 时长和字数是否只统计可拍正文，排除写作卡、底部结尾钩子备注、来源链接、canon 状态和上一集 / 下一集关联信息？ | 把管理信息算进正文，导致误判切集；或全文档超字数就机械拆分。 |
| 原创化重构 | 若任务要求素材重构或去相似化，是否已按 [[神思-原创化重构规则]] 剥离原文事件顺序、标志性台词、独特名场面和独特设定机制？ | 只是换名、换场景，原文桥段排列和人物组合仍高度相似。 |
| 单集主戏剧问题 | 本集到底争什么是否清楚？ | 一集塞多个主任务，观众不知道本集核心。 |
| 开场有效性 | 是否按连续追剧、随机进入或混合模式，并依据 [[神思-开场钩子与时间叙述控制规则]] 选择一个由人物问题自然产生的主钩？ | 每集机械复述前情；为固定秒数强塞解释；套用同一种灾难、报时、死亡或未来预告；上集强后果未被直接承接。 |
| 时间叙述 | 时间开场是否区分模板报时、叙事性时间锚点与因果性时间锚点并通过删除、换时、承接测试；时间、倒计时与转场是否改变人物选择、证词、期限、状态、场景身份或制作连续性？ | 把时间领句一律硬禁；或用字幕、旁白和生僻计时词按时间表串场，跳过关键反应、反制和关系后果。 |
| 身体魅力开场风险 | 若项目明确使用身体魅力或性张力，是否为成年角色、平台允许、剧情必要且不损害人物尊严与因果？ | AI 擅自使用擦边镜头；只有感官刺激，没有剧情功能。 |
| 主角目标 | 主角本集要争取、逃避、证明、隐藏或夺回什么是否可见？ | 主角只是被动听别人说，被剧情推着走。 |
| 反派压力 | 反派、规则、关系、时间或环境是否持续加压？ | 冲突只靠吵架，局势没有变糟。 |
| 情绪变化 | 本集是否让观众情绪从一个状态变化到另一个状态？ | 从头到尾情绪平直，或爆点突然出现没有蓄力。 |
| 人物弧线 | 本集是否对人物弧线产生推进、强化、阻碍、验证、反复或制造改变条件中的至少一种作用？ | 强制人物每集顿悟；或本集对人物长线完全无作用。 |
| 关系弧线 | 关键关系是否通过身体距离、称呼、站位、选择或道具交换发生变化？ | 关系靠解释变化，没有可见行为。 |
| 信息差 | 本集谁知道、谁不知道是否清楚，信息差是否服务爽点、悬念、恐怖、误会或反转？ | 信息权限混乱，观众不知道该期待什么。 |
| 信息负荷 | 多条信息是否标明知情者、观众权限、功能、载体和行动后果；同一时刻是否只有一个主要认知变化？ | 机械限制每集只能一个信息，或同时塞入多个需要解释的大认知。 |
| 大信息延迟 | 终局身份、最大反派、核心阴谋是否被过早释放？ | 前几集就把长期钩子说透。 |
| 大爽点延迟 | 阶段爆发是否有足够情绪蓄力？ | 刚受辱就全面打脸，后续期待被抽空。 |
| 理解台阶 | 新规则、新身份、新危险是否通过短对白、反应、惩罚后果、道具变化或场面验证让观众看懂？ | 为了快节奏删掉必要桥句，观众不知道为什么危险。 |
| 视听化 | 心理、设定和旁白是否转成动作、表情、道具、镜头、空间变化或对白冲突？ | 大段旁白解释，缺少可拍画面。 |
| 台词声口 | 台词是否符合人物身份、权力关系、类型气质和情绪状态？ | 所有人都像同一种网文口吻。 |
| 关系性对话颗粒 | 原著中表现依赖、照顾、默契、试探、控制、回避或边界的问答回合是否保留？ | 信息结果还在，但提出需求、回应、追问、改口和停顿被合并，人物关系明显变薄。 |
| 问答语义闭环 | 回应中的具体命题是否已在前一句、同一回合或既有上下文明确提出？压缩后是否仍能指出“这句话在回答什么”？ | 提问只说“不喜欢”，回应却说“绝不分手”；问题前提被删，答案仍残留，形成答非所问或信息凭空出现。 |
| 口语自然度 | 台词朗读时是否像具体人物在当下对具体对象说话？ | 像助理提醒、客服播报、剧情摘要、作者说明或书面工作汇报。 |
| 单句信息负荷 | 每句是否只有一个主要意图；并列多项信息是否有角色动机？ | 为追求信息量，把行程、药物、工作和情绪等不同事项塞进同一句。 |
| 对话回合运行 | 对方是否对上一句产生即时回应，关系和情绪是否在来回中变化？ | 一人负责连续交代，另一人没有追问、确认、回避或反应。 |
| 声口不可互换 | 遮掉人物名后，关键台词是否仍能辨认说话者？ | 台词可以无损交给场内任何角色，人物只有功能没有性格。 |
| 台词功能 | 每句关键台词是否推动冲突、释放信息、制造误会、揭露关系或强化情绪？ | 台词只是解释设定、重复情绪或寒暄。 |
| 高频表达与模板复用 | 开场窗口是否零命中？动作 / 台词中的受控词是否有具体功能且未越过条件上限？是否与近期 20 集同构？ | 用“看一眼—沉默—没有立刻—真正—不是而是”替代反应；多集只换人名、地点或道具。 |
| 场景贡献 | 场景是否完成外部状态变化，或必要定向、情绪余波、关系重定位、对比蓄力中的明确功能？ | 场景既无变化也无蓄力/余波价值；或为“每场必翻面”制造虚假反转。 |
| 道具功能 | 重要道具、标记、信物、伤口、系统提示或能力是否承担证据、关系、规则、危险或伏笔功能？ | 道具只是装饰，原著已有兑现被误删，新增道具空挂。 |
| 反派系统 | 直接施害者、利益受益者、保护伞、舆论放大者、操盘者是否至少有明确层级或推进方向？ | 反派只是坏，没有利益逻辑和加压方式。 |
| 结尾后续需求 | 结尾是否通过危机、选择、关系、认知、代价、错误胜利、阶段兑现或新阶段开启形成继续观看需求？ | 没有实质变化地收平；普通停顿或疑问被备注硬命名为钩子。 |
| 尾钩重构 | 当前切点是否经过主动设计，必要时是否前置后一集爆点、羞辱升级、规则后果、奖励临门、答案揭晓、危机临爆或谎言将破？ | 机械切断剧情后，在底部备注里强行把普通停顿、普通疑问或被晾着命名为钩子。 |
| 钩子连续性 | 尾钩是否承接前文已建立事实，角色撒谎 / 切割是否被写成角色行为而不是作者改事实？ | 为了刺激直接推翻前文关系、身份、道具状态或因果，让观众觉得胡编。 |
| 商业转化节点 | 项目存在转化要求时，全集大纲是否标明节点集数与依据，并由前序债务、阶段性兑现或重大变化自然形成？ | 凭经验强制第十集卡点；节点靠突发新角色、新设定或巧合成立。 |
| AI 制作可执行 | 单场人物数、站位、主次、动作和空间关系是否清楚？ | 人物过多、站位混乱、动作归属不清，后续分镜难生成。 |
| 格式一致 | 是否严格符合用户模板或 [[短剧剧本格式模板]]？ | 字段缺失、顺序改变、编号混乱、动作台词混成散文。 |
| 单集独立文档 | 正式多集剧本是否已一集一个 Markdown 文档落盘，汇总文件是否只作为索引 / 大纲 / 编译视图？ | 多个已成稿单集正文长期混在同一剧本文档中，后续返修、分镜和资产拆分无法按集追踪。 |

## 台词口语化硬闸门

正式剧本逐集自检时，本集存在亲密 / 关系对白就抽取至少一段，本集存在冲突 / 任务对白就抽取至少一段；两类都存在时分别抽取。只看文字信息完整不算通过。

出现以下任一问题，台词项判定为必须返修：

1. 一句连续交代两个以上不同类别事项，却没有汇报、命令、紧急处理或刻意回避的角色动机。
2. 原著通过多轮问答表现关系，改编后只剩一个人的总结性台词。
3. 台词语法完整、信息清楚，但现实中没有人会在该关系、该情绪和该场合这样说。
4. 删除人物名后，多数关键台词可以在角色之间任意互换。
5. 为追求“短、狠、信息量大”删除自然回应，导致亲密、关心、压迫、犹豫或防御只能由动作说明补写。
6. 回应依赖的提问前提、指控、承诺或行动提议已被删除，导致对白回答了前文没有提出的问题。

返修顺序固定为：先恢复人物当下意图，再恢复必要问答回合，再调整口语节奏，最后压缩重复字词。不得先追求金句、攻击性或单句信息密度。

## 多集剧本轮询自检

多集生成时，不得先批量写完再统一总评。每一集都必须执行：生成本集 -> [[短剧剧本自检]] -> 按返修意见修改 -> 再次自检。内容质量、内容衔接和制作执行三条合格线全部通过后，才能进入下一集。

硬规则：

1. 每集生成后立即自检。
2. 自检不通过时，必须返修本集对应段落。
3. 返修后必须复检，不能只写“已检查”。
4. 上下集衔接不合格时，本集不得通过。
5. 不得以集数多、节省算力、节省 token、赶进度或先占坑为由跳过轮询。
6. 上下文预算不足时，宁可停在已通过的一集后，输出下一集接续卡和未完成清单，也不能输出未达标剧本。
7. 项目存在商业转化节点时，每集自检按全集大纲记录对节点的实际贡献；节点前仍缺必要铺垫或只能靠突发新角色、新设定、巧合成立时，必须回修对应前序集。
8. 每集须按 [[神思-正文高频表达限制与语境裁决规则]] 检查开场、词族、固定模板及前 20 集复用；同批次 3 集以上同骨架立即停止生成。
9. 每集还须比较目标、阻力、策略、转折、代价、结果、动作—台词链和尾拍。固定台词、推物件、手机弹窗、倒计时或总结句只换人名/道具即视为槽位换皮，直接停止批量生成。
10. 所有检查项先合并为一张返修单，由剧本主笔统一修改；修改后按 [[神思-正文质量净增益与防退化规则]] 做质量差值，不能让多个检查器轮流磨薄原作。

## 内容衔接自检

| 自检项 | 合格标准 | 不合格表现 |
|---|---|---|
| 上集钩子承接 | 上一集结尾画面钩子在本集开头或前段产生直接后果。 | 上集钩子被遗忘，本集另起事件。 |
| 人物情绪延续 | 上集造成的恐惧、愤怒、误会、信任变化或羞辱，在本集反应中可见。 | 人物像重置状态，情绪无后果。 |
| 关系后果延续 | 上集关系变化影响本集站位、台词、选择或冲突。 | 关系裂痕、亲近、背叛或误会没有后续。 |
| 道具状态连续 | 重要道具、伤口、信物、系统提示、能力状态和空间变化没有断档。 | 上集关键物件或状态突然消失。 |
| 因果桥完整 | 本集行动由上集结果自然推出，删减合并后的信息来源有替代。 | 人物突然出现，决定没有理由。 |
| 信息释放连续 | 本集只解释当前危机所需信息，不提前讲透后续谜底。 | 信息跳级，观众被剧透或看不懂当前危机。 |
| 闪回回接 | 闪回由当前线触发，并改变当前人物行动或情绪。 | 闪回插入后当前冲突没有变化。 |
| 下一集接力 | 本集结尾产生下一集必须处理的新危险、新选择、新关系后果或新画面问题。 | 结尾收平，下一集只能硬开。 |

## 类型契约专项自检

| 类型 | 必须检查 | 红线 |
|---|---|---|
| 重生复仇 | 重生动机、前世背叛、信息差反杀、证据公开、旧账清算。 | 复仇长期无回报，反派罪行模糊，主角只靠嘴赢。 |
| 豪门虐恋 / 追妻 | 强误会、强亏欠、女主尊严、男主发现真相后崩溃、女主边界。 | 一句道歉就原谅，女主长期卑微无成长。 |
| 无限流 / 恐怖 | 规则、死亡代价、危险 NPC、智力破局、漏洞试探。 | 规则无后果，机制全靠长解释。 |
| 玄幻 / 修仙 / 异能 | 等级压制、隐藏实力、环境反应、强者失态、当众打脸。 | 只堆境界名，战斗没有胜负转折。 |
| 校园霸凌 / 现实复仇 | 群体压迫、制度失职、证据链、公开反转、社会性清算。 | 没证据，只有情绪宣泄。 |
| 乙女 / 多男主 | 女主特殊性、差异化偏爱、危险关系、阵营冲突、女主主动权。 | 男主同质化，所有人无理由爱女主。 |

## 单集结构自检

使用“一集 = 一个主戏剧推进方向 + 一条完整行动—反应—反制链 + 一个实质状态变化 + 下一集需求”检查。一集允许多个因果连续的小事件和多个情绪节拍。

“承接钩子、冲突爆发、主角应对、情绪变化、新钩子”只作结果检查，不作为机械生成模板。谈判、调查、追逐、误会升级、准备—执行—失控等结构均可使用。

不合格表现：只有压迫没有局部推进；只有打脸没有后果；只有解释没有行动；只有闪回没有当前线变化；只有吊胃口没有有效进展；只有异常没有理解台阶。

## 格式自检

格式检查优先级：用户模板 > [[短剧剧本格式模板]] > 本文件通用规则。

必须检查：集数标题、分场编号、场景标题、人物行、动作行、台词行、字幕行、VO/OS 使用、正文内的集尾功能、单集独立文档落盘。格式不合格时必须重排格式，不能只在自检里说明“格式需调整”。正式单集文件不得出现“写作卡 / 单集写作卡 / 本集结尾说明 / 自检 / 评分 / 记忆增量 / 上下集管理备注”等内部区块；这些内容应保留在系统内部或独立控制/报告文件，不得因为计时排除就继续展示在剧本中。

## 禁止项

- 禁止机械照搬原著章节顺序。
- 禁止需要原创化重构时只换人名、地点和台词口吻，仍保留原文事件顺序和标志性场面。
- 禁止把小说心理活动直接写成旁白。
- 禁止用角色长篇解释世界观。
- 禁止删角色后不转移功能。
- 禁止删情节后不修复因果。
- 禁止连续多集没有情绪推进。
- 禁止主角长期被动受虐但没有反击期待。
- 禁止把主角高光转移给配角。
- 禁止第一集揭完主角全部底牌。
- 禁止刚受辱就完成全面打脸。
- 禁止为了快节奏牺牲情绪蓄力。
- 禁止把剧情压缩成只有事件结果而没有情绪因果、理解台阶和人物反应。
- 禁止违反项目目标时长；未指定时按默认时长规划。超时时不得优先删除关键反应、判断、选择、关系过渡和行动后果。
- 禁止把写作卡、底部结尾钩子备注、来源链接、canon 状态和上一集 / 下一集关联信息计入单集时长或字数。
- 禁止把上述写作卡、结尾说明和管理信息留在正式剧本产物中；计时排除不等于允许对观众/用户展示。
- 禁止机械切割剧情后强行把切点命名为钩子；尾钩必须通过正文内的冲突升级、强反差、奖励临门、羞辱加剧、极致反常、剧情/局势反转、答案即将揭晓、危机临爆、谎言将破、规则后果、关系站位变化或台词点明爽点成立。
- 禁止把普通停顿、普通疑问、角色被晾着、没有代价的状态停留当成合格尾钩。
- 禁止没有推进价值地收平；允许以重大决定、错误胜利、关系变化、代价显形或新阶段开启形成自然但有效的结尾。
- 禁止让所有人物使用同一种声口。
- 禁止把承担亲密、关心、依赖、试探、控制或边界变化的多轮问答压成单人清单式报备。
- 禁止用台词信息完整掩盖人物说话不口语、关系回合消失或角色声口可互换。
- 禁止道具只做装饰。
- 禁止现实复仇没有证据。
- 禁止恐怖副本规则写成说明书。
- 禁止玄幻强弱差距只靠境界名。
- 禁止追妻一句道歉就被原谅。
- 禁止用同义词替换绕过受控词族；禁止把角色对白当作自动豁免；禁止未登记地跨集复用长台词、旁白、动作段或集尾总结骨架。
- 禁止用汇报、新闻播报或蒙太奇一次性宣布本应成为核心场面的调查、取证、对抗、关系翻面和后果。
- 禁止任何返修以时长、钩子、视听化或商业评分提升为由损失核心选择、关系颗粒、因果桥、情绪蓄力和人物声口。
