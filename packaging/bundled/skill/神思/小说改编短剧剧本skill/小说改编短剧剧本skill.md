关联理论：[[小说改编短剧剧本理论]] V2.6

关联自检：[[短剧剧本自检]]

关联格式：[[短剧剧本格式模板]]

关联调度：[[神思]]、[[神思-短剧与视觉资产规则]]

关联重构：[[神思-原创化重构规则]]、[[小说原创化重构skill]]

## 定位

本 skill 是 [[神思]] 的小说改编短剧 / 漫剧 / AI 仿真人剧本主执行 skill。它以 [[小说改编短剧剧本理论]] V2.6 为核心理论源，用于把小说、剧情梗概、章节、大纲或原型素材改编为全集大纲、详细剧集大纲、单集短剧剧本、漫剧前置剧本或 AI 仿真人剧本。

它不是把小说缩写成剧本，也不是逐章搬运原文，而是完成媒介转换、剧情颗粒保护、结构重组、戏剧强化、情绪再分配、人物弧线重建、关系弧线推进、信息分级释放、视听语言转译、短剧节奏设计和 AI 制作可执行化。

总原则：忠于原著的魂，重构原著的形。

若任务要求借鉴型重构、素材重排、去相似化或不保留原小说具体形态，必须先按 [[神思-原创化重构规则]] 输出原创化重构卡，再进入本 skill。

## 触发场景

用户提出以下需求时使用本 skill：

- 把小说改成短剧剧本、漫剧剧本、AI 仿真人剧本。
- 生成剧集大纲、单集剧本、样集、核心爆点集。
- 将小说章节、剧情控制文件或原型素材改编为可拍剧本。
- 按 [[小说改编短剧剧本理论]] V2.6 执行改编。
- 写正式短剧剧本前需要拆原著骨架、短剧化重构或逐集自检。

## 输入默认值

用户未指定时默认：

- 单集时长：优先服从用户、平台或项目合同；未指定时默认 1-2 分钟。
- 单集字数：只作粗略估算，必须结合台词朗读、动作、停顿、群像调度、转场和特效节奏判断；管理信息不计入。
- 单集结构：一个主戏剧推进方向，允许多个因果连续的小事件。
- 单集场景：按剧情完整性和制作条件决定；未指定时建议 1-2 个主场景，不作绝对上限。
- 结尾：必须在正文最后一拍形成可拍的下一集需求，可以来自危机、选择、关系、认知、代价、错误胜利、阶段兑现或新阶段开启。强悬念钩子是常用形式，不是唯一形式；底部说明不能替代正文结果。
- 输出格式：[[短剧剧本格式模板]] 的分场短剧剧本格式。
- 用户提供格式模板时，用户模板优先于内置模板。

## 工作流程

正式小说改编固定使用以下规划链：

```text
原著剧情颗粒拆解
-> 全集大纲
-> 详细剧集大纲（内含逐场剧情链）
-> 单集正式剧本
```

正式改编不得从小说正文、原著拆解或全集大纲直接跳写单集剧本。只有用户明确要求试写、样集或指定单集试作时，才可豁免全集大纲；试写仍必须先建立本集单集总控与逐场剧情链，不得直接把原文压成格式正确的剧本。

术语边界：

- “全集大纲”专指短剧整季总控，负责全局主线、阶段结构和长线兑现。
- “剧集大纲”专指短剧逐集详细规划，不得称为小说“分集细纲”。
- 小说作品目录中的 `01_剧情控制/分集细纲/` 仍由 [[神思-大纲与章纲规则]] 管理，与本 skill 的剧集大纲无关。

### 第一步：拆原著

收到小说、章节、大纲或剧情梗概后，不能直接写剧本。必须先拆原著骨架，并明确读者为什么上头。

若已存在原创化重构卡，先承接其中“可继承的功能层、必须剥离的相似风险、新人物 / 新关系、新场景 / 新压力、新事件顺序、新集尾钩子”，不得再机械回到原文顺序。

必须提取：

| 项目 | 要求 |
|---|---|
| 作品类型 / 目标受众 | 判断类型契约和平台观看期待。 |
| 一句话故事 / 核心卖点 | 说清楚故事靠什么吸引人。 |
| 读者上头原因 | 身份反差、复仇打脸、追妻后悔、副本规则、偏爱、成长、多男主拉扯、恐怖压迫、现实清算、玄幻扮猪吃虎等。 |
| 类型契约 | 本类型观众必须看到什么，哪些写法会违约。 |
| 主角当前身份 / 隐藏身份 | 当前处境和后续期待分开记录。 |
| 主角表面目标 / 真实欲望 | 区分当集行动目标和长期人物欲望。 |
| 主角最大创伤 / 错误信念 / 最怕失去什么 | 用于人物弧线和情绪蓄力。 |
| 主角最终蜕变方向 | 主角最后不只是赢，还要完成什么变化。 |
| 主要反派 / 反派压迫系统 | 直接施害者、利益受益者、权力保护伞、舆论放大者、最终操盘者。 |
| 核心关系 / 关系弧线 | 追妻、乙女、宿敌、师徒、亲情复仇等关系如何变化。 |
| 核心爽点 / 虐点 / 悬念 | 改编后必须保留的观看快感。 |
| 信息差 / 信息分级 | 谁知道、谁不知道；一级到四级信息何时释放。 |
| 名场面保护清单 | 名称、位置、功能、人物、台词、道具、情绪、视觉化方式、是否必须保留。 |
| 人设底线 / 经典台词 | 原著粉风险最高的保护项。 |
| 可删除 / 可合并 / 需原创强化 | 每一项都要说明被转移的叙事功能。 |

硬规则：没有找到“读者为什么上头”，不能开始改编。

原著宏观拆解完成后，必须继续进行剧情颗粒拆解。不得只提取剧情结果，必须按原著场景记录：

```text
场景入口状态：
人物目标：
触发事件：
人物即时反应：
人物对局势的判断：
人物采取的行动或策略：
对手回应或反制：
场景转折：
人物关键选择：
结果与代价：
关系变化：
信息变化：
情绪变化：
推动下一场的具体原因：
```

以下剧情颗粒默认不可摘要化删除：人物第一次获得关键信息、认知改变、关键选择、关系转向、首次规则验证、爽虐点蓄力、行动造成的后果、下一场行动的触发原因。

### 第二步：标注改编策略

对原著情节逐项标注：保留、删除、合并、前置、后置、视觉化、钩子化、原创强化、功能转移。

核心规则：删角色不删功能，删情节不删因果。删掉角色或桥段后，原本承担的信息、误会、压迫、情绪爆点、人物选择、世界观暴露、伏笔或名场面功能，必须转移给其他角色、道具、对白或事件。

每项删除、合并、前置、后置或功能转移必须通过剧情损耗检查：

```text
原著内容及位置：
原著承担的因果功能：
人物反应与选择功能：
情绪与关系功能：
信息与理解台阶功能：
新承载位置：
新载体：动作 / 对白 / 道具 / 场景 / 其他人物
是否损失人物反应：
是否损失关键选择：
是否损失情绪蓄力：
是否造成后续行动突兀：
裁决：允许 / 必须补桥 / 禁止删除
```

只在改编说明中写“功能已转移”不算完成。转移后的功能必须在全集大纲、剧集大纲或正式剧本中找到明确的新承载位置。

### 第三步：建立全集大纲

全集大纲是短剧整季唯一全局事实源，只管全局，不展开逐场剧情，也不复制剧集大纲。正式改编必须先完成全集大纲并通过全局检查。

全集大纲必须包含：

- 项目定位：类型、受众、总集数、单集目标时长、核心卖点和类型契约。
- 全剧核心：一句话故事、核心矛盾、主线因果、结局方向和主题落点。
- 原著保护：必须保留的剧情链、人物选择、关系节点、名场面和核心爽虐点。
- 阶段结构：每一阶段的目标、压力升级、局部兑现、阶段高潮和进入下一阶段的原因。
- 长线人物弧线、关系弧线、反派升级链、信息释放链、伏笔与道具兑现链。
- 商业转化节点：按项目真实要求设置；未指定且项目确有转化需求时，第 10 集只作为经验候选，不得替代项目指定节点。
- 每集一行集级路标：只写本集对全剧的核心推进、关键变化和承接方向，不写分场过程。

单一事实源硬规则：全剧结局、阶段结构、长线弧线、信息释放总顺序和集级路标只在全集大纲维护；剧集大纲只能引用对应路标，不得另建冲突版本。

### 第四步：建立详细剧集大纲

不能按“小说一章 = 短剧一集”硬切。短剧单集是一个主戏剧推进方向，不等于只能发生一个事件；允许多个因果连续的小事件共同构成完整的行动—反应—反制链。正式单集最长不得超过项目合同规定的时长；未指定时默认 1-2 分钟。超过目标时长时，优先调整集数、事件组合和低功能重复内容，不得先删除人物反应、判断、关键选择和行动后果。

剧集大纲必须逐集引用全集大纲中的对应集级路标，并分为“单集总控”和“分场规划”两层。

单集总控必须标注：

| 字段 | 要求 |
|---|---|
| 本集核心事件 | 一句话说清楚本集发生什么。 |
| 本集主戏剧问题 | 本集到底争什么。 |
| 本集情绪功能 | 压迫、误判、试探、半反击、代价、关系、线索、升级、爆发或余波。 |
| 本集主角目标 | 主角本集要争取、逃避、证明、隐藏或夺回什么。 |
| 本集反派压力 | 谁在加压，如何加压，失败代价是什么。 |
| 本集情绪变化 | 观众情绪从什么状态变成什么状态。 |
| 本集信息释放 | 只释放当前需要的信息，长期信息按级别延后。 |
| 本集暂不释放的信息 | 防止过早揭底牌或过早兑现大爽点。 |
| 本集关系变化 | 身体距离、称呼、站位、选择或道具交换如何变化。 |
| 本集人物弧线作用 | 推进、强化、阻碍、验证、反复或制造改变条件；不强制每集顿悟。 |
| 本集场景价值变化 | 场景开始和结束的权力关系、危险等级或情绪状态是否变化。 |
| 本集结尾画面钩子 | 必须是正文最后一拍中的强冲突、强反差、奖励临门、羞辱加剧、极致反常、剧情/局势反转、答案即将揭晓、危机临爆、谎言将破或规则后果；可前置后一集爆点重构尾钩。 |

每一场的分场规划必须标注：

| 字段 | 要求 |
|---|---|
| 场次与场景 | 场号、时段、内外、地点和出场人物。 |
| 入场状态 | 人物、关系、信息、情绪和现场局面从什么状态开始。 |
| 本场目标 | 本场主要人物具体想得到、阻止、隐藏、确认或改变什么。 |
| 触发事件 | 什么具体刺激使人物必须行动。 |
| 即时反应与判断 | 人物先如何反应，又怎样理解当前局势。 |
| 行动或策略 | 人物为目标采取什么可拍行动，不得只写抽象态度。 |
| 对手回应或反制 | 对手必须针对上一拍行动作出有因果的回应。 |
| 场景转折 | 新信息、新行动或新代价怎样改变原有局面。 |
| 关键选择 | 人物在压力下作出什么不能被结果摘要替代的选择。 |
| 结果与代价 | 本场结束时谁得到什么、失去什么、承担什么后果。 |
| 三类变化 | 关系、信息、情绪分别发生什么变化；无变化项可省略。 |
| 场尾推动 | 本场结果通过什么具体原因触发下一场，而不是大纲机械跳转。 |

剧集大纲不是剧情梗概。若某场只有“发生事件 -> 得出结果”，缺少必要的反应、判断、策略、反制、选择或后果，判定为剧情链断裂，不能进入正式剧本。

项目存在付费、投流、收藏或平台指定节点时，全集大纲必须建立商业转化节点卡，标注节点集数、依据、承接债务、阶段性兑现、重大选择或未完成后果。未指定且项目确需默认节点时，可把第 10 集作为经验候选，但不得硬编码；保障节奏从实际节点反推。

### 第五步：审核并锁定剧集大纲

信息释放已经属于剧集大纲字段，不另建重复产物。进入剧本前必须随剧情流一起确认：

- 本集观众必须看懂的信息。
- 本集允许观众暂时疑惑的信息。
- 本集谁知道真相，谁不知道真相。
- 本集信息差服务爽点、悬念、恐怖、误会还是反转。
- 本集规则、身份或危险的验证画面。
- 本集原著名场面的情绪功能。
- 本集重要道具是否需要兑现。
- 本集大信息是否过早释放。
- 本集大爽点是否需要延迟。

信息设计按 [[小说改编短剧剧本理论]] V2.6 标注知情者、观众权限、戏剧功能、表达载体和行动后果；一级到四级只作为重要度参考，不作为每集信息数量的硬限制。审核还必须确认每场因果链、不可压缩颗粒、关系性对话回合、删减损耗、全集路标、阶段任务和场间推动均已通过，随后锁定本集剧集大纲作为正式剧本的唯一规划源。

### 第六步：写单集剧本

每集写作前先填写写作卡：

```text
原著来源范围：
改编方式：单章单集 / 拆章成集 / 合章成集 / 跨章重组
可拍正文预计时长：
可拍正文字数估算：
计时 / 字数排除项：写作卡、底部结尾钩子说明、来源链接、canon 状态、上一集 / 下一集关联信息
是否超过2分钟：
若超过，拆分 / 重构点：
尾钩重构方案：正常切点 / 爆点前置 / 后集爆点前移 / 台词点明爽点 / 道具状态突变
本集保留的情绪链：
本集删减 / 合并的原著功能：
本集核心事件：
本集主戏剧问题：
本集情绪功能：
本集主角目标：
本集反派压力：
本集情绪变化：
本集结尾钩子：
是否命中项目商业转化节点：
节点集数与依据：
节点承接债务：
节点阶段性兑现 / 重大选择 / 未完成后果：
本集对商业转化节点的贡献：
下一集必须补的商业转化节点债务：
本集场景数量：
本集目标字数：
本集人物出场数量：
本集必须保留的原著信息：
本集必须保留的关系性对话回合：
本集必须闭环的问答前提与回应：
人物口语声口锚点：
本集禁止合并的问答 / 追问 / 改口：
本集必须视觉化的心理 / 设定：
本集信息差：
本集关系变化：
本集场景价值变化：
本集主题或人物弧线作用：
本集不能提前释放的信息：
本集不能写的内容：
```

正式剧本要求：

- 尾钩重构允许把后一集爆点前置到本集尾部，或用一句短台词直接点明即将到来的爽点、特权、危险、羞辱升级或关系撕裂，再戛然而止。普通停顿、普通疑问和“被晾着”不能直接算钩子。

- 开头 10 秒进入有效情绪状态。
- 一集围绕一个主戏剧推进方向，允许多个连续事件和多个有因果关系的情绪节拍。
- 少解释，多发生。
- 规则在事件中验证，不写说明书。
- 台词按人物当下意图分回合；短的是单句，不是关系链。
- 原著问答、追问、改口和停顿若在表现依赖、照顾、试探、控制或边界，必须保留为关系性对话颗粒。
- 每个回应必须能在前一句、同一回合或已建立上下文中找到明确语义前提。压缩时若删掉提问中的具体命题，不得保留只对该命题成立的回答；必须恢复前提、补自然桥句，或改写回答以直接回应现有问题。
- 每句默认只承载一个主要意图；没有汇报、命令或紧急处理动机时，禁止把多个不同事项并成清单式台词。
- 写后朗读台词；听起来像助理提醒、剧情摘要、客服播报或作者代为交代时，必须拆回自然互动。
- 场景少，但视觉状态要变。
- 单场核心人物建议 2-4 人，无名配角必须编号。
- 重要道具必须承担叙事功能。
- 结尾必须形成下一集需求，可以来自危机、选择、关系、认知、代价、错误胜利或新阶段开启；禁止没有推进价值地收平，也禁止机械切断后靠备注命名钩子。
正式剧本落盘要求：

- 单集剧本直接落为一个独立 Markdown 文档。
- 连续多集剧本必须一集一个 Markdown 文档，不能把多集正文长期写在同一个正文文件里。
- 可以保留剧集大纲、总控卡、索引页或编译视图，但它们不得替代单集正文文档。
- 后续自检、返修、分镜提示词、视频提示词、图片资产提示词和站位线稿图均以单集正文文档为源。

正式单集剧本必须从已经通过检查的本集剧集大纲生成。写作时允许优化动作、台词和场面调度，但不得擅自删除剧集大纲中标记为不可压缩的反应、选择、后果和场间推动。

尾钩必须从完整剧情链自然形成：先让人物冲突运行到产生重大未完成变化，再选择或强化切点。不得先定尾钩，再删除人物过程去迁就时长和卡点。

### 第七步：逐集轮询自检

逐集轮询硬规则统一按 [[神思-短剧与视觉资产规则]] 和 [[短剧剧本自检]] 执行。本 skill 只保留调用要求：每集完成后必须自检、返修、复检，通过后才能进入下一集；不得先批量写完再统一粗检。

## 自检重点

自检细项统一读取 [[短剧剧本自检]]。本 skill 不重复维护完整清单，只负责确保正式交付前已经通过对应自检。

## 输出格式

正式短剧剧本使用 [[短剧剧本格式模板]]。用户提供模板时，以用户模板为最高优先级。

## 禁止项

- 禁止机械照搬原著章节顺序。
- 禁止在需要原创化重构的任务中保留原文事件顺序、标志性台词、独特名场面和独特设定机制。
- 禁止把小说心理活动直接写成旁白。
- 禁止用角色长篇解释世界观。
- 禁止删角色后不转移功能。
- 禁止删情节后不修复因果。
- 禁止连续多集没有情绪推进。
- 禁止主角长期被动受虐但没有反击期待。
- 禁止把主角高光转移给配角。
- 禁止第一集揭完主角全部底牌。
- 禁止刚受辱就完成全面打脸。
- 禁止为了快节奏牺牲情绪蓄力。
- 禁止把超过2分钟的可拍正文强塞进一集；必须拆分、重组，并保证拆分后每集都有正文内成立的结尾钩子。
- 禁止把写作卡、底部结尾钩子备注、来源链接、canon 状态和上一集 / 下一集关联信息计入单集时长或字数。
- 禁止机械切割剧情后强行把切点命名为钩子；尾钩必须通过冲突升级、强反差、奖励临门、羞辱加剧、极致反常、剧情/局势反转、答案即将揭晓、危机临爆、谎言将破、规则后果、关系站位变化或台词点明爽点完成重构。
- 禁止没有推进价值地收平；允许以重大决定、错误胜利、关系变化、代价显形或新阶段开启形成自然但有后续需求的结尾。
- 禁止让所有人物使用同一种声口。
- 禁止把原著中承担亲密、关心、依赖、试探或权力变化的多轮问答压成单人信息播报。
- 禁止删掉提问、指控、承诺或行动提议中的关键前提，却保留依赖该前提的回应，造成对白答非所问或凭空引入新命题。
- 禁止用“信息量大”掩盖台词不口语、角色可互换和关系动作消失。
- 禁止道具只做装饰。
- 禁止把现实复仇写成没有证据的情绪宣泄。
- 禁止把恐怖副本规则写成纯说明书。
- 禁止把玄幻强弱差距写成境界名堆砌。
- 禁止把追妻写成一句道歉就被原谅。
