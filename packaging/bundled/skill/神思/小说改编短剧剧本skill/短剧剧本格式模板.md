# 短剧剧本格式模板

关联：[[小说改编短剧剧本理论]] V2.6、[[小说改编短剧剧本skill]]、[[短剧剧本自检]]

## 标准格式

硬规则：

- 用户提供格式模板时，用户模板优先级最高；字段、顺序、编号和行首符号必须逐项一致。
- 本模板内的场景标题、人物行、动作行、字幕行、台词行、VO/OS 行不得混成散文段落。
- 台词压缩必须保留关系性对话回合。问答、追问、改口或停顿若在表现依赖、照顾、试探、控制或边界，不得合并成单人清单式报备。
- 正式短剧剧本正文必须一集一个 Markdown 文档；多集汇总文件只能作为索引、剧集大纲或临时编译视图，不得作为长期正文源。
- 正式短剧单集时长服从用户、平台或项目合同；未指定时默认按 1-2 分钟规划。超过目标时长时优先调整集数、事件组合和低功能重复内容，不得先删除关键反应、选择与后果。
- 单集时长和字数只统计可拍正文；写作卡、底部“本集结尾钩子”说明、来源链接、canon 状态和上一集 / 下一集关联信息不计入。
- 底部“本集结尾说明”是审查说明，不是正文；真正的下一集需求必须发生在最后一场的可拍动作、选择、台词、道具变化、关系变化、认知变化、代价或场面结果里。
- 每集结尾可以使用强冲突、强反差、奖励临门、羞辱升级、剧情 / 局势反转、危机临爆等强钩子，也可以使用重大决定、错误胜利、关系破裂、代价显形、阶段兑现或新阶段开启；不得没有推进价值地收平。
- 禁止用解释性文字钩子收尾，例如“未完待续”“真正的危机才刚刚开始”“他不知道的是”“命运的齿轮开始转动”等。
- 输出前必须按 [[短剧剧本自检]] 检查；剧情流、格式、内容衔接或结尾后续需求不合格时，直接重写对应段落。

## 剧本正文模板

```text
第X集

X-1、时段，内/外，地点
人物：人物A，人物B，人物C
△场景动作、人物状态、镜头信息。
【字幕：必要字幕】
人物A：台词。
人物B：（动作/语气）台词。
△动作推进。
人物A VO：极少量旁白。
人物A OS：内心声，仅在必要时使用。

X-2、时段，内/外，地点
人物：人物A，人物D
△场景动作。
人物D：台词。
△集尾画面钩子：具体动作、道具状态、人物反应、空间变化或场面突变。
```

## 示例骨架

```text
第一集

1-1、夜，外，山林
人物：主角，追兵，神秘人
△空无一人的山路，远处城市灯火微亮。
【字幕：三日前失踪案现场】
△主角停下脚步，听见密林深处传来急促喘息。
△一道黑影从镜头前掠过。
追兵：别让他跑了！
△主角抬眼，转身走进密林。

1-2、夜，外，废弃坟地
人物：主角，神秘人，追兵
△神秘人负伤靠在墓碑旁，掌心血迹发黑。
主角：你惹了什么人？
神秘人：你不该看见我。
△追兵破雾而出。
追兵：把人交出来。
△主角挡在神秘人身前。
主角：我要是不交呢？
△神秘人忽然消失，只留下一枚染血信物。
主角：（低头）人呢？
```

## 格式规则

- 分场编号使用 `集数-场次`，如 `1-1`、`1-2`。
- 场景标题格式：`1-1、夜，外，山林`。
- 人物行格式：`人物：纪灵，鬼王，拘魂使`。
- 动作行以 `△` 开头。
- 字幕使用 `【字幕：内容】`。
- 旁白使用 `人物VO：内容`，必须极少使用。
- 内心声使用 `人物OS：内容`，仅在无法视听化时使用。
- 台词格式：`人物名：台词`。
- 每句台词默认只承载一个主要意图；同一人物连续交代多个不同类别事项时，必须有明确的汇报、命令、紧急处理或刻意回避动机。
- 关系性信息优先通过人物来回完成。短的是单句，不是对话链。
- 台词中动作可写成：`人物名：（赔笑）台词`。
- 多个无名配角必须编号，如 `侍卫1`、`侍卫2`、`弟子1`、`弟子2`。
- 禁止漏写场景标题、人物行、动作行。
- 禁止把动作、台词、旁白混成同一段散文。

## 集尾画面钩子规则

集尾画面钩子允许重构剧情顺序：可以把后一集爆点前置到本集尾部，可以让下一集关键道具 / 规则 / 来人 / 权力承认 / 羞辱升级先露出一半，也可以用一句短台词直接点明即将到来的爽点、特权、危险或关系撕裂后戛然而止。禁止机械切割后用底部备注强行命名钩子。

有效钩子必须让观众急需看下一集来解释、兑现或拆穿前一集最后一拍。它至少要命中以下一种：冲突升级、强反差、正向奖励临门、羞辱加剧、极致反常、剧情反转、局势反转、答案即将揭晓、危机即将爆发、逃跑 / 藏匿被发现、谎言即将被拆穿、规则后果显形。

合格的集尾画面钩子必须是可拍画面：人物做出无法撤回的选择；道具状态突然变化；门、屏幕、棺盖、帘子、车门、牢门等空间边界被打开或关闭；角色看见具体物件、伤口、名字、照片、尸体、信号、账单、名单；原本安全的空间出现具体危险；关系在一句台词或一个动作中被反转；羞辱从私下比较升级为公开否认、公开贬低或公开站队。

不合格的集尾画面钩子：旁白解释风险；字幕写悬念句；作者告诉观众下一集更精彩；角色无对象地自言自语解释阴谋；只有抽象词，没有具体画面；随便一句话；普通疑问；普通停顿；角色单纯被晾着；没有代价、利益、危险、反差或后果的状态停留。

## 输出后自检

剧本输出后必须按 [[短剧剧本自检]] 依次检查：剧情流与人物行动因果、原著不可压缩颗粒、全集与阶段任务、类型契约、人物与关系、信息负荷、内容衔接、商业转化节点、AI 制作可执行性和格式一致性。

项目存在商业转化要求时，输出前还必须检查实际节点是否按全集大纲完成铺垫、阶段性兑现或重大变化；不得凭经验强制使用固定第十集卡点。
