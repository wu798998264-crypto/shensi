# 给 AI 的使用提示

当用户要求把小说改编为短剧、全集大纲、剧集大纲、第一集剧本或短剧脚本时，使用本 skill，并遵循 [[小说改编短剧剧本理论]] V2.6。

若用户提供格式模板，用户模板优先级最高。字段名、字段顺序、编号方式、行首符号和分场结构必须逐项一致；格式不一致时，不得视为完成稿。

## 必须先做

1. 读取用户提供的小说内容或大纲。
2. 提取原著骨架，并按场景拆出触发、反应、判断、行动、反制、选择、后果和下一场触发。
3. 标记不可压缩剧情颗粒，判断保留、删除、合并、前置、视觉化、钩子化的内容及损耗。
4. 正式改编先写全集大纲，再写内含逐场剧情链的详细剧集大纲；不得从原著或全集大纲直接跳写正式剧本。
5. 试写、样集或指定单集试作可以跳过全集大纲，但仍须建立本集单集总控和逐场剧情链。
6. 按 [[短剧剧本自检]] 先检查剧情流与人物行动因果，再检查结构、格式和制作执行。

如果用户明确要求“直接写剧本”，可以压缩前置分析，但内部仍必须完成上述判断。

多集任务的逐集轮询硬规则统一按 [[神思-短剧与视觉资产规则]] 和 [[短剧剧本自检]] 执行；本提示不重复展开。

商业转化节点由用户、平台或项目合同指定。未指定且项目确有转化需求时，第 10 集可以作为经验候选，但不能硬编码；铺垫节奏从实际节点反推。

## 默认输出顺序

1. 改编判断：
   - 原著核心。
   - 本集核心事件。
   - 改编取舍。
   - 集尾画面钩子。
2. 正式剧本。
3. 自检清单。

如果用户只要成稿，不要分析，则只输出正式剧本。

## 剧本格式

必须使用：

```text
第X集

X-1、夜，外，山林
人物：人物A，人物B
△动作、场景、镜头。
【字幕：内容】
人物A：台词。
人物B：（动作）台词。
△动作推进。
人物A VO：旁白。
人物A OS：内心声。
```

## 改编硬规则

- 一集围绕一个主戏剧推进方向，允许多个因果连续的小事件和多个情绪节拍。
- 开头按连续追剧、随机进入或混合模式建立观看理由，不机械套固定秒数。
- 每集结尾必须通过可拍动作、选择、关系变化、认知变化、代价、错误胜利、阶段兑现或危机形成下一集需求；强悬念钩子不是唯一形式。
- 心理活动必须外化为动作、表情、道具、场面或对白。
- 世界观必须从冲突中露出，不用角色长篇解释。
- 台词要按人物意图自然来回；短的是单句，不是关系链。简化台词不能丢失原版意思、人物态度、关系动作和信息功能。
- 原著的问答、追问、改口、打断和停顿若在表现依赖、照顾、试探、控制或边界，必须保留，禁止合并成单人清单式报备。
- 每集分别抽取本集实际存在的关系对白和冲突 / 任务对白朗读；两类都存在时各抽一段。像助理提醒、剧情摘要或客服播报时必须返修。
- 删除角色时必须保留其叙事功能，并把功能转移给其他角色、道具、对白或事件。
- 改编可以重排事件，但不能丢掉原著核心爽点、人物欲望和关键关系，也不能造成剧情断裂。
- 闪回必须有当前线触发、有叙事功能、有回接，不能突然插入。
- 多个无名配角同时出现时，必须编号区分，如 `侍卫1`、`侍卫2`、`弟子1`、`弟子2`。
- 禁止用“未完待续”“真正的危机才刚刚开始”“他不知道的是”“命运的齿轮开始转动”等解释性文字钩子收尾。

## 字数与时长

| 单集时长 | 建议字数 |
|---|---:|
| 1 分钟 | 500-800 字 |
| 1 分 30 秒 | 800-1100 字 |
| 2 分钟 | 1000-1500 字 |
| 3 分钟 | 1500-2200 字 |

## 自检

每集完成后检查：

- 是否通过 [[短剧剧本自检]]？
- 是否保留原著核心？
- 是否围绕一个主戏剧推进方向形成完整行动—反应—反制链？
- 开头是否按实际传播模式有效承接或建立观看理由？
- 主角目标是否明确？
- 反派或外部压力是否足够？
- 删减、合并、重排后剧情是否连贯？
- 台词是否简化但没有丢失原版意思、态度、关系动作和信息？
- 是否保留了塑造关系的问答、追问、改口与停顿？
- 是否存在一句塞入多个不同事项的清单式信息报备？
- 遮掉人物名后，关键台词是否仍能辨认说话者？
- 闪回是否有触发、功能和回接？
- 多个无名配角是否编号清楚？
- 情绪是否升级？
- 是否有爽点、虐点、反转或悬疑点？
- 集尾是否是可拍的画面钩子，而不是字幕钩子、旁白钩子或作者解释？
- 项目存在商业转化节点时，是否按实际节点完成前序铺垫、阶段兑现或重大变化？
- 场景和人物是否可拍？
- 台词是否口语自然、意图明确，并符合该人物与当前关系？
- 是否严格符合用户模板或本 skill 模板？

自检不通过时，必须直接重写对应段落，不得只写“已检查”或解释问题。
