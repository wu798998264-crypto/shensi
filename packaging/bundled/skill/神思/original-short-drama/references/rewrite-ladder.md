# 短剧四轮重写机制

## 目的

顶级短剧不能只靠一次“自检 -> 返修 -> 复检”。综合返修容易把结构、场景、台词和制作问题混在一起，最后得到格式正确但锋利度不足的剧本。

本机制把终稿复检拆成四个责任域：结构、场景、台词、制作。它们不是“四次必改全文”；每轮先诊断，只有存在有证据的问题且能通过 [[神思-正文质量净增益与防退化规则]] 时才修改。没有问题可以记录“无需修改”，后轮不得无故磨掉前轮保住的人物、因果、关系和声音。

## 启用时机

必须启用：

- 用户要求顶级、人类编剧水平、爆款、投流、投稿、满血终稿。
- [[original-short-drama/references/original-short-drama-audit|原创短剧专项自检]] 判定可冲顶级。
- [[original-short-drama/references/top-tier-benchmark|顶级短剧样本标尺]] 指出开场、尾钩、关系回合、反派压力或台词普通。
- 连续多集剧本完成后准备终稿验收。

可选启用：

- 样集、第一集、商业转化节点、中段转折、终局集。

不启用：

- 只做轻量脑洞、初步方向、草案样例。

## 四轮总流程

```text
第 0 步：锁定剧集大纲和本轮目标
-> 第 1 轮：结构轮
-> 第 2 轮：场景轮
-> 第 3 轮：台词轮
-> 第 4 轮：制作轮
-> 通用短剧自检与复检
```

每一轮只允许改自己负责的问题。发现其他问题时记录到下一轮，不在当前轮顺手乱改。

## 第 0 步：锁定目标

重写前必须确认：

```text
本次对象：全集大纲 / 剧集大纲 / 单集剧本 / 多集剧本
本次目标：合格 / 优秀 / 顶级
不能改动的 canon：
质量保护资产：核心选择 / 人物动机 / 关系回合 / 因果桥 / 情绪蓄力 / 理解台阶 / 人物声口 / 类型承诺 / 后续空间
可以自由改写的范围：
用户审美禁区：
商业节点：
制作硬限制：
```

没有锁定范围和质量保护资产，不进入四轮复检。

每轮统一规则：先列目标缺陷与预期读者收益，做最小有效修改，再与上一版本对照。目标未改善、保护资产下降或产生同级新问题时立即回退；禁止用评分、钩子、时长或“更短更狠”抵消退化。

## 第 1 轮：结构轮

目标：解决“这一集到底值不值得看”。

检查：

- 本集主戏剧问题是否清楚。
- 开场是否立刻进入有效处境。
- 中段是否有策略变化和局势反转。
- 尾钩是否由本集结果自然产生。
- 本集是否推进阶段任务，而不是孤立爽点。
- 商业节点是否由前序债务自然形成。
- 大信息和大爽点是否过早或过晚。
- 是否与近期剧本复用同一目标—阻力—策略—尾拍骨架。

允许改：

- 事件顺序。
- 分场组合。
- 开场切点。
- 尾钩切点。
- 本集信息释放。
- 局部爽点和压迫点的位置。

禁止改：

- 已确认人物底线。
- 已确认关系事实。
- 已确认设定规则。
- 为了尾钩删除必要反应、选择和后果。

输出：

```text
结构轮结果
主戏剧问题：
开场调整：
中段转折：
尾钩调整：
阶段推进：
仍需场景轮解决：
质量差值与采用 / 回退：
```

## 第 2 轮：场景轮

目标：解决“场面是否真的在运行”。

检查：

- 每场是否有目标、阻力、策略、反制、转折、选择、代价。
- 人物行动是否引发对手针对性回应。
- 下一场是否由上一场结果触发。
- 道具、空间、站位是否参与冲突。
- 关系变化是否由行为产生。
- 核心调查、证据、争辩、失败、关系翻面或后果是否被汇报/蒙太奇跳过。

允许改：

- 动作。
- 调度。
- 对手反制方式。
- 场景转折。
- 道具使用。
- 场间推动。

禁止改：

- 结构轮锁定的主戏剧问题和尾钩方向。
- 用解释替代行动。
- 用巧合替代反制。

输出：

```text
场景轮结果
最弱场：
新增 / 强化的策略：
新增 / 强化的反制：
新增 / 强化的代价：
场间推动：
仍需台词轮解决：
质量差值与采用 / 回退：
```

## 第 3 轮：台词轮

目标：解决“人物是否像真人在关系里说话”。

检查：

- 每句是否有当下意图。
- 是否存在清单式信息播报。
- 是否有前提缺失、答非所问或凭空回应。
- 遮掉人物名后，关键台词是否仍能辨认人物。
- 是否有潜台词、回避、试探、控制、求证或边界。
- 是否有不必要的金句、解释句、作者总结。

允许改：

- 台词长短。
- 问答回合。
- 潜台词。
- 沉默、打断、改口。
- 称呼变化。
- 角色声口。

禁止改：

- 为了金句牺牲信息清楚。
- 为了短狠删除关系动作。
- 把台词改成同一种短剧腔。

输出：

```text
台词轮结果
保留的关键句：
删除的说明句：
恢复的问答回合：
声口区分：
仍需制作轮解决：
质量差值与采用 / 回退：
```

## 第 4 轮：制作轮

目标：解决“能不能拍、能不能生成、能不能稳定执行”。

检查：

- 单场核心人物是否过多。
- 场景数量是否超出项目规格。
- 9:16 画面中人物站位、朝向、动线是否清楚。
- 关键道具、屏幕文字、字幕、系统音是否可执行。
- 动作是否能被演员、分镜或 AI 视频理解。
- 尾钩最后一拍是否可拍，而不是说明。
- 是否需要后续 [[多人物场景站位线稿图 Skill]]。

允许改：

- 场景合并。
- 人物进出场。
- 道具呈现方式。
- 动作简化。
- 屏幕文字。
- 镜头价值说明。

禁止改：

- 为了省场景删掉关键选择。
- 为了制作简单削弱本集核心冲突。
- 把不可拍心理活动留在动作行。

输出：

```text
制作轮结果
场景数：
核心人物数：
关键道具：
可拍尾钩：
AI 制作风险：
是否需要站位图：
质量差值与采用 / 回退：
```

## 最终复检

四轮完成后，必须再执行 [[短剧剧本自检]]。最终通过条件：

- 结构轮没有遗留主戏剧问题。
- 场景轮没有遗留因果断裂。
- 台词轮没有遗留前提缺失和声口同质。
- 制作轮没有遗留不可拍动作和空间混乱。
- 通用短剧自检结论为通过。
- 各轮目标缺陷有改善证据，质量保护资产零实质下降；任何失败轮已回退。
