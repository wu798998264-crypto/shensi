# 顶级短剧样本标尺

## 目的

本文件提供“顶级感”的判断标尺。它不复制任何现成影视剧文本，也不把某部作品当模板照搬；它把优秀短剧、竖屏剧、商业剧和专业编剧流程中可复用的效果原则，转化为原创短剧可执行的正反例标准。

普通自检判断是否合格；本标尺判断是否有高级、锋利、不可替代和人类总编感。

## 启用时机

- 用户要求顶级、人类编剧水平、爆款、投流、投稿、平台重点项目。
- 原创短剧专项自检为 S，准备冲顶级。
- 自检结果合格但用户反馈“普通”“AI 味”“像模板”“不够狠”“不够高级”。
- 第一集、商业转化节点、中段转折、终局集、样集或重点名场面。

## 顶级感总标准

顶级短剧不是“每秒都有刺激”，而是每个刺激都改变人物、关系、信息、权力或代价。观众不是只想知道下一秒发生什么，还要在情绪上被迫站队、期待、害怕、误判或重新理解人物。

## 八类标尺

### 1. 顶级开场

合格开场：

- 10 秒内让观众知道人物处境、当前压力和未完成问题。
- 画面、台词或动作能立住类型承诺。
- 主角不是抽象受害者，有具体目标或具体损失。

顶级开场：

- 一开始就是人物无法忽略的选择。
- 观众比主角更早看见某种不值得、危险或反常。
- 当前事件同时暴露人物欲望、弱点和压力系统。
- 一个具体物件、称呼、站位或动作就能说明关系。

反面：

- 先解释世界观。
- 先堆身份和设定。
- 先放普通争吵，但没有代价。
- 只靠性感、暴力、哭喊或奇观吸引，和主线无关。

### 2. 顶级尾钩

合格尾钩：

- 最后一拍出现强刺激。
- 下一集必须处理后果。
- 不是底部备注命名出来的钩子。

顶级尾钩：

- 不只让观众问“会怎样”，还让观众立刻重估人物、关系或规则。
- 有情绪代价、利益诱惑、身份变化或关系撕裂。
- 能承接本集冲突链，而不是借下一集爆点硬贴。
- 下一集开头不用重解释，直接处理后果就能成立。

反面：

- 普通沉默、普通疑问、普通转身。
- 角色被晾着但没有代价。
- 反转刺激但推翻前文事实。
- 为卡点删除人物反应和选择过程。

### 3. 顶级关系回合

合格关系：

- 双方有目标、有回应、有变化。
- 台词符合人物身份和情绪。

顶级关系：

- 每句都在做关系动作：试探、退让、控制、保护、撒谎、求证、逼迫、边界。
- 表面说小事，实际改变权力位置。
- 亲密不是甜话，而是对对方弱点、习惯和禁区的精准了解。
- 冲突不是吵架，而是双方策略互相拆穿。

反面：

- 一人负责交代信息，另一人负责震惊。
- 所有人都说短剧金句。
- 关系靠旁白解释变化。
- 删除追问、改口和停顿后，只剩事实结果。

### 4. 顶级羞辱链

合格羞辱：

- 有公开压力、身份贬低或关系否认。
- 主角有反应和后果。

顶级羞辱：

- 羞辱先击中主角最珍惜或最害怕被看见的部分。
- 观众先替主角判断“不值得”，主角却仍暂时做不到放手。
- 羞辱升级不是骂得更狠，而是社会位置、关系位置或证据位置发生改变。
- 反击时回收前面被羞辱的具体物件、称呼或证据。

反面：

- 上来就骂，主角无所谓。
- 羞辱只有脏话，没有关系代价。
- 刚受辱就全面打脸，情绪未蓄满。

### 5. 顶级反派压力

合格反派：

- 有目标、有优势、有加压方式。

顶级反派：

- 反派不是坏人标签，而是压力系统的执行者。
- 反派的每次动作都会改变主角选择成本。
- 反派有自己的恐惧、利益和误判。
- 反派失败会释放更深层的制度、关系或资源后果，而不是只换更大反派。

反面：

- 反派只会吼、嘲笑、派人。
- 反派行为只为送爽点。
- 压力和主角欲望无关。

### 6. 顶级道具与场景

合格道具：

- 承担证据、规则、身份、关系或伏笔功能。

顶级道具：

- 首次出现是日常物件，后续逐步变成证据、承诺、武器或关系锚点。
- 道具状态变化等于人物关系或权力关系变化。
- 观众看到道具就记得一条情绪债。

反面：

- 道具只为好看。
- 关键道具突然出现，没有前置。
- 道具功能靠解释，不靠行动验证。

### 7. 顶级台词

合格台词：

- 口语、短、能推动冲突或信息。

顶级台词：

- 有潜台词，字面意思和真实目的不完全一样。
- 能听出人物职业、阶层、关系和当下情绪。
- 台词不是金句堆砌，而是让对方必须回应。
- 关键句能回收前面某个物件、称呼、羞辱或承诺。

反面：

- 像客服、助理、剧情摘要或作者说明。
- 每个角色都说同一种短狠句。
- 一句塞多个无关事项。
- 台词漂亮但不改变局面。

### 8. 顶级阶段兑现

合格阶段：

- 阶段目标完成，出现新缺口。

顶级阶段：

- 局部胜利同时带来新责任、新关系债或新误判。
- 观众获得阶段爽点，但更想看下一阶段。
- 阶段结尾改变规则解释、资源结构、公开身份或关系边界。
- 中段转折让观众重新理解前面若干集。

反面：

- 阶段只是换地图、换反派。
- 爽点兑现后没有新代价。
- 中段靠空降设定续命。

## 顶级模式硬流程

顶级模式必须依次执行：

```text
原创短剧专项自检
-> 顶级样本标尺对照
-> 短剧四轮重写机制
-> 短剧剧本自检
-> 人类总编拍板点
```

## 人类总编拍板点

以下判断不得由框架自行假装完成，必须交给用户或总编拍板；如果用户明确授权全自动，可采用临时倾向并标注：

- 这个原创卖点是否值得做。
- 主角最终价值选择是否符合作者审美。
- 核心关系是否允许走向伤害、背叛、原谅或不可逆分离。
- 是否接受更狠的羞辱、更黑的现实、更强的性张力或更高的制作成本。
- 结局是爽感优先、余味优先、商业续作优先，还是人物完成优先。
