## 目的

在进入短剧结构之前，先制造能够持续运转、人物驱动且具有原创辨识度的故事。不要输出完整小说正文；输出供短剧规划使用的剧情母本。

## 原创输入编译

从用户材料中提取：

```text
题材与受众：
目标读者 / 观众反应：
明确卖点：
已有角色或关系：
已有世界规则：
必须保留：
禁止方向：
总集数与单集时长：
平台 / 商业节点：
用户正例与反例：
```

缺少普通细节时自行采用临时倾向；只有核心结局、人物命运、重大关系、价值禁区和项目硬规格不明时交给 [[创作引导]]。

## 三层原创竞争

### 第一层：核心概念

至少比较：

- 人物困境最锋利的概念。
- 类型期待与商业追看最清楚的概念。
- 机制或关系最意外但能长期成立的概念。

每个候选回答：谁被困在什么处境、最想得到什么、为什么现在必须行动、谁或什么阻止他、退出会失去什么、胜利会制造什么新问题。

### 第二层：人物与关系

主要人物不能只是剧情功能。为主角、核心关系人物和主要压力人物建立：

```text
表面目标：
真实欲望：
最怕失去 / 承认 / 被看穿：
错误信念：
合理误判：
底线：
惯用策略：
策略失效条件：
愿意付出的代价：
绝不愿付出的代价：
```

核心关系必须同时回答：

```text
为什么互相吸引或需要：
为什么不能真正信任：
双方分别隐瞒什么：
利益在哪里一致：
利益在哪里冲突：
哪次选择会改变关系：
关系最终靠什么选择完成：
```

### 第三层：故事发动机

使用公式检查长线可持续性：

```text
具体欲望
x 错误信念
x 核心关系
x 外部压力
x 世界规则
x 资源与代价
= 可持续剧情循环
```

一个有效剧情循环必须包含：目标、阻力、策略、反制、局部结果、代价、新缺口。循环只能升级压力与选择，不能机械重复换敌人。

## 故事层级

- 大故事：全剧核心欲望、最大矛盾、最终选择与结局证明。
- 中故事：每个阶段的局部目标、压力系统、阶段兑现和不可逆变化。
- 小故事：单集主戏剧推进与逐场行动—反应—反制链。

下层必须服务上层；单集爽点不得抽走阶段兑现，阶段反转不得破坏终局因果。

## 原创性检查

类型标签不是原创点。至少形成一个不可替换组合：

- 特殊人物关系；
- 特殊矛盾机制；
- 特殊规则代价；
- 特殊职业或社会处境；
- 特殊胜负方式；
- 特殊价值选择；
- 特殊叙述权限。

如果更换人物姓名、职业和世界皮肤后故事仍完全相同，原创辨识度不足，退回概念竞争。

## 中段压力测试

进入剧情母本前检查：

- 核心矛盾是否能支撑目标集数。
- 每次局部胜利是否改变人物责任、关系、资源、风险或信息。
- 中段是否只能靠新反派、新能力或新秘密续命。
- 主要人物是否都有独立目标，不只围绕主角提供服务。
- 核心关系是否会经过选择和代价，而不是误会拖延。
- 终局是否回收开篇欲望与错误信念。

任一关键项失败，退回人物、关系或发动机竞争，不在薄弱骨架上扩写全集大纲。

## 高价值场景原型

剧情母本至少构造：

- 开篇不可忽略的选择或处境；
- 第一次策略有效但产生代价；
- 核心关系第一次改变；
- 阶段性局部兑现；
- 中段不可逆转折；
- 主角最大错误选择或最大代价；
- 终局关键选择；
- 结局对开篇命题的回应。

这些是戏剧母场景，不写成完整小说章节，也不提前限定短剧场号。

## 通过标准

- 剧情由人物欲望、误判和选择发动。
- 关系、规则与外部压力能够互相放大。
- 局部胜利产生新后果，而不是重置循环。
- 原创点进入因果结构，不只是视觉皮肤。
- 故事具备明确结局，但仍有足够阶段变化支撑目标集数。
