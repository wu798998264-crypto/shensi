## 剧本设定域

原创短剧建立独立剧本 canon，不依赖小说正文，也不得反向污染小说正史。设定至少分为：人物、关系、世界、规则、地点、势力、物品、事件、时间线和术语。

核心设定包：

```text
世界前提：
现实 / 超现实边界：
核心规则：
规则成立条件：
规则限制：
规则代价：
规则例外：
人物设定：
人物知情权限：
人物关系：
势力与利益：
地点与空间限制：
关键物品：
时间线：
术语：
禁止擅自改变：
待确认：
```

设定必须回答它是什么、如何运行、谁会接触、怎样改变人物行动、限制与代价是什么。不能产生选择、限制、代价、信息差或关系压力的设定，不进入核心设定包。

## 设定候选与 canon

- 新项目首轮设定是草案 canon。
- 用户确认、正式大纲锁定或正式剧本明确发生后，才能成为剧本已确认 canon。
- 幕后作者真相、人物已知和观众已知必须分开。
- 新设定若改变终局、人物命运、核心关系或世界底层规则，进入待确认，不直接覆盖。
- 设定生成字段与具象度服从 [[神思-设定生成规则]]。

## 长记忆六本账

### 人物状态账

记录目标、情绪、伤势、能力、资源、身份暴露、当前误判和不可重置状态。

### 关系状态账

记录信任、亏欠、依赖、敌意、称呼、边界、公开立场、秘密共享范围和最近不可逆选择。

### 道具与资源账

记录归属、位置、状态、已知功能、隐藏功能、使用代价、证据效力和是否已兑现。

### 伏笔与承诺账

记录提出、显影、误导、局部解释、正式回收、延后原因和最迟处理节点。

### 信息释放账

记录作者真相、人物知情、观众知情、误判、信息载体、验证后果和下一次允许释放范围。

### 观众当前知识库

记录观众已经确认、正在怀疑、当前误判、期待验证和必须继续未知的内容。

六本账不必每次全部加载。记忆核按当前集人物、场景、道具、伏笔和信息权限编译最小充分胶囊。

## 剧集记忆增量

每集写后生成：

```text
本集已发生事件：
人物关键选择与后果：
人物目标及状态变化：
关系位置变化：
新增或偿还的情绪债：
人物知情变化：
观众知识变化：
道具与资源状态：
规则验证结果：
伏笔新增 / 推进 / 回收：
仍未兑现的承诺：
商业节点贡献：
下一集必须承接：
禁止重置：
新增事实及 canon 状态：
待确认或冲突：
```

下一集必须读取最新增量，不得只从初始全集大纲重新生成。

```text
本集结束后必须发生的变化：

```

## 信息台阶

重要身份、规则、秘密、关系真相和世界机制必须根据复杂度建立信息台阶：

```text
第0阶：只有异常现象，没有解释
第1阶：出现具体可见后果
第2阶：得到最低行动规则
第3阶：人物尝试或验证
第4阶：发现例外、漏洞或原有误判
第5阶：获得局部真相
第6阶：获得完整真相及其代价
```

并非所有信息都走满六阶。当前行动必需的信息及时给；长期期待依赖的信息分阶段给；每次释放都应改变人物判断、行动、关系或风险。

## 分场信息字段

详细剧集大纲的相关场次记录：

```text
本场人物已知：
本场观众已知：
本场人物误判：
本场观众误判：
本场新增信息：
信息表达载体：
信息验证画面：
人物得知后的行动：
本场继续隐藏：
```

禁止用作者解释填补信息台阶。若人物行动需要一个尚未获得的信息，必须补发现、告知、验证或合理推断过程。

## 硬冲突检查

以下问题阻止进入下一集：

- 违反已确认剧本 canon。
- 人物使用不可能知道的信息。
- 时间、地点、伤势、能力、资源或道具状态冲突。
- 关系跨越必要选择和代价突然跳级。
- 本集无视上一集不可逆后果。
- 提前释放全集大纲要求继续隐藏的真相。
- 关键承诺、伏笔或规则代价被遗忘。

发现硬冲突时，只向创作核发送最小返修约束：冲突位置、必须保留、必须修正、允许自由改写范围和修正后需更新的账本。
