## 前置条件

只有剧情母本、核心设定与长线信息结构通过后，才建立正式全集大纲。不要用大纲填表掩盖故事发动机薄弱。

## 全集大纲

全集大纲是整季唯一全局事实源，维护：

```text
项目定位与参数：
一句话故事与核心矛盾：
主线因果：
结局方向与终局选择：
阶段单元：目标 / 压力 / 局部兑现 / 不可逆变化 / 转段原因
主角长线弧线：
核心关系长线弧线：
压力升级链：
设定与规则显影顺序：
信息释放总顺序：
伏笔与道具兑现：
商业转化节点：
每集一行集级路标：
```

全集大纲不展开逐场内容。总集数、时长、商业节点和阶段位置服从用户、平台或项目合同；未指定时才使用经验默认值。

## 阶段单元

不要机械套固定 30 集结构。每个阶段必须明确：

- 阶段起点和终点；
- 主角阶段目标；
- 主要压力及升级方式；
- 核心关系任务；
- 设定与信息台阶；
- 局部兑现；
- 阶段结束的不可逆变化；
- 下一阶段必须处理的新缺口。

阶段不能只靠出现更大反派升级。优先改变责任、关系、资源、信息、规则解释、社会位置或人物选择成本。

## 详细剧集大纲

剧集大纲逐集引用全集路标，并包含单集总控与分场规划。

```text
第X集

【单集总控】
引用全集路标：
所属阶段与阶段任务：
本集主戏剧推进方向：
本集主戏剧问题：
主角目标：
主要压力：
情绪起点 -> 情绪终点：
人物弧线作用：推进 / 强化 / 阻碍 / 验证 / 反复 / 制造改变条件
关系变化及行为依据：
设定与规则使用：
本集信息台阶：
本集继续隐藏：
本集结尾形成的下一集需求：
下一集必须承接：

【分场规划】
第X-1场：
场景与人物：
入场状态：
本场目标：
触发事件：
人物即时反应：
人物判断：
行动或策略：
对手回应或反制：
场景转折：
关键选择：
结果与代价：
关系 / 信息 / 情绪变化：
需要闭环的问答前提与回应：
场尾如何推动下一场：
```

一集围绕一个主戏剧推进方向，允许多个因果连续的小事件和多个情绪节拍。禁止多个互不相干的主任务争夺篇幅。

## 剧集大纲锁定

进入剧本前检查：

- 本集服从全集路标与阶段任务。
- 每场由上一拍或上一场具体触发。
- 人物根据自己实际拥有的信息行动。
- 行动引发针对性回应或反制。
- 转折来自前置因果，不靠临时巧合。
- 关键选择产生真实结果和代价。
- 信息释放改变判断、行动、关系或风险。
- 每个回应都能在前一句、同一回合或已建立上下文中找到明确前提，没有回答观众尚未听见的问题。
- 结尾后续需求来自本集结果，不机械借用下一集爆点。

锁定后的剧集大纲是正式剧本唯一规划源；正式剧本可以优化动作、对白与调度，但不得擅自改变关键选择、因果、信息权限和结果。

## 正式剧本

格式服从 [[短剧剧本格式模板]]。Agent 使用短剧创作 Skill 时重点执行：

- 把人物欲望、恐惧、误判和掩饰写成行动、停顿、对白与选择。
- 让双方根据上一拍行动调整策略，不写轮流放狠话。
- 保持问答的前提—回应闭环；压缩台词时若删掉具体命题，必须同步改写依赖该命题的回应或补回自然前提。
- 保留必要的理解台阶，不用长篇解释。
- 让设定通过验证、限制和代价进入场景。
- 让关系变化来自承担代价、共享秘密、建立边界、公开站队或利益选择，而不只靠站位和称呼。
- 让结尾形成可拍的后续需求；危机、选择、关系、认知、代价、错误胜利、阶段兑现或新阶段开启均可。

## 时长控制

时长是项目参数。未指定时默认按 1-2 分钟规划，但必须结合台词朗读、动作、停顿、群像、转场与特效节奏估算。

超时时优先处理：重复信息、重复冲突、低功能人物、无变化寒暄、重复环境、已被画面证明的解释。禁止优先删除人物反应、判断、关键选择、关系过渡、首次规则验证和行动后果。

## 逐集循环

```text
读取锁定剧集大纲与最新动态胶囊
-> 候选竞争和正式剧本
-> 剧情流与人物效果复核
-> [[短剧剧本自检]]
-> 定向返修与复检
-> 剧集记忆增量
-> 编译下一集胶囊
```

多集任务不得先批量写完再统一检查。局部自检必须同时检查是否损害阶段和全剧结构。

## 试写模式

试写、样集和指定单集试作允许：

```text
最小剧情母本
-> 相关人物 / 关系 / 设定
-> 本集总控与逐场剧情链
-> 正式样集
-> 自检
```

试写不伪装成完整项目 canon，也不根据一个样集反推全部全集事实。

## 完成标准

- 故事不是类型标签换皮。
- 人物行动由欲望、误判、关系和代价驱动。
- 设定参与选择与后果。
- 全集、阶段、单集和分场因果一致。
- 信息台阶与人物 / 观众知情权限正确。
- 对白没有前提缺失、答非所问或回应凭空引入新命题。
- 每集吸收上一集实际结果，不重置状态。
- 剧本通过 [[短剧剧本自检]]，格式通过 [[短剧剧本格式模板]]。
