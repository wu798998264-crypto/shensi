# 原创短剧专项自检

## 目的

本文件只检查从零原创短剧、原创漫剧前置剧本和 AI 仿真人原创剧本。它不替代 [[短剧剧本自检]]，而是在通用短剧合格线之前，先判断这个原创项目是否有足够强的故事发动机、人物不可替代性、题材辨识度和冲顶级潜力。涉及样集、单集或其他实际剧情 / 动作 / 台词时，必须并行执行 [[神思-正文质量净增益与防退化规则]]、[[神思-正文高频表达限制与语境裁决规则]] 与 [[神思-开场钩子与时间叙述控制规则]]。

通用短剧自检解决“剧本是否合格”；本文件解决“原创项目是否值得被写成剧本，以及是否有可能写得高级”。

## 启用时机

必须启用：

- 无原著素材的原创短剧、原创漫剧剧本、原创 AI 仿真人剧本。
- 用户要求原创全集大纲、原创剧集大纲、原创连续多集。
- 用户要求顶级、人类编剧水平、爆款、投流、投稿、平台交付或满血终稿。
- 自检发现结构合格但剧情普通、人物普通、题材撞车、钩子普通、台词普通。

可选启用：

- 用户只要求一个轻量脑洞、卖点方向或样集试写时，可用最小版检查。

不启用：

- 明确存在小说、章节、大纲或原著素材的改编任务。此时走 [[小说改编短剧剧本skill]] 和 [[短剧剧本自检]]。

## 原创项目四级结论

| 等级 | 判定 | 处理 |
|---|---|---|
| S | 有鲜明原创发动机、强人物选择、强关系冲突和明确阶段续航。 | 可进入顶级模式，启用 [[original-short-drama/references/top-tier-benchmark|顶级短剧样本标尺]] 和 [[original-short-drama/references/rewrite-ladder|短剧四轮重写机制]]。 |
| A | 商业方向成立，人物和冲突可写，但原创辨识度或中段续航仍需加强。 | 可进入正式大纲，但必须先补强薄弱项。 |
| B | 类型标签成立，但核心人物、关系或设定可以被轻易替换。 | 不得直接写正式剧本，退回故事发动机。 |
| C | 只有题材、反转、身份或设定噱头，没有持续剧情循环。 | 停止扩写，重做原创候选竞争。 |

## 核心自检表

| 维度 | 必查问题 | 不合格表现 | 修法 |
|---|---|---|---|
| 原创辨识度 | 更换姓名、职业、时代或设定皮肤后，这个故事是否仍然成立？ | 换皮后和常见短剧没有区别。 | 找一个不可替换组合：特殊关系、特殊胜负方式、特殊代价或特殊价值选择。 |
| 故事发动机 | 主角欲望、错误信念、核心关系、外部压力、规则代价能否持续循环？ | 只能靠新反派、新身份、新系统奖励续命。 | 让每次局部胜利制造新责任、新代价或新关系债。 |
| 人物不可替代 | 主角是否只有他才能做出这个选择？ | 主角换成任何爽文主角都能跑。 | 强化恐惧、底线、惯用策略和策略失效条件。 |
| 关系双驱动 | 核心关系是否同时有吸引 / 需要与伤害 / 冲突？ | 只有甜、只有虐、只有误会或只有功能搭档。 | 写出互相需要的利益和无法信任的原因。 |
| 压力系统 | 压力是否来自人物、关系、制度、资源、时间、规则或价值冲突的组合？ | 反派只是坏，压迫只靠骂人。 | 给压力方目标、优势、代价和升级方式。 |
| 中段续航 | 中段是否能靠责任、关系、信息、规则和资源变化升级？ | 中段只能空降更大反派或新秘密。 | 每阶段结束都改变一种不可重置状态。 |
| 结局价值选择 | 终局是否由人物关键选择证明主题？ | 结局靠外力、系统、身份揭示或反派自爆代办。 | 让主角必须付出代价并主动选择新的价值立场。 |
| 类型契约 | 该类型观众必须看到的东西是否明确？ | 只有混合标签，没有核心观看承诺。 | 写清主看点：复仇、偏爱、追妻、恐怖规则、成长、反转或关系拉扯。 |
| 题材撞车风险 | 是否只是近期常见爆款元素拼贴？ | 霸总、重生、真假千金、系统等元素没有新机制。 | 用人物困境或规则代价制造新组合，而不是只换壳。 |
| 生活质感 | 是否有非模板化细节支撑人物和场景？ | 所有人都像短剧功能人；或每集固定塞入同类“生活毛刺”。 | 在能改变判断、关系或可信度的位置恢复职业手感、地域细节、关系旧账、具体物件和不完美反应，不设配额。 |
| 表达原创度 | 开场、反应链、解释句和集尾是否与近期剧本同构？受控词是否在语境配额内？ | 只换人名 / 道具继续使用“没有立刻—真正—不是而是—更大威胁”等骨架。 | 执行开场零容忍、逐条功能裁决与跨集复用检查；模板坍缩时回退场景发动机。 |
| 开场钩子 | 是否先从本集任务和人物问题出发，只选择一个主钩、必要时最多一个真正增益的辅钩？ | 把二十四类当固定句库；堆叠灾难、死亡、身份和未来预告；钩子与本集选择无关。 | 按 [[神思-开场钩子与时间叙述控制规则]] 重选机制，以独有异常、核心问题、强情绪和未揭事实形成心理缺口。 |
| 时间叙述 | 时间开场是否区分模板报时、叙事性时间锚点和因果性时间锚点并完成删除、换时、承接测试？全文密度和连续领段是否越界？ | 把时间领句一律硬禁；用“次日—随后—片刻后—当晚”串场；用生僻计时词冒充质感；用跳时掩盖本应呈现的反制和后果。 | 删除无功能报时；与独有制度、物件、声响、自然规律或人物感知绑定且被后续动作承接的时间—场景组合可以保留；连续非因果时间词领起直接返修。 |
| 廉价反转 | 反转是否来自前置因果，而不是作者临时推翻？ | 为刺激而突然改身份、改关系、改规则。 | 在早段埋可见异常、误导和局部证据。 |
| 审美边界 | 用户不想要的气质是否被明确排除？ | 生成结果滑向土味、擦边、苦情、幼稚或说明书。 | 交给 [[创作引导]] 固化方向、边界、验收和取舍。 |

## 顶级潜力检查

原创短剧若要进入“顶级模式”，至少满足 6 项：

- 开篇不是普通事件，而是人物无法忽略的选择或处境。
- 主角的最大欲望和最大恐惧会在同一条主线中互相冲突。
- 核心关系不是奖励品，而是会改变主角选择成本的压力源。
- 反派或压力系统有自洽利益，不只是为了让主角爽。
- 每个阶段的胜利都会带来新代价、新责任或新误判。
- 中段转折会改变观众对前半段的理解。
- 终局选择回应开篇命题，而不是只完成打脸。
- 至少一个道具、地点、规则或称呼能贯穿多集并逐步变义。
- 观众能用一句话记住这个项目的独特卖点。

## 打回规则

命中以下任一项，不得进入正式全集大纲：

- 主角没有具体欲望，只是被事件推着走。
- 核心关系没有伤害、利益、秘密或选择成本。
- 中段只能靠更大反派或新设定续命。
- 结局由外力解决，不需要主角关键选择。
- 原创点只存在于设定名，不改变人物行动。
- 用户要求顶级，但项目没有不可替换的原创卖点。
- 样集或正式剧本命中开场硬禁、固定模板、条件上限，或存在未登记的跨集模板复用。
