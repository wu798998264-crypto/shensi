# 原创短剧主笔

## 定位

用小说级创作能力发明故事，用短剧规则完成媒介结构。不要先写完整小说再压缩，也不要从一个脑洞直接填短剧字段。

固定优先级：

```text
人物与故事发动机
> 长线因果、设定与关系稳定
> 信息台阶与观众期待
> 全集和单集结构
> 时长、钩子与格式
```

## 与其他入口的边界

- 有现成小说、章节、大纲或原著素材需要媒介转换：改用 [[小说改编短剧剧本skill]]。
- 从零原创短剧：使用本 skill。
- 小说级原创能力只负责概念、人物、关系、设定、剧情循环、长线因果和高价值场景原型；不主写短剧格式。
- 短剧主笔只在剧情母本通过后接管全集大纲、剧集大纲、视听转译和正式剧本；不得削弱上游人物与因果。

## 正式生产链

```text
创作意图与项目参数
-> 三类原创候选竞争
-> 核心故事发动机压力测试
-> 人物心智与关系发动机
-> 剧本剧情母本
-> 原创剧本设定域
-> 全集大纲
-> 详细剧集大纲（内含逐场剧情链）
-> 单集正式剧本
-> 剧集记忆增量
-> 下一集动态创作胶囊
```

正式项目不得跳过剧情母本、全集大纲和详细剧集大纲。试写、样集和指定单集试作可以豁免完整全集大纲，但仍必须建立最小剧情母本、本集总控、相关设定与逐场剧情链。

## 阶段闸门

### 故事闸门

剧情母本通过前，不得写全集大纲。必须确认：

- 原创卖点不是常见标签的简单相加。
- 主角欲望、恐惧、误判、错误信念和底线能够持续产生选择。
- 核心关系同时包含吸引 / 需要与伤害 / 冲突。
- 局部胜利能自然制造新代价、新责任或更深矛盾。
- 中段不依赖临时新增更大反派、新设定或巧合续命。
- 结局由人物关键选择完成，而不是外力代办。
- 已按 [original-short-drama-audit.md](references/original-short-drama-audit.md) 判断项目等级；B / C 级不得进入正式全集大纲，必须退回原创候选竞争或故事发动机。

### 设定与信息闸门

设定包通过前，不得锁定全集大纲。必须确认：

- 核心设定能够改变人物行动并产生限制或代价。
- 主要人物、关系、地点、规则、物品与时间线边界清楚。
- 重要秘密和规则已经建立信息台阶。
- 幕后作者真相、人物知情和观众知情相互分离。

### 大纲闸门

正式剧本生成前，必须确认：

- 全集大纲只维护全局事实与集级路标。
- 剧集大纲引用全集路标，并维护逐场剧情链。
- 每场存在必要的触发、反应、判断、行动、反制、转折、选择、结果和场间推动。
- 每组问答保持前提与回应语义闭环；回应中的具体命题必须已被前文提出，不得让人物回答一个观众尚未听见的问题。
- 时长、场景数、商业节点和开场速度服从项目参数，不覆盖人物因果。
- 若用户要求顶级、人类编剧水平、爆款、投流、投稿或满血终稿，已按 [top-tier-benchmark.md](references/top-tier-benchmark.md) 完成开场、尾钩、关系回合、反派压力、台词和阶段兑现标尺对照。

### 顶级模式闸门

普通原创短剧不承诺自动达到顶级人类编剧水平。顶级模式只在用户明确要求或项目被判定具备 S / A 级冲顶潜力时启用，必须执行：

```text
原创短剧专项自检
-> 顶级样本标尺对照
-> 短剧四轮重写机制
-> 短剧剧本自检
-> 人类总编拍板点
```

顶级模式下，创作核不能用“字段完整”“自检通过”替代审美判断。以下事项必须交给用户或总编确认；用户明确授权全自动时，只能采用临时倾向并标注：

- 原创卖点是否值得继续做。
- 主角终局价值选择是否符合作者审美。
- 核心关系是否允许伤害、背叛、原谅、分离或不可逆改变。
- 是否接受更狠的羞辱、更黑的现实、更强的性张力或更高制作成本。
- 结局优先爽感、余味、续作空间还是人物完成。

顶级模式正式剧本必须按 [rewrite-ladder.md](references/rewrite-ladder.md) 至少完成结构轮、场景轮、台词轮和制作轮；未完成四轮时，只能标记为合格稿或优秀稿，不得标记为顶级终稿。

### 连续生产闸门

每集写后必须先生成剧集记忆增量，才能编译下一集胶囊。记忆核发现 canon、时间、知情权限、关系、伤势、道具或行动后果硬冲突时，阻止进入下一集并定向返修。

## 候选竞争

下列节点内部至少比较三种明显不同的方案：原创核心、主角与核心关系、故事发动机、阶段转折、中段不可逆变化、终局选择和高价值样集。

候选至少覆盖：

1. 人物最强版：最符合人物欲望、恐惧和防御机制。
2. 商业效果版：核心期待、追看与阶段兑现最强。
3. 意外成立版：最不常规，但长线因果与设定能够支撑。

淘汰靠降智、巧合、临时设定、纯标签、机械反转或更大反派续命的方案。

## 输出模式

- 用户只要正式剧本：内部仍完成剧情母本和双层大纲，只交付剧本与必要回执。
- 用户要求审核过程：依次交付剧情母本、设定包、全集大纲、剧集大纲和剧本。
- 用户只要全集大纲或剧集大纲：执行到对应阶段并完成该阶段自检。
- 用户只要试写：输出最小剧情母本、本集逐场剧情链和正式样集，明确草案状态。
- 用户要求顶级、人类编剧水平、爆款、投流、投稿或满血终稿：必须交付或内部保留“原创短剧专项自检 -> 顶级样本标尺 -> 四轮重写 -> 短剧自检”的链路结果；最终回执说明是否仍需人类总编拍板。

## 禁止项

- 禁止从题材标签直接生成全集事件表。
- 禁止先写完整小说再机械压缩成剧本。
- 禁止让短剧钩子反向支配人物欲望和长线因果。
- 禁止用反派升级、隐藏身份、系统奖励或突发秘密代替故事发动机。
- 禁止设定只做装饰或靠旁白说明。
- 禁止每集从初始全集大纲独立生成而不读取最新记忆增量。
- 禁止把人物不知道的信息写进行动依据。
- 禁止提问只谈“不喜欢”，回应却凭空回答“不分手”等前文未提出的命题；必须补足前提或改为直接回应现有问题。
- 禁止用格式正确、自检字段齐全掩盖剧情普通或因果断裂。
- 禁止把“中等编剧 + 神思框架”自动宣称为顶级人类编剧水平；只有启用顶级模式并经过人类总编拍板点，才可称为冲顶级流程。
