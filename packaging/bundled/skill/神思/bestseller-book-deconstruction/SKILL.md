# 爆款拆书

把读者的“好看”体验还原成可验证、可迁移的创作工程。重点回答“为什么这样安排有效”，而不是复述剧情。

## 与 `01-oh-story-claudecode` 互补

本 Skill 是爆款拆书主控，`01-oh-story-claudecode` 中的 `story-long-analyze` / `story-short-analyze` 是专项拆解器，两者必须互相补充，不得判定为重复能力或历史资料替代关系。

- 本 Skill 负责来源覆盖审计、逐单元证据账本、事实/判断/机制分层、跨媒介适配与改编依据。
- 长篇或超过 20000 字的来源，追加读取 [[skill/神思/小说写作技能skill/01-oh-story-claudecode/原始资料/story-long-analyze/SKILL|story-long-analyze]]，补充黄金三章、逐章摘要、剧情聚合、读者需求、情绪引擎、节奏、角色关系、设定和文风画像。
- 短篇或低于 15000 字的来源，追加读取 [[skill/神思/小说写作技能skill/01-oh-story-claudecode/原始资料/story-short-analyze/SKILL|story-short-analyze]]，补充故事核、功能分段、情感曲线、爆点、反转铺垫、写作手法、共鸣层次与结构计数。
- 15000—20000 字按用户明确的长短篇定位优先；没有明确定位时根据章节结构、单元密度和作品完成形态自动选择，不为机械字数边界单独阻断任务。
- 最终只交付一份合并后的爆款拆书报告，不分别输出两套重复报告。两套分析发生冲突时，以实际原文证据、本 Skill 的覆盖边界和可追溯结论为准。
- `01-oh-story-claudecode` 的 slash command、外部 Agent、浏览器、安装更新、项目初始化和固定目录写入属于原宿主操作说明；神思软件版只调用其文学分析方法，读取、分块、恢复和落盘仍由可信内核负责。

## 执行边界

1. 只分析用户本轮粘贴、@引用或附件中实际可读的内容，不补写未读章节。
2. 先确认覆盖范围。完整处理全部来源才可标注“全书拆解”；来源不完整、抽取失败或只处理片段时必须标注“样本拆解”。
3. 长文本按章节或自然段分块，逐块建立证据账本，再进行全书综合；不得只读开头后推断全书。
4. 报告属于研究资料，不是作品正史。可落盘至笔记或作品资料库，作为原创研究、改编取舍与对标依据，但不能替代原作事实核验。
5. 分析以概括和定位证据为主，不大段复刻原文，不模仿受版权保护作者的独特文风。
6. 小说、短剧、短视频使用不同时间单位：小说按章/剧情单元，短剧按集/场，短视频按秒点/节拍。短视频理论不得冒充短剧理论。
7. 材料已提供时直接拆解，不启动创作引导。材料缺失时只请求粘贴正文、@文档或添加可读取附件。

## 工作流

### 1. 建立来源与覆盖清单

记录作品名、来源文件、可读字符数、检测到的章节或段落范围、分块数量、缺失或异常。多附件分别列明，禁止用“已完整读取”掩盖截断。

### 2. 分块建立拆解账本

逐章或逐单元分析：发生了什么、谁要什么、谁在阻碍、局面如何变化、该单元承担什么结构功能、制造何种情绪、兑现什么、留下什么问题、释放或隐藏什么信息、人物关系如何变化，以及删除后会损失什么。

详细维度与类型适配读取 [拆解框架](references/deconstruction-framework.md)。

### 3. 跨块综合

综合全局结构、人物发动机、冲突升级链、情绪与爽点曲线、信息台阶、期待链、世界与资源循环、语言表达和商业追读机制。区分：

- 原作事实：文本中实际发生的内容；
- 分析判断：对结构功能和效果的解释；
- 可迁移机制：可换题材复用的原理；
- 表面元素：身份、道具、桥段外壳，不可直接照搬。

### 4. 生成改编依据

标记必须保留的因果粒子、可压缩或合并的部分、最适合视觉化的场面、需要重排的信息、改编后容易失效的机制及验证条件。改编建议必须能够追溯到拆解账本。

### 5. 输出与落盘

严格使用 [输出模板](references/output-template.md)。报告开头给出覆盖结论，结尾给出可迁移机制库和改编使用说明。若软件支持落盘：

- 笔记模式：写入当前笔记或新建“《作品名》爆款拆书报告”；
- 作品模式：写入资料库/参考资料，不回写正史设定、状态、记忆或正文。

## 质量门槛

交付前确认：

- 不是剧情摘要，而是包含功能、机制和因果解释；
- 所有重要全局结论都有章节/集/场/段落定位；
- 情绪兑现与追读钩子被分开分析；
- 能说明高潮为何成立，也能指出水段、重复和失效处；
- “爆款”是待解释的市场结果，不被当成无条件正确；
- 没有把单本作品的偶然做法伪装成普遍公式；
- 覆盖不完整时明确写成样本结论。
