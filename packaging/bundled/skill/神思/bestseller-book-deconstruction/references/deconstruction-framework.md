# 爆款拆书分析框架

## 一、最小分析单元

每个章节、集、场或短视频节拍至少记录：

1. 内容定位：范围、视角人物、时间与地点。
2. 事件链：起因 → 行动 → 阻力 → 结果 → 新局面。
3. 欲望与对抗：行动者想得到什么，阻碍者如何反制，失败代价是什么。
4. 单元功能：建人设、立目标、加压、误导、揭密、兑现、转场、蓄势或收束。
5. 情绪轨迹：进入情绪 → 压力变化 → 释放/延迟 → 离开情绪。
6. 兑现类型：打脸、升级、智谋、关系、真相、恐惧、喜剧、治愈等；同时记录铺垫成本。
7. 信息台阶：角色知道什么、读者知道什么、何时改变理解。
8. 期待链：本单元解决的问题、保留的问题、新增的问题与章尾/集尾钩子。
9. 变化：人物、关系、资源、风险、目标、规则或空间位置的状态变化。
10. 删除测试：删除后损失的因果、情绪、信息或节奏；若几乎无损则标记疑似水段。

## 二、全局分析层

### 定位与读者承诺

- 一句话故事发动机；
- 目标读者获得的核心情绪与幻想；
- 开篇承诺、首个不可逆事件、首次有效兑现；
- 作品持续生产故事的机制，而非只概括主线。

### 整体结构

- 阶段目标、阶段阻碍、阶段转折和阶段高潮；
- 主线、关系线、成长线、谜题线之间的咬合；
- 压力如何逐级升级，世界如何扩张；
- 中段是否换挡，高潮是否由前文因果积累而来。

### 人物发动机

- 身份反差、核心欲望、深层原因、弱点、底线和失败代价；
- 主角主动选择与被动遭遇的比例；
- 配角的独立欲望与结构功能；
- 反派施压能力、价值冲突和升级方式；
- 人物弧与关系弧的关键状态转换。

### 故事五力

- 信息力：读者最想知道什么；
- 冲突力：谁阻碍谁，手段如何升级；
- 情绪力：压抑、期待和释放怎样循环；
- 期待力：为什么继续读/看；
- 变化力：每个有效单元改变了什么。

### 商业节奏

- 付费点、追读点、章尾/集尾钩子类型及密度；
- 小兑现、中兑现、大兑现的间隔；
- 延迟满足是否有新增信息或代价支撑；
- 重复机制如何换条件、换代价、换关系，避免机械复制。

### 世界与成长循环

仅在作品适用时分析规则、等级、资源、能力边界和地域扩张，重点识别“获取资源 → 能力变化 → 进入更高压力区域 → 新资源需求”的循环及其漏洞。

### 表达层

- 视角、人称、句长、段长、对话/叙述/描写比例；
- 信息密度、动作密度、场景切换频率；
- 关键情绪如何通过动作、细节、对白和留白呈现；
- 可迁移的是表达策略，不是作者标志性措辞。

## 三、类型单位适配

### 小说/网文

以章、场景和剧情弧为单位，重点看章功能、追读钩子、信息台阶、阶段兑现和长线升级。

### 短剧/漫剧

以集和场为单位，重点看每集目标、场间因果、人物行动、视觉可拍性、集尾钩子及制作约束。不能用“每15秒一变”的短视频规则替代完整短剧结构。

### 剧情短视频

以秒点和节拍为单位，重点看首帧/前三秒、信息压缩、单一核心冲突、情绪反馈、反转和结尾期待。

## 四、从拆解到改编

把结果分成四类：

- 必保：删除会破坏核心因果、人物动机、情绪积累或关键兑现；
- 可压缩：功能重复，可合并人物、场景或事件；
- 可重排：原媒介依赖内心或叙述，改编时需前置冲突、视觉化信息；
- 高风险：依赖巧合、误会拖延、设定漏洞、重复打脸或只在文字中成立。

任何改编取舍都标注来源范围与保留功能，避免只保留事件外壳却删掉情绪和因果发动机。
