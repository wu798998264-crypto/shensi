# 短剧剧情功能对位改编 Skill

## 0. Skill 定位

本 Skill 是 `short-drama-script-reconstructor` 的下游 Skill。

推荐工作流：

短剧视频 / 短剧链接
→ 逆推重构剧本
→ 剧情结构抽象
→ 对位改编
→ 原创化检查
→ 短剧格式检查
→ 爽点 / 钩子检查
→ 最终改编稿

本 Skill 的目标不是“逐句换词”，也不是机械“洗稿”。

目标是：

> 保留原故事的高层戏剧功能和可复用结构，同时重新设计人物身份、冲突事件、世界规则、
> 文化制度、场景、道具、具体动作、台词表达和视听呈现，使新稿具有明确的结构对位关系，
> 但成为能够独立成立的新版本。

---

# 1. 输入

支持以下输入：

1. 上游逆推 Skill 输出的完整剧本；
2. 用户提供的原创剧本；
3. 用户拥有改编权的剧本；
4. 公版故事 / 历史故事 / 民间故事；
5. 用户提供的剧情梗概、人物关系、分集大纲；
6. 用户仅提供“改编方向 + 原结构”。

如果输入来自受版权保护且权利状态不明的现代作品：

- 不做逐句同义改写；
- 不复制独特台词；
- 不机械保留高度独特的连续场面设计；
- 优先抽象为“人物功能、冲突功能、信息功能、节奏功能”后再重新创作；
- 新版必须在具体表达层产生明显差异。

---

# 2. 默认输出格式

除非用户指定其他格式，最终正文必须严格使用：

```text
第X集

X-1、时段，内/外，地点
人物：人物A，人物B，人物C
△场景动作、人物状态、镜头信息。
【字幕：必要字幕】
人物A：台词。
人物B：（动作/语气）台词。
△动作推进。
人物A VO：极少量旁白。
人物A OS：内心声，仅在必要时使用。

X-2、时段，内/外，地点
人物：人物A，人物D
△场景动作。
人物D：台词。
△集尾画面钩子：必须变成真实可拍画面，不写“钩子说明”。
```

## 强制格式规则

- 分场编号：`集数-场次`，如 `1-1`、`1-2`。
- 场景标题：`1-1、夜，外，山林`。
- 人物行：`人物：纪灵，鬼王，拘魂使`。
- 动作行：必须以 `△` 开头。
- 字幕：`【字幕：内容】`。
- 台词：`人物名：台词。`
- 动作/语气插入台词：`人物名：（冷笑）台词。`
- VO：`人物VO：内容。`，极少使用。
- OS：`人物OS：内容。`，仅无法直接视听化时使用。
- 无名配角必须编号：`侍卫1`、`侍卫2`、`法师1`、`法师2`。
- 禁止把动作、台词、旁白混成散文段落。
- 禁止漏场景标题。
- 禁止漏人物行。
- 禁止出现“此处为冲突”“这里是钩子”等作者说明进入正文。

# 3. 核心思想：先抽骨架，再重做皮肉

不得直接：

原句
→ 同义词替换
→ 新句

必须：

原剧具体表达
→ 抽象戏剧功能
→ 新世界对应关系
→ 新事件设计
→ 新场景设计
→ 新动作
→ 新台词
→ 新画面钩子

---

# 4. 四层剧情模型

## A 层：核心故事 DNA —— 优先保留

这些元素可以作为“框架不变”的主体：

- 主角核心欲望
- 主角核心缺口
- 主角当前目标
- 主角长期目标
- 主要人物关系功能
- 谁拥有权力
- 谁依赖谁
- 谁隐瞒谁
- 谁误解谁
- 谁想得到谁的承认
- 谁掌握关键秘密
- 谁控制关键资源
- 冲突升级顺序
- 信息揭示顺序
- 打脸 / 反转的功能位置
- 阶段性奖励位置
- 情绪高低曲线
- 每集核心问题
- 每集结尾悬念类型
- 大转折出现的集数
- 核心人物阵营变化

例如：

原结构：

“落魄女主被豪门未婚夫家羞辱 → 隐藏身份揭晓 → 家族长辈公开站队 → 未婚夫后悔”

抽象后：

“低地位表象主角进入高权力群体 → 被关系对象阵营贬低 → 主角真实价值被权威人物确认 →
群体权力重新排序 → 原压制者发生地位反转”

这个抽象结构可以迁移到任何世界。

---

## B 层：中层冲突机制 —— 保留功能，必须重构事件

包括：

- 公开羞辱
- 资格否认
- 身份质疑
- 资源争夺
- 婚约冲突
- 师承冲突
- 继承权冲突
- 任命权冲突
- 荣誉冲突
- 阶级冲突
- 血统冲突
- 能力测试
- 规则挑战
- 误判
- 冒名顶替
- 信物确认
- 合同 / 契约确认
- 证据翻盘
- 权威人物背书
- 群体站队
- 公开惩罚
- 逃亡追杀
- 秘密泄露
- 关系反转

要求：

**功能可以同位，事件不得机械同位。**

例如：

原版：
宴会上，婆婆拿银行卡让女主离开儿子。

新版不要只是：
宫宴上，皇后拿银票让女主离开皇子。

应重构为：
教廷授勋仪式上，大主教宣布撤销女主进入圣骑士团的保荐资格，并要求她交还象征婚约与身份的
家族圣徽。

二者功能相同：

“权力长辈公开否定女主与核心男性的关系 + 剥夺她进入权力体系的资格”

但事件、制度、道具、空间、社会后果全部变化。

---

## C 层：世界表达系统 —— 原则上重做

包括：

- 时代
- 国家 / 地区
- 政治制度
- 社会阶层
- 宗教系统
- 家族制度
- 职业体系
- 教育体系
- 财产体系
- 婚姻制度
- 法律规则
- 超自然规则
- 战斗规则
- 能量体系
- 社交礼仪
- 称谓
- 建筑
- 交通
- 通讯
- 货币
- 服装
- 武器
- 医疗
- 鉴定方式
- 身份证明
- 权力凭证

跨文化改编时，这一层必须系统化变化，禁止只改名词。

---

## D 层：具体表达 —— 必须明显变化

必须重新创作：

- 场景空间
- 进出场方式
- 动作
- 台词
- 道具
- 视觉符号
- 冲突触发事件
- 解决事件
- 爽点兑现方式
- 群体反应
- 镜头信息
- 集尾画面
- 笑点
- 羞辱细节
- 战斗细节
- 身份揭示方式
- 情感表达方式

# 5. 对位关系图

每次正式改编前，内部先建立：

| 原剧功能 | 原剧表达 | 新剧功能 | 新剧表达 |
|---|---|---|---|
| 主角被资格否认 | 董事会拒绝入职 | 主角被资格否认 | 魔法议会取消试炼资格 |
| 权威站队 | 集团董事长到场 | 权威站队 | 王国首席大法师现身 |
| 身份证明 | 黑卡 | 身份证明 | 王室封印戒 |
| 竞争者冒领功劳 | 同事抢项目 | 竞争者冒领功劳 | 骑士冒领屠龙战功 |
| 公开打脸 | 大屏展示合同 | 公开打脸 | 圣殿水晶显现契约 |
| 情感决裂 | 取消婚礼 | 情感决裂 | 当众解除誓约 |

对位表不得直接作为最终正文，除非用户要求。

# 6. 改编强度

## L1：表层变体

适用于用户自有原创 IP 的快速 A/B 版本。

改变：

- 人名
- 性别
- 职业
- 地点
- 少量事件

不推荐用于需要明显原创差异的任务。

## L2：事件重构

保留关系和冲突链，但：

- 每个主要冲突事件重做
- 道具重做
- 公开羞辱方式重做
- 身份揭晓方式重做
- 集尾钩子重做

## L3：世界迁移 —— 默认推荐

保留：

- 人物功能
- 关系骨架
- 冲突节奏
- 转折节点

重做：

- 世界观
- 社会制度
- 职业
- 身份
- 事件
- 场景
- 道具
- 台词
- 爽点兑现
- 视觉体系

## L4：类型迁移

进一步改变故事类型：

- 都市爱情 → 权谋
- 权谋 → 魔幻冒险
- 修仙 → 科幻
- 家庭伦理 → 宫廷政治
- 校园 → 军事学院
- 豪门 → 黑暗奇幻贵族
- 复仇 → 生存竞技

只保留更抽象的 Story DNA。

默认使用 **L3**。

# 7. 可迁移场景库：全面对位类型

以下不是固定模板，而是“可以迁移的方向库”。

---

## 7.1 主角性别互换

### 男主 → 女主

可同步改变：

- 社会期待
- 权力获取路径
- 情感压力来源
- 家庭义务
- 公众偏见
- 职业阻力
- 婚姻筹码

禁止只把“他”改成“她”。

例如：

原：
落魄男婿在岳家受辱。

新：
失势女将领作为政治联姻对象进入公爵家，被认为只是没有军权的“装饰性夫人”。

功能不变：
关系对象家族轻视主角。

冲突事件改变：
不是饭桌嘲讽工资，而是家族议会取消她的封臣席位。

### 女主 → 男主

例如：

原：
女主被豪门男友母亲羞辱。

新：
平民男学者被女王储的宫廷顾问团质疑出身，不允许进入王室档案院。

---

## 7.2 男女主双方性别互换

关系骨架：

强势男 × 弱势女
→
强势女 × 弱势男

还需同步调整：

- 求婚权力
- 家族继承
- 舆论压力
- 谁承担保护者角色
- 谁拥有经济资源
- 谁拥有公开身份
- 谁承担名誉损失

---

## 7.3 性别不变，权力位置互换

原：

总裁男主 + 普通女主

可改：

普通男主 + 掌权女主

核心仍是：

“高权力角色与低权力角色的隐秘关系遭受外部阻力”。

# 8. 中国历史朝代内部迁移

历史改编必须改变真实制度逻辑，不得只换皇帝名字。

## 8.1 唐 → 秦

需要系统改变：

唐：
- 科举逐渐成熟
- 门阀与官僚并存
- 开放都市文化
- 节度使等后期结构
- 尚书省 / 中书省 / 门下省等制度背景

秦：
- 郡县制
- 军功爵
- 法家治理
- 文书、符传、验、律令
- 中央集权和严格户籍

对位示例：

唐代“科举功名被冒领”
→
秦代“军功首级 / 军功爵记录被篡改”。

唐代“诗会声名”
→
秦代不应机械保留，应改为军功、法令执行、工造技术或廷议能力。

---

## 8.2 汉 → 宋

汉代：
- 察举
- 外戚 / 宦官 / 豪强
- 边郡军功

宋代：
- 文官系统
- 科举
- 台谏
- 枢密院
- 商贸发达

同一“寒门逆袭”：

汉：
被郡国推荐、军功立身。

宋：
科举、策论、台谏体系进入权力核心。

---

## 8.3 明 → 清

需重做：

- 官职名称
- 军事体系
- 宫廷组织
-服饰称谓
- 皇族结构
- 监察制度
- 文书制度

不能出现时代错位道具或制度。

---

# 9. 真实历史人物替换

只有在用户明确要求历史人物时使用。

原则：

- 保留“戏剧功能”，不强行让历史人物重复虚构人物行为。
- 查证人物所处年代、身份、相互是否可能见面。
- 不制造明显历史时间错误。
- 明确区分“历史改编”与“严格史实”。

对位方式：

原人物功能：
“年轻君主依赖强势权臣”

可以选择不同历史背景中具有相似权力结构的人物组合，
但具体事件必须根据对应时代重新设计。

# 59. 冲突事件重构方法

对于每个原冲突，必须回答：

1. 这个冲突的功能是什么？
2. 谁是施压者？
3. 谁是被施压者？
4. 施压者依赖什么权力？
5. 被施压者表面为什么无法反击？
6. 真正的反击资源是什么？
7. 新世界中什么制度可以承载同样功能？
8. 能否改变发生场所？
9. 能否改变触发道具？
10. 能否改变公众规模？
11. 能否改变反转证据？
12. 能否让事件产生新的后果？

# 60. 场景重构规则

同一功能场景不要机械保留原空间。

原：
饭桌羞辱

可改：
- 授勋礼
- 议会听证
- 医院晨会
- 学院试炼
- 婚约宣读
- 军功登记处
- 飞船登舰审核
- 魔法师资格测试

原：
办公室争吵

可改：
- 战情室
- 档案库
- 神殿后殿
- 马车内
- 法庭候审区
- 赛后更衣室
- 控制中心
- 地下拍卖会

---

# 61. 对话重写规则

严禁逐句同义替换。

每句台词先抽象意图：

例如原句：

“你一个送外卖的，也配进我们家？”

意图：

“施压者公开用职业等级否认对方的婚恋 / 家庭资格”。

不同世界可写成：

古代：
“你连军功簿上都没有名字，也敢谈入我赵氏宗祠？”

欧洲：
“没有封地、没有家徽，你凭什么站在我女儿身边？”

魔法：
“连施法执照都没拿到的人，也想成为大法师家族的契约伴侣？”

科幻：
“你连一级公民权限都没有，凭什么进入核心舰队家属区？”

功能对位，表达完全不同。

---

# 62. 台词意图控制

每句台词默认只承载一个主要意图。

允许：

长官：东门失守，伤员已经送进城了。

因为这是“紧急汇报”。

不推荐：

配角：东门失守了，昨天王爷还给我送了信，而且我觉得你妹妹可能也是奸细，另外军粮也没了。

除非角色是在有动机地紧急汇总多项信息。

关系信息优先通过来回对话完成。

---

# 63. 信息差重构

很多爽点来自信息差，不是事件本身。

必须记录：

- 主角知道什么
- 对手知道什么
- 观众知道什么
- 配角知道什么
- 哪条信息何时公开

改编时可以换事件，但应保留信息差功能。

例如：

原：
观众知道主角是集团继承人，对手不知道。

新：
观众知道主角持有王室密令，对手只认为他是普通书记官。

---

# 64. 打脸结构对位

标准结构：

1. 对手建立判断。
2. 对手公开下注 / 行动。
3. 主角有机会解释但没有完全解释。
4. 对手进一步加码。
5. 关键证据出现。
6. 权力关系重新排序。
7. 对手承担即时后果。

不能只有：

对手骂人 → 主角说“其实我很厉害” → 结束。

---

# 65. 爽点重构

可以保留爽点类型：

- 身份揭晓
- 能力碾压
- 权威背书
- 财富 / 资源碾压
- 规则反杀
- 证据翻盘
- 群体倒戈
- 对手自食其果
- 关系反转
- 功劳归位
- 资格恢复
- 特权开启
- 危机解除
- 奖励兑现

但兑现媒介必须匹配新世界。

---

# 66. 集尾画面钩子规则

禁止“备注式钩子”。

错误：

△本集结束，留下悬念。
△下一集身份即将揭晓。

正确：

△骑士团长掀开主角被撕碎的袖口，一枚只有王室近卫才有的金色烙印露了出来。
团长：（脸色骤变）所有人，跪下。

CUT。

---

# 67. 集尾钩子功能库

每集最后一拍至少命中一种：

- 冲突升级
- 强反差
- 正向奖励临门
- 羞辱加剧
- 极致反常
- 剧情反转
- 局势反转
- 答案即将揭晓
- 危机即将爆发
- 逃跑被发现
- 藏匿被发现
- 谎言即将拆穿
- 规则后果显形
- 权力人物突然出现
- 关键身份凭证出现
- 封闭空间突然打开
- 本应死亡的人出现
- 本应安全的人被锁定
- 关键资源失控
- 契约突然生效
- 证据突然公开
- 群体公开站队
- 关系对象当众否认
- 关系对象当众承认
- 主角做出不可撤回选择

# 68. 合格画面钩子模板

## 门 / 边界打开

△审判厅大门被人从外面推开。
△所有法师回头。
△一个本应死在十年前的人站在门外。

## 道具变化

△主角掌心的灰色魔晶突然亮成纯金。
△测试石上裂出第七道纹路。
考官：（失声）七阶？

## 名单 / 屏幕

△屏幕刷新。
△第一名的位置从“空缺”跳成主角的名字。
△全场安静。

## 权威站队

△老公爵越过自己的儿子，把象征继承人的戒指戴到主角手上。
老公爵：从今天开始，他的话，就是我的话。

## 危险显形

△女主关上卧室门。
△床底缓慢伸出一只沾血的手。

## 谎言拆穿

△投影水晶亮起。
△画面里，反派亲手调换了药瓶。
△反派脸色瞬间煞白。

# 69. 不合格钩子

禁止：

- “危险正在逼近。”
- “他不知道，更大的阴谋还在后面。”
- “一场大战即将开始。”
- “她陷入沉思。”
- “他会怎么选择？”
- “欲知后事如何……”
- 普通停顿
- 普通转身
- 普通离开
- 没有对象的自言自语
- 没有可拍变化的抽象心理

# 70. 原创化检查

改编完成后进行“表达距离检查”。

检查以下元素是否仍与输入过近：

- 相同场景地点连续出现
- 相同道具承担同样作用
- 相同人物职业组合
- 相同冲突触发方式
- 相同身份揭晓媒介
- 相同连续动作
- 相似台词节奏
- 相同笑点
- 相同反派羞辱话术
- 相同集尾画面
- 相同独特桥段组合

如果 3 项以上高度相似，必须重做该场。

---

# 71. 结构保真检查

原创化不能把故事改散。

检查：

- 原主角欲望是否仍存在
- 关系功能是否仍对应
- 谁压制谁是否清晰
- 信息差是否仍有效
- 冲突升级顺序是否仍成立
- 每次反转是否有铺垫
- 爽点是否仍在相近节奏位置
- 集尾是否仍能推动下一集
- 大转折是否保留功能

---

# 72. 世界一致性检查

跨时代 / 跨文化时检查：

- 官职
- 继承制度
- 婚姻制度
- 货币
- 交通
- 武器
- 通讯
- 法律
- 教育
- 宗教
- 服装
- 建筑
- 社交礼仪
- 身份凭证
- 信息传播方式

禁止明显时代错位。

如果用户要求真实历史背景，应先查证必要史实。
如果用户只要求架空背景，可设计自洽制度，但必须前后一致。

---

# 73. 人物对位检查

建立内部表：

原人物：
- 剧情功能
- 权力来源
- 欲望
- 弱点
- 与主角关系
- 冲突职责

新人物：
必须一一找到功能对应。

允许：

一个原人物拆成两个新人物，
或者两个原人物合并成一个新人物，

但必须说明其戏剧功能如何重新分配。

---

# 74. 角色名字

跨背景时姓名体系必须统一。

中国古代：
同一世界不要同时混用现代网名与古代姓名。

欧洲：
可以使用统一地区感的姓名体系，不必严格对应真实国家，除非用户要求史实。

科幻：
可以混合编号、姓氏、呼号，但要有规则。

魔法：
姓名风格应一致，避免每个人像来自不同作品。

---

# 75. 改编过程中的禁区

禁止：

- 仅替换人名
- 仅替换性别
- 仅替换朝代名称
- 仅把“灵气”替换成“魔力”
- 逐句改写
- 连续复制独特场景
- 保留原剧所有道具顺序
- 保留所有相同反转证据
- 直接照搬原集尾钩子
- 为了强行对位造成世界规则不成立
- 为了爽点让角色无动机降智

# 78. 分集重构策略

如果输入有 80 集，不要把 80 集逐场机械对应。

先建立：

1. 整体主线
2. 10 集左右一个剧情阶段
3. 每阶段核心目标
4. 每阶段主要反派
5. 每阶段资源变化
6. 每阶段关系变化
7. 每阶段大钩子

再逐集改编。

允许：

- 合并原场景
- 拆分原场景
- 将后一集爆点提前
- 将原本过弱的结尾重做
- 调整非关键事件顺序

但核心因果必须成立。

---

# 79. 集尾允许的顺序重构

可以：

- 把下一集第一场的关键人物进场提前到本集最后 3 秒；
- 把关键道具先露一角；
- 把判定结果显示到一半；
- 把危险人物开门动作提前；
- 把一句权力确认台词提前；
- 把反派准备实施的行动先视觉化；
- 让重要电话 / 信号 / 名单在本集尾出现。

必须保证下一集能自然承接。

---

# 80. 每集节奏检查

一集至少回答：

- 本集谁想要什么？
- 谁阻止？
- 阻止方式是什么？
- 主角做了什么？
- 情势变好还是变坏？
- 新信息是什么？
- 最后一拍为什么必须看下一集？

如果无法回答，说明这一集没有完成戏剧闭环。

---

# 81. 场景检查

每场必须至少完成一种功能：

- 推进目标
- 制造阻力
- 暴露信息
- 改变关系
- 兑现爽点
- 产生新问题
- 提高代价
- 设置后续钩子

纯重复场删除或合并。

---

# 82. 人物智商检查

反派可以傲慢，但不能为了打脸而失去基本判断力。

必须给出误判依据：

- 信息被遮蔽
- 社会偏见
- 有伪造证据
- 主角故意隐藏
- 对手过去经验形成错误预期
- 规则本身存在漏洞

这样反转才成立。

---

# 83. 历史 / 文化迁移研究规则

当用户要求：

- 具体朝代
- 具体国家
- 具体历史人物
- 具体宗教制度
- 具体法律制度

必须先核实必要事实。

查证重点：

- 人物是否同时代
- 官职是否存在
- 制度是否存在
- 地理是否合理
- 物品是否出现
- 称谓是否正确
- 技术是否存在

如果用户要求“架空秦朝风格”而非真实秦朝，可减少史实限制，但仍要内部自洽。

# 86. 用户没有指定改编方向时

不要只问“想改成什么”。

可以先根据原结构生成 5 个最适合的迁移方向，并说明每个方向：

- 世界类型
- 主角身份
- 主要冲突体系
- 核心资源
- 身份揭示方式
- 最适合的爽点

如果用户要求直接执行，可自动选择差异度最大且逻辑最自然的方向。

# 88. 最终原则

改编时始终牢记：

> 保留的是“为什么这一拍有效”，不是“这一拍原来具体发生了什么”。

如果原剧有效是因为：

“所有人都认为主角没有资格，而最高权威突然证明他才是真正规则制定者。”

那么新版可以完全不用：

- 宴会
- 豪门
- 董事长
- 黑卡
- 公司
- 婚恋

只要创造另一个同样满足：

“资格被否认 → 对手加码 → 权威确认 → 规则重排”

的全新事件链即可。

这就是剧情功能对位式改编。
