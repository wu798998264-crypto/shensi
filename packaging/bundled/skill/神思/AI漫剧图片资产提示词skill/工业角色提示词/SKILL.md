# 工业角色提示词

把人物参考图或文字设定整理为标准化工业角色设计提示词。输出必须便于检查，并能直接用于生图。

## 内容提取

1. 有参考图时，先观察人物的年龄感、性别呈现、地域外貌特征、体型、面部结构、肤色、五官、发型、服装、鞋履与可穿戴配饰；参考图原有风格不改变本技能的固定风格。
2. 只写能够观察或合理延展的特征。参考图未展示全身时，为完成全身视图，可依据已露出的服装与人物气质做最小限度的连贯补全，不增加剧情、职业身份、标志、武器或装饰性道具。
3. 有文字设定时保留用户明确指定的特征；未指定的细节采用中性、协调、易于建模的设计。
4. 眼镜、耳饰等贴身可穿戴物属于角色外观；“无道具”专指无手持物、悬浮物、展示台和场景物件。用户明确要求去除配饰时，以用户要求为准。

## 角色等级与差异化

1. 只有用户明确说明“普通路人”“路人甲”“群演”或“普通非玩家角色”时，才按普通路人处理；未说明角色等级时，一律按主要人物处理。
2. 设计主要人物前，先对照当前任务、同一项目或当前对话中已经确定的主要人物，检查服装轮廓、身材比例、脸型五官和发型轮廓，禁止复用相同组合。
3. 没有统一制服时，主要人物必须同时在四个维度形成显著区别：
   - 服装：改变整体轮廓、层次、版型、结构和材质组合，不能只更换颜色。
   - 身材：改变高矮、胖瘦、肩胯比例、肌肉量或四肢比例。
   - 长相：改变脸型、骨相、眉眼形态、鼻唇结构和年龄感，避免模板脸。
   - 发型：改变长度、体积、分区、走向和外轮廓，不能只更换发色。
4. 有统一制服时，保留统一的制服体系与核心识别元素，但仍须在制服版型、穿着层次、领口袖口、下装鞋履等细节，以及身材、长相、发型四方面制造明显差异；不得破坏用户明确规定的制服一致性。
5. 同批主要人物应仅凭黑色剪影也能区分。颜色变化、轻微配饰变化或表情变化不能作为主要差异。普通路人可简化设计并共享服装体系，但不得完全复制同一张脸和同一发型。

## 固定画面规范

- 十六比九横版，统一中性灰色无缝背景。
- 画面从左到右分为百分之三十四、二十二、二十二、二十二。
- 最左侧是人物正面面部特写；右侧依次是正面全身、标准九十度侧面全身、背面全身。
- 四个视图的身份、年龄、体型、脸型、发型、服装、材质、颜色与配饰必须一致。
- 人物表情自然平静，嘴部放松；站姿自然稳定，双臂自然下垂，无遮挡，不采用夸张动作。
- 无手持道具、无文字、无标注线、无边框、无装饰、无复杂场景；仅保留轻微落地阴影。
- 使用平视镜头与柔和均匀棚拍光，避免广角畸变、戏剧化透视、强烈明暗和环境色污染。

## 固定风格锚点

所有角色统一使用以下风格句，必须逐字复用，不得根据人物身份、参考图风格或单次角色要求自行改写：

> 三维高精度国漫风格，非仿真人质感，面部精致立体，皮肤细腻哑光，发丝分组清晰，服装材质考究，光影柔和统一。

只有用户明确要求修改本技能的固定风格时，才可更换该句。固定风格句必须同时出现在“风格定位”字段和成品提示词最后一句。

## 输出格式

只用中文自然语言，不解释过程，不给建议或备选版本。严格按以下结构输出，字段名称、顺序和数量不得改变：

```markdown
### 角色规格

- 画幅规格：十六比九横版标准工业角色设定图
- 分栏布局：百分之三十四、二十二、二十二、二十二；正面面部特写、正面全身、侧面全身、背面全身
- 身份与体型：<年龄感、性别呈现、地域外貌特征、身高感、体型和身体比例>
- 面部特征：<肤色、脸型、轮廓、眉眼、鼻、唇及其他关键辨识点>
- 发型与配饰：<发色、长度、走向、质感、贴身可穿戴配饰>
- 服装与鞋履：<外套、内搭、下装、鞋履的版型、颜色、材质与结构>
- 表情与姿态：<自然表情、手臂状态、站姿、侧面角度和背面展示要求>
- 背景与光线：<中性灰色无缝背景、平视镜头、柔和均匀棚拍光、轻微落地阴影>
- 排除内容：<手持道具、文字、标注线、边框、装饰和复杂场景等>
- 风格定位：三维高精度国漫风格，非仿真人质感，面部精致立体，皮肤细腻哑光，发丝分组清晰，服装材质考究，光影柔和统一

### 成品提示词

<一段完整提示词>
```

## 成品提示词句序

成品提示词必须是一段连续文字，按照以下顺序组织：

1. “十六比九横版标准工业角色设定图”与四栏百分比分配。
2. 从左到右的四个视图及一致性要求。
3. 人物身份、体型和身体比例。
4. 肤色、脸型、五官和关键辨识点。
5. 发型与贴身配饰。
6. 服装、下装与鞋履。
7. 表情、手臂状态与自然站姿。
8. 灰色背景、镜头、光线和落地阴影。
9. 无手持道具、无文字、无装饰、无复杂场景等排除内容。
10. 固定风格锚点。

第一句优先使用下列固定句式：

> 十六比九横版标准工业角色设定图，画面按百分之三十四、二十二、二十二、二十二分栏。最左侧为人物正面面部特写，右侧依次为正面、侧面、背面全身照，造型与比例严格统一。

最后一句必须逐字使用固定风格锚点。固定风格句之后不得再出现尺寸、构图、负面要求、解释或补充信息。

## 交付前检查

- 成品提示词是否精练且只保留生成所需信息。
- 是否明确十六比九、四栏比例、四视图顺序和统一灰色背景。
- 面部特写是否为正面，侧面是否为标准九十度，背面是否完整。
- 是否保持人物一致、自然表情、自然站姿和无手持道具。
- 主要人物是否按制服条件，在服装、身材、长相和发型上形成显著差异，而非仅改变颜色。
- 结构化规格与成品提示词是否逐项一致、没有互相矛盾。
- “风格定位”和最后一句是否逐字使用固定风格锚点。
