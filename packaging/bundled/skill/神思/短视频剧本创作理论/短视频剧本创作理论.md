# 短视频剧本创作理论

显示名称：短视频剧本类型识别与理论路由

## 定位

[[短视频剧本创作理论]] 是神思剧情类短视频理论的统一管理入口，与 [[小说类型理论研究]]、[[公众号文章创作理论]] 同级。

它负责识别剧情短视频的内容形态、观看机制、情绪主轴和制作介质，再按需加载一个主理论 Skill。本文不是短视频剧本主笔，也不等同于短剧理论。普通抖音剧情号、单条剧情视频、连续剧情号和 AI 剧情短片由独立短视频剧本主笔执行；只有最终产物明确为微短剧、竖屏短剧、分集剧情、剧集大纲或多集正式剧本时，才进入 [[skill/神思/original-short-drama/SKILL|原创短剧剧本skill]] 或 [[小说改编短剧剧本skill]]。

后续新增的治愈动画、搞笑反转、悬疑、爽文、科幻世界观及其他剧情短视频理论，统一收录在本目录中。

## 总原则

1. 先判断最终内容是单条完整剧情、连续剧情号或 AI 剧情短片，再选择节奏和闭环尺度；若最终内容是微短剧、竖屏短剧、真人短剧、漫剧剧本或分集产物，立即转交短剧链，不继续加载本文细分类理论。
2. 理论顾问负责观看问题、状态变化、情绪兑现、反转依据和制作适配；原创或改编主笔负责正式故事与剧本。
3. 人物选择与因果成立高于秒数公式。不得为满足“三秒、十五秒、每集反转、人物一句话”而删掉关键前提、关系回合、情绪蓄力和行动后果。
4. 通用理论可以与一个细分理论组合；多个细分方向同时命中时必须确定主方向，辅助方向只补充局部机制。
5. 短视频经验尺度不是平台官方规范。涉及当前平台政策、时长、投流、付费或推荐机制时，必须另行核验一手来源。
6. 未命中细分方向时，只读取通用 Skill，不得默认套用爽文、悬疑或搞笑结构。

## 与主笔和自检的关系

| 任务 | 主笔 | 本理论的作用 |
|---|---|---|
| 无原著的单条或连续剧情短视频 | 短视频剧本主笔 | 提供信息流观看、单元节奏、情绪反馈和制作压缩依据。 |

| 交付前检查 | [[短剧剧本自检]] | 理论提供诊断依据，自检负责最终质量闸门。 |

## 新理论接入标准

新增方向必须满足：

1. 使用独立 Skill 目录，至少包含 `SKILL.md` 和必要的 `references/`。
2. 在本页登记触发关键词、读取入口、适用范围和禁止套用范围。
3. 明确相对通用理论发生变化的节奏、情绪、信息和制作参数，不复制通用理论全文。
4. 说明与原创短剧、改编短剧、格式模板和自检的职责边界。
5. 把秒数、钩子密度和场景数量区分为硬约束、项目参数或经验基线。
6. 通过 Skill 基础校验和神思框架健康检查后，才允许进入活动路由。

## 调用流程

```text
剧情类短视频任务
-> 判断最终交付物是单条 / 剧情号内容还是分集短剧
-> [[短视频剧本创作理论]] 识别内容形态和主情绪方向
-> 加载通用 Skill；命中细分方向时再加载一个主细分 Skill
-> 短视频剧本主笔完成脚本；只有明确分集短剧才追加原创或改编短剧故事引擎
-> 短视频效果自检完成质量与制作检查
-> 交付或返修
```

短问答、单纯格式转换、纯图片资产和站位图任务不加载本理论。只要任务进入正式剧情设计、剧集大纲、单集剧本或剧情节奏诊断，即可启用通用 Skill。

## 未命中处理

- 未命中细分方向时，仅使用 [[skill/神思/短视频剧本创作理论/general-short-video-screenwriting/SKILL|短视频剧本通用创作概论 Skill]]。
- 不得因为出现“短视频”三个字就默认使用爽文打脸、强身份反转或每集悬念。
- 用户要求新增方向时，先建立独立 Skill，再登记到本管理页；临时建议不得伪装成正式理论。
