## 一、媒介差异与核心定义

传统长影视通常允许观众先进入人物和世界，再等待冲突展开。信息流中的剧情短视频面对的是持续滑动和即时比较：观众会反复判断“我是否看懂了”“这件事是否在变化”“继续看能得到什么”。

因此，短视频剧情的优势不是“不完整”，而是单位时间内拥有更高的有效变化密度：

```text
抓住：第一眼出现值得判断的变化
刺激：阻力直接作用于人物欲望
释放：此前积累的情绪获得可见结果
期待：结果带来新的压力、选择或理解空间
```

这四项构成循环，而不是只在整条视频中各出现一次。好的短视频既有短周期反馈，也有中周期推进；连续剧还要服务长周期人物和主线。

“剧情不是为了讲完整故事”只能理解为“不按传统铺陈顺序讲述”，不能理解为“可以不要因果、人物和兑现”。没有局部完成的内容只是一段预告，没有持续后果的反转只是一条段子。

## 二、底层剧情公式

通用公式：

```text
人物欲望
+ 可见阻碍
+ 连续升级
+ 情绪释放
+ 新的未完成压力
```

更精确的执行链：

```text
异常或冲突已经发生
-> 观众形成明确问题
-> 人物采取行动
-> 阻力改变局势
-> 人物被迫选择
-> 选择产生可见结果
-> 结果兑现一种情绪
-> 后果形成下一步需求
```

与传统顺序相比，短视频经常把结果、危机或强关系动作前置，再逐层回答“为什么会这样”。结果先行不能透支全部答案；它的作用是建立追问，不是用旁白提前讲完故事。

例如，“女孩照顾流浪狗，后来狗救了她”只是事件摘要；“她救下的狗突然咬住她父亲，不让他走进家门”则同时产生异常、人物关系、行动阻断和原因追问。后续必须用现场行动揭示危险，而不是再用旁白说“三天后它救了全家”。

## 三、开头：先让事情发生

### 1. 第一有效拍

有效开头至少完成一项：

- 异常事件已经发生。
- 人物之间正在进行不可忽略的对抗。
- 主角面临清楚的限时目标。
- 强视觉动作改变安全、关系或局势。
- 结果先行，引出具体因果问题。

“在宁静的小镇，有一个善良的女孩”没有提供当下判断；“女孩把最后一块面包递给流浪狗，狗却冲她身后的父亲狂吠”则立即让人物善意、异常行为和关系危险同时可见。

### 2. 三秒原则的正确用法

“前三秒发生事情”适合用来检查信息流开头是否被背景、寒暄或片头占据。它不是要求所有作品在第三秒完成爆炸、耳光或身份揭晓。

判断标准不是声量，而是观众是否获得了一个清楚且持续的问题。静默拆开离婚协议、手指停在报警键上、门外出现不该存在的鞋，也可以是强开头。

### 3. 开头与后文必须同源

开头承诺的对象必须是当前剧情真正处理的问题。不得用未来高潮、梦境、无关奇观或标题党对白骗取停留，随后切回漫长铺垫。倒叙或结果先行必须在合理时间内回扣。

## 四、人物：快速识别不等于扁平

短视频确实需要降低人物识别成本，但“一句话能介绍”只应是入口层。

### 三层人物结构

| 层级 | 功能 | 示例 |
|---|---|---|
| 识别层 | 让观众迅速知道他是谁。 | 退休杀手开小餐馆。 |
| 驱动层 | 解释他现在为什么行动。 | 他想保护来历不明的养女。 |
| 矛盾层 | 让选择不再机械。 | 他最擅长暴力，却答应孩子永不杀人。 |

身份反差、核心欲望和明确弱点可以构成人物入口，但连续剧情必须通过选择、代价、关系和失误逐步扩展人物。

### 标签的使用边界

- 标签负责识别，不负责替代动机。
- 反派可以傲慢，但必须说明他为什么此刻阻止主角、他能付出什么、害怕失去什么。
- 帮助者可以嘴硬心软，但每次帮助都应符合关系位置和利益边界。
- 主角可以隐藏实力，但隐藏原因、暴露代价和能力边界必须成立。

## 五、冲突：把事件变成力量对抗

“小明去参加比赛”只有行为，没有阻力；“小明必须参赛，但全队认为他靠作弊入选”才形成目标、阻力和关系压力。

### 四类阻力

1. 人与人：欲望直接冲突，理解成本最低。
2. 人与规则：制度、契约、禁令或生存规则阻断行动。
3. 人与自己：恐惧、欲望和价值冲突必须外化为选择。
4. 人与环境：空间、时间、资源或灾难持续施压。

人与人的直接冲突常适合短视频，但不能把所有题材都降格为吵架。规则、环境和内心冲突可以通过一个具体人物、道具、时限或行动后果变得可见。

### 场内对抗链

```text
触发
-> 人物即时反应
-> 对局势作出判断
-> 采取策略行动
-> 对方或环境反制
-> 人物面临选择
-> 选择形成结果与代价
```

缺少判断与选择，人物像被情节拖动；缺少反制，冲突会变成单方面展示；缺少代价，胜利没有重量。

## 六、节奏：连续状态变化

节奏不是剪辑快，也不是所有人说短句。节奏的本质是观众持续感到局势在变化。

### 六类有效变化

- 目标变化：人物想做的事改变或升级。
- 优势变化：主动权发生转移。
- 关系变化：信任、控制、依赖或敌意改变。
- 信息变化：新事实改变先前判断。
- 危险变化：威胁逼近、扩大或转向。
- 代价变化：选择的损失变得更具体。

“每十五秒有变化”是约 30 至 90 秒内容的常用诊断基线，不是硬切点。变化过密而没有消化，会让剧情像梗概；变化过慢且没有表演张力，会形成卡顿。

### 六十秒参考波形

```text
0—3 秒：第一有效拍
3—10 秒：明确人物目标与观看问题
10—25 秒：行动遭遇第一轮反制
25—45 秒：关键选择、误判或理解变化
45—60 秒：情绪兑现与新后果
```

实际创作应按节拍而非秒表裁决。感动题材可能需要更长蓄力，搞笑反差可能在十几秒内完成，微短剧单集则可以有两到三轮小循环。

## 七、反转：重写理解并改变行动

好的反转不是隐瞒所有信息，而是让同一事实获得新的解释。

### 常见类型

- 身份反转：人物真实身份改变权力或关系。
- 关系反转：敌人、盟友、保护者或利用者的位置改变。
- 目的反转：同一行为的真实目的被重新理解。
- 信息反转：先看到结果，后发现原因或条件。

### 四项合格条件

1. 前文存在可回看的迹象。
2. 反转符合人物欲望和行动能力。
3. 揭晓后改变当前选择、关系或局势。
4. 反转产生必须承受的后果。

“他其实是首富”“她其实一直在保护你”若只是最后一句声明，没有前置行为和后续结果，只是身份贴纸，不是有效反转。

## 八、情绪：蓄力、释放与余波

剧情是情绪的因果载体。短视频需要高反馈，但反馈必须偿还此前建立的情绪债。

### 爽感

```text
具体压迫
-> 主角暂时受限
-> 找到策略或完成选择
-> 能力 / 身份 / 证据公开生效
-> 压迫秩序被改变
```

爽点不是“所有人震惊”，而是此前限制主角的力量真实失效。

### 感动

```text
关系误解或距离
-> 一方持续付出且承担代价
-> 关键选择暴露真实在乎
-> 真相改变另一方行动
-> 关系留下不可逆变化
```

### 恐惧

```text
可识别的正常秩序
-> 一个可验证异常
-> 人物尝试解释或逃离
-> 异常突破原有规则
-> 真相或未知迫使人物选择
```

### 搞笑

```text
建立明确期待 A
-> 出现合理但意外的 B
-> 人物认真应对荒谬后果
-> 后果继续升级或回扣人物弱点
```

情绪释放后要留余波：胜利带来暴露，真相带来后悔，笑点改变关系，恐惧揭示更大规则。余波让视频不是一次性刺激。

## 九、对白：短句服务行动，回合服务关系

短视频对白应尽量让一句话承担一个主要行动目的：质问、拒绝、试探、威胁、掩饰、请求、确认或揭示。

长篇解释可以拆成行动回合，但不能机械删除上下文：

```text
“你要走？”
“我留下，只会害死你。”
“那就一起死。”
```

这三句都短，却形成前提、理由和关系选择。若只保留“那就一起死”，情绪强但语义悬空。

### 对白检查

- 是否改变行动、关系或信息？
- 是否能由演员自然说出口？
- 回应是否存在明确前提？
- 是否把背景说明伪装成角色互相告知已知信息？
- 是否把多个事项压成助理播报式清单？
- 能用动作表达的内容，是否仍被重复说出？

## 十、视听化：让变化可以被拍见

“他很痛苦”是解释；照片在雨中化开、手停在门把上、说到一半把戒指摘下，才是可拍的情绪动作。

可视化优先寻找：

- 身体反应：退后、僵住、松手、遮挡、越界。
- 道具变化：破损、转移、暴露、失效、被夺走。
- 空间关系：谁挡门、谁占中心、谁被隔开、谁主动靠近。
- 行动结果：门是否打开、电话是否接通、证据是否被看见。
- 他人反应：只在确有关系和利益时使用，不靠群众齐声震惊。

首帧应尽量明确主要人物、空间和关键动作，但悬疑内容可以有控制地隐藏身份或位置。隐藏必须服务问题，不能让观众连基本动作都看不懂。

## 十一、AI剧情视频的制作语法

AI 视频需要额外控制连续性，但制作约束应在故事成立后叠加。

### 1. 场景经济

一个情绪段尽量由一个主要空间承载，减少无必要转场。若剧情必须跨场景，明确每次转场带来的状态变化。禁止把“单场景更稳定”升级成“一分钟绝对只能一个场景”。

### 2. 人物稳定

固定并复用年龄段、发型、服装、体态、显著特征和关键道具。人物发生换装、受伤或状态变化时，记录变化原因和起止镜头。

### 3. 动作可分解

用主体明确、方向明确、一次一动作的描述。复杂打斗、多人争抢或细腻心理表演应拆成镜头级动作，不写“复杂地表现内心挣扎”。

### 4. 空间连续

固定人物站位、朝向、距离、出入口和道具位置。多人场景需要时调用 [[多人物场景站位线稿图 Skill]]。

### 5. 首帧与末帧

首帧建立主体、空间和动作；末帧落在可识别结果或下一动作临界点。不要只靠字幕说明镜头发生了什么。

## 十二、四种内容形态的结构差异

### 单条完整剧情

用一条主要因果链完成局部闭环。可以开放结尾，但不能把核心兑现全部推到不存在的下一集。

### 连续剧情号

每条既是内容单元，也是连续主线的一步。当前条至少改变一个长期变量：关系、资源、身份风险、目标、规则理解或主要敌我格局。

### 微短剧单集

服从全集大纲和详细剧集大纲。本集不必独立解释全部世界，但必须承接上一集后果、推进本集主问题，并生成下一集的真实需求。

### AI剧情短片

在以上任一结构上增加制作约束。不得把“AI 难生成”直接等同于删掉人物反应、关系回合或因果桥；应优先简化动作、镜头、场景和群演调度。

## 十三、常用结构原型

结构原型用于快速起草，不是交付模板。

### 逆袭兑现

```text
具体限制
-> 对方公开施压
-> 主角找到行动窗口
-> 隐藏资源或能力产生结果
-> 权力关系改变并付出新代价
```

### 温情治愈

```text
孤独或缺失
-> 特殊关系建立
-> 日常行动积累依赖
-> 面临失去或选择
-> 关系留下具体改变
```

### 悬疑追问

```text
异常结果
-> 人物验证
-> 线索指向一个解释
-> 解释出现矛盾
-> 新理解迫使人物行动
```

### 搞笑反差

```text
清楚期待
-> 违反常识但符合人物的结果
-> 人物认真补救
-> 补救制造更大后果
-> 回扣人物弱点或关系
```

## 十四、常见失败模式

- 只有钩子：开头很炸，后文没有同等级因果和兑现。
- 机械秒表：每到规定秒数塞一个新信息，情绪来不及形成。
- 人物标签化：角色只有身份反差，没有欲望、弱点和选择。
- 冲突等于吵架：人物提高音量，但目标、优势和关系都没变。
- 反转空降：靠新身份、新人物或新规则突然改写答案。
- 永久延迟：每条都说“你不知道真相”，从不交付阶段答案。
- 过度删减：删掉判断、反应、关系回合和后果，剧情像提纲。
- 情绪代演：配乐、字幕和旁白宣布感动或爽，人物没有具体行动。
- 视觉重复：对白已经说明，画面只拍站着说话。
- 制作反客为主：为了单场景和简单动作牺牲故事核心。
- 围观者工具化：群众只负责震惊，没有利益、关系或真实反应。
- 模板复印：不同题材都使用同一套打脸、身份曝光和集尾电话。

## 十五、完整检查清单

### 开头与观看问题

- 第一有效拍是否尽早出现？
- 异常、冲突或目标是否与后文主线同源？
- 观众能否形成一个具体问题，而不是只感到“很吵”？

### 人物与对抗

- 主角欲望和当前阻碍是否可见？
- 人物标签之外是否有弱点、矛盾和选择？
- 对抗者是否有自己的目标、能力和代价？

### 节奏与因果

- 每个节拍是否改变目标、优势、关系、信息、危险或代价？
- 前一拍的结果是否成为后一拍的原因？
- 是否保留了人物反应、判断和行动后果？

### 情绪与反转

- 主情绪是否有真实蓄力？
- 释放是否偿还此前建立的情绪债？
- 反转是否有前置迹象、动机和后果？
- 当前单元是否完成至少一次局部兑现？

### 对白与视觉

- 对白是否可说、可演、一次承担一个主要目的？
- 问答前提和回应是否闭环？
- 关键信息是否能通过动作、道具、站位或表情呈现？
- 不听声音时是否仍能理解主要局势变化？

### 连续性与制作

- 连续内容是否改变了长期变量？
- 人物外观、服装、道具、伤势和空间是否连续？
- 动作是否可分解、归属清楚？
- 场景控制是否服务制作，而没有破坏剧情？

## 十六、后续细分理论接口

通用理论只规定共同底层。以下方向应各自建立独立 Skill 后再由 [[短视频剧本创作理论]] 路由：

- 治愈动画类：关系积累、静态表演、温柔兑现和余韵。
- 搞笑反转类：期待建立、节奏压缩、人物认真感和回扣。
- 悬疑类：证据链、错误答案、公平信息和认知翻转。
- 爽文类：压迫合法性、情绪债、公开兑现和升级代价。
- 科幻世界观类：陌生规则的最低解释、视觉奇观和信息台阶。

细分理论不得复制通用 Skill 全文，只记录相对通用底层发生变化的参数、结构和风险。
