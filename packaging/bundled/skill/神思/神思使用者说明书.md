# 神思使用者说明书

状态：正式说明，Agent 运行版。

## 你如何使用神思

你可以直接在对话区说明目标，也可以继续手动新建、编辑、重命名、移动、复制、粘贴、删除和恢复文档。Agent 操作和手动操作作用于同一工作区；Agent 获得操作能力不意味着软件只能由 Agent 操作。

自然描述即可，不需要记忆任务关键词、固定命令或先选任务类型。当前打开文档只帮助 Agent 理解“当前文档”指向哪里；除非你明确指定，它不会被自动当作默认写入目标。

## Agent 如何工作

Agent 读取 [[神思任务路由]]、[[神思运行规范]] 和实时 Skill 面板，结合完整对话、当前阶段、作品结构与实际资料，自主选择能力和操作。只有真正读取到非空内容的文档与真正加载的 Skill 才显示在任务卡中。

正式内容默认自动落盘，除非你明确说不写入或不落盘。探讨、解释和未采用方向默认留在对话；你明确要求保存时也可以落盘。任何写入完成都应附带可点击的真实文档链接。

覆盖、续写、追加、局部替换、重命名、移动、复制和删除发生前，神思保存完整可恢复历史；写入后回读验证。局部修改先显示修改前后对比，确认后才替换。

## 选择框和多候选

Agent 确实需要你在有限方向中决定时，会先在对话区发出问题，再在输入框上方显示选项和确认按钮。选项不会因等待而过期。你也可以直接在输入框发送其他想法，这会跳过当前选项并作为新的用户指令继续任务。

编号步骤、规则和仅供阅读的方案不会自动变成选择框。需要多个创作候选时，直接说明数量和差异；神思保留多候选，不询问谁当主笔或需要几个主笔。

## 对话与任务

- 用户手动新建的对话持久保存，更新或重启后仍在。
- 多个对话可以同时运行；每个对话显示独立进度、思考或等待状态。
- 撤回用户指令会同步撤回它产生的选择框。
- 编辑历史指令可以建立新的问答分支，不覆盖原分支。
- 任务失败、取消、中断、阻断或等待确认时都会显示真实原因和可执行的下一步，不应静默结束。

## Skill 面板

面板中的并行、主次和组织关系会真实影响 Agent 路由。你可以在允许的同一容器内拖拽排序或交换角色；不能把成员拖到另一个模块或模组。保存面板后，当前文字模型会生成与拓扑绑定的动态路由候选，校验通过后生效；失败时保留上一份有效路由并提示原因。

## 作品、笔记和白板

作品用于结构化长期创作，笔记用于自由文档管理，两者切换不会改变文档事实。每个作品和笔记本相互隔离。

白板、图片和视频属于独立媒体域，不受文档路由修改影响。对话区生成成功的图片和视频会备份到“全部资产”。媒体失败必须显示供应商或 CLI 返回的真实原因；需要人工确认或彻底终止时可在待处理项中操作。

## 自检与报告

Agent 根据检查对象和目标选择实际需要的自检 Skill，不强制加载完整规则库。自检报告属于正式成果时，默认写入 `07_编译报告/` 的具体报告文档并提供跳转链接；`report-compile` 是自动汇总索引，不存放报告正文。

## 权限

对话区左上角的权限菜单控制 Agent 本轮可以执行的范围。无论档位如何，作品隔离、历史保护、真实回执和失败显式反馈始终有效。选择外置运行器时，任务完整交给该 Agent 执行，不回退旧 Chat 路径。
