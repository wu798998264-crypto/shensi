# 网文科幻创作理论

## 定位

使用未来科技承载成长故事，以“人物成长 + 科技体系 + 持续升级 + 世界扩张”构成长篇追读引擎。科技既要提供可见爽点，也要改变主角可做的选择、冲突等级和世界规则；不得只把玄幻境界换成机甲、基因或文明等级。

本 skill 归属 [[小说类型理论研究]]。它负责商业长篇科幻的类型方法，不覆盖作品 canon，不替代 [[神思-设定生成规则]]、[[神思-大纲与章纲规则]]、[[神思-正文写作规则]] 或对应自检。

任务明确要求硬科幻严谨性、社会推演、哲学问题或文明思想实验时，按需补读 [[skill/神思/小说类型理论研究/traditional-science-fiction/SKILL|传统科幻创作理论 skill]]；只需要通用男频商业追读判断时，按路由补读 [[男频网文创作逻辑研究]]。不得默认同时加载三套理论。

正式建项、整卷规划或全量诊断前，读取 [[skill/神思/小说类型理论研究/web-novel-science-fiction/references/theory|网文科幻创作理论详版]]。

## 固定工作流

### 1. 锁定商业承诺

先用一句话明确：

```text
处于【限制 / 危机】的主角，获得【科技变量】，
通过【持续成长方式】进入【逐步扩大的世界】，最终面对【文明级问题】。
```

开局必须同时给出当前压力、近期目标、第一次科技机遇和长线世界承诺。

### 2. 建立六条成长账

分别记录能力、科技、资源、身份、势力、世界与主题。每个阶段至少实质推进两条；战力增长不能长期替代身份变化、关系责任、制度位置或世界认知。

### 3. 建立科技阶梯

为个人能力、装备和文明分别建立可理解等级。每一级必须写清：新能力、使用条件、可见兑现、成本或反制、下一等级目标。等级名称不是成长，新增可做之事和新增代价才是成长。

### 4. 切分阶段目标

按作品需要从个人生存、资源获取、身份立足、势力建立、星球竞争、星际文明、宇宙规则或终极秘密中选取阶段。每阶段固定包含：明确目标、主要压力、完成标准、阶段奖励、升级代价和打开的新未知。

### 5. 把科技转成剧情体验

让科技在危机、竞赛、战争、交易、探索、生产、救援、治理或公开验证中发挥作用。每次关键科技兑现使用：

```text
旧限制
-> 科技能力介入
-> 主角作出策略选择
-> 可见结果或反转
-> 他人 / 组织 / 世界承认变化
-> 新成本、反制或更高规则出现
```

先让读者看见科技改变结果，再解释当前理解所需的最少机制。

### 6. 运行章节追读循环

```text
具体压力或目标
-> 主角使用科技、判断或资源行动
-> 获得局部进展或爽点
-> 暴露代价、更强敌人或未知规则
-> 形成下一章必须回答的具体问题
```

每章按主任务推进或完成成长账、阶段目标、科技规则、关系责任、未知真相、后果消化或阶段闭合中的至少一项。非终局且需要续读时，后续需求必须来自本章结果；不得靠无关新敌人硬续，也不得破坏后果章和结局的闭合。

### 7. 同步扩大世界与情感

地图从个人、城市、国家、星球、银河扩展到宇宙时，同步扩大主角的责任、关系、损失风险、伦理选择和文明位置。更大的地图必须带来不同的问题类型，不能只换更强敌人和更大爆炸。

### 8. 回收成长主题

中后期持续追问主角为什么变强、力量保护了什么、技术让他失去了什么。终局不仅兑现最强等级，还要让成长路线对文明、生命、孤独、自由、责任或宇宙未知形成回答。

## 硬规则

- 主角必须始终知道当前所处层级、近期目标和下一步缺口。
- 每次升级必须改变行动方式，不得只增加数值或更换等级名。
- 黑科技、AI、遗迹、系统和特殊能力必须有边界、成本、来源线索或可被针对的弱点。
- 科技必须产生至少一次可见剧情兑现，不能只停留在说明和参数。
- 每个阶段结束必须兑现旧承诺并打开不同性质的新问题。
- 更高文明和更强敌人必须拥有新规则，不能只是旧敌人的数值放大版。
- 主角可以强，但必须保留资源、认知、伦理、关系或文明层面的限制。
- 世界扩大时必须同步扩大情感责任和选择代价。
- 后期不得无限重复升级循环，必须回到力量意义和文明主题。
- 爽点不能破坏科技因果；无法解释的胜利应返修能力边界或前置铺垫。

## 最小自检

- 主角是否有清晰起点、机遇、成长方式和终点愿景？
- 读者是否知道主角当前层级与下一目标？
- 科技等级是否对应新能力、新场景和新代价？
- 每个阶段是否完成旧目标并开启新未知？
- 科技是否在具体事件中产生爽点或反转？
- 主角是否仍受更高文明、未知规则或现实成本限制？
- 世界扩大是否同步改变关系、责任和问题类型？
- 章节结尾是否形成具体追读问题？
- 后期是否从无限升级回到力量意义和文明主题？

核心项失败时，先返修成长账、科技阶梯或阶段目标，不要靠新增等级、敌人和地图延长篇幅。
