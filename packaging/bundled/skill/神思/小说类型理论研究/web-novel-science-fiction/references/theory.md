## 一、核心定义与边界

网文科幻是以未来科技、宇宙环境或文明变化承载成长叙事的商业长篇类型。核心目标是让读者持续知道：主角正在争取什么、科技能带来什么、下一层世界有什么，以及本章结果为什么迫使他继续行动。

核心公式：

```text
人物成长
+ 科技体系
+ 持续升级
+ 世界扩张
+ 章节追读
= 网文科幻长篇引擎
```

它与传统科幻的差异是重心，不是科学因果的豁免。

| 维度 | 网文科幻 | 传统科幻 |
|---|---|---|
| 首要牵引 | 成长、目标、兑现和追读 | 科学假设、文明推演和思想实验 |
| 科技表现 | 能力、资源、身份、战争和世界扩张 | 制度、存在方式、认知和伦理变化 |
| 人物位置 | 主动成长并改变局部或时代 | 在更大规律中观察、验证和选择 |
| 长线结构 | 阶段升级与新世界连续开启 | 模型修正与思想问题深化 |
| 共同底线 | 科技有规则、限制、代价和后果，不能成为任意黑箱。 | 科技有规则、限制、代价和后果，不能成为任意黑箱。 |

商业性不等于只写打脸和数值。科幻感来自成长方式、资源结构、战争形态和文明问题都由科技决定。

## 二、四引擎模型

### 1. 人物成长引擎

主角从受限起点出发，通过选择、学习、承担风险和组织资源获得能力、地位与责任。机遇只能打开道路，不能代替主角行动。

### 2. 科技体系引擎

科技提供层级、专业分工、限制、克制关系和社会位置。读者要能理解当前能力解决什么、不能解决什么、下一层为何值得期待。

### 3. 阶段目标引擎

长篇由一组可完成的阶段目标组成。每完成一段，必须结算奖励、关系、身份和代价，再打开性质不同的新问题。

### 4. 世界扩张引擎

主角的成长不断暴露更大地图、更高文明、新资源结构和陌生规则。世界扩张不是背景更换，而是问题类型升级。

## 三、六条成长账

| 成长账 | 记录内容 | 有效升级标准 |
|---|---|---|
| 能力 | 身体、意识、操作、判断、指挥和生存能力 | 主角能完成过去不能完成的行动。 |
| 科技 | 装备、AI、基因、能源、航行、生产与文明技术 | 新技术进入事件并改变结果。 |
| 资源 | 能源、材料、数据、人口、舰队、生产线和情报 | 稀缺性、选择空间或竞争方式发生变化。 |
| 身份 | 平民、成员、指挥官、领袖、文明代表等 | 世界对主角的权限、责任和评价改变。 |
| 势力 | 同伴、团队、基地、组织、星球与文明联盟 | 主角可以调动更复杂的协作系统。 |
| 世界与主题 | 地图、规则、历史真相、文明位置和价值判断 | 新世界迫使主角重新定义力量意义。 |

每一卷至少让三条成长账产生阶段变化。连续只推进能力和装备，会使故事退化成数值升级。

## 四、科技成长体系

### 1. 个人成长阶梯

可从普通人、强化者、改造生命、超级生命延展到宇宙尺度生命，但每一级必须改变感知、行动、寿命、身份或伦理边界。名称可替换，功能差异不可省略。

### 2. 装备成长阶梯

装备可从工业量产、军用精英、战略级、文明遗产发展到规则级工具。每一级需要不同能源、制造体系、权限和维护代价，不能只增加伤害数字。

### 3. 文明成长阶梯

文明可从行星、恒星、星系发展到更高尺度。文明升级必须改变能源来源、生产组织、通信时间、战争逻辑、个体权利和资源定义。

### 4. 单级设计卡

```text
层级名称：
进入条件：
新增能力：
仍然不能解决的问题：
代表性兑现事件：
资源与维护成本：
主要克制方式：
社会身份变化：
下一层期待：
```

## 五、阶段目标系统

推荐扩张顺序可参考：个人生存、资源获取、身份立足、势力建立、星球竞争、银河竞争、宇宙文明冲突、终极秘密。它是选型工具，不是所有作品必须照搬的固定八段式。

每阶段必须包含：

```text
起点缺口
-> 明确目标
-> 主要敌人与规则压力
-> 科技或资源破局路线
-> 中段失败或代价
-> 阶段性兑现
-> 身份 / 关系 / 世界变化
-> 新未知或更高规则
```

新阶段不能只是敌人更强。至少改变一个核心变量：目标性质、资源逻辑、组织规模、道德代价、时间压力、敌我边界或文明真相。

## 六、科技爽点转化

科技爽点来自“旧限制被新能力以可见方式突破”，并由世界确认其价值。

常见类型：

- 生存爽：科技让主角在别人无法生存的环境中活下来。
- 机动爽：空间、航行或机甲能力改变战场位置和节奏。
- 生产爽：主角建立自动工厂、能源体系、基地或舰队。
- 信息爽：AI、传感器、意识技术或情报模型识破未知。
- 战术爽：同一装备被主角用出更高策略价值。
- 身份爽：技术成果让组织、军方、文明或敌人重新评价主角。
- 文明爽：一项技术改变星球、联盟或文明的生存资格。

有效结构：

```text
具体困境
-> 旧方案失败
-> 科技能力与主角判断结合
-> 结果可视化
-> 世界承认或利益重排
-> 新限制显形
```

只有科技展示、没有阻力与后果，是产品演示；只有主角胜利、没有科技规则，是普通爽文换皮。

## 七、七类题材方向

| 方向 | 主要成长资源 | 核心爽点 | 长线风险 |
|---|---|---|---|
| 星际冒险 | 航行权限、坐标、舰船、遗迹、情报 | 新星球、新文明、远距离破局 | 地图重复，星球只是换皮副本。 |
| 末日废土 | 生存物资、基地、人口、生产与秩序 | 从求生到重建规则 | 只杀怪，不处理文明重建。 |
| 机甲战争 | 驾驶技术、机体、能源、编队、军衔 | 战术反杀、机体迭代、战场认可 | 机甲只剩境界和数值。 |
| 基因进化 | 样本、适应性、身体边界、物种身份 | 进化突破、环境适应、形态反差 | 能力增加却不改变人的定义。 |
| 人工智能 | 算力、数据、权限、协同与自治目标 | 预判、调度、生产、认知领先 | AI 成为无成本外挂或万能助手。 |
| 文明升级 | 能源、人口、制度、科技树、外交 | 从弱文明到规则制定者 | 只写科技树，不写社会与代价。 |
| 宇宙争霸 | 舰队、联盟、资源区、文明规则 | 战略扩张、文明博弈、规则战争 | 后期只堆规模，人物与主题消失。 |

## 八、开局、章节与整卷循环

### 1. 开局承诺

开局尽快建立四件事：主角当前限制、迫近危机、科技机遇、这项机遇将打开的更大世界。不要先写宇宙史和科技百科。

可采用三步验证：

1. 情绪或生存钩子：主角为什么必须行动。
2. 科技首次验证：机遇第一次改变具体结果。
3. 世界承诺：胜利暴露组织、星球、文明或未知规则。

不要求机械对应前三章，但三项长期缺失会导致开局没有类型承诺。

### 2. 单章循环

阶段内应持续交替提供进展与未完成；单章按任务获得信息、资源、能力、身份、关系变化、后果消化或阶段闭合。只有非终局且确需续读时，才留下由本章结果自然产生的新目标、风险、代价或疑问。

### 3. 整卷循环

```text
卷初：锁定阶段目标与主要缺口
卷中：科技成长、资源竞争、关系责任与规则压力交替升级
卷高潮：用本卷积累完成不可替代的阶段兑现
卷末：结算身份、资源、人物和科技代价，打开不同性质的新世界
```

## 九、读者代入与强度控制

主角应满足被认可、掌握力量、改变命运和影响时代的幻想，但认可必须来自事件验证，力量必须来自选择与成本。

保留成长空间的方法：

- 更高文明拥有不同规则，而不只是更高战力。
- 敌人能针对主角当前技术建立反制。
- 资源、维护、时间和信息始终有限。
- 每次能力扩张同步扩大责任和暴露面。
- 主角可以解决战术问题，却无法独自解决制度和文明问题。

## 十、世界与情感同步扩张

尺度扩大时，人物情感不需要变成抽象的“爱全宇宙”，而要扩大责任对象和选择代价。

| 世界尺度 | 对应情感与责任 |
|---|---|
| 个人生存 | 身体、尊严、亲人或同伴。 |
| 城市 / 国家 | 团队、故乡、公共安全与制度信任。 |
| 星球 | 族群、生态、历史记忆与集体选择。 |
| 银河 | 文明联盟、异质生命、战争责任与不可通约。 |
| 宇宙 | 文明存续、生命定义、孤独、自由与存在意义。 |

地图升级后仍只处理最初的私人打脸，会产生尺度失配。

## 十一、后期主题回收

后期必须回答三个问题：

1. 主角为什么持续变强？
2. 力量让他能够保护、创造或决定什么？
3. 哪些问题无法靠更强力量解决？

终局可以让主角影响文明或宇宙，但必须让此前的成长方式发生主题回声。例如最强力量无法消除文明孤独，绝对算力不能替代价值选择，永生技术迫使主角重新定义人类。

## 十二、常见失败模式

- 科幻换皮：体系、剧情与玄幻升级完全相同，只替换名词。
- 数值空转：升级没有新增行动方式和剧情场景。
- 黑科技发钱：机遇自动解决问题，主角无需判断、学习和选择。
- AI 代打：AI 提供所有答案，人物只负责确认。
- 敌人通胀：每阶段只出现更大、更强但结构相同的敌人。
- 地图通胀：星球与星系不断增加，资源、制度和生命差异不变。
- 阶段不结算：旧目标长期拖延，只靠新危机覆盖欠账。
- 爽点无后果：科技每次都成功，没有反制、成本和社会影响。
- 情感缩水：尺度越大，人物越像没有私人关系的功能机器。
- 主题失踪：终局仍只剩战力排名，没有回答力量意义。

## 十三、完整检查清单

- 一句话商业承诺是否同时包含压力、科技变量、成长方式和世界方向？
- 主角的六条成长账是否至少有两条持续推进？
- 科技层级是否对应新能力、场景、成本和反制？
- 读者是否知道当前层级和下一目标？
- 每阶段是否有完成标准、兑现和代价结算？
- 新阶段是否改变问题类型，而不只是提高战力？
- 科技是否在事件中产生可见爽点？
- 爽点是否由主角判断和选择参与完成？
- 当前阶段是否形成进展与未完成的有效波形；本章结束功能是否符合自身任务？
- 每卷是否完成一个阶段问题并打开新世界？
- 更高文明是否拥有不同规则和利益逻辑？
- 世界扩张是否同步扩大关系责任和伦理代价？
- 主角是否保留资源、认知、时间、伦理或文明限制？
- 后期是否回答力量的意义及其无能为力之处？
