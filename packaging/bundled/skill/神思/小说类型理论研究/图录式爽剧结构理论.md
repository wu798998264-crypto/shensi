## 一、核心叙事引擎

黄金循环结构：

```text
压迫出现（Threat Spawn）
-> 主角被低估（Underestimate）
-> 冲突升级（Escalation）
-> 规则打破（Break Rule）
-> 斩杀/解决（Kill / Resolve）
-> 掉落奖励（Loot）
-> 能力反哺（Power Gain）
-> 引发更大威胁（Bigger Threat Spawn）
```

核心判断：

> 把叙事变成可循环的奖励机制。

这一模型的长线牵引不是人物情感变化，而是“怪物 / 事件 -> 战斗 -> 掉落能力 -> 进入更大危机”的连续兑现。每一轮单元都必须让观众看到新敌人、新规则、新战斗、新掉落和新地图压力。

## 二、三层结构模型

### 1. 单集结构

每一集必须包含：

```text
A. 强钩子开场（0-10%）
- 危机 / 怪物 / 羞辱 / 死亡边缘

B. 现实压制（10-30%）
- 主角弱势 / 被误解 / 被压制

C. 威胁显形（30-60%）
- 怪物完整展示 / 规则解释 / 战力压迫

D. 反转破局（60-85%）
- 主角首次突破 / 使用新能力

E. 斩杀与掉落（85-95%）
- 明确击败 + 可视化奖励

F. 新局开启（95-100%）
- 更大势力 / 更强敌人 / 新地图
```

单集最低交付标准：

- 至少一次“主角被低估”。
- 至少一次“能力展示反转”。
- 至少一次“明确斩杀 / 解决”。
- 至少一次“即时可见的掉落”。
- 结尾必须打开更大问题。

### 2. 单元怪物结构

每个“怪物 / 敌人 / 事件实体”必须具备六要素：

```text
1. 视觉奇观：长什么样。
2. 压迫机制：如何让主角或群众恐惧。
3. 规则机制：能力体系如何运转。
4. 弱点机制：如何被破解。
5. 掉落机制：击杀后获得什么。
6. 延展机制：如何引出更大敌人。
```

硬原则：

> 没有掉落的怪物 = 无效剧情。

怪物不是单纯敌人，而是“视觉冲击 + 战斗难度 + 能力掉落 + 下一关钥匙”的能力生产机器。

### 3. 季度长线结构

季度结构不是传统剧情线，而是能力地图扩展系统：

```text
S1：觉醒与验证（单体怪）
S2：组织系统进入（人类秩序 / 官方体系）
S3：区域级怪物生态
S4：跨势力战争（妖 / 人 / 神 / 组织）
S5：世界规则重写
```

长线扩张必须遵守：

- 小怪 -> 精英 -> 区域 Boss -> 世界 Boss。
- 单体能力 -> 组合能力 -> 权限能力 -> 法则能力。
- 随机事件 -> 组织任务 -> 区域生态 -> 世界规则。

## 三、角色系统

### 主角

主角是能力增长载体，不是情感载体。

必须满足：

- 弱起点 / 低身份 / 高潜力。
- 不依赖恋爱推进。
- 主要行为是破局、斩杀、掉落利用。
- 每次胜利都要把上一轮掉落转化为下一轮破局工具。

### 怪物

怪物是掉落来源。

设计公式：

```text
怪物 = 视觉冲击 + 战斗难度 + 能力掉落 + 下一关钥匙
```

怪物功能不是“阻碍主角”，而是让观众看到能力体系如何被拆解、夺取和升级。

### 人类反派

人类反派是压力系统。

主要作用：

- 制造羞辱。
- 延迟主角爆发。
- 提供身份压制。
- 把战斗胜利变成公开打脸。

人类反派通常不是最终 Boss，而是情绪燃料。

### 组织体系

组织体系是进阶阶梯。

如镇魔司、宗门、朝廷、调查局、猎妖协会、异能管理局等，其核心作用是把随机事件变成可持续任务流：

```text
异常报告 -> 任务派发 -> 等级评估 -> 战斗验证 -> 权限升级 -> 更高危险区开放
```

## 四、掉落系统

掉落系统是本理论与普通升级流的核心差异。

每次击杀或解决必须产生以下至少一种收益：

```text
能力 A：战斗型。
能力 B：感知型。
能力 C：规则型。
身份升级 / 权限解锁。
地图钥匙 / 组织资格 / Boss 线索。
```

掉落设计公式：

```text
怪物特性 -> 掉落能力形态
```

示例：

- 速度型怪物 -> 身法 / 追踪能力。
- 精神型怪物 -> 幻术 / 感知能力。
- 力量型怪物 -> 肉身强化。
- 规则型怪物 -> 系统权限 / 法则碎片。
- 寄生型怪物 -> 识别伪装 / 排异净化。
- 群体型怪物 -> 分身调度 / 群战统御。

掉落必须即时可见，不能只说“以后会有用”。最佳做法是在掉落后的下一秒、下一场或结尾钩子里让能力产生作用。

## 五、爽点生成规则

### 规则 1：每集至少一次被低估

没有“看不起主角”，就没有可兑现的爽点账本。

### 规则 2：每集至少一次能力展示反转

基础形态：

```text
被压制 -> 旧能力不够 -> 新掉落触发 -> 规则反杀
```

### 规则 3：掉落必须即时可视化

能力不能停留在说明文字。必须通过画面、动作、战斗结果或权限变化呈现。

### 规则 4：怪物必须形成升级链条

基础链条：

```text
小怪 -> 精英 -> 区域 Boss -> 世界 Boss
```

每个小怪都应当携带上级生态的气味、标记、组织烙印或规则碎片。

### 规则 5：结尾必须打开更大问题

单集结尾不是结局，而是扩张钩子：

- 更强敌人被唤醒。
- 组织注意到主角。
- 新地图权限开启。
- 掉落能力暴露副作用。
- 被击杀怪物只是某个图录编号的一页。

## 六、AI 创作流程

用于自动生成该类型内容时，按以下流程执行：

```text
Step 1：生成世界规则（怪物体系 + 能力体系）
Step 2：生成主角起点（弱身份 + 初始能力）
Step 3：生成单元怪物列表（至少 10 个）
Step 4：为每个怪物绑定掉落能力
Step 5：生成 10 集结构循环
Step 6：为每集填充压迫、战斗、掉落、反转
Step 7：检查每集是否满足爽点、反转、掉落和更大危机
```

怪物列表建议字段：

```text
编号：
名称：
视觉奇观：
压迫机制：
规则机制：
弱点机制：
掉落能力：
即时用途：
延展敌人：
适配集数：
```

## 七、标准输出模板

```text
【第 X 集结构】

1. 开场威胁：
（怪物 / 人类压迫）

2. 主角状态：
（弱势 / 被误解 / 被压制）

3. 冲突升级：
（规则说明 + 战力展示）

4. 破局点：
（新能力 / 旧能力组合）

5. 战斗过程：
（阶段变化）

6. 斩杀结果：
（视觉高潮）

7. 掉落能力：
（明确写出能力）

8. 新危机：
（更强敌 / 组织 / 世界事件）
```

## 八、禁用模式

以下内容会破坏本理论：

- 长情感线压过奖励循环。
- 无掉落战斗。
- 无压迫敌人。
- 战斗无反转。
- 能力不可视化。
- 单集闭合结局。
- 过多解释性对白。
- 怪物只负责恐怖气氛，不产生能力、线索或权限。

## 九、与传统剧本理论的区别

| 传统剧本 | 图录式爽剧结构理论 |
|---|---|
| 情绪驱动 | 奖励驱动 |
| 人物成长 | 能力增长 |
| 故事完整性 | 循环可刷性 |
| 线性结构 | 迭代结构 |
| 结局导向 | 无限升级 |

## 十、使用时的自检清单

- 本集是否有一个可被画出来的怪物或事件实体？
- 主角是否被明确低估、羞辱或压制？
- 怪物规则是否能用一句话说清？
- 弱点是否来自规则破解，而不是作者硬降智？
- 斩杀是否有视觉高潮？
- 掉落是否明确、可见、可立即使用？
- 掉落是否反向打开更大危机？
- 本集结尾是否让观众知道下一集要看什么？
