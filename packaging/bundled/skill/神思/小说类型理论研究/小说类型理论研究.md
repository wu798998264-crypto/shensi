# 小说类型理论研究

显示名称：小说类型识别与理论路由

## 定位

[[小说类型理论研究]] 是类型研究顾问的路由入口，不是具体类型理论本体。

它负责根据用户任务、作品标签、题材关键词、目标平台和自检问题，判断是否需要读取某个具体类型理论板块。具体类型理论必须由本路由命中后再读取，不得绕过路由默认调用某个细分文档。

## 总原则

1. 标准创作任务会先做一次轻量题材识别；命中明确细分类别后，题材顾问从规划阶段启用。没有命中具体题材，或用户明确要求关闭题材理论时不启用。日常快问、局部轻改和视觉提示词任务不进入题材识别。
2. 类型研究顾问只解释类型规律、读者期待和结构依据，不担任正文主笔、大纲主笔、设定主笔或最终自检裁决者。
3. 类型理论不得覆盖 canon，不得把理论建议直接写入正史设定或剧情控制。
4. 没有命中细分类别但明确命中已接入的上位类型时，读取上位类型与网文通用理论；上位类型也没有覆盖时，不读取题材理论。女频任务的上位类型是女频通用理论，不是女频爽文理论。
5. 一个任务可以命中多个类型关键词，但必须先判断主类型；无主类型时只记录“类型路由不明”，不得强行套用已有男频爽文理论。
6. 细分母题命中时必须同时参考细分理论、对应上位理论与网文通用理论。例如明确命中“真假千金 / 真千金 / 假千金 / 豪门认亲”等关键词时，组合读取 [[真假千金剧情创作概论]]、[[女频小说通用理论]] 与网文通用理论；细分理论负责差异化机制，上位理论负责类型承诺，网文通用理论负责人物、因果和追读底座。
7. 没有独立实际 Skill 的女频类型只读取 [[女频小说通用理论]]，不得为了填满下位插槽而套用女频爽文。只有任务明确出现“女频爽文、先虐后爽、虐转爽、后期转爽”等爽文或转爽意图时，才读取 [[女频爽文创作概论]]。
8. 任务明确同时要求商业长篇追读、主角持续成长与传统科幻深度时，优先读取 [[skill/神思/小说类型理论研究/hybrid-science-fiction/SKILL|融合型科幻创作理论 skill]]；由该 skill 再按需追加网文科幻或传统科幻来源，不得默认同时加载三份完整理论。
9. 明确命中短篇科幻、科幻短篇、思想实验短篇或未来生活切片时，优先读取 [[skill/神思/小说类型理论研究/short-science-fiction/SKILL|短篇科幻创作理论 skill]]；不得直接套用长篇传统科幻或网文科幻框架。

## 待扩展板块

后续可按同一格式接入其他细分类型，例如女频复仇、追妻火葬场、无限流、规则怪谈、悬疑破案、民俗诡案、玄幻升级、都市异能、末世、高武、权谋、群像史诗等。

新增板块必须满足：

1. 有独立理论文档。
2. 有明确触发关键词。
3. 有适用范围和禁止套用范围。
4. 写入本路由表后才允许被 [[神思]] 调用。

## 调用流程

1. 标准创作任务先由 [[神思]] 或 [[神思-任务路由规则]] 执行一次轻量题材识别。
2. 命中明确题材时，先读取 [[小说类型理论研究|小说类型识别与理论路由]]，不得直接读取具体类型文档；未命中或用户明确关闭时停止，不加载题材资料。
3. 根据任务文本、作品标签、用户要求和当前自检问题匹配触发关键词。
4. 命中具体细分类别后，再读取对应类型理论文档。
5. 类型理论只输出原因解释、类型风险和修改依据。
6. 最终修改意见必须回到 [[强剧情自检]]、[[常规推进自检]]、[[神思-长篇结构自检规则]] 或对应生产规则中裁决。

## 上位类型回退

- 玄幻、仙侠、修仙、都市异能、悬疑推理、末世、高武、无限流、规则怪谈、系统流和升级流等尚无独立细分理论时，回退到 [[男频网文创作逻辑研究]] 与网文通用理论。
- 古言、现言、宫斗、宅斗、甜宠、女性成长等未命中下位专精时，回退到 [[女频小说通用理论]] 与网文通用理论，不默认进入爽文。
- 女频虐文、纯虐文、虐恋、虐心、BE 结局和追妻火葬场目前只读取 [[女频小说通用理论]]；待存在经过验证的独立理论 Skill 后，才能增加新的下位插槽。只有明确“先虐后爽、虐转爽、后期转爽”才进入 [[女频爽文创作概论]]。
- 已有细分理论时仍组合对应上位理论，不再采用“细分覆盖后完全让上位退出”的方式。
- 题材词无法可靠归入任何已接入上位类型时停止理论召回，不为了填满流程强行套用男频或女频理论。

## 未命中处理

如果任务没有明确命中已接入类型：

- 不得在没有男频题材证据时默认读取 [[男频网文创作逻辑研究]]。
- 不得把民俗诡案、悬疑、女频、短剧、权谋、现实题材等强行套入男频爽文标准。
- 可以说明“当前没有对应类型理论板块”，并仅按通用正文、大纲、自检和信息权限规则处理。
- 如果用户要求新增该类型理论，应先建立对应理论文档，再补入本路由。
