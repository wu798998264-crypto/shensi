## 一、核心定义

传统科幻以科学假设作为变量，对未知世界、人类存在和未来可能性进行思想实验。它不以预测准确为唯一价值，也不以主角获得力量为中心，而是追问：如果某种科学可能性成立，世界、社会、生命和认知会变成什么。

核心关系是：

```text
科学可能性
+ 稳定规则与限制
+ 社会和文明后果
+ 有限认知者的选择
= 科幻思想实验
```

科技是推动思想实验的核心变量。宇宙、自然规律和文明进程不为主角服务；人物的意义在于让抽象变化变成可感知的处境、选择与代价。

## 二、科学假设与推演链

### 1. 假设四层状态

- 已知科学：直接建立在当前可验证知识上。
- 合理外推：沿已知机制向未来延伸，但明确工程和资源门槛。
- 高风险猜想：科学上未证实，但内部规则稳定并承认不确定性。
- 刻意未知：作品只呈现证据与影响，不替未知现象给出虚假答案。

科学严谨不等于解释越多越好，而是清楚区分“已知、推测、误判和不可知”。

### 2. 六段推演

```text
现象或技术的工作机制
-> 能力边界
-> 成本与副作用
-> 个体行为变化
-> 制度适应与权力重组
-> 文明结构或存在方式变化
```

任何一步缺失，都容易让科技退化为黑箱道具。剧情反转只能修正人物对规则的理解，不能临时改写规则本身。

## 三、科技改变世界的后果矩阵

每项核心科技至少推导三列，并优先寻找相互冲突的后果。

| 维度 | 必问问题 |
|---|---|
| 政治与权力 | 谁控制技术、标准、能源、数据或解释权？国家与组织如何重组？ |
| 经济与劳动 | 稀缺性如何变化？什么成为新财富？哪些劳动消失或被强制保留？ |
| 阶层与分配 | 谁先获得技术？谁承担风险？新特权如何继承？ |
| 法律与治理 | 新主体是否拥有权利？责任如何认定？证据和身份如何验证？ |
| 伦理 | 哪些旧禁忌失效？哪些新行为必须被禁止？谁有权划线？ |
| 亲密关系 | 生育、婚姻、家庭、记忆、忠诚和死亡如何被重新定义？ |
| 身份与生命 | 人、复制体、AI、增强者或群体意识的边界在哪里？ |
| 文明结构 | 国家、市场、宗教、战争、教育和历史记忆是否仍以原形存在？ |

有效推演不只写“技术带来便利”，还要写获益者、受损者、制度滞后、反制机制和长期不可逆后果。

## 四、八类创作方向

| 方向 | 核心追问 | 重点变量 | 常见误区 |
|---|---|---|---|
| 宇宙尺度 | 人类在宇宙中的位置是什么？ | 恒星、黑洞、热寂、高维、宇宙规律 | 把宇宙写成等待征服的冒险地图。 |
| 文明演化 | 文明发展到极限后会成为什么？ | 能源、资源、组织、战争、记忆、灭亡 | 只升级科技，不改变国家、财富和个体意义。 |
| 人工智能 | 被创造的智能是否是生命与政治主体？ | 记忆、目标、情感、劳动、治理、人机融合 | 只把 AI 写成聪明助手或失控反派。 |
| 异质生命 | 生命是否必须符合人类定义？ | 感知、时间尺度、思维、需求、繁殖、交流 | 外星人只是换皮人类。 |
| 生命进化 | 人类是否仍是进化终点？ | 基因、增强、后人类、生物机械、复制 | 只增加战斗能力，不改变“什么算人”。 |
| 意识与精神 | 意识、人格和连续自我是什么？ | 上传、复制、记忆修改、虚拟世界、梦境 | 把上传当永生，不处理副本与原体问题。 |
| 微观尺度 | 不同尺度是否拥有不同现实？ | 量子、纳米、细胞、亚原子、尺度效应 | 把微观世界写成缩小版现实。 |
| 时间与空间 | 因果、选择和时空是否客观存在？ | 时间旅行、循环、平行世界、多维、因果约束 | 时间能力只用于撤销剧情后果。 |

主方向负责最终追问，辅助方向负责增加验证场景或代价。一次作品不必同时覆盖八类。

## 五、尺度选择

| 尺度 | 适合的问题 | 典型后果 |
|---|---|---|
| 个人 | 意识、身份、记忆、身体、死亡 | 自我连续性、亲密关系、选择责任。 |
| 家庭 / 群体 | 生育、复制、共同意识、代际变化 | 亲属关系、忠诚、继承、群体边界。 |
| 城市 / 社会 | 劳动、治理、分配、监控、法律 | 新阶层、新职业、制度滞后、公共风险。 |
| 星球 / 文明 | 资源、能源、战争、文明路线 | 国家消失、文明分叉、伦理重写、历史断层。 |
| 星际 / 宇宙 | 文明尺度、自然规律、终极未知 | 人类渺小、规则冷漠、存在意义与不可通约。 |

尺度可以逐步扩大，但问题必须随尺度改变。个人故事可以让宇宙问题被感知，不能代表整个宇宙被一个人的情感解决。

## 六、世界与人物

“世界优先于人物”应理解为：世界规律不因主角需要而改变，社会与文明在主角之外持续运行。它不意味着人物只能旁观。

有效科幻人物同时具备：

- 有限信息：只能接触局部证据，并可能误判。
- 现实位置：职业、阶层、身体、组织和关系决定其可见范围。
- 私人利益：真相会让他失去什么，误解又保护了什么。
- 验证能力：能够观察、试验、比较模型或承担行动。
- 不可回避选择：即使无法改变宇宙规律，也必须决定如何存在。

人物弧线优先围绕认知变化：无知到理解、确信到动摇、恐惧到接受、服从到拒绝、个体视角到文明视角。力量成长可以存在，但不能替代认知与伦理变化。

## 七、冲突设计

传统科幻的强冲突不是“科学阵营对反科学阵营”，而是多套合理模型争夺行动权。

### 1. 认知冲突

各方依据不同证据解释同一现象。冲突来自模型不兼容，而非一方愚蠢。

### 2. 价值冲突

双方都承认事实，却对何种代价可以接受意见相反，例如个体权利与文明存续。

### 3. 人类与创造物

AI、复制生命、改造人或自治系统获得自身目标后，创造关系转化为政治关系。

### 4. 生命形式冲突

不同感知、时间尺度和生存需求使双方无法共享同一“善意”定义。

### 5. 个体与自然规律

对手不是人格化反派，而是资源、熵、光速、环境或不可逆过程。

### 6. 个体与宏大真相

真相本身改变身份、责任或现实定义。人物必须决定知道之后如何生活。

冲突双方至少写清：证据、利益、价值、恐惧、可接受代价和不可退让边界。

## 八、未知、严谨性与解释边界

未知比答案重要，但未知不能等于含糊。

合格未知包含：

```text
可观察现象
+ 可重复证据
+ 至少两个竞争模型
+ 当前无法验证的边界
```

硬科幻更强调机制与数量级一致，社会科幻更强调制度和群体后果，哲学科幻更强调概念边界，宇宙科幻更强调尺度与不可知。侧重点可以不同，内部因果一致性不能豁免。

避免用伪专业名词制造权威感。无法准确说明机制时，缩小断言范围，明确角色只知道现象或模型。

## 九、剧情发动机

推荐使用“模型迭代”而非单纯升级作为剧情循环：

```text
异常出现
-> 人物提出解释模型
-> 设计观察或试验
-> 证据支持 / 反驳模型
-> 科技或社会后果扩大
-> 人物修正认知
-> 新选择制造不可逆代价
-> 更深层未知出现
```

每一轮至少推进一种内容：科学理解、制度变化、人物认知、伦理边界或文明风险。若一轮只增加名词和奇观，没有改变模型或选择，就是无效扩展。

## 十、结局与思想余震

高潮不是默认胜利，而是人物与文明再也不能回到旧理解。

常用结局形态：

- 认知反转：真相推翻了关于生命、意识或宇宙的旧定义。
- 文明取舍：文明存续，但必须放弃一种被视为人类核心的东西。
- 存在迁移：人物或文明进入新的生命、时间或认知形态。
- 局部选择：人物无法改变宇宙，只能决定自己如何回应冷漠规律。
- 开放未知：主要因果完成，但终极解释仍有多个成立模型。

结局必须回收科学假设的社会后果与人物代价。开放结局可以不回答终极问题，不能不解决主要行动后果。

## 十一、常见失败模式

- 科技贴皮：删除科技术语后仍是相同的战争、恋爱或升级故事。
- 黑箱万能：技术只在作者需要时有效，没有边界和成本。
- 设定百科：世界很完整，但没有人物验证、误判、选择和后果。
- 人类中心：宇宙文明都围绕人类价值和主角命运安排。
- 反派代替问题：把制度、认知或伦理冲突缩成击败一个坏人。
- 尺度失配：用私人和解解决文明冲突，或用宇宙灾难装饰私人争吵。
- 外星人换皮：只改变外形、器官或武器，不改变感知和需求。
- 时间撤销器：时间旅行只负责重置失败，使选择没有代价。
- 演讲代替主题：人物直接宣读作者观点，事件本身没有证明或反驳。
- 假开放：作者未完成因果，却用“宇宙仍然神秘”掩盖缺口。

## 十二、完整检查清单

- 科学假设是否能用一句反事实问题说明？
- 知识状态是否区分已知、外推、猜想和未知？
- 机制、边界、成本、副作用和后果是否连成一条因果链？
- 科技是否改变至少三类社会制度或关系？
- 世界是否在主角之外持续成立？
- 人物是否通过有限证据、试验和选择理解世界？
- 核心冲突是否包含认知或价值差异？
- 不同立场是否都拥有证据、利益和代价？
- 异质生命或尺度变化是否真正改变规则？
- 作品尺度是否匹配核心问题？
- 未知是否建立在明确证据边界上？
- 高潮是否产生模型修正、价值选择或存在方式变化？
- 主要行动因果是否完成？
- 结局是否留下关于人类、生命、意识、文明、科技或宇宙的持续追问？
