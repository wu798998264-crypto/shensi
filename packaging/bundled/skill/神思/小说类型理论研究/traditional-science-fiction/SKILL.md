# 传统科幻创作理论

## 定位

把未来世界当作思想实验场：先提出科学可能性，再推导存在方式、社会制度、文明结构和人物选择如何改变。不要把科技当装饰、战斗技能或临时剧情工具。

本 skill 归属 [[小说类型理论研究]]。它既可作为严肃科幻创作的专项知识源，也可作为类型顾问诊断大纲、设定和正文；不得覆盖作品 canon，不替代 [[神思-设定生成规则]]、[[神思-大纲与章纲规则]]、[[神思-正文写作规则]] 或对应自检。

正式创作、世界推演或全量诊断前，读取 [[skill/神思/小说类型理论研究/traditional-science-fiction/references/theory|传统科幻创作理论详版]]。

## 固定工作流

### 1. 锁定科学假设

用一句可检验的反事实问题开局：

```text
如果【科学现象 / 技术】成立，并受到【限制与代价】约束，
那么【个人 / 社会 / 文明 / 宇宙认知】会发生什么不可逆变化？
```

标注假设的知识状态：已知科学、合理外推、高风险猜想或刻意保留的未知。不得把幻想包装成已证实事实。

### 2. 建立因果推演链

按以下顺序推导，不得从科技名称直接跳到剧情结果：

```text
科学机制
-> 能做什么
-> 不能做什么
-> 成本、边界与副作用
-> 第一阶生活变化
-> 第二阶制度变化
-> 第三阶文明与存在方式变化
```

每项核心科技至少检查政治、经济、劳动、亲密关系、伦理、法律、阶层和文明结构中的三项影响。

### 3. 选择正确尺度

让尺度服从问题：意识与身份优先使用个人尺度；制度与分配使用城市或社会尺度；文明演化使用星球或星际尺度；存在意义与宇宙规律使用宇宙尺度。不得用个人胜负解决宇宙终极问题，也不得用宇宙战争掩盖本质上只属于私人关系的问题。

### 4. 选择主方向

从八类方向中选择一个主方向，必要时再选一个辅助方向：宇宙尺度、文明演化、人工智能、异质生命、生命进化、意识与精神、微观尺度、时间与空间。主方向决定核心问题，辅助方向只能增加压力，不能争夺主题中心。

### 5. 建立思想问题与对立模型

把主题改写成没有廉价答案的问题，例如“拥有连续记忆是否足以构成同一个人”。至少建立两套内部自洽、都会付出代价的解释或价值模型。冲突优先来自认知差异、价值不兼容、创造者与创造物、生命形式差异、个体与自然规律或个体与宏大真相。

### 6. 让人物承担验证成本

确保世界在删除主角后仍可运行，但叙事必须由具体人物落地。让人物拥有有限信息、现实利益、关系牵连和不可回避的选择；通过观察、试验、误判、修正和付出代价理解更大的世界。人物弧线优先是“无知 -> 理解”“确信 -> 动摇”“恐惧 -> 接受或拒绝”，不默认写成“弱者 -> 强者”。

### 7. 把未知写成可推理边界

允许不解释终极答案，但必须明确已知证据、可验证模型、相互竞争的解释和当前不可知边界。神秘感来自证据不足，不来自作者随时改规则。

### 8. 设计思想余震

高潮必须完成一次模型修正、价值选择或存在方式改变。结局可以失败、存活、迁移、分裂或开放，但必须让此前的科技与世界推演产生不可逆后果，并留下一个比“谁赢了”更大的问题。

## 硬规则

- 科技必须改变世界，而不只是帮助主角解决一次问题。
- 重要能力必须有机制、限制、成本、滥用方式和社会后果。
- 世界必须独立于主角成立，人物也必须对事件拥有能动选择。
- 冲突至少包含一组认知或价值差异，不能只靠单纯善恶敌对。
- 宇宙不为人类或主角提供特殊道德保证。
- 异质生命的差异必须进入感知、时间尺度、思维、需求或交流方式，不能只换外形。
- 未知可以保留，已经展示的规则不得为反转随意失效。
- 主题必须通过事件、制度、选择和后果呈现，不能由角色演讲代替。
- 结局不得仅以升级、击败反派或拯救宇宙冒充思想完成。

## 标准创作卡

```text
科学假设：
知识状态：已知科学 / 合理外推 / 高风险猜想 / 刻意未知
机制与证据：
限制、成本与副作用：
主方向 / 辅助方向：
叙事尺度：
第一阶生活变化：
第二阶制度变化：
第三阶文明变化：
核心思想问题：
对立认知 / 价值模型：
主角的位置、盲区与利益：
关键观察 / 试验 / 误判：
不可逆选择与代价：
结局中的认知改变：
保留的未知：
```

## 最小自检

- 删除科技后，故事是否仍基本成立？若是，科技没有成为核心变量。
- 科技是否至少改变三类社会关系或制度？
- 机制、限制、代价和后果是否形成闭环？
- 世界是否独立于主角运行，同时人物选择仍能改变局部结果？
- 冲突双方是否拥有各自证据、利益与代价？
- 尺度是否与主题匹配？
- 未知是否建立在证据边界上，而非规则缺失？
- 结局是否改变读者对人类、生命、意识、文明或宇宙的理解？

任一核心项失败时，先返修科学假设或推演链，不要用更多设定名词补洞。
