# 复仇爽剧创作概论

## 定位

[[复仇爽剧创作概论]] 是神思网文类型研究中的“情绪债务驱动型高频反转叙事系统”板块。

它研究的不是单一题材，而是一类以“情绪欠债 -> 延迟清算 -> 集中释放”为核心的工业叙事算法，可用于分析和生成：

- 世情短剧
- 婚恋虐恋剧
- 逆袭爽剧
- 误解复仇剧
- 家庭伦理冲突剧
- 阶层羞辱剧

本理论只负责解释类型机制、情绪账本、反转节奏和商业风险，不得覆盖 canon，不得替代 [[神思-正文写作规则]]、[[神思-大纲与章纲规则]] 或具体作品设定。

## 核心定义

复仇爽剧的底层系统可以定义为：

> 情绪债务驱动型高频反转叙事系统（Emotional Debt Short Drama System, EDSDS）。

它的核心不是“复仇事件”，而是“情绪债务流动”：

1. 先让角色被压制、被误解、被否定。
2. 再让观众知道存在未结算的不公。
3. 持续推迟真相和反击。
4. 最后用身份、权力、关系或立场反转一次性清算情绪债。

一句话概括：

> 把“剧情”降级为载体，把“情绪债务流动”升级为主系统。

## 三条硬指标

复仇爽剧生成时必须同时满足三条硬指标：

1. 情绪密度持续上升。
2. 信息永远不完全结算。
3. 爽点必须延迟，但不可缺席。

如果一集只制造压制却不给观众明确的未来清算预期，会变成纯虐；如果太早解决冲突，会丢失短剧追更动力；如果信息一次讲完，会削弱误解、反转和身份揭露的空间。

## 三层债务模型

每一部复仇爽剧都应同时运行三条情绪债务线。

### 1. 羞辱债

羞辱债负责制造情绪欠账。

常见表现：

- 主角被轻视。
- 主角被误解。
- 主角被当众否定。
- 主角被权力、身份、亲缘或舆论压制。

升级顺序通常是：轻 -> 中 -> 重。不能一开场就把羞辱强度打满，否则后续很难继续加压。

### 2. 信息债

信息债负责制造追看动力。

常见表现：

- 真相被隐藏。
- 身份被误认。
- 关键证据被延迟出现。
- 观众知道一点，但永远没有拿到完整答案。

信息债的要点不是“观众全知”，而是“观众比角色多知道一点，但仍然不完全知道”。

### 3. 关系债

关系债负责让冲突变得具体、可痛、可清算。

常见表现：

- 家庭关系错位。
- 爱情关系背叛或误判。
- 权力关系倒置。
- 身份低估与最终身份反转。

关系债决定复仇是否有重量。单纯打脸陌生人通常不如打脸亲人、恋人、老板、家族、阶层共同体更有效。

## 单集 LOOP 结构

每一集应至少包含 2 个情绪循环单位。标准 LOOP 为：

```text
轻冲突 -> 信息误导 -> 羞辱升级 -> 反转悬停 -> 再压一层
```

### 1. 轻冲突

建立不适感，让观众快速知道“这件事不公平”或“这个关系不对劲”。

### 2. 信息误导

给出一个看似合理但不完整的解释，使主角或观众暂时误判。

### 3. 羞辱升级

把冲突从私下不适推向公开压制、身份否定、情绪否认或权力压制。

### 4. 反转悬停

让反转即将出现，但不立刻完成结算。

### 5. 再压一层

在观众以为要释放时继续追加更大的冲突，形成情绪债滚动。

## 30 秒微结构

短剧、漫剧和高密度网文开头可采用 30 秒微结构：

- 0-10 秒：冲突建立。
- 10-20 秒：羞辱或误解升级。
- 20-25 秒：反转即将出现。
- 25-30 秒：强行打断，形成 cliffhanger。

原则：

- 禁止完整解决任何冲突。
- 禁止长铺垫。
- 禁止解释性台词替代现场冲突。
- 开头 30 秒必须已经出现误解、身份压制或情绪冲突。

## 情绪控制引擎

标准情绪曲线：

```text
压制上升 -> 再压上升 -> 更压上升 -> 短爆 -> 再压
```

禁止：

- 平稳推进。
- 长解释。
- 情绪缓冲过长。
- 连续多场没有新增压力。

短爆不是最终清算，只是给观众一个局部确认：主角不是永远无能，真相不是永远沉默，反击不是永远缺席。

## 情绪强度等级

| 等级 | 内容 |
|---|---|
| E1 | 冷漠 / 忽视 |
| E2 | 嘲讽 / 轻辱 |
| E3 | 当众羞辱 |
| E4 | 权力压制 |
| E5 | 身份剥夺 / 社会性否定 |

工业节奏建议：

- 每 3 分钟至少出现一次 E4 以上压力。
- E5 不宜过密，否则会显得情绪失真。
- E1/E2 用于垫压，E3/E4 用于拉追看，E5 用于中段大压制或终局前低谷。

## 信息控制引擎

### 信息三层

| 层级 | 定义 | 功能 |
|---|---|---|
| L1 | 观众已知 | 制造焦虑和优越感 |
| L2 | 角色部分知道 | 制造误解和行动偏差 |
| L3 | 核心真相 | 延迟释放，支撑中段或终局反转 |

### 释放规则

- 每集最多释放 20% 核心真相。
- 每次释放必须同时制造新疑问。
- 大真相应延迟到中段反转、大结局或身份揭露。
- 不允许用旁白一次性讲清所有误会。

## 反转引擎

复仇爽剧常用反转类型：

- 身份反转：被轻视者原来拥有更高身份。
- 权力反转：压制者失去权力，被压者掌握处置权。
- 误解反转：观众或角色之前的判断被推翻。
- 关系反转：亲缘、恋爱、婚姻、主仆、上下级关系重新定义。
- 立场反转：看似敌人的角色成为盟友，看似盟友的角色成为债务源。

反转延迟公式：

```text
爽感 = 压制时间 x 羞辱强度 x 反转级别
```

没有压制就没有爽；没有延迟就没有爆；没有明确清算对象就没有复仇感。

## 角色功能系统

复仇爽剧的角色可先按功能配置，再补人格。

### 1. 压制者

功能：

- 制造羞辱。
- 推动冲突升级。
- 代表错误秩序、阶层偏见、家庭压迫或关系背叛。

### 2. 被压者

功能：

- 承受羞辱。
- 积累情绪债。
- 在关键节点保留反击能力或真相入口。

### 3. 观察者

功能：

- 替观众提问。
- 替观众震惊。
- 通过误判、旁观、补刀或倒戈推动情绪外化。

注意：角色可以功能化，但不能彻底工具化。至少核心被压者需要具备可理解的目标、底线和行动选择，否则会削弱复仇释放的正当性。

## 场景结构

优先使用低成本、高压强、易公开羞辱的场景：

- 家庭客厅
- 公司会议室
- 餐桌
- 婚礼现场
- 医院走廊
- 门口
- 楼梯
- 电梯

原则：

> 越公共，越容易制造羞辱；越亲密，越容易制造关系债；越制度化，越容易制造权力压制。

## 终局机制

终局必须完成 FINAL RELEASE，集中清算全部主要债务。

三重释放：

1. 身份揭晓。
2. 权力反杀。
3. 羞辱反弹。

终局不能只解释真相，必须让压制者承担后果，让旁观者重新站队，让被压者获得情绪位置的回收。

## 与绿帽剧情绪拉扯的关系

[[绿帽剧情绪拉扯概论]] 是认知羞辱、疑似背叛和婚恋误判方向的强情绪子型。

[[复仇爽剧创作概论]] 范围更宽，核心是情绪债务、延迟反转和复仇清算。两者可以叠加，但不能互相替代：

- 如果任务重点是疑似出轨、认知羞辱、判断权剥夺，应优先读取 [[绿帽剧情绪拉扯概论]]。
- 如果任务重点是阶层压制、身份反转、误解复仇、家族羞辱、逆袭清算，应优先读取 [[复仇爽剧创作概论]]。
- 如果两者同时出现，应先判断主情绪债：婚恋背叛感为主时绿帽剧情绪拉扯优先；公开压制和复仇清算为主时复仇爽剧优先。

## 适用边界

适用：

- 短剧剧集大纲。
- 漫剧分集结构。
- 网文强情绪开篇。
- 世情、逆袭、误解复仇、阶层羞辱类剧情诊断。
- 爽点账本、情绪债务和反转释放节奏分析。

不适用：

- 慢热文艺叙事。
- 低冲突日常流。
- 纯悬疑推理。
- 以真实心理疗愈为目标的文本。
- 需要复杂人格弧线优先于情绪工业节奏的作品。

禁止将本理论用于现实报复、骚扰、网暴、侵犯隐私、人肉搜索、非法取证、针对未成年人的羞辱桥段，或针对受保护群体的仇恨煽动。创作中出现复仇和羞辱机制时，应保持虚构边界、平台合规和角色后果逻辑。

## 调用检查表

当任务命中复仇爽剧时，至少检查：

- 是否存在三条债务线：羞辱债、信息债、关系债。
- 单集是否至少有 2 个 LOOP。
- 开头 30 秒是否已经进入冲突。
- 每 3 分钟是否有 E4 以上压力点。
- 每集是否释放过多核心真相。
- 反转是否有清算对象。
- 终局是否完成身份揭晓、权力反杀、羞辱反弹。
- 主角是否只是在挨打，而没有保留行动能力或未来反击入口。
- 压制者是否只会叫骂，而缺少权力、关系或信息优势。
