# 融合型科幻创作理论

## 定位

以网文叙事作为骨架，以传统科幻思想作为深层驱动。让具体人物的命运变化带领读者逐步认识更大的未来世界：爽点负责吸引，世界负责承接，思想负责留下余震。

本 skill 归属 [[小说类型理论研究]]，用于同时要求商业成长与科幻深度的项目。它不覆盖作品 canon，不替代 [[神思-设定生成规则]]、[[神思-大纲与章纲规则]]、[[神思-正文写作规则]] 或对应自检。

本 skill 是协调层，不默认加载两份完整来源。需要细化商业成长、阶段目标与追读循环时，按需读取 [[skill/神思/小说类型理论研究/web-novel-science-fiction/SKILL|网文科幻创作理论 skill]]；需要加强科学边界、社会推演与哲学问题时，按需读取 [[skill/神思/小说类型理论研究/traditional-science-fiction/SKILL|传统科幻创作理论 skill]]。

正式建项、整卷设计或全量诊断前，读取 [[skill/神思/小说类型理论研究/hybrid-science-fiction/references/theory|融合型科幻创作理论详版]]。

## 固定工作流

### 1. 建立双重承诺

同时写清：

```text
表层承诺：主角如何成长、破局并进入更大世界？
深层承诺：核心科技将怎样改变人、社会或文明，并逼出什么问题？
```

两者必须由同一核心科技连接，不能一条写升级、一条另贴哲学主题。

### 2. 对齐成长与尺度

为个人、社会、星球和宇宙四类尺度分别确定主角位置、科技形态、主要冲突和思想问题。尺度提升必须由上一阶段的科技后果触发，而不是换地图；每次主角升级都要同步改变其责任、身份或世界认知。

### 3. 检查科技三价值

每项核心科技必须同时具备：

- 剧情价值：制造行动、危机、目标或转折。
- 成长价值：改变主角能力、关系、身份或选择。
- 思想价值：改变社会、生命或文明定义，并提出问题。

缺一项时，降为辅助科技或返修，不得占据核心设定位置。

### 4. 建立双层科技体系

显层负责读者可感知的等级、能力、装备、资源和文明进度；隐层负责机制、限制、代价、社会后果和伦理问题。每次显层升级必须至少显影一项隐层变化，避免前期只爽、后期突然讲道理。

### 5. 让升级产生改变

固定使用：

```text
升级 = 获得新能力 + 失去旧稳定 + 承担新责任
```

代价不只包括能量和冷却，还可进入身体、认知、关系、身份、制度或文明。重要升级必须留下不可完全撤销的变化。

### 6. 叠加四层冲突

个人、生存和敌我冲突负责即时爽感；制度、阶层和利益冲突负责现实重量；文明理念与生存方式冲突负责宏大感；生命、时间、宇宙与未知冲突负责思想深度。每个阶段至少运行两层，后续阶段逐步让更深冲突反过来改写表层目标。

### 7. 维持主角三重身份

让主角同时是普通人、成长者和观察者：普通人身份提供代入与珍视之物，成长者身份推动行动和升级，观察者身份理解科技后果与文明差异。主角的“人性”必须体现在压力下的具体选择，不用口号证明。

### 8. 运行双螺旋循环

```text
表层：压力 -> 科技破局 -> 可见兑现 -> 新目标
深层：科技使用 -> 世界后果 -> 价值冲突 -> 新问题
```

每个重要爽点必须留下世界后果，每个思想问题必须落到人物选择、关系损失或现实利益。章节以表层线保证追读，卷与阶段以深层线累积主题。

### 9. 完成终局汇合

终局同时结算成长目标和思想问题：主角可以达到力量或文明高位，但必须面对力量不能解决的部分。结局要证明此前的成长方式为何有意义，也要显示它改变或破坏了什么。

## 硬规则

- 商业成长与思想问题必须共享同一核心科技和因果链。
- 主角升级必须同步改变世界尺度、身份责任或认知边界中的至少一项。
- 核心科技必须同时具备剧情、成长和思想价值。
- 显层升级不得脱离隐层机制、限制、代价与社会后果。
- 代价必须进入后续剧情，不能只写在设定说明里。
- 四层冲突必须逐步联动，不能前期打怪、后期突然讨论文明。
- 科技问题必须通过事件和选择显影，不得用长篇演讲代替。
- 更高文明不能只是更高战力，必须拥有不同生存逻辑或价值模型。
- 科幻玄幻融合可以使用超常能力，但必须建立稳定规则、限制和文明后果。
- 终局不能只以最强、称霸或打败终极敌人完成，必须回收存在问题。

## 最小自检

- 表层成长和深层问题是否由同一科技变量连接？
- 主角每次升级是否同步改变世界、责任或认知？
- 核心科技是否同时具备三种价值？
- 显层等级是否有隐层限制、代价和后果？
- 重要代价是否持续影响后续选择？
- 四层冲突是否逐步联动而非分段拼接？
- 主角是否同时保持代入、行动和观察能力？
- 每个爽点是否留下世界后果？
- 每个思想问题是否进入人物处境？
- 终局是否同时完成成长兑现与思想余震？

若作品只剩升级、战斗和装备，返回科技三价值与深层后果；若只剩设定、理论和讨论，返回表层目标、章节行动与可见兑现。
