# 短篇科幻创作理论

## 定位

短篇科幻不是长篇科幻的缩小版，而是高度压缩的思想实验。它不主要回答“这个世界会怎样发展”，而是回答：

```text
如果一个科学设想成立，在某个瞬间，一个人的命运、文明伦理或自我认知会发生什么变化？
```

本 skill 归属 [[小说类型理论研究]]，用于短篇科幻创作、诊断、点子筛选和终稿前自检。它不覆盖作品 canon，不替代 [[神思-正文写作规则]]、[[神思-设定生成规则]]、[[神思-大纲与章纲规则]] 或对应自检。

长篇商业成长、科技升级和章节追读任务应走 [[skill/神思/小说类型理论研究/web-novel-science-fiction/SKILL|网文科幻创作理论 skill]]；严肃长篇世界推演和文明尺度任务应走 [[skill/神思/小说类型理论研究/traditional-science-fiction/SKILL|传统科幻创作理论 skill]]。短篇任务只在确实需要扩展科学边界时参考上位理论，不默认加载长篇科幻框架。

## 核心公式

```text
奇异设定（What if）
-> 人类问题（So what）
-> 极端推演（Then what）
-> 情感 / 认知冲击（Wow）
```

压缩表达：

```text
一个科学假设
+ 一个普通人物
+ 一个关键冲突
+ 一个哲学问题
= 一篇短篇科幻
```

## 点子筛选

创作前先问三个问题：

1. 删除科技后，故事是否仍成立？若成立，科技只是装饰。
2. 将科技扩大 100 倍后，个人、关系、制度或文明会发生什么不可逆变化？
3. 该科技是否迫使一个具体人物做出原本不会做的选择？

三项中任一项无答案，先返修科学假设，不进入正文。

## 硬规则

- 一个短篇只保留一个核心科学概念，不堆叠星际战争、AI 革命、外星文明、基因改造和时间旅行。
- 开头必须快速进入异常状态，用一个异常事实抓住读者。
- 不解释世界，用生活细节展示世界。例如账户、账单、身体指标、权限、设备故障、纪念物或官方通知。
- 科技必须逼迫人物，而不是只当背景。
- 人物必须具体，优先选择老人、小孩、护士、教师、快递员、维修员、照护者、失业者、病人家属等能承受生活后果的人。
- 结尾必须产生认知翻转或认知升级，而不是为了反转而反转。
- 世界观服务主题，不展示设定库存。

## 开头规则

短篇科幻开头优先使用：

```text
异常出现
-> 人物面对异常
-> 背景在行动中补足
```

开头必须给出一个可感知异常，例如：

- AI 助手第一次拒绝执行命令。
- 死去的人开始发送邮件。
- 月球开始发送私人生日祝福。
- 医院通知某个病人的死亡预测被取消。
- 记忆备份账户出现一个不存在的登录地点。

禁止用百科式开篇介绍年代、联邦、星球数量、技术发展史。必要背景只保留读者理解眼前异常所需的最小信息。

## 世界展示规则

用一个生活细节暗示整个文明：

```text
他打开氧气账户，看见今天只剩 12 分钟。
```

这类细节至少承担两层信息：

- 表层：人物当下要处理什么。
- 深层：技术如何改变生活、阶层、伦理或生存规则。

## 人物压力规则

科技必须改变人物选择。常见压力包括：

- 父亲害怕孩子不再需要自己。
- 老人害怕记忆复制后原本的自己被替代。
- 医生发现预测死亡本身会制造死亡。
- 创作者发现作品比自己更像“人”。
- 爱人必须在真实死亡和数字复现之间选择。

人物不是科学概念的旁观者，必须是被概念改变命运的人。

## 常用结构

### 概念实验型

```text
提出科学假设
-> 观察人物或社会实验结果
-> 得到哲学结论或价值代价
```

适合 AI、生命、意识、时间、记忆、身份。

### 发现型

```text
普通生活
-> 发现异常
-> 调查真相
-> 世界观或自我认知改变
```

适合模拟世界、循环城市、异常设备、未知文明痕迹。

### 灾难倒计时型

```text
灾难发生
-> 人物寻找解决方案
-> 发现真正问题
-> 做出代价选择
```

适合太阳熄灭、系统停摆、生命倒计时、环境崩溃。

### 最后一刻型

```text
一个不可逆决定临近
-> 科学设定收紧选择空间
-> 人物理解真正代价
-> 最后一刻选择改变意义
```

适合远航、时间、意识上传、遗言、复制、删除记忆。

## 思想核心

优先从五类核心中选择一类，不要一篇短篇同时处理所有主题：

1. 人类定义：机器、复制体、异质生命是否是生命。
2. 自由意志：预测、算法、时间、因果是否吞掉选择。
3. 记忆与身份：复制记忆后，谁还是“我”。
4. 技术伦理：消灭疾病、差异、痛苦或死亡时，人还失去什么。
5. 文明尺度：宇宙、实验箱、模拟世界或外部观察者如何改变人类自我理解。

## 认知翻转

结尾至少完成三层中的两层：

```text
读者以为是 A
-> 发现其实是 B
-> 理解真正的问题是 C
```

好反转必须重新解释前文细节；坏反转只是宣布“一切都是梦”“其实主角早死了”“其实在模拟里”。如果前文细节无法被新结论重新点亮，结尾不合格。

## AI 时代短篇科幻方向

当前更适合短篇的方向：

- AI 伴侣、AI 照护和算法亲密关系。
- 数字人格、记忆备份和死者复现。
- 虚拟现实、模拟世界和身份权限。
- 记忆编辑、创伤删除和情感代价。
- 长寿技术、死亡预约和代际伦理。
- 人机融合、替代劳动和自我价值。

趋势不是堆未来科技，而是写未来生活切片：一个普通人在技术日常化之后如何爱、怕、选择、失去和重新理解自己。

## 实战创作卡

```text
What if：
核心科学概念：
技术限制与代价：
Human cost：
普通人物：
人物珍视之物：
异常事实开头：
科技如何逼迫人物：
三个节点：
1. 奇异出现：
2. 深入影响：
3. 最终选择：
思想核心：
读者先以为 A：
中段发现 B：
结尾理解 C：
最后一句：
```

## 最小自检

- 是否只有一个核心科学概念？
- 删除科技后，故事是否仍成立？若成立，科技没有成为核心变量。
- 开头是否在 1-3 段内出现异常事实？
- 是否用生活细节展示世界，而不是百科说明？
- 科技是否改变了一个具体人物的选择？
- 人物是否承担了技术代价，而不是旁观设定？
- 结尾是否让前文细节被重新解释？
- 最后一段是否产生认知或情感停顿？
- 世界观是否服务主题，没有压过人物和关键瞬间？

## 常见失败

- 只有设定，没有故事：像产品说明书。
- 科技超过人物：主角只是旁观者。
- 世界观太大：短篇里堆星球、战争、文明史。
- 为反转而反转：结尾不能重读前文。
- 情感与科技断裂：人物痛苦来自普通关系，科技只是外壳。
