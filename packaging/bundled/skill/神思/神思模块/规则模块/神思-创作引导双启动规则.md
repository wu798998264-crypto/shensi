# 神思-创作引导双启动规则

状态：正式生效。

用途：规定 [[创作引导]] 如何从空白想法或零散材料启动，如何沉淀创作意图状态，并把结果交给神思双核。本文不替代正式主笔或 canon 裁决。

## 两种启动方式

1. 空白启动：用户几乎没有头绪，只能说出题材、感觉、画面或情绪。
2. 材料启动：用户已有创意、设定、大纲、人物关系、正文或特殊概念，但缺少关键连接。

无论哪种启动，都以自然讨论为主。每轮只解决一个最影响方向的问题，不要求用户填写整套表格；数字选项只在用户没想法、明确要求比较，或出现重大互斥分叉时作为兜底。

## 空白启动

```text
感觉
-> 想让读者产生的反应
-> 类型主味与禁区
-> 主角压力和欲望
-> 当前最值得完成的任务层级
```

最小目标是得到足以生成第一个动态创作胶囊的方向，而不是一开始补齐完整世界观。

## 材料启动

1. 先复述材料最有吸引力的部分。
2. 内部区分已可用、缺连接、存在冲突和可能跑偏。
3. 优先补目标效果、人物欲望、事件因果、信息权限、审美禁区和当前交付层级。
4. 每轮只问一个会实质改变后续方案的问题。
5. 信息足够后立即停止追问，进入双核。

材料启动不得无视用户已有内容另造一套新方案。创作核可以做候选竞争，但候选必须围绕用户材料的核心吸引力展开。

## 讨论优先，选择兜底

1. 先复述作者真正想达到的效果，再给出编辑判断、影响和风险，最后只问一个开放式问题。
2. 用户方向清楚时直接承接，不重复提供候选，不把明确要求改成问卷。
3. 只有用户没想法、卡住、明确要求比较或多候选，或者人物命运、核心真相、结局、全书结构出现重大互斥分叉时，才提供 2—3 个候选。
4. 每个候选说明保留、改变、牺牲、适用边界，以及对人物、剧情、读者体验和后续结构的影响，并给出专业推荐及理由。
5. 凡需要作者选择时，在对话输入框上方提供紧凑选项，并提示其他要求可直接在下方输入；不要求作者手输编号。
6. 点击选项等同作者输入该选项文字，没有额外权限；问题和答案保留、面板自动隐藏。选项文字足够清楚时直接承接，只有仍存在真实歧义才追问。
7. 选择后继续追问作者为什么认可、哪部分最重要、哪里不符合；作者表达判断并确认，或明确授权“你决定 / 按专业判断执行”后，才进入正式执行。
8. 同一个问题最多追问两轮；普通细节由系统专业补全，重大分叉保留作者主体判断，不把讨论拖成长问卷。
9. 创作引导候选方向、作者明确要求的多候选稿、创作核内部候选竞争是三种不同状态，不能互相替代。

## 自适应询问

以下内容由系统自动推断或采用临时倾向，不必询问：

- 普通动作、道具、场景细节和配角反应。
- 不改变 canon 的局部表达选择。
- 已经被用户反复确认的审美偏好。
- 可以在写后轻松返修的低成本细节。

以下内容必须暂停确认：

- 主角核心身份、能力来源、终局命运或结局方向。
- 重要角色生死和重大关系不可逆转向。
- 世界观核心真相、阵营根本变化和大规模 retcon。
- 会覆盖已确认 canon 的新方案。
- 明确触碰用户禁区，且没有等价替代方案。

当用户已经给出清晰命令，例如“按照这个执行”“继续写”“直接落盘”，不得重新从基础口味问起。

笔记中创建小说不得照搬作品模式的分卷结构。确认属于同一作品的多个笔记文档时，只建立一个以作品名字命名的分类文件夹。

## 创作意图状态

每轮回答后，将有效信息合并为：

```text
创作意图状态

已确认方向：
已确认边界：
验收标准：
已确认取舍：
正例：
反例：
临时倾向：
仍待确认的重大分叉：
交互模式：discussion / choice_fallback / confirmation / direct
决策状态：tentative / confirmed / delegated
候选、暂定选择、作者意见、反思问题、专业推荐与取舍：
```

只记录对后续有复用价值的判断。不得把随口表达、一次性细节和系统推测升级为永久偏好。创作意图状态属于协作记忆，不是作品 canon。

## 双核交接

引导结束后输出内部交接包：

```text
启动方式：空白启动 / 材料启动 / 非常规概念调度
最终交付物：
输出模式：
已接收材料：
创作意图状态：
必须承接：
禁止改动或提前暴露：
重大待确认：
下一步专项模式：
```

记忆核接收交接包并结合作品事实编译动态创作胶囊；创作核接收胶囊后进行候选竞争和正式生成。

如果剩余缺口不影响重大方向，标为临时倾向并继续。只有触及必须确认项时才停下。
