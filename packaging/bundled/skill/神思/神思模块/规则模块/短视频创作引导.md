# 短视频创作引导

状态：正式生效。

用途：为单条剧情短视频、剧情号、AI 剧情短片和带剧情表演的口播建立可执行创作合同。本文负责观看机制、视频风格、表演形式、人物声口、开头与结尾钩子、核心看点、增益方案和制作边界，不替代 [[短视频剧本创作理论]]。最终产物明确为短剧、微短剧、竖屏短剧、真人短剧、漫剧剧本、剧集大纲或多集剧本时，改由 [[短剧剧本创作引导]] 处理。

## 启用边界

- 用户准备创作、构思、续写或重做剧情类短视频时启用。
- 短剧、微短剧、竖屏短剧、真人短剧、漫剧剧本及分集产物不启用本引导；“竖屏”只是画幅时，仍以最终产物是单条短视频还是分集短剧为准。
- 是否启用由最终产物决定，不受当前工作区、打开文档或目录类型限制。
- 纯知识问答、资料整理、摘要和普通笔记不启用；带表演、角色或剧情推进的口播属于本引导范围。
- 只有题材、主题、角色、梗、热点或一句剧情时必须启用，不得据此直接生成正式脚本。
- 用户明确要求“直接写”“必须直出”“不要追问”“按现有信息生成”时，立即停止追问，以临时合同交给对应主笔。

## 引导原则

每轮只处理一个决策簇，同时给出 2—3 个可比较方向、各自的观看效果、制作代价和明确推荐。用户回答后立即合并合同，已确认内容不重复询问。用户说“你决定”“按推荐来”时，将该项记为授权委托，并采用已经说明的推荐。

“3 秒、15 秒、单场景”只作为诊断尺度和制作参考，不得用来牺牲人物因果、压缩必要反应或强迫所有视频套同一模板。

## 必需决策簇

| 决策簇 | 必须挖掘的内容 | 对成品的控制作用 |
|---|---|---|
| `format-platform` | 平台、目标时长、竖屏或横屏、单条完结或连续更新、真人或 AI、口播或纯剧情。 | 决定节拍密度、画面组织和制作格式。 |
| `style-performance` | 视频风格、现实度、表演形式、演员数量、表演强度、镜头前的呈现方式。 | 决定观众第一眼对内容类型的判断。 |
| `character-voice` | 角色身份、关系、说话习惯、口癖是否需要、台词密度、语气、方言或声音辨识度。 | 让角色可记忆，避免所有人说同一种台词。 |
| `audience-payoff` | 目标观众、主要情绪收益、核心看点、看完要得到的满足或认知变化。 | 决定整条视频为什么值得看。 |
| `story-engine` | 主角当前欲望、直接阻碍、对抗关系、升级方式、本条必须发生的状态变化与代价。 | 保证视频不是只有情绪和金句。 |
| `opening-hook` | 第一画面、第一动作、第一句台词、异常或冲突、观众在前段产生的具体问题。 | 决定停留率和开场承诺。 |
| `payoff-escalation` | 中段如何升级、核心看点出现几次、先兑现什么、反转依据、是否增加新的可视化看点。 | 防止有钩子无过程或中段塌陷。 |
| `ending-hook` | 本条完成了什么、最后新增什么问题、关系或局势如何变化、下一条的明确期待。 | 同时控制满足感和追更动力。 |
| `production-boundary` | 场景数、人物数、地点切换、动作复杂度、服化道、特效、连续性、平台尺度和预算限制。 | 确保脚本可拍、可演或可生成。 |

## 风格与表演深挖

视频风格不能只停留在“高级、电影感、网感、搞笑”。必须转成可执行选择，例如：

- 写实生活流、强情绪短剧、冷面喜剧、荒诞反常、悬疑压迫、伪纪录、采访体、监控视角、Vlog 叙事或舞台化表演。
- 单人口播演绎、双人对手戏、多人群像、画外音推动、无台词肢体戏、聊天记录加实拍或 AI 漫剧。
- 表演是克制自然、略带夸张、强节奏喜剧、情绪爆发还是反差式平静。
- 角色是否需要口癖。口癖只能承担身份、节奏、关系或记忆点，不能每句重复；不需要时明确禁止硬加。

## 开头钩子设计

开头必须同时回答三件事：观众第一眼看见什么、立刻产生什么问题、继续看能得到什么。可选钩子包括：

- 可见冲突：动作正在发生，人物已经被迫反应。
- 结果前置：先展示异常结果，再追溯原因。
- 身份反差：角色行为与身份预期冲突。
- 关系失衡：一句话或一个动作暴露权力差。
- 信息缺口：观众知道人物不知道，或人物知道观众不知道。
- 强承诺口播：先明确收益，但必须迅速转成具体事件或证据。

不得只用空泛威胁、无依据倒计时、与正文无关的猎奇画面或“你绝对想不到”充当钩子。

## 核心看点与增强

核心看点必须能用可见事件描述，不得只写“很爽、很虐、很感人”。例如“被压制的人用对方刚说过的话完成反击”比“增加爽点”更可执行。

基础合同完成后必须提出 1—3 个适配本条的增强建议，例如：

- 把抽象冲突变成一个可见动作、道具或空间关系。
- 增加角色声口或表演反差，让同一剧情更有记忆点。
- 提前一次小兑现，再用更大的代价升级局势。
- 给反转补一个观众可以回想起来的视觉依据。
- 把结尾从“突然中断”升级为“已兑现一件事，同时制造一个更具体的新问题”。
- 在不增加场景的前提下，用站位、进退、视线或道具改变权力关系。

建议必须说明预期收益和制作成本，让用户选择、拒绝或委托系统决定。

## 自适应回路

```text
识别内容形态与已有材料
-> 保护现有最强冲突、人物选择和因果
-> 选择最高影响缺口
-> 提供方案、推荐与一个问题
-> 合并答案并重新计算缺口
-> 基础合同完整后讨论看点增强
-> 展示最终合同摘要并确认
-> 交给短视频主笔、专项自检和必要返修
```

已有故事材料时先从材料中提取可用答案，不得让用户重复说明。只有主题或一句梗时，第一轮优先确定“目标观众要获得的主要满足”和“这条视频唯一核心看点”中的更大缺口。

## 停止条件与交接

只有以下条件同时满足时停止追问：

1. 九个必需决策簇均已确认或由用户明确授权系统决定。
2. 至少一次看点增强讨论已经完成，用户已选择、拒绝或授权采用推荐。
3. 已展示压缩后的最终创作合同，用户明确确认可以生成。

内部交接至少包含：平台与时长、画幅、单条或连续、真人或 AI、视频风格、表演形式、角色声口与口癖规则、目标观众、目标情绪、核心看点、开头钩子、人物欲望与阻碍、状态变化、中段升级、局部兑现、结尾钩子、制作约束、尺度禁区和已选增强项。普通道具和低风险动作可由主笔补全，但不得擅自改变这些已确认决策。
