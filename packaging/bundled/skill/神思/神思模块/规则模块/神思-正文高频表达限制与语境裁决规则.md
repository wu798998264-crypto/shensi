# 神思-正文高频表达限制与语境裁决规则

状态：正式生效，正文主笔与全部正文自检共同使用的强制规则。

用途：阻止高频词、固定句式和跨章模板复用替代人物反应、场景因果与作者判断；同时保留确有场景功能的自然用法。词句阈值以本文为唯一来源；钩子选型、时间锚点功能与全文时间密度统一读取 [[神思-开场钩子与时间叙述控制规则]]，不另建冲突标准。

适用范围：小说正文、短篇小说、公众号文章正文（含叙事、评论、科普等），以及短剧、漫剧和短视频剧本中的实际剧情、动作与对白。标题、场次栏、制作参数、提示词字段不按正文频率统计，但不得借字段把模板句带回成品。诗歌不机械套用散文的篇均限额；有意复沓必须登记为母题并满足本文的“有意复现”条件。

## 一、深层病因：限制的是低熵写法，不是孤立字词

全作品复检表明，问题并非某个词“像 AI”，而是模型反复调用低成本的叙事捷径：

1. **否定后重定义**：用“不是 A，而是 B”替代证据、动作和读者自行判断。
2. **反应占位**：用“看着、看了一眼、沉默、没有立刻”替代人物独有的防御、误判和关系动作。
3. **速度代写**：用“立刻、慢慢、猛地、一点点”替代动作发生的原因、阻力与身体过程。
4. **意义封口**：用“这句话、真正、终于明白、他知道”替作者解释心理、主题或规则，提前关闭歧义。
5. **批量槽位泄漏**：保留同一句法，只替换人物、地点、怪物或概念名，导致不同章节共享同一“骨架”。
6. **开头熵坍缩**：用可替换的模板报时、泛化异常、否定判断或“第一反应”启动任何章节，首句可无损搬运。时间词领句本身不是硬禁；只有未通过删除、换时与承接测试的通用报时才进入本项。
7. **时间线代替剧情**：用“次日、随后、片刻后、几分钟后、到了晚上”完成段落和场景连接，跳过人物判断、反制、关系后果与可见状态变化。

因此，裁决顺序固定为：**先查固定模板与开头硬禁，再查语境功能，再查章内密度，最后查跨章复用**。出现次数少不自动合理；确有语境功能也不能无限累积。

## 二、正文主笔的明确限制项

以下表达进入“非必须不可使用”清单。主笔起草时必须优先寻找人物化动作、具体证据、关系行为、物件变化或直接事实；不能用同义词轮换规避。

### 2.1 语境受控词族

- 否定与弱化：`没有`、`不是`、`只是`、`没有立刻`。
- 视线与停顿：`看着`、`看了一眼`、`又看了一眼`、`沉默`。
- 速度与突发：`立刻`、`马上`、`迅速`、`慢慢`、`缓缓`、`一点点`、`猛地`、`忽然`、`突然`、`骤然`。
- 本能占位：`下意识`、`本能地`、`第一反应`。
- 意义解释：`这句话`、`真正`、`忽然觉得`、`终于明白`、`这才明白`、`他知道`、`她知道`。
- 时序指针：`这一次`、`第一次`。

### 2.2 固定句式与骨架限制

下列已经形成批量生产痕迹的句式，正文主笔不得主动生成；仅当它是用户要求逐字保留的外部引文或已登记的作品内固定台词时，才可原样引用，并且不能充当生成正文的第一句：

- “事情 / 现场 / 房间没有立刻结束、安静或恢复。”
- “真正的 X 从来不是 A，而是 B。”
- “X 终于明白，自己要面对的从来不是 A，而是 B。”
- “X 最狡猾的地方，是它总披着 Y 的外衣。它说这只是 A，只是 B，只是 C。”
- “这不是孤立的一次遭遇。”
- “此刻摆在 X 面前的，不只是 A，也是 / 更是 B。”
- “X 的第一反应不是……”
- “先看人。看谁……”
- “有些话一旦说出口……”
- “X 现在比任何时候都……”
- “下一次……会比这一次更……”
- 连续使用“没有 X，没有 Y”“不是 X，是 Y”“不只是 X，也是 Y”完成旁白解释。

不得通过替换“从来不是 / 并非 / 不像 / 更像”“立刻 / 马上 / 当即”“慢慢 / 缓缓 / 一点点”规避。结构与功能相同即视为同一模板。

## 三、三层修改标准

三层不是三个强度档，也不是把同一句话依次润色三遍，而是按问题性质选择不同的最小返修单位。主笔和自检必须先定层，再修改；不得把第一层问题降格成第三层换词。

### 第一层：固定模板硬禁层

- 对象：第二节列出的固定句式、同构槽位句、未登记的跨篇精确 / 近似复用，以及开头窗口内命中的任何第二层或第三层表达。
- 判定：直接阻断，不做“此处似乎合理”的语境放行。
- 修法：至少退回一个完整叙事节拍，重新确定压力来源、人物选择、动作后果和信息落点，再重写句子或段落。
- 禁止修法：只替换人物名、地点、名词槽位、关联词或近义词；这种修改仍按原模板命中。

### 第二层：强占位语境裁决层

- 对象：`没有立刻`、`不是`的解释性 / 重定义用法、本能族、意义解释族、否定后重定义句式和装饰性否定三连。
- 判定：每一处都必须回答功能、相邻证据、不可替代性和密度；默认配额为零的表达不能因为全篇只出现一次而自动通过。
- 修法：把占位判断还原成角色化否认、可观察证据、身体反射、关系动作或不完整且可能出错的人物判断。无法举证时删除整段解释功能，而不是一对一换词。
- 允许保留：只有删除后会损失事实精度、人物声口、关系攻击、证据排除或明确因果时，且仍未超过条件上限。

### 第三层：普通高频密度控制层

- 对象：`没有`、`只是`、视线族、急速族、缓速族、突发族、`沉默`和时序指针族等本身可以自然出现的普通语言成分。
- 判定：配额以内不自动优秀，配额以外也不立即等于禁词；先检查相邻句重复、同段堆叠、同一功能反复承担和整篇节奏，再在条件上限内裁决。
- 修法：优先删去无功能的一处、合并重复信息、改变句子关注点或补足动作因果。不得为了清零词频制造“未曾、旋即、顷刻、徐徐”等生硬替身。
- 允许保留：表达直接、自然、精确，且换词反而损害事实或人物声口时，应保留原词。

统一验收：修改后必须同时满足“原模板骨架消失、原叙事功能由具体内容承接、语义没有被削弱、没有产生生硬同义词、重新扫描通过”。只满足词面变化不算修复。

## 四、开头零容忍闸门

### 4.1 检查窗口

- 小说、短篇和公众号正文：从首个正文字符开始，取**前三个完整正文句或前 150 个汉字，覆盖范围取较大者**。
- 短剧、漫剧和短视频剧本：跳过标题与场次栏，检查前三个实际剧情节拍 / 台词回合或约前 15 秒正文。
- 引文、题记若由用户明确提供，应标为外部固定文本；其后第一个生成句仍按开头检查。

### 4.2 绝对禁止

开头窗口内绝对禁止第二节列出的所有受控词和固定骨架，不接受“此处语境合理”“只出现一次”“为了节奏”等豁免。还必须禁止：

- 可批量套换人物、地点和时段的时间从句或模板报时，例如“凌晨三点，城市一片寂静”。
- 以凌晨、清晨、子夜、三更、具体钟点等领起后只接通用环境，且删去时间、替换时段仍无损成立、随后一至两个叙事节拍也不承接其秩序、感官、异常、限制或后果。
- “事情没有……”“第一反应……”“这一切 / 这一次 / 这句话……”等泛化指代启动。
- 与此前 30 个同类成品开头共享 12 个以上连续实词，或规范化相似度达到 0.75。

开头必须从本篇独有的压力、错误选择、关系动作、关键物件、异常后果或相互冲突的感官事实切入。执行“槽位替换测试”：若只换人物名、地点、时间或题材名仍适用于另一篇，必须重写。

叙事性时间锚点不属于上述绝对禁止：时间若与独有地点、制度、习俗、物件、声响、自然规律或人物感知组成不可替换的时间—场景组合，能够建立时代 / 地域声口、社会秩序、异常、反差、压力或期待，则降为第二层逐条语境裁决。陌生或古代计时词不是单独证据；只把“凌晨”换成“子夜”仍按模板报时硬禁。

## 五、章内频率预算

以下为 2000—2800 汉字标准章节的预算。**默认配额**以内仍须有具体功能；超过默认配额的每一处都必须逐条举证；超过**条件上限**一律返修，不能靠整体观感放行。

| 词族 / 句式 | 层级 | 默认配额 | 条件上限 | 超额仅可能成立的情景 |
|---|---:|---:|---:|---|
| `没有` | 3 | 4 | 8 | 人物化否认、撒谎、审讯或有证据的事实排除；对白不自动豁免 |
| `不是` | 2 | 1 | 3 | 关系反击、身份否认、排除误判；每一处都须裁决 |
| `只是` | 3 | 1 | 3 | 角色主动弱化事实、掩饰或自我欺骗 |
| `没有立刻` | 2 | 0 | 1 | 延迟本身造成可见后果；不能只买停顿 |
| 视线族 | 3 | 2 | 4 | 目光对象提供新证据或改变关系；`又看了一眼`默认 0、条件上限 1 |
| 急速族 | 3 | 1 | 3 | 速度改变结果或暴露人物训练、恐惧与选择 |
| 缓速族 | 3 | 1 | 3 | 过程阻力可见，且速度变化承担信息或情绪作用 |
| 突发族 | 3 | 2 | 4 | 动作 / 惊变章节可到上限；同段不得连续使用 |
| `沉默` | 3 | 1 | 2 | 沉默改变谈判、权力或误判；需写出他人如何应对 |
| 本能族 | 2 | 0 | 1 | 明确的生理反射、训练反应或创伤触发 |
| 意义解释族 | 2 | 0 | 2 | 仅限人物不完整、可能出错的当下判断；每个具体词至多 1 次 |
| 时序指针族 | 3 | 1 | 3 | 精确区分多次尝试、证词或规则轮次 |
| 否定后重定义句式 | 2 | 0 | 1 | 对白中的关系攻击或基于证据的排除；旁白主题总结不豁免 |
| 装饰性三连排比 | 2 | 0 | 1 | 节奏与意义同时递进，且相邻篇章未用同骨架 |

篇幅换算：

- 1200 汉字及以下：默认配额减半并向下取整；零配额仍为零，条件上限减半并至少保留 1 次语境裁决空间。
- 1201—3200 汉字：使用表中配额。
- 3201—5000 汉字：非零配额乘 1.5；零配额不因篇幅自动增加。
- 5000 汉字以上：按每 2500 汉字滚动窗口检查，不得只用总字数稀释局部堆叠。

类型变化只能在条件上限内调整：动作章可放宽突发族，审讯 / 辩论场可放宽否定族，关系戏可保留角色化沉默；不得同时放宽多个词族来迁就模板化写法。

## 六、逐条语境裁决

每一处受控表达至少回答四个问题：

1. **功能**：它是在完成角色否认 / 撒谎 / 反击、有证据的排除、精确时序、因果性速度变化，还是已登记母题？
2. **证据**：本句前后哪个动作、物件、关系变化或事实使该功能成立？
3. **不可替代性**：删除该词后是否会丢失事实、声口、节奏因果或误判？只损失“顺滑感”不算必要。
4. **密度**：本词族是否超过默认配额、是否与相邻段或相邻篇章形成同构？

允许保留的功能仅限：

- 角色特有的否认、撒谎、自我欺骗、关系攻击或口头习惯。
- 调查、推理、审讯中的证据排除；结论必须有可观察依据。
- 多轮尝试、规则轮次或证词差异所需的精确时序。
- 不可替换的时间—场景组合：时间与地域 / 时代制度、习俗、物件、声响、自然规律或人物感知绑定，删除或换时会损伤场景身份、题材声口、社会秩序或异常判断，且随后一至两个叙事节拍存在承接。
- 速度变化确实改变动作结果、暴露身体状态或形成因果。
- 用户指定引文、法律 / 技术精确定义，或已经登记且发生功能变化的母题。

下列理由一律不成立：营造氛围、增强悬疑、让句子更高级、过渡更自然、强调情绪、读起来顺、网文常用、人物需要停顿。对白也不是自动豁免区；若换成任何角色仍成立，视为作者模板。

## 七、跨篇与批量复用闸门

1. 当前成品须与此前 20 个同类成品比较；开头比较此前 30 个。
2. 规范化后连续 20 个以上汉字完全相同的段落，不得跨篇复用。
3. 40 汉字以上段落与既有段落相似度达到 0.82，必须人工 / 模型复核；若仅替换名词、数字、地点或人物，直接判为模板复用。
4. 同一批次有 3 篇及以上出现同骨架段落，判定为“批量模板坍缩”：停止后续生成，废弃受影响候选，从场景因果重新起草，不能逐词洗稿。
5. 同一成品内部重复 40 汉字以上段落，除已登记复沓外直接返修。
6. 有意复现必须登记原句、首次位置、再次出现的间隔和本次新增功能。普通母题同一卷最多 3 次，且每次必须改变人物理解、关系位置或后果；口号、法定誓词和用户指定固定台词按项目规则另行锁定。

## 八、所有自检的统一执行协议

任何标准自检、强剧情自检、常规推进自检、满血自检、作者化 / humanizer、自定义用户自检、短剧自检和程序语言扫描，只要对象包含正式正文，就必须输出或内部形成：

1. 开头零容忍：通过 / 不通过，以及命中位置；时间领句须先分类为模板报时、叙事性时间锚点或因果性时间锚点，只有模板报时属于开头硬禁。
2. 三层归类：命中属于固定模板硬禁层、强占位语境裁决层还是普通高频密度控制层。
3. 固定模板：精确命中与结构近似命中。
4. 词族计数：汉字数、默认配额、条件上限、实际次数。
5. 逐条裁决：词、位置、功能、证据、不可替代性、保留 / 返修决定。
6. 跨篇复用：比较范围、精确重复、近似重复、批量坍缩判断。
7. 返修后复扫：同义替换不得视为修复；必须确认叙事功能已经由具体内容承接。

任一开头硬禁、固定模板硬禁、条件上限超标、未完成的逐条裁决、未登记的跨篇复用或批量模板坍缩，均为阻断项，不得落盘、不得进入下一章 / 下一集、不得声称全文通过。

## 九、校准与维护

频率阈值来自全作品复检后的去异常基线：已发生大规模段落复用的项目只用于提取风险模板，不参与“正常频率”校准，避免异常样本抬高上限。阈值刻意低于现有语料中位水平，因为目标不是复制旧习惯，而是迫使主笔用人物化、场景化表达替代省力句法。

新增作品复检时，先看每万字频率、篇章覆盖率、开头覆盖率、相邻篇章同构率和段落复用率，再决定是否调表。不得因为某词在整个语料中常见就放宽；只有它在多种作者化场景中承担稳定、不可替代功能时，才可调整条件上限。调整必须在本文完成，其他自检只引用。
