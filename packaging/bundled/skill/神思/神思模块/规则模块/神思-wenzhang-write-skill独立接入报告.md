# 神思-wenzhang-write-skill隔离评估

评估日期：2026-07-22

评估对象：第三方 `wenzhang-write-skill` 与神思本地端的集成边界。

来源记录：`https://github.com/lyc19900620/wenzhang-write-skill`

## 最终结论

不把第三方原包、范文库、固定署名或口令作为神思可信内置规则，也不在运行时读取用户主目录中的副本。

原因：

- 来源未提供可确认的再分发许可，不能直接进入正式安装包。
- 原 Skill 含强制品牌署名与明文口令，自动加载会污染普通公众号输出。
- 原 Skill 要求读取范文库，但旧运行时只加载单个 `SKILL.md`，能力合同并不完整。
- 以用户目录回退会造成开发机可用、干净安装失效，破坏可复现性与数据边界。

神思使用自有的 [[skill/神思/公众号文章创作理论/public-account-humanizer/SKILL|公众号文章人味优化 Skill]] 提供诊断和返修能力，并由 [[神思-公众号去AI味规则]] 约束事实、隐私、改动范围和检测承诺。

## 第三方导入边界

用户将来仍可把拥有合法使用权的第三方 Skill 导入“我的 Skill”，但必须经过：

1. 静态安全扫描与权限声明。
2. 明确的能力槽和显式激活。
3. 署名、品牌、隐私、样本版权与再分发许可检查。
4. 用户数据目录隔离；不得覆盖应用内置能力包。
5. 版本记录、可撤销安装和可迁移导出。

未完成以上检查的第三方 Skill 不能转为官方内置资产。
