# 神思-创作效果验收规则

状态：正式生效，按需深度验收。

用途：当用户要求终稿、完整验收、质量争议或阶段复盘，或 Agent 判断本轮确需独立效果验收时使用。普通任务不固定加载本文全表；需要连续性证据时按需组合 [[神思-记忆检查规则]]。

## 验收边界

本文只判断创作效果与长线风险，不建立第二套常驻 reviewer，不要求未启用的外部运行时 artifact。若项目明确启用了 webnovel-writer，其运行有效性仍由该运行时负责。

## 必检项

| 验收项 | 通过标准 |
|---|---|
| 目标命中 | 产物真正引发本轮指定的读者反应，不只是完成事件。 |
| 人物因果 | 关键行为来自欲望、恐惧、误判、底线、信息差或现实限制。 |
| 场景贡献 | 主要场景完成外部变化，或情绪余波、关系重定位、认知校准、必要定向、对比蓄力中的真实功能。 |
| 情绪承载 | 强情绪有具体处境和形成过程，按叙事模式由行动、对白、物件、后果或具体内心承载，不靠空泛标签。 |
| 承诺处理 | 本轮按章节任务兑现、推进或有充分理由延迟承诺、反制、发现、关系变化或代价。 |
| 人物真实感 | 需要处可见私心、生活反应、职业习惯、嘴硬、误判或不工整反应，不按章强塞毛刺。 |
| 信息权限 | 未提前解释受限信息，未把角色或读者未知当作已知。 |
| 长线价值 | 本轮结果为后续留下可承接的压力、债务、选择或空间。 |
| 结束功能 | 结尾按章节任务形成后续需求、后果、关系位移、余波、阶段兑现或闭合；不统一强塞悬念。 |
| 用户审美 | 没有重新出现用户已明确否定的节奏、措辞和套路。 |
| 概念完整性 | 关键自造概念的身份、剧情功能、可观察表现和解释程度没有漂移，也没有被常见套路替代。 |
| 叙事形态 | 已锁定的真实时序、呈现顺序、视角边界和信息释放得到执行，没有被自动改回普通线性叙事。 |
| 成品隔离 | 正式产物没有混入写作卡、动态胶囊、候选方案、自检、记忆或运行字段。 |
| 内容唯一性 | 无精确/近似正文复用、场景骨架换槽位、固定动作—台词链和批量模板坍缩。 |
| 质量守恒 | 实际修改带来可说明的读者收益，且人物、因果、关系、情绪、信息梯度、声音、类型承诺和后续空间零实质退化。 |

## 候选追溯

高价值节点验收时，若结果“成立但不够强”，先判断是否真正比较过人物本能版、效果聚焦版和意外成立版。没有比较时由当前写作 Skill 补做候选比较；已有比较但效果仍弱时，检查是否把响度当强度，或忽略了必然感、基调一致性、最小必要力度与后续空间。

## 返修补丁

```text
返修补丁

- 当前最强部分：
- 核心失败项：
- 必须保留：
- 必须修改：
- 禁止修改：
- 返回位置：创作引导 / 候选竞争 / 正文局部 / 记忆冲突 / 章纲
- 目标读者反应：
- 修正后的记忆影响：
- 预期与实际读者收益：
- 质量保护资产：
- 退化检查与采用 / 回退：
```

小修只处理局部场次、人物反应、信息显影、章尾或语言。人物驱动、本章功能、信息权限或因果失败时，应返回候选竞争或章纲，不在坏结构上润色。收益无法证实或保护资产下降时保留/回退原文，不为完成验收项强改。

## 报告归档

需要入库时，验收结论写入或更新 `07_编译报告/小说自检.md` 或 `07_编译报告/剧本自检.md`。同一对象只保留最新有效结论，不为单项检查建立无限细分目录。
