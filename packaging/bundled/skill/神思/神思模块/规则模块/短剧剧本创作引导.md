# 短剧剧本创作引导

状态：正式生效。

适用：用户最终希望获得原创短剧、小说改编短剧、漫剧剧本、短剧全集大纲、剧集大纲或单集正式剧本，但关键创作合同仍不完整。

## 启动原则

1. 先锁定来源模式：从零原创，或基于小说、原著、章节、大纲与现有故事改编。来源模式一经确认，必须随当前任务和目标文档持续保存，后续“继续写”不得重新猜测。
2. 最终产物明确为短剧或漫剧时，只使用本引导，不得转入小说创作引导，也不得调用小说正文主笔。
3. 每轮只询问一个最高影响问题，优先顺序为：来源模式、目标形态与集数、核心故事发动机、主角欲望与阻碍、主要情绪承诺、单集时长与平台、制作限制、结尾与长线回收。
4. 原创任务的信息充分标准至少包括：核心前提、主角、核心欲望、主要阻碍、持续升级机制、主要情绪、预计集数或单集范围。
5. 改编任务的信息充分标准至少包括：获准读取的原著范围、必须保留的剧情颗粒、允许调整的部分、目标集数或单集范围、受众与制作限制。
6. 用户明确说“直接写”“直接生成”“不要追问”“全自动”时，立即建立临时剧本创作合同并进入对应原创或改编主笔；不得跳过剧本格式、自检、信息台阶和来源保真门禁。

## 看点增强

基础合同完整后只进行一次看点增强，给出二至三个具有明确成品差异的选择，并说明推荐项。优先增强：不可替代的核心关系、能够持续升级的矛盾机制、付费或追更期待、可表演场面、视觉记忆点，以及终局价值选择。

## 剧本全流程覆盖

当最终产物是原创短剧、小说改编短剧、漫剧、全集大纲、剧集大纲、集纲或单集剧本时，对话区与白板卡片必须使用同一套短剧创作链，不得因入口不同改用小说正文主笔或通用问答。

引导必须能持续覆盖：

1. 项目定位：来源模式、题材赛道、观众、平台、集数、单集时长、制作成本与画面边界。
2. 剧本设定：角色欲望、核心关系、持续对抗机制、可表演冲突、场景与道具限制。
3. 全集规划：故事发动机、阶段升级、付费/追更节点、人物弧、终局选择和回收表。
4. 剧集大纲：每一阶段或每组分集的目标、兑现、反转与承接。
5. 单集集纲：本集开场抓点按 [[神思-开场钩子与时间叙述控制规则]] 从人物问题和本集任务选择，不机械报时或套爆点；随后明确主动行动、冲突升级、情绪或爽点兑现、信息台阶与尾钩。
6. 正式剧本：逐集生成、格式检查、可拍性检查、人物与跨集连续性检查、返修与下一集交接，直至全剧完成。

单集效果必须同时服务全集结构。不得为了当前一集的反转破坏后续回收，不得只看本集起承转合而忽略阶段目标、角色弧和制作连续性。确认生成后，原创项目交给原创短剧主笔，改编项目交给小说改短剧主笔，并强制执行正式格式与短剧自检。

## 结束条件

引导结束时形成压缩合同：

- 来源模式：原创 / 小说改编
- 最终产物：全集大纲 / 剧集大纲 / 单集剧本 / 漫剧剧本
- 核心前提与主要情绪
- 主角、欲望、阻碍与代价
- 持续升级机制与终局方向
- 集数、时长、平台与制作限制
- 必保剧情颗粒或原创禁区
- 用户授权系统代为决定的项目

随后只交给对应的原创短剧主笔或小说改短剧主笔。
