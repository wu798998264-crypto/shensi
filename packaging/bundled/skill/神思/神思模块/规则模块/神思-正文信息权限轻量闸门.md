# 神思-正文信息权限轻量闸门

用途：普通单章正文生成、续写和改写时使用的最小信息权限卡。它不替代 [[神思-正文信息权限规则]]，只把正式生成必须执行的四项边界压缩进标准短链。

## 写前四项

1. 本章允许明说：只使用当前章纲、信息释放表和读者当前知识库已经允许明确揭示的信息。
2. 本章只能显影：尚未轮到揭示的重要信息，只能通过异常、物件、行动后果、称呼错位、误判或局部证据出现。
3. 本章必须隐藏：作者知道但角色或读者尚未知的幕后真相、终局答案、真实身份、完整规则和后续结果不得进入旁白、台词、标题、梦境、系统提示或解释。
4. 本章信息动作：每条重要信息只允许处于“不出现、首次登场、推进可疑、维持误判、局部揭示、正式揭示、解释完成”中的一个状态；不得跳级。

## 写后闸门

- 首次登场必须有可感知的场景承载，不能第一次出现就讲透答案。
- 读者未知的信息不得被叙述当作已知事实。
- 若候选需要提前改变揭示顺序，必须进入待确认事项，不得静默改写信息台阶。
- 记忆增量中的同一重要信息必须沿用既有信息 ID；没有 ID 时按稳定信息名称建立一次，后续只更新状态，不重复追加新条目。

任一项失败属于信息权限硬冲突，候选不得进入可落盘状态。
