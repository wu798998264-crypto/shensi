# 神思-本章创作合同模板

状态：兼容保留，按需启用。

用途：当外部运行时、固定工作流或用户明确要求必须使用字段化合同输入时，把 [[神思-记忆核运行卡]] 生成的动态创作胶囊转换为固定格式。神思原生双核正文不再强制生成独立合同。

## 启用条件

仅在以下情况使用：

- 明确启用 webnovel-writer 或其他需要固定字段的外部执行器。
- 团队协作需要把章节约束交给另一位主笔。
- 用户要求查看或保存章节合同。
- 排查外部执行器多次偏离任务的问题。

普通单章、多章连续生产和神思原生写作，直接使用动态创作胶囊即可。

## 胶囊到合同的映射

```text
本章创作合同

一、目标
- 本章核心任务：
- 目标读者反应：
- 本章结束后必须发生的变化：
- 章尾具体期待：

二、人物与因果
- 相关人物欲望：
- 恐惧/底线：
- 合理误判：
- 关系位置与情绪债：
- 必须承接的事实和后果：

三、信息权限
- 可明说：
- 只能弱显影：
- 只能维持可疑或误判：
- 禁止出现：

四、审美约束
- 正例：
- 反例：
- 禁止写成：
- 本章特殊取舍：

五、硬边界
- 禁止改动的 canon：
- 时间/地点/资源限制：
- 外部执行器必须返回的产物：
```

## 使用规则

- 合同内容必须来自动态创作胶囊，不另造第二套章节事实。
- 不把完整自检表、语言病灶库和商业理论全文塞进合同。
- 高价值节点的候选竞争由创作核完成，不用合同字段替代推演。
- 外部执行器完成后，仍由记忆核提取记忆增量并检查硬冲突。
- 合同是运行输入，不是 canon，也不是必须长期落盘的章节文档。

## webnovel 适配

启用 webnovel-writer 时，可把合同作为 `CHAPTER_GOAL`、context-agent 任务或等效写作输入。具体 artifact、commit 和同步要求按 [[神思-webnovel-writer运行边界规则]] 与 [[神思-webnovel同步适配规则]] 执行。
