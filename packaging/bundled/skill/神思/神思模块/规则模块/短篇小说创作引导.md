# 短篇小说创作引导

状态：正式生效。

用途：为短篇小说、短篇故事和微型小说建立可执行创作合同。本文负责短篇分类、基础设定、人物发动机、叙事结构、叙事方式、核心看点、深度取向、节奏、结尾余味和增强建议，不替代小说正文主笔或 [[小说类型理论研究]]；只有明确命中科幻时才调用短篇科幻理论，不把普通短篇强行改成科幻。

## 启用边界

- 用户准备创作、构思、续写或重做短篇小说时启用。
- 是否启用由最终产物决定，不受当前工作区、打开文档或目录类型限制。
- 阅读分析、知识问答、资料整理、摘要和普通笔记不启用。
- 只有题材、概念、反转点、人物或一段开头时必须启用；不得把一个脑洞直接扩写成缺乏取舍的全文。
- 用户明确说“直接写”“必须直出”“不要追问”“自由补全”时，立即停止追问，以临时合同交给正文主笔。

## 引导原则

短篇容量有限，每个新增元素都必须服务人物选择、核心变化或结尾余味。每轮只处理一个决策簇，并提供 2—3 个方向、各自的阅读效果与明确推荐。回答后立即合并合同，已确认内容不重复询问。用户说“你决定”“按推荐来”时，将该项记为授权委托并采用已说明的推荐。

## 必需决策簇

| 决策簇 | 必须挖掘的内容 | 对成品的控制作用 |
|---|---|---|
| `classification-length` | 类型与子类型、目标篇幅、目标读者、发布场景、读者预期。 | 决定叙事容量和类型承诺。 |
| `premise-setting` | 一句话故事前提、时间地点、必要规则、基础设定、异常点及设定边界。 | 确保世界只保留故事真正需要的部分。 |
| `character-engine` | 主角欲望、恐惧或缺陷、直接阻碍、核心关系、必须选择和不可回避的代价。 | 让故事由人物选择推动，而不是设定展示。 |
| `narrative-form` | 主要叙事结构、第一或第三人称、叙述者可靠性、顺叙倒叙插叙、时间跨度、叙述距离。 | 决定信息如何进入读者视野。 |
| `core-value` | 核心看点、主要情绪、反常小故事或深度质量文的取向、主题问题、故事独特性。 | 决定作品最值得记住的东西。 |
| `progression-reveal` | 场景数量、冲突升级、信息释放、误导边界、反转依据、高潮前的关键选择和节奏。 | 防止中段松散和反转失信。 |
| `ending-aftertaste` | 结尾是行动结果、关系改变、认知翻转、价值选择、命运闭环还是开放余味；读者离开时保留什么。 | 反向控制全文铺垫和删减。 |
| `voice-boundary` | 文风、句式与感官密度、克制或浓烈程度、解释量、尺度、禁区、不要滑向的套路。 | 建立作者质感并避免模板化。 |

## 分类与质量取向

引导必须帮助用户明确短篇主要依靠什么成立，而不是简单贴题材标签：

- 反常小故事：依靠异常设定、强反差、快速反转或黑色幽默抓眼球，必须保证反转前有可回看依据。
- 情绪型短篇：依靠关系、选择和代价制造心疼、治愈、愤怒、恐惧或释然，不能只堆悲惨事件。
- 悬疑或谜题型：依靠信息差、证据链和认知修正，答案必须改变人物或主题，而非只解释机关。
- 现实观察型：依靠具体生活细节和价值冲突，避免把人物写成观点传声筒。
- 深度质量文：依靠人物困境、价值两难、象征或余味，仍然需要明确事件和阅读驱动力，不能以“有深度”为由拖慢故事。
- 类型融合：只保留一个主承诺，其他类型为主承诺服务。

用户可以选择“抓眼球优先”“深度与余味优先”或“先抓人、后转深度”。系统必须说明这种选择会怎样改变开篇、信息密度、反转力度和结尾。

## 叙事结构与叙事方式

根据故事发动机提出 2—3 个适配结构，而不是默认三幕式：

- 线性升级：目标、阻碍、策略、代价逐步升级。
- 结果前置：先展示异常结果，再追索原因与责任。
- 倒计时或封闭空间：用时间和空间压缩选择。
- 双线交汇：两条人物或时间线在关键意义上碰撞。
- 循环与变奏：重复场景逐次改变含义。
- 认知翻转：读者对人物、事件或叙述者的理解被证据修正。
- 切片式：截取一个关键时段，以留白扩展完整人生。

同时讨论第一或第三人称、可靠或不可靠叙述、现在或过去时、近距离或远距离叙述。选择必须服务信息权限和情绪效果，不能只因“更高级”采用复杂结构。

## 核心看点与增强

核心看点必须落在人物、事件或阅读体验上，例如“一个人为了保住关于母亲的最后记忆，主动放弃证明自己清白的证据”，而不是“感人、有反转、有深度”。

基础合同完成后必须提出 1—3 个适配增强建议，例如：

- 把抽象主题压进一个必须当场作出的选择。
- 给反转增加早期细节、重复意象或行为证据。
- 删除不能改变选择或结尾含义的设定与配角。
- 让高潮同时改变行动结果、关系和主角自我认知中的至少两项。
- 设计一个贯穿物件、动作或句子，在结尾发生意义变化。
- 在抓眼球的异常前提下补一层现实情感或价值代价。
- 在深度型故事中提前设置一个具体问题，避免开篇只做氛围铺陈。

建议必须说明会增加什么效果、需要补什么铺垫以及可能牺牲什么。

## 自适应回路

```text
识别已有概念与材料
-> 把概念压到人物欲望、选择和代价上
-> 选择最高影响缺口
-> 提供方案、推荐与一个问题
-> 合并答案并重新计算缺口
-> 基础合同完整后讨论看点增强
-> 展示最终合同摘要并确认
-> 交给小说正文主笔、效果检查和必要返修
```

用户只有概念时，第一轮优先确定“谁因这个概念被迫作出什么选择”；用户已有材料时，先指出其中最值得保留的选择、代价和余味，再追问缺失连接。

## 停止条件与交接

只有以下条件同时满足时停止追问：

1. 八个必需决策簇均已确认或由用户明确授权系统决定。
2. 至少一次看点增强讨论已经完成，用户已选择、拒绝或授权采用推荐。
3. 已展示压缩后的最终创作合同，用户明确确认可以生成。

内部交接至少包含：分类与篇幅、目标读者、故事前提、基础设定、主角欲望、阻碍、核心关系、关键选择、代价、叙事结构、视角与时间组织、核心看点、质量取向、信息释放与反转依据、高潮功能、结尾作用与余味、文风执行规则、禁区和已选增强项。次要人物、普通场景和可返修表达可由主笔补全，不用为追求设定完整拖长引导。
