# 神思-原创化重构规则

显示名称：原创化重构执行规则

状态：正式生效。

适用：小说改写、素材重构、同源文本重写、去 AI 味后的重写、借鉴型创作、小说改短剧 / 漫剧前的素材重构。

本文不鼓励照搬、换名、同义改写或规避相似度。它的目标是把输入素材拆成可复用的叙事功能、情绪机制和类型承诺，再重建为新的角色、场景、动机、事件顺序和表达。

## 触发场景

命中以下任一情况时，先读本文，再进入正文或剧本生产：

- 用户说“洗稿”“改写”“重写”“换一种写法”“去 AI 味”“仿写但不要像原文”。
- 用户提供一段小说、章节、剧情梗概或拆文材料，要求生成新的小说正文。
- 用户提供小说素材，要求改成短剧、漫剧、剧集大纲或剧本。
- 用户要求学习某文本的爽点、节奏、结构、关系拉扯、情绪链或类型机制。
- 用户要求保留核心效果，但不保留原有表达、事件顺序、人物组合或场景设计。

## 三层拆解

处理素材时必须分三层，不能直接进入同义改写。

| 层级 | 可以继承 | 必须重构 |
|---|---|---|
| 功能层 | 爽点功能、压迫功能、误判功能、关系变化功能、信息释放功能、章尾期待功能。 | 不得照搬原桥段的具体事件和场景组合。 |
| 情绪层 | 读者上头原因、情绪推进、羞辱 / 反击 / 心疼 / 悬疑 / 压迫 / 甜虐节奏。 | 不得照搬原文的台词、名场面、独特动作和标志性意象。 |
| 表达层 | 只能学习节奏原则、视角距离、信息密度和句群功能。 | 人名、地点、道具、台词、叙述句、段落结构、独特比喻必须重写。 |

## 原创化重构流程

执行顺序：

1. 素材功能抽取：提取每段承担的剧情功能、情绪功能、信息功能和关系功能。
2. 保留目标确认：确认要保留的是读者反应、类型承诺、人物压力、关系张力还是结构节奏。
3. 高相似风险剥离：列出必须替换的专名、场景、事件顺序、台词、道具、独特设定、标志性动作和名场面。
4. 新方案重建：重设人物身份、动机、场景压力、道具功能、冲突触发点、事件顺序和信息释放方式。
5. 输出重构卡：把新方案交给 [[神思-记忆核运行卡]] 编译为动态创作胶囊，再由 [[神思-创作核运行卡]] 的目标产物模式、[[神思-正文写作规则]] 或 [[小说改编短剧剧本skill]] 执行。
6. 写后相似度风险自检：检查是否仍保留过多原文表达、事件排列、名场面、人物组合和独特设定。

## 原创化重构卡

进入正式正文或剧本前，至少生成以下短卡：

```text
原创化重构卡：
- 输入素材核心吸引力：
- 要保留的读者反应：
- 可继承的功能层：
- 必须剥离的相似风险：
- 新人物 / 新关系：
- 新场景 / 新压力：
- 新事件顺序：
- 新道具 / 新信息承载：
- 新章尾或集尾钩子：
- 禁止保留的表达：
- 后续交给：正文写作 / 短剧改编 / 漫剧提示词 / 诊断审查
```

## 高相似风险清单

以下内容不能只做表面替换：

- 原文人物关系组合：例如同样的身份差、同样的背叛关系、同样的救赎结构。
- 原文事件顺序：例如受辱 -> 反击 -> 公开打脸 -> 身份揭露完全同序。
- 原文标志性场景：例如独特审判、宴会、雨夜、祭坛、课堂、婚礼、战场归来等名场面。
- 原文台词和句式：包括标志性狠话、表白、宣判、反转句。
- 原文独特设定：系统规则、能力机制、世界规则、组织结构、仪式、道具功能。
- 原文意象和母题：反复出现并能识别作品气质的符号。
- 原文节奏模板：每一段的情绪起伏、信息点排列和章尾类型完全一致。

处理要求：只保留“功能”，不保留“具体实现”。例如可以保留“公开羞辱后反击”的爽点功能，但必须重建羞辱场景、证据来源、反击方式、人物关系和后果。

## 改写等级

| 等级 | 适用 | 规则 |
|---|---|---|
| 语言修复 | 用户自己的原文润色、去 AI 味、局部病句修复。 | 可保留事实和事件，只修语言；仍需按 [[神思-正文语言质量规则]] 检查。 |
| 结构重写 | 同一素材改成更强章节、样章或剧本。 | 可保留核心事件功能，但必须重建场景承载、人物行动和信息释放。 |
| 原创化重构 | 借鉴素材机制生成新文本。 | 只保留功能层和情绪层；表达层、人物层、场景层、事件顺序必须重建。 |
| 改编转换 | 小说改短剧、漫剧或提示词。 | 保留原著魂和观看快感，按媒介重构形态；新增内容属于改编产物，不自动回写小说 canon。 |

## 正文链路

小说正文改写、素材重构、借鉴型新写法：

```text
输入素材
-> [[神思-原创化重构规则]]
-> 原创化重构卡
-> [[神思-记忆核运行卡]] 编译动态创作胶囊
-> [[神思-创作核运行卡]]
-> [[神思-正文写作规则]]
-> 正文生成
-> 双核检查；满血或专项命中时再读取 [[神思-正文质量规则]] / [[神思-正文语言质量规则]] / 对应自检
```

若只是用户自有正文的语言修复，可以不生成完整原创化重构卡，但仍需执行语言质量自检。

## 改剧本链路

小说改短剧、漫剧、AI 仿真人剧本：

```text
输入小说 / 章节 / 梗概
-> [[神思-原创化重构规则]]
-> 功能层、情绪层、表达层拆解
-> [[小说改编短剧剧本skill]]
-> 剧集大纲 / 单集剧本
-> [[短剧剧本自检]]
```

授权或指定保留原著时，可以保留角色名、名场面和关键台词；未指定保留时，默认只保留功能和情绪机制，不照搬具体表达。

## 自检要求

交付前必须检查：

- 是否只是换人名、换地点、换同义词。
- 是否保留了原文事件顺序和场景组合。
- 是否保留了标志性台词、独特道具、独特规则或独特意象。
- 是否把原文名场面改成近似场面。
- 是否只在语言层变了，人物动机和冲突结构没变。
- 是否产生了新的明确人物欲望、场景压力、行动因果和章尾 / 集尾钩子。

命中前三项任一项时，不得进入正式交付，必须回到原创化重构卡重建。
