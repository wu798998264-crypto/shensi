# 神思-正文语言质量规则

状态：正式生效。

适用：小说正文的语言清理、机械句式、重复信息、比喻密度、章尾废话、情绪承载和画面感边界。

本文是 [[神思-正文质量规则]] 的语言专项子规则，只在正文成稿后、自检返修、文字质量诊断时读取；不得作为普通正文起草的默认前置全文加载。所有命中先受 [[神思-正文质量净增益与防退化规则]] 裁决，语言指标变好但意义、声音、情绪或节奏下降时必须回退。

高频词族、固定模板、开头零容忍、篇幅配额、逐条语境裁决与跨篇复用的唯一标准读取 [[神思-正文高频表达限制与语境裁决规则]]。钩子选择、三段式开头的非模板化转译、时间锚点功能和流水账密度读取 [[神思-开场钩子与时间叙述控制规则]]。本文保留一般语言病灶，不复制第二套阈值。

## 正文文字自检硬规则

自检文档在检查小说正文时，必须主动识别以下常见文字问题。每次生成小说正文后先诊断，再区分必须修正、增益机会、明确保留和不建议改动；只有净增益成立时才自动修改。

### 1. 禁止模板报时开篇，保留叙事性时间锚点

不得使用可批量替换人物、地点和时段的时间从句或“凌晨三点，城市一片寂静”式模板报时。检查范围、受控词零容忍和跨章开头相似度统一按 [[神思-正文高频表达限制与语境裁决规则]] 的开头窗口执行，不能只检查第一句。时间词领句本身不构成硬禁：先按 [[神思-开场钩子与时间叙述控制规则]] 分类，再执行删除、换时与后文承接测试。时间与独有地点、制度、习俗、物件、声响、自然规律或人物感知形成不可替换组合时，应作为叙事性时间锚点明确保留或进入语境复核；陌生古代计时词不能单独豁免通用环境句。

全文也不得把时间当作段落骨架。按 [[神思-开场钩子与时间叙述控制规则]] 统计非因果性时间锚点和连续时间词领段；期限、证词、选择、时序谜题、状态断裂、连续性或不可替换的时间—场景身份需要时可以保留。超配额命中必须逐条举证，连续两段非因果、可替换的时间词领起直接返修。

### 2. 少用连词

不要在叙事中频繁使用“然后、接着、于是、随后、同时、紧接着”等连词机械串联动作。小说推进应尽量依靠动作、画面、人物反应和场景变化自然衔接。

### 3. 少用关联词

“不是”属于神思小说正文的语境受控词，不得机械使用；“而是、因为、所以、但是、可是、虽然、如果、那么、因此、然而、不过”等关联词也不得频繁用来直接解释人物心理和剧情逻辑。能通过动作、表情、细节、环境暗示出来的，就不要把因果、转折、条件关系说得太满。

同类变体也必须检查，尤其禁止把“不是 A，而是 B”替换成更隐蔽的机械句式：

- “不是……就……”：例如“他不是害怕，就是还没想明白”。除非这是角色口语或明确排比，否则必须改成具体动作、反应或场面后果。
- “没…… / 没……就……”：例如“他没说话”“她没回头，就这么走了”“他没看她，就把门关上”。若缺席本身改变他人判断、关系位置、行动后果或节奏，它就是有效动作；只有作为空白占位、没有任何后果时才改写。
- “没有……只是 / 只……”：例如“她没有崩溃，只是沉默”。若沉默改变了谁的判断、造成关系压力或形成节奏断点，可以保留；没有新功能时才具体化或删减。
- “并不……只是 / 却……”：若只是把判断换成更精致的解释，也按关联词过载处理。

处理原则：先确认功能和删除损失。无功能才删；承担人物口吻、误判、反讽、关系压力、缺席动作或节奏功能时保留。不得机械执行“能删就删”，也不得用同义词替换掩盖原结构。

- 强动作后只写有剧情功能的后果，不补无功能的物理解释。

#### “不是”语境受控词

“不是”不得作为绝对禁词一律删除，也不得只按出现次数放行。正文、自检、返修、改稿、去 AI 味和正式落盘时，每一处命中都必须按 [[神思-正文高频表达限制与语境裁决规则]] 进行功能、证据、不可替代性和密度四项裁决。

允许保留场景：角色口语中的强否认、撒谎、反讽、关系反击；推理或规则判断中排除常识误判，且紧邻文本给出可见证据；主题性排比。保留时必须逐条说明它在当前场景承担的具体功能。无法说明功能，或只是替作者解释心理、规则、意象和情绪，必须改写。

### 3.1 否定解释句式密度

否定解释句式是 AI 正文常见机械句式：先否定一个表层判断，再用后半句重新定义情绪、规则、画面或意义。它容易制造“高级感”和“悬疑感”，但高频出现会让正文变成作者解释，而不是动作发生。

重点扫描句式：

- “不是 A，而是 B。”
- “不是因为 A，而是因为 B。”
- “不像 A，更像 B。”
- “那不是 A，是 B。”
- “这不是 A，这是 / 它是 B。”
- “他不是害怕，而是明白 / 意识到 / 知道……”
- “规则不是 A，它是 / 它利用 / 它要求 B。”

密度阈值统一使用 [[神思-正文高频表达限制与语境裁决规则]] 的默认配额与条件上限。“不是 / 不像 / 而是 / 更像”结构默认配额为 0、标准章条件上限为 1；同一自然段出现即须裁决，超过条件上限直接返修。不得因每一处单独看似通顺就放任整章形成机械节奏。

允许保留：

- 角色口语中的否认、反驳、撒谎、辩解。
- 推理、调查、规则怪谈中排除误判，且下一句立刻给出可见证据。
- 主题性排比，例如“不是破案。不是主持正义。只是确认一个人曾经被记录过。”
- 关系冲突中的立场反击，例如“我不是求你，我是通知你。”

必须改写：

- 用“不是 A，而是 B”替代动作、身体反应或外部后果。
- 用“不是因为 A，而是因为 B”直接解释人物心理。
- 用“不像 A，更像 B”连续制造意象，而不推进场景。
- 用“不是规则说明，而是更深规则”之类句子直接总结设定。

修法优先级：

1. 若 A 不承担排除误判、对照、反讽、人物信条或关系压力，直接写 B。
2. 实时冲突需要亲历过程时优先动作；反思、误判和自我欺骗需要内心时保留具体思维。
3. 物件、环境、身体反应和抽象判断按功能组合，不把通用身体反应当作自动替代品。
4. 规则认知先通过一次错误尝试、代价或环境反馈呈现，不先总结理论。

示例：

```text
原句：那不是声音，是某种更深的震动。
改法：地面先震了一下，杯沿的水纹一圈圈散开。

原句：他不是害怕，而是终于明白了什么。
改法：他盯着那行字，手指慢慢松开，脸上的血色退了下去。
```
#### 关联词与否定句反例库

以下样例用于自检时识别高风险写法；入库目的，是让模型优先判断句子是否承担剧情功能。

高风险反例：

- “它没有张口，没有扑击，也没有露出恶意。”问题：连续否定描述怪物状态，若后文没有马上产生逼近、封路、误判或人物选择变化，就会变成静态解释。处理：静止恐怖可以使用否定句，但否定三连后必须立刻给出正向压迫。
- “他却没有叫。不是因为他能忍，而是因为他知道……”问题：先写“不做什么”，再解释心理逻辑，容易把强生理场景拖成作者说明。处理：痛苦、恐惧、忍耐类场景，不优先解释“为什么没反应”，先写身体代价和外部压力。
- “幻境的规则不是随机杀人。它利用需求……”问题：直接抽象总结规则，像复盘，不像现场推进。处理：规则认知不要先总结成理论，优先通过一次错误尝试、一次代价、一次环境反馈让读者看见规则。
- “真正塌下来的，是陆衡从小相信的天。”问题：情绪结论过早替读者总结，动作后直接升华，容易变成作者替角色感慨。处理：重大打击后，不急着写抽象崩塌，先写人物手上动作、视线偏移、判断失误或当场选择变形。
- “可这些事加在一起，好像已经足够让整个钦天监杀他。”问题：用内心总结解释追杀理由，紧张感被概括掉。处理：追杀、通缉、清算类压力，少用“足够让谁杀他”总结，优先给令牌、脚步、封门、搜查口令等可见压力。
- “他没有答案。”问题：空泛内心状态，信息量低。处理：“没有答案 / 不知道 / 想不明白”类句子，除非承担节奏停顿，否则改成错误判断、迟疑动作或被迫选择。
- “他终于明白，名字在这里不是个人信息，而是通向人的入口……”问题：规则总结句过完整，容易像设定说明书。处理：“终于明白”后不要直接给完整理论，最多给当前可用判断；完整规则留给后续验证。
- “他仍旧不相信自己完全没有办法。”问题：意志状态抽象，缺少可见行动。处理：人物不服输不要写成信念判断，写成试探、失败、换办法、付代价。
- “他第一反应是……” / “她下意识想……” / “他本能地觉得……”问题：直接替角色概括心理起点，常把选择、私心和犹豫写成解释句。处理：先写脚步、手、视线、停顿、避让或抓取等可见动作，再让读者从后果中判断人物第一念头；除非是角色自述或强口语反讽，否则按高风险解释句处理。

允许保留的边界样例：

- “不是破案。不是主持正义。只是确认一个人曾经被记录过。”保留原因：否定排比承担主题和人物信条，不是解释动作。
- “不是纸湿了。那一块往里缩……”保留原因：短否定用于排除常识解释，下一句立刻给出更异常、更具体的现场事实。

边界规则：否定句、关联词、排比句可以保留，但必须承担主题、人物信条、认知反转、排除常识误判、关系压力或现场阻力；若只是替作者解释动作、心理、规则或物理状态，必须删改。

### 4. 少用无功能副词

“少用副词”不等于禁用副词。正文自检只处理无功能副词：它们不提供人物口吻、误判、节奏、动作强度、信息差或情绪转折，只是在替作者提前下判断、解释心理、补足情绪或让句子显得顺滑。

重点检查：

- 判断副词：果然、显然、当然、确实、明显、自然、原来、其实。
- 情绪副词：极其、非常、十分、格外、莫名、隐隐、微微。
- 动作副词：立刻、马上、迅速、猛地、忽然、突然、下意识、本能地。
- 模糊副词：似乎、仿佛、好像、几乎、约莫、大概。

处理原则：

1. 若副词只是把“角色看见什么 -> 判断什么”压缩成结论，优先删掉副词，改为可见证据、动作、停顿或身体反应。
2. 若副词只是替情绪加码，例如“非常害怕”“明显愤怒”，优先恢复产生情绪的处境、判断或后果；动作、内心、物件、站位和环境按叙事模式选择。
3. 若副词承担角色口吻、反讽、误判、节奏突停、时间压力或动作强度，可以保留。
4. 是否无功能由自检根据上下文判断，不建立机械禁用词表；同一个词在不同句子里可能保留，也可能删除。

高风险样例：

- “果然，又做梦了。”问题：用判断副词替角色完成“看见异常 -> 判断为梦”的过程。处理：先给异常画面，再让角色以更短、更具体的判断承接，例如“又是梦”。
- “他下意识想躲开。”问题：解释心理起点，缺少可见动作。处理：写脚步、肩膀、手指或视线先动。
- “她明显生气了。”问题：作者替读者判断情绪。处理：写杯盏、停顿、声音、眼神或关系压力。

允许保留的边界样例：

- “他忽然停住。”保留原因：若前后动作链需要瞬时断裂，“忽然”承担节奏功能。
- “果然。”保留原因：若它是角色对白、反讽或误判确认，可以保留为人物口吻。
### 5. 避免无意识重复同一词汇

非排比、非刻意强调的情况下，同一个词不要在相邻句或同一段里反复出现。重点检查“看、走、说、笑、房间、眼睛、声音、害怕、冰冷、黑暗”等高频词。

### 6. 检索并处理重复信息

自检时不能只查重复词，还必须查重复信息、重复判断、重复解释和重复意象。同一信息如果已经通过场景、动作、旁白、台词、回忆或物件交代过，后文再次出现时必须判断它是否承担新功能。

重点检查：

- 旁白说过一次，角色台词又原样确认一次。
- 回忆解释过一次，现实动作又用同一组词重复一次。
- 同一概念连续使用同一组例子，例如“门能开、墙能裂、天能改写”前后重复。
- 同一心理判断用旁白、内心独白和动作反应反复说明。
- 同一设定信息没有升级，只是换句话再讲一遍。
- 同一章尾钩子、危险判断或主题句重复出现，削弱第一次出现的力量。

处理规则：

1. 若第二次出现没有新信息、新情绪、新误判、新反转或新动作功能，必须删除。
2. 若需要保留第二次出现，必须改变功能：第一次负责说明，第二次负责推进、反讽、误判、反转、情绪爆发或后果验证。
3. 旁白和台词不得连续重复同一判断；优先让旁白给出判断，台词给出反应，或让台词给出判断，旁白写后果。
4. 回忆段与现实段可以呼应，但不能机械复述；呼应必须产生对照、升级或打脸。
5. 关键词重复如果是母题、排比或刻意回环，必须确认它有节奏和结构功能；否则按无意识重复处理。
6. 必须把当前正文与此前 20 个同类成品进行精确段落和近似骨架比较；同批次 3 篇以上同构时按模板坍缩处理，不得逐词洗稿。

### 7. 避免连续使用不合时宜的比喻

不要让多个比喻争抢同一焦点，尤其不要使用不符合人物身份、当前情绪、作品母题或场景速度的比喻。数量只定位聚集区，不设跨题材统一硬上限。紧张、争吵、打斗、逃跑、真相揭露等强行动段落优先保证动作、对象和空间清晰；有认知增量且不打断链条的比喻可以保留。

最终标准：小说正文应与题材和章节任务相符，画面/思维推进自然，句子准确，情绪有形成与余波，关键动作清楚。不要用连词过度解释，不要无意识重复信息，不要堆砌漂亮但无用的比喻，也不要为了“干净、克制”抹掉必要的内心、声音和抒情强度。

### 8. 画面感与“可拍”边界

小说正文可以使用“可拍”“画面感”“镜头感”这类质量描述，含义仅限于：读者能看见人物站位、动作路径、物件状态、环境压力、身体反应和场景变化。

本规则不触发 [[短剧剧本自检]]。只有最终交付物是短剧剧本、剧集大纲、漫剧提示词、视频提示词、图片资产提示词或站位线稿图时，才进入短剧与视觉资产规则。

小说正文的“可拍”要求必须通过具体动作、对白、道具、空间、光线、声音、触感和后果实现；不得用“像电影镜头一样”“镜头推近”“可拍感很强”等元叙述替代正文。

### 9. 禁止总结式万能章尾

章节结尾不得使用“这一切才刚刚开始”“真正的风暴还在后面”“命运的齿轮开始转动”“没人知道接下来会发生什么”“更大的危机正在逼近”等万能总结句。这类句子看似有钩子，实际是在用作者总结替代悬念。

需要形成追读的章节可以精准停在以下位置；后果章、关系章和结局还可以停在余波、关系重定位、阶段兑现、意象回声或真正闭合处：

- 角色情绪爆发前后的一瞬间。
- 一个悬而未决的冲突动作。
- 一个新压力刚刚落到人物身上的后果。
- 一个物件、伤口、环境或他人反应暴露出的新信息缺口。
- 一个选择被迫发生，但答案尚未说出的空白处。

章尾处理规则：

1. 删除总结性废话，不用旁白告诉读者“事情还没完”。
2. 按章节任务使用动作、选择、关系、物件、内心余波或环境结果完成结束功能，不统一强塞悬念。
3. 留白必须有可推断证据；需要追读时读者知道等待什么，结局或阶段收束时允许真正闭合。
4. 强情绪段落在力量最完整的位置停下；动作、反应、内心或意象都可成为落点，不追加重复解释。
5. 写后检查最后 1-3 段：如果删掉最后一句总结后钩子更强，必须删除。

错误写法：

```text
他蓦然感到极度痛苦，眼底闪过一丝绝望。这一切才刚刚开始。
```

修正方向：

```text
战报从他残缺的指缝间滑落。

他一言不发，另一只手死死扣住轮椅扶手。
```

前者把痛苦说给读者听；后者让读者从物件、残缺、动作和停顿里自己感到痛。

### 10. 情绪必须有具体形成过程与合适载体

正文不得用空泛标签替代人物痛感、恐惧、绝望、愤怒、羞耻、心动和崩溃。强情绪必须有具体处境、欲望受阻、关系或判断作为来源；实时场景可偏外部承载，反思、关系和文学段落可让具体内心承担主体。不得把所有情绪机械改成身体动作。

可用载体（按当前叙事模式选择，不设固定顺序）：

1. 动作：抓、停、退、摔、扣、避开、攥紧、失手、没能站稳。
2. 物件：战报、杯盏、门槛、血迹、灰尘、断剑、轮椅、旧衣、空床。
3. 身体反应：必须符合人物、伤势与现场，不循环套用“指节发白、喉咙卡住、呼吸断裂”等库存反应。
4. 神态和停顿：不说话、视线错开、笑意停住、迟迟没抬头。
5. 环境压力：风声、塌墙、火灰、雨水、空院、远处哭声、门轴响动。

禁止写法：

- “他感到极度痛苦。”
- “她眼底闪过一丝绝望。”
- “他内心掀起惊涛骇浪。”
- “她终于明白自己已经无路可退。”

抽象词、判断和内心在带有独特立场、认知翻面、自我欺骗或压缩功能时可以保留，不强制排在动作之后；不能用空泛结论代替本应让读者亲历的关键场面。
