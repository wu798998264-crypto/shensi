# 神思-正文质量净增益与防退化规则

状态：正式生效，隐藏底层规则，不作为软件模板、可编辑模块或正式产物展示。

用途：统一裁决正文生成、续写、改写、自检和返修中的质量冲突。目标不是让更多指标变绿，而是让人物、剧情、阅读体验和语言表现获得可验证的净增益，并阻止“越改越平、越检越像模板”。

适用：小说、短篇、短剧剧本、叙事长文以及小说改编剧本。题材专项规则可以补充标准，不能取消本文的质量守恒、内容唯一性和防退化要求。

## 一、最高裁决原则

```text
用户明确意图与已确认 canon
> 人物真实、因果成立、信息权限与类型承诺
> 读者理解、情绪体验与长线可写空间
> 场景和语言表现
> 字数、频次、评分与其他统计信号
```

1. 指标只能定位问题，不能成为正文目标。禁止为了字数、钩子、比喻、句长、动作或信息团指标制造填充内容。
2. “更强”指更符合人物、更准确、更有后果、更能兑现类型承诺，不等于更吵、更狠、更快或反转更多。
3. 修改必须同时满足：目标问题有实质改善；受保护资产没有实质下降；没有制造同级或更严重的新问题。
4. 无法确认净增益时，保留原文并报告风险；不得为了证明自检有用而强行修改。
5. 结构问题回到章纲、场景或候选方案处理，禁止在坏结构上反复润色。
6. 本文与旧规则中的固定配额、统一硬钩子、统一修辞上限或统一篇幅线冲突时，以本文的任务适配和净增益裁决为准；用户明确指定的交付规格除外。

## 二、质量守恒资产

改写前先识别下列受保护资产。未被本轮目标明确否定的资产不得丢失、弱化或被同义词替换磨平。

| 资产 | 必须保护 | 常见误伤 |
|---|---|---|
| 事实与 canon | 身份、时空、能力、物件、伤势、知情状态、既成事件 | 润色时改事实或补出未确认设定 |
| 因果桥 | 动机、触发、尝试、阻力、结果、代价的连接 | 为提速删关键过程，只剩结果 |
| 人物驱动 | 欲望、恐惧、误判、底线、策略和选择痕迹 | 为强剧情让人物降智或突变 |
| 关系压力 | 站位、权力差、亏欠、隐瞒、试探和默契 | 把潜台词改成直白说明 |
| 情绪电压 | 情绪形成、转折、峰值和余波 | 只加身体动作，删掉内心矛盾 |
| 信息梯度 | 角色/读者已知、可推断、未知和误判 | 为讲清过早解释；为悬疑故意写乱 |
| 时空清晰度 | 人物位置、动作先后、指代对象、场景边界 | 压缩后动作无法想象 |
| 声音与节奏 | 叙述距离、句法、幽默、停顿、留白、作者签名 | 统一成安全顺滑的无个性文字 |
| 类型承诺 | 爱情、悬疑、恐怖、动作、喜剧、文学性等核心体验 | 用通用商业规则抹平类型差异 |
| 长线空间 | 未兑现承诺、可升级矛盾和后续选择空间 | 单章追求刺激，提前耗尽底牌 |

任一关键资产明显下降，即使文本更短、更顺、更刺激或评分更高，也判为质量退化。

## 三、问题分级

### A 级：硬故障，必须阻止交付

- canon、时间线、空间、身份、物件、能力或知情状态冲突。
- 动机缺失、因果断裂、结果无来源，或关键过程被一句话/汇报/蒙太奇跳过。
- 人物为推进剧情突然降智、越权知情、无因转性或放弃核心欲望。
- 未授权剧透、作者全知越权、角色说出不可能知道的信息。
- 完整正文、长段落、场景骨架或动作—台词链与近期/项目其他成品精确或近似复用。
- 只替换人名、地点、物件、标题或结果名词，主体场景和句序不变。
- 正式产物混入写作卡、自检、评分、候选、规则名、结尾说明、记忆增量或其他内部内容。
- 关键动作无法执行、指代无法辨认、场景无法定位，已影响基本理解。
- 改编时删掉不可压缩的核心选择、关系转折或后果，只留下剧情摘要。
- 文件缺章、空壳、章集号或文件名异常，正文未完成却标记为完成。

### B 级：语境风险，只能触发复检

- 高频词、关联词、否定重定义、解释句、抽象情绪、身体反应、比喻、单句段落偏密。
- 篇幅偏离、场景数异常、对白比例异常、句长过齐、感官通道单一。
- 章首环境/时间起笔、章尾无悬念、主角暂时不行动、场景表面没有外部变化。
- 叙述多于展示、内心多于动作、说明多于对话、节奏较慢或余波较长。

B 级不能单凭计数判错。必须回答：本处功能是什么；删除会损失什么；是否有更自然且不损失功能的方案；同章和近期成品中是否机械聚集。

### C 级：意图性表达，应主动保护

- 有意义的复沓、回声、口头禅、仪式语、主题意象和结构性重复。
- 与人物身份、时代、地域、职业和关系状态一致的特殊措辞。
- 为节奏、幽默、压迫、哀悼、恍惚或意识流服务的句法偏离。
- 有明确视角来源、不可被通用表达替代的比喻、判断或沉默。

C 级可保留，但每次复现必须产生新含义、新关系或新后果；“作者风格”不能豁免整段、整场或槽位换皮复用。

## 四、章节任务裁决

写作和自检前必须内部确定一个主任务，可有一个次任务。

| 任务 | 核心验收 | 不应强迫 |
|---|---|---|
| 压力/行动 | 目标清楚、阻力升级、动作可追踪、结果有代价 | 长反思、密比喻、无关生活填充 |
| 调查/揭示 | 证据链可回看、误判合理、真相改变行动 | 一次讲透背景、靠巧合交答案 |
| 关系推进 | 立场和权力关系发生可感变化、潜台词成立 | 必须打斗、必须大反转 |
| 后果/余波 | 前事作用于身体、选择、关系和环境 | 人为加入新危机只为钩子 |
| 铺垫/转场 | 方向、资源、承诺或认知重新定位 | 用空景和行程流水账填章 |
| 高潮/兑现 | 前置压力回报、选择不可逆、代价落地 | 临时外挂或再强塞危机 |
| 收束/结局 | 核心承诺完成、余义成立、人物变化可见 | 为追读破坏闭合感 |

章节可以安静，但不能无目的；可以闭合，但不能抹掉真实后果；可以留下未知，但不能靠故意含混冒充悬念。

## 五、叙事模式裁决

同一章可以切换模式，每段按主导功能判断。

| 模式 | 合理功能 | 主要风险 |
|---|---|---|
| 实时场景 | 让选择、冲突和关系变化当场发生 | 动作流水账、空间混乱、句句解释 |
| 概述/压缩 | 跳过低价值重复过程，建立时间尺度和趋势 | 把关键决定、证据、对抗和代价也跳过 |
| 转场/定位 | 交代时空变化、方向和必要背景 | 行程清单、天气模板、重复前情 |
| 反思/内心 | 呈现矛盾、误判、自我欺骗和价值选择 | 抽象结论代替具体思维 |
| 说明/定向 | 降低理解成本，补足规则、身份或因果 | 讲解员对白、封死推断空间 |
| 对话/关系 | 完成交换、试探、隐瞒和权力变动 | 人物同声同气、轮流播报设定 |
| 蒙太奇/余波 | 表现跨度、积累、群像或创伤残留 | 结果清单替代核心戏剧过程 |

关键选择、首次发现、重要证据、主要对抗、关系翻面和不可逆代价原则上需要戏剧化；重复劳动、无新策略的行程和已充分建立的日常可以压缩。

## 六、全因素质量清单

### 1. 意图与类型

- 明确读者为什么读、本章承诺哪种体验，以及本章是制造、兑现、延迟还是重解释承诺。
- 检查题材、受众、平台、叙事距离是否一致。
- 不把商业追读、文学留白、类型刺激或现实质感当成所有作品的统一答案。

### 2. 概念与剧情发动机

- 核心设定应持续制造选择、代价和关系冲突，不只是名词新奇。
- 主角欲望与世界阻力应能长期相互作用。
- 对立力量有自己的目标、资源、判断与适应能力。
- 主题从冲突和选择中生长，不由旁白反复宣判。

### 3. 宏观结构与因果

- 事件由人物选择和既有条件推动，不靠作者便利、偶遇或拖延性误会。
- 每次升级改变风险、资源、关系、认知或行动边界。
- 伏笔可回看；兑现既有前因又产生新理解。
- 支线独立有价值并与主线形成压力或照见。
- 高潮迫使核心人物作出只能由其作出的选择；结局兼具必然感与新鲜感。

### 4. 章节功能

- 章前与章后状态可明确区分，并有不可忽略的变化或完成。
- 存在一个主导读者问题；复杂章节允许支持问题，但层级清楚。
- 承诺得到部分兑现，或有充分理由延迟。
- 相邻章节不重复同类目标、阻力、策略、情绪曲线和结尾功能。
- 删掉后只影响字数的章节应合并或重构。

### 5. 场景

- 进入足够晚、退出足够准；在场人物各有目标和策略。
- 动作、反动作、误读与后果形成链条；转折来自证据、选择、失败或关系变化。
- 空间、距离、视线、物件位置和动作先后可想象。
- 静态场景可用情绪余波、关系重定位、认知校准、必要定向或对比蓄力证明价值，不强制外部翻面。

### 6. 人物与能动性

- 人物以自己的感知习惯、知识结构和价值排序理解世界。
- 欲望、恐惧、底线和自我欺骗并存，避免单一功能人。
- 决策留下“看见—误判/权衡—选择—承担”的痕迹。
- 能动性可表现为行动、拒绝、隐瞒、等待、忍耐、改变解释或主动承受后果，不等于每章先发制人。
- 错误来自人物局限；变化有积累和余波，不一次谈话即治愈或一次刺激即转性。

### 7. 关系与对白

- 同一信息由不同人物说出时，措辞、目的、风险和隐瞒不同。
- 重要对白尽量同时承担信息、行动、关系、情绪、身份中的两项。
- 潜台词来自表面意图与真实需求的差异，不是故意说半句。
- 沉默、回避和不回答只有在改变他人判断、关系位置或行动后果时才成立。
- 不为“身份化”固定塞入怪癖、口头禅或金句。

### 8. 信息与读者认知

- 区分作者知道、角色知道、读者知道和读者可推断。
- 悬疑来自证据不完整或解释竞争，不来自省略必要主语、空间和因果。
- 控制同时出现的新名词、人名、规则与时间跳转，避免工作记忆超载。
- 解释在读者需要且能使用时出现；重复解释必须带来新语境或新后果。
- 留白必须有可推断证据；无证据的空白只是信息缺失。

### 9. 情绪

- 情绪由处境、欲望受阻、记忆、关系和判断共同产生。
- 动作、身体、内心、物件和环境都是载体，没有一种天然高级。
- 峰值前有积累，峰值后有余波；持续满格会让读者麻木。
- 身体反应符合人物和场景，不循环使用通用替身。
- 允许人物说不清、误认或压抑情绪；作者不把每层意义解释完。

### 10. 节奏与张力

- 节奏是重要信息和情绪变化的间隔，不等于短句多、事件多。
- 压力、反应、理解、选择、行动、后果有可读次序。
- 紧张后允许恢复、观察和后果消化；恢复段需增强下一步重量或人物真实感。
- 连续章节保持强弱、快慢、内外、群像/独处和兑现/蓄力波形。
- 不用每章反转、每场翻面、每段刺激制造多巴胺流水线。

### 11. 语言与声音

- 细节由视角人物筛选，优先写其会注意且会误读的事物。
- 名词动词承担精度，形容词、副词和比喻补足不可替代的质地。
- 句长、停顿与段落形态服务认知和动作，不为统计变化而刻意打乱。
- 连接词只在逻辑无法由顺序和语义自然看出时使用。
- 抽象判断若带独特立场、认知翻面或节奏功能可保留；重复解释同一意义应删减。
- 修正保持事实、语气、叙述距离和情绪温度，不做无意义的同义词升级。

### 12. 感官、意象与比喻

- 感官细节少而准，优先影响判断、行动或情绪的信号。
- 比喻来自人物经验、作品母题或当前物质环境，并产生认知增量。
- 密度按场景速度、叙述声音和类型判断；动作高峰少而清，抒情、爱情、怪诞或文学段落可适当提高。
- 连续比喻同效、喧宾夺主或打断动作链时返修；超过统一数字不能单独判错。
- 重复意象必须改变含义或人物关系，否则退化成自动装饰。

### 13. 开头

- 严格执行 [[神思-正文高频表达限制与语境裁决规则]] 的零容忍窗口：已监测固定模板、受控开头词族、泛化指代和近期同型签名不得出现，语境不豁免。
- 尽快提供本篇独有的行动者、压力/异常/欲望、可感对象和最低必要定向。
- 第一句应难以无损搬到另一章；换人名、地点仍成立即独特性不足。
- 命中后重建切入点和信息顺序，禁止换近义词沿用原模板。
- 禁止为避词制造晦涩倒装、丢主语、强行对话、凭空动作或不合时宜的冲突。

### 14. 结尾

- 结尾完成与本章任务相符的具体结束功能，不统一要求悬念式钩子。
- 可接受功能：新压力、选择、后果、关系位移、认知翻面、承诺、余波、意象回声、阶段兑现或真正闭合。
- 强剧情、付费点和短剧集尾需要明确后续需求；后果章、关系章和结局可由余波、意义变化或闭合成立。
- 不用万能总结、作者箴言、主题复述或临时新危机代替前文结果；与近期成品比较功能和句法同型。

### 15. 连续性与世界可信度

- 现实题材遵守现实约束；幻想题材遵守已建立前提、代价和认知边界。可信不等于日常现实主义。
- 巧合可引发麻烦，不能解决核心冲突、免除选择或抹掉代价。
- 能力、制度、技术和社会反应产生二阶后果，不只在需要时存在。
- 伤势、资源、名誉、关系和创伤保留余波，不在下一章自动复原。

### 16. 原创性与反模板

- 每章/集有独立的目标、阻力、策略、转折、代价、结果、关系/信息变化和结尾功能；不要求项项外显，但不得成套同型。
- 精确正文、长段近似、同句序换槽位、同动作—台词链换人名均为 A 级硬故障。
- 登记的口头禅、仪式语或主题回声可保留，但每次必须改变语境、解释或后果。
- 不把“承接—冲突—应对—钩子”等检查项直接写成批量生成模板。
- 批量任务逐章做近期复用检查；模板坍缩时立即停止后续生成，先重建事件差异。

### 17. 生产完整性

- 正式产物只包含读者/观众应看到的内容。
- 写作卡、单集写作卡、本章合同、结尾说明、自检、评分、来源链接、canon 状态和记忆增量必须分离。
- 文件名、章集号、标题、目录与正文状态一致；异常占位符、空壳和短桩不得标记完成。
- 字数/时长剔除元数据和管理内容；剔除后不足按未完成处理，管理文字不能充数。

### 18. 剧本与改编

- 可视化不等于把心理换成动作标签，应寻找可表演的选择、关系反应、调度、道具或声音。
- 调查、争辩、失败、证据确认、关系翻面和惩罚若是核心看点，不得由汇报或蒙太奇全部代替。
- 台词可说、可演、有对象和目的，避免所有人物用同一种结论腔讲剧情。
- 每集动作—反应链和尾拍独立，禁止固定台词、倒计时、推物件或手机弹窗换槽位复用。
- 改编可压缩重复过程，但保护核心选择、情绪因果、关系转折、标志性意象和必要代价，并记录损耗与补偿。

## 七、易误判表达的语境裁决

### 展示与讲述

实时冲突、关键选择、首次发现和关系翻面优先展示；跨时段趋势、重复劳动、必要定向和低价值过程允许讲述。标准是读者是否需要亲历过程才能相信结果，而不是“讲述一律低级”。

### 内心与动作

动作呈现外部后果，内心呈现矛盾、误判和自我欺骗。两者按需组合。把所有内心改成身体反应会减少人物深度；只写内心而没有选择后果也会失去戏剧性。

### 否定与缺席句

“没说话、没回头、没有回答”等在缺席本身改变他人判断、关系或节奏时成立；只是占位时才改写或删除。不得机械执行“能删就删”。

### 重复与复沓

重复形成升级、对照、讽刺、仪式或情绪回声时可保留；沿用省力句式、意义原地踏步或跨章批量复制时必须重构。判断功能变化与分布，不只看次数。

### 篇幅与信息团

用户/项目明确篇幅是交付规格。未指定时，历史默认范围只作参考；场景自然完成、任务充分和阅读密度优先。不得为下限加无后果细节，也不得为紧凑删因果桥和情绪余波。信息团数量是诊断工具，不是配额。

### 钩子与闭合

连载压力章需要后续需求，结局需要闭合，余波章需要残留影响。用“结束功能”判断，不把所有结尾改成电话、门响、新敌人、倒计时或问句。

### 人性化细节

私心、习惯、非最优反应、生活物件和语言毛刺只有在暴露人物、改变选择或增强可信度时才添加。禁止每章固定插入若干毛刺或固定删除若干表达制造人工人味。

## 八、三层修改标准

### 第一层：结构重建

适用：目标错误、人物驱动失败、因果断裂、信息次序错误、模板坍缩、关键过程缺失、章节任务不成立。

动作：重定任务；更换场景切入/退出；重排信息；重建目标—阻力—策略—转折—代价；必要时回到候选竞争。第一层未修复，不进入表层润色。

### 第二层：功能恢复

适用：场景存在，但动作、对白、内心、说明、意象或结尾没有完成应有功能。

动作：补清对象、意图、证据、空间、后果和关系变化；把抽象结论落回必要细节；恢复被压缩的因果桥、情绪余波或潜台词。

### 第三层：语言与密度调整

适用：结构和功能成立，但有冗余、节奏过齐、词族聚集、修辞堆叠、指代模糊或局部不顺。

动作：删重复信息；调句序和段落；用更准确的名词动词；降低无功能聚集；保留声音和意义。禁止把同义词替换冒充三层修改。

问题在哪层就从哪层开始。浅层问题不必强拆结构，深层问题不得只做第三层清洗。

## 九、净增益返修流程

1. **定任务**：确认章节任务、主导叙事模式、类型承诺和目标读者反应。
2. **列保护项**：提取现有事实、因果、人物、关系、情绪、信息、声音和长线价值。
3. **定级定层**：区分 A/B/C 级，选择结构、功能或语言密度入口。
4. **说明收益**：本次修改让读者更清楚、更相信、更在意、更惊讶或更想继续中的哪项上升。
5. **最小有效修改**：只动所需最小范围；结构失败时才扩大。
6. **前后对照**：检查目标问题改善和每项保护资产的变化。
7. **退化检查**：查新增解释、模板、跳步、语气中和、节奏失衡、信息泄露和结尾同型。
8. **裁决**：只有“至少一项实质收益 + 关键资产零实质下降 + 无新硬故障”才采用，否则回退或换方案。

禁止多个自检器顺次各自重写全文。先合并问题、去重、按优先级形成一张返修单，再由一个主笔执行；每轮最多一次结构返修和一次针对性语言复核，仍有 A 级故障时例外。

## 十、自检统一输出

所有正文自检至少内部区分：

- **必须修正**：A 级故障，或有证据证明破坏本章任务的 B 级问题。
- **增益机会**：不阻断交付，说明预期收益与修改风险。
- **明确保留**：容易被机械规则误杀但确有功能的表达或段落。
- **不建议改动**：收益不确定、会伤保护资产，或需要缺失资料才能判断。
- **资料缺失**：无法验证 canon、前后承接、平台或类型要求。

自动修改后内部形成质量差值单：

```text
目标缺陷：
采用层级：结构 / 功能 / 语言密度
预期读者收益：
保护资产：
实际改善证据：
退化检查：无 / 有（列明）
裁决：采用 / 回退 / 需人工决定
```

高频、字数、句长、对白比、感官和评分可作为证据，但不得单独决定总判定。商业评分只在用户或项目明确商业/平台目标时启用，并按章节任务调整权重。

## 十一、最低通过条件

1. 无 A 级硬故障。
2. 开头零容忍、固定模板和跨篇内容唯一性硬门通过。
3. 本章主任务成立，关键结果有可追踪因果与人物选择。
4. 读者可分清必要时空、对象、知识边界和问题层级。
5. 类型承诺、本章情绪和人物声音未被通用规则抹平。
6. 所有实际修改至少带来一项可说明的阅读收益。
7. 质量守恒资产零实质下降；有下降即回退，不能用总分抵消。
8. 正式产物无内部管理内容，文件与完成状态一致。

最终目标不是“没有任何风险词”，而是让每一章都成为只有这部作品、这些人物、这个时刻才能发生的文本。
