## 旧核心要求的去向

| 原要求 | 双核位置 |
|---|---|
| 读者最强反应 | 动态创作胶囊：目标读者反应 |
| 本章推进内容 | 动态创作胶囊：必须发生的变化 |
| 主角能动性 | 创作核：按章节任务判断行动、拒绝、隐瞒、等待、解释变化或承受后果 |
| 必须隐藏的信息 | 记忆核：读者信息状态与硬边界 |
| 局部兑现 | 创作核：场景变化与效果复核 |
| 章尾功能 | 动态创作胶囊与创作核按任务检查追读、后果、余波、阶段兑现或闭合 |
| 平台或读者承诺 | 创作意图状态；明确商业任务时读取商业规则 |
| 人物私心和生活质感 | 创作核：有功能时自然显现，不设按章配额 |
| 内容唯一性与修改防退化 | [[神思-正文质量净增益与防退化规则]] |

## 当前执行方式

命中旧入口时直接转为：

```text
[[神思-记忆核运行卡]] 编译动态创作胶囊
-> [[神思-创作核运行卡]] 小说正文模式
-> [[神思-正文写作规则]]

```

高价值节点由创作核内部比较至少三种方案；普通章节只执行必要推演。不得因为进入旧核心卡而重新加载完整自检表、独立本章合同或未启用的外部运行时。
