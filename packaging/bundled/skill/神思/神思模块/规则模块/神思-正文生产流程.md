# 神思-正文生产流程

状态：正式生效。

适用：小说正文、续写、扩写、改写、样章、单章协作和多章连续生产。正文效果标准以 [[神思-正文写作规则]] 为准，所有生成与返修以 [[神思-正文质量净增益与防退化规则]] 为隐藏裁决层，默认运行时以 [[神思-双核运行规则]] 为准。

## 主笔与后台

- 主笔：[[神思-创作核运行卡]] 的小说正文模式。
- 写前与写后后台：[[神思-记忆核运行卡]]。
- 用户协作：[[创作引导]]。
- 专项规则：只在明确命中时加载。
- 外部运行时：按需兼容，不是默认前置条件。

已有作品姓名、称谓、人物事实和正式 canon 必须承接。只有新增且未命名的人物才读取 [[神思-命名去污染规则]]。

## 单章短链

1. [[神思]] 裁决输出模式、执行强度和 canon 状态。
2. 读取用户本轮要求与既有创作意图状态；方向明确时不重复追问。
3. 记忆核读取最近必要正文、人物状态、关系位置、因果、伏笔、读者知识、近期表达指纹和禁区，编译含章节任务、叙事模式与质量保护项的动态创作胶囊。
4. 创作核判断是否属于高价值节点；命中时内部构造并比较至少三种场景走法。
5. 创作核按最优方案生成正文，只携带胶囊和当前专项硬规则。
6. 创作核做一次效果复核：人物、因果、情绪、场景贡献、承诺处理、结束功能、内容唯一性和用户反例。
7. 记忆核检查 canon、因果、时间地点、知情边界、关系跳级和未兑现承诺。
8. 局部问题执行一次定向返修；目标或人物驱动失败则退回候选竞争。返修后做质量差值，保护资产下降或收益无法证实时回退。
9. 记忆核生成记忆增量和结构化更新包。
10. 按用户授权交付、落盘或回写。

普通章节不生成独立本章合同，不建立第二套 reviewer，不要求外部 commit。动态创作胶囊可以内部存在，不必作为永久文件落盘。

## 动态创作胶囊最小字段

```text
本章任务与目标读者反应
主导叙事模式与类型承诺
本章结束后必须发生的变化
前章必须承接的动作、后果和情绪余波
人物欲望、恐惧、误判、底线、关系位置和知情状态
必要 canon、因果、时间地点与现实限制
读者已知、可疑、误判和必须未知
未兑现承诺、伏笔和情绪债
用户正例、反例、禁区和本章取舍
质量保护项：事实 / 因果 / 人物 / 关系 / 情绪 / 信息梯度 / 声音 / 后续空间
近期正文、场景骨架、动作—台词链和开头/结尾复用指纹
具体结束功能；承担追读职责时再写章尾期待
```

字段由系统自动补齐。缺失内容不影响重大方向时采用临时倾向，影响重大方向时只向用户询问一个最关键分叉。

## 高价值节点加深

开篇、前三章、高潮、重大虐点、打脸、身份揭示、关系转折、付费节点和结局，自动增加以下内部工作：

- 主要人物心智模拟。
- 三种候选走法竞争。
- 目标读者反应预演。
- 对后续三章以上的因果影响检查。
- 强剧情专项自检或等效硬项检查。

普通过渡章不强制三候选，但仍必须完成可说明的贡献：外部变化，或情绪余波、关系重定位、认知校准、必要定向、对比蓄力，并完成记忆增量。

## 多章连续生产

用户一次要求多章正式正文时，按章节顺序自动循环。每章都独立生成正文和记忆增量，但不要求用户逐章确认：

```text
第N章：胶囊 -> 候选/生成 -> 效果复核 -> 唯一性检查 -> 质量差值 -> 记忆检查 -> 增量
第N+1章：读取第N章增量 -> 新胶囊 -> 继续生产
```

出现以下情况才暂停：

- 会改变已确认 canon。
- 会改变主角命运、核心身份或结局。
- 会造成重大关系不可逆转向。
- 会揭示核心真相或越过用户明确禁区。
- 既有资料相互冲突，无法通过正文事实判断。

其余细节由双核根据创作意图和当前状态自主完成。

## 返修流程

返修先定位责任层：

| 问题 | 返回位置 |
|---|---|
| 用户觉得方向不对、口味不对 | [[创作引导]] 更新创作意图状态。 |
| 场景不够狠、不够爽、不够自然 | 创作核重新进行候选竞争。 |
| 人物行为或关系变化矛盾 | 记忆核给出硬冲突或软风险约束，再由创作核改写。 |
| 语言刻意、总结过多、AI 味 | 局部语言返修；明确命中时读取对应语言或作者化规则。 |
| 章节本身无功能或因果失败 | 打回章节目标或章纲。 |
| 与近期正文、场景或动作—台词链同构 | 停止批量生产，回到章节任务和事件发动机重建，禁止逐词洗稿。 |
| 指标改善但原文优点下降 | 按质量保护项回退，改用更小范围或更高层级的方案。 |

一次定向返修能解决的问题，不重新走完整流程。

## 外部兼容运行时

用户明确要求 webnovel-writer、作品已经接入其运行记录或确实需要 commit/projection 时：

1. 先由记忆核生成动态创作胶囊。
2. 按 [[神思-本章创作合同模板]] 把胶囊适配为固定字段。
3. 外部运行时执行其原生 reviewer 和 commit 链。
4. 双核只验收创作效果、硬冲突和记忆增量，不伪造外部 artifact。
5. 按 [[神思-webnovel同步适配规则]] 同步。

未启用时，上述步骤全部豁免。

## 正文落盘

正式小说正文一章一个 Markdown 文件。结构化作品的单正文源为 `作品/作品名/04_正文/小说/第001卷-卷名/第001章-章名.md`。后续续写、返修、记忆抽取和状态回写均以该单章文件为准。正文文件只保留读者应看到的内容，不得混入动态胶囊、写作卡、候选、自检、评分、记忆增量或质量差值单。
