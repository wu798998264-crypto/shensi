# 神思-正文信息权限规则

适用：长篇小说信息权限、重要信息登场账本、伏笔显影、读者当前知识库、终局泄露检查、大纲到正文的信息降级。

本文件负责防止长篇小说在开头或前期章节中过早泄露终局、幕后真相、世界规则答案和主线谜底。[[神思]] 可以读取作者层面的完整大纲，但正文生产时必须按读者当前可见信息写作，不能把作者知道的终局直接转写成前期正文。信息隐藏同时受 [[神思-正文质量净增益与防退化规则]] 约束：悬疑来自证据与解释竞争，不得靠丢失主语、空间、因果或必要定向制造混乱。

## 信息权限分层

所有长篇小说、连续正文、卷纲、章纲和改稿任务，都必须把重要信息分为四层：

| 层级 | 名称 | 允许存在位置 | 正文使用权限 |
|---|---|---|---|
| S级 | 作者终局真相 | 总纲、终局设计、幕后设定、作者备注。 | 禁止直接进入前期正文；只能作为方向控制。 |
| A级 | 中后期揭示信息 | 卷纲、信息释放表、伏笔管理。 | 只能通过异常、误判、后果、局部证据间接出现。 |
| B级 | 当前卷可见信息 | 当前卷写作包、当前阶段章纲。 | 可以局部揭示，但不得讲透完整答案。 |
| C级 | 当前章可见信息 | 章节功能表、当前章写作上下文包。 | 可以明确写入正文。 |

硬规则：大纲知道终局，不等于正文可以写出终局。AI 可以知道 S级信息，但当前章正文只能使用 C级信息；B级信息需要受本章功能和信息释放表约束；A级和 S级信息只能做暗线控制，不能以解释、台词、旁白、系统提示、梦境、标题、章节名、弹窗、预言、幻象等方式提前泄露。

## 重要信息登场账本

正式长篇项目必须维护该作品完整路径下的 `作品/作品名/01_剧情控制/重要信息登场账本|重要信息登场账本`，或在临时上下文包中生成同等字段。该账本不是伏笔表的重复，而是管理“读者第一次接触重要信息”的独立控制表，用来防止重磅信息首次出现过晚、过早讲透、没有场景承载，或被正文误当作读者已知。

账本至少包含以下字段：

| 字段 | 内容 |
|---|---|
| 信息名称 | 主角身世、核心世界规则、力量体系真相、关键人物真实身份、组织目的、重大旧案、终局反转、地图隐藏层等。 |
| 信息等级 | S级 / A级 / B级 / C级。 |
| 当前读者状态 | 未接触 / 可疑 / 误判 / 局部知道 / 正式知道 / 完全理解。 |
| 首次登场章节 | 第一次让读者看见该信息的正文位置；可以是物件、异常、行动后果、称呼错位或局部证据，不等于解释。 |
| 首次登场方式 | 物件 / 异常 / 台词 / 行动后果 / 误判 / 旁证 / 场景规则。 |
| 首次伏笔章节 | 如该信息同时是伏笔，记录首次伏笔入口。 |
| 局部揭示章节 | 给出部分答案但不讲透核心真相的位置。 |
| 正式揭示章节 | 正文明确告诉读者核心事实的位置。 |
| 解释完成章节 | 完整因果、规则、代价或历史被解释清楚的位置。 |
| 当前允许写法 | 不出现 / 弱显影 / 中显影 / 强显影 / 可明说。 |
| 本章禁写方式 | 禁止台词解释、禁止旁白讲透、禁止标题剧透、禁止系统弹窗明示等。 |
| 风险备注 | 过早、过晚、无承载、一次讲透、读者权限越权、与伏笔显影不一致。 |

硬规则：

1. 每个 S级、A级、影响主线理解的 B级重要信息，正式揭示前必须至少有一次可感知登场或异常承载。
2. 首次登场只能让读者“看见问题”，不能直接给出完整答案；除非该信息本身就是本章 C级明确揭示目标。
3. 正文写作前，章节功能表必须从该作品的 `重要信息登场账本` 中抽取本章相关条目，明确本章是“不出现、首次登场、推进可疑、维持误判、局部揭示、正式揭示、解释完成”中的哪一种。
4. 正文写作中，任何重要信息不得绕过账本临时明示；如果剧情确实需要提前揭示，必须先把该调整写入对应作品完整路径下的 `待确认事项` 或临时结构化更新包。
5. 正文写后，凡本章让读者第一次接触、可疑、误判、局部知道、正式知道或完全理解的重要信息，必须回写该作品完整路径下的 `重要信息登场账本` 和 `读者当前知识库`。

## 终局信息禁写规则

以下内容默认属于 S级或 A级重磅信息，除非该作品完整路径下的 `信息释放表` 明确标注本章允许正式揭示，否则不得在前期正文中明示或半明示：

- 主角最终命运、终局选择、最终牺牲、最终胜负结果。
- 幕后主谋、最终反派、组织真实目的、系统真实来源。
- 世界规则真相、力量体系本质、主线谜底、核心反转。
- 关键人物真实身份、亲缘真相、前世今生、被篡改的历史真相。
- 终局级道具、终局级地点、终局级仪式或终局解决方案。

前期正文允许写的是角色当下能感知的异常和基于有限信息形成的合理误判，不是作者视角下的正确答案。

## 伏笔显影等级

伏笔不是提前告诉答案。伏笔只能制造未来可回收的异常、缺口、错位和代价。每条重要伏笔都应标注显影等级：

| 等级 | 用途 | 允许写法 | 禁止写法 |
|---|---|---|---|
| 弱显影 | 前期埋设 | 错字、错称、细节不一致、记录异常、角色短暂迟疑、无人解释的小后果。 | 直接说出规则名、终局名词、幕后答案。 |
| 中显影 | 中期推进 | 局部证据、反常规律、角色误判被推翻、某个代价被验证。 | 一次性解释完整体系。 |
| 强显影 | 后期揭示 | 正式揭露、规则闭环、真相反转、前文伏笔回收。 | 在开局或前几十章提前使用。 |

长篇开头、前三章、前十章和第一卷前段通常优先弱显影；但类型承诺、开局核心事件或阶段结构需要中/强显影时，可以按信息释放表提前，前提是说明读者收益、替代悬念和后续升级空间。不得用统一章数压住本应兑现的信息。

## 读者当前知识库

正式长篇项目应维护该作品完整路径下的 `作品/作品名/01_剧情控制/读者当前知识库|读者当前知识库`，或在临时上下文包中生成同等内容。该知识库只记录读者已经从正文中明确知道或可合理推断的信息，不记录作者知道但读者尚未接触的幕后真相。

`读者当前知识库` 标准字段：

| 字段 | 内容 |
|---|---|
| 读者已知 | 正文已明确写出或角色公开确认的信息。 |
| 读者可疑 | 正文出现异常但尚未解释的信息。 |
| 读者误判 | 当前希望读者暂时相信的错误方向。 |
| 作者/AI已知但读者未知 | 禁止直接写入正文的幕后信息。 |
| 下一次允许揭示 | 下章或下阶段可释放的信息。 |
| 来源章节 | 信息来自哪一章或哪个已确认结构文档。 |

每次写正文前，[[神思]] 必须区分三类信息：

| 类型 | 定义 | 写作处理 |
|---|---|---|
| 读者已知 | 正文已经明确写出，或角色公开确认过。 | 可以直接承接。 |
| 读者可疑 | 正文出现过异常，但尚无答案。 | 可以继续加压、制造误判、追加证据。 |
| 读者未知 | 只存在于大纲、设定、作者备注中的真相。 | 不得直接写进正文。 |

## 章节泄密闸门

章节功能表必须新增以下检查项。没有完成这些检查，不得进入正式正文输出：

| 项目 | 内容 |
|---|---|
| 本章读者允许知道什么 | 本章可以明确揭示的 C级信息。 |
| 本章只能制造什么疑问 | 本章允许新增或强化的误判、异常、悬疑点。 |
| 本章作者知道但必须隐藏什么 | S级、A级或尚未轮到揭示的 B级信息。 |
| 本章重要信息登场动作 | 不出现 / 首次登场 / 推进可疑 / 维持误判 / 局部揭示 / 正式揭示 / 解释完成。 |
| 本章首次登场承载 | 若有重要信息首次登场，必须写清具体物件、异常、行动后果、台词错位、场景规则或人物误判。 |
| 本章伏笔显影等级 | 弱显影 / 中显影 / 强显影，并说明原因。 |
| 本章禁写方式 | 禁止台词解释、禁止系统弹窗明示、禁止旁白讲透、禁止标题剧透等。 |

若章节功能表中出现“本章要埋下终局伏笔”，必须进一步拆解为“读者会看到什么具体异常”。不能只写“埋终局伏笔”，也不能把终局名词、终局结果、终局身份直接写成画面或台词。

## 大纲到正文的转换原则

长篇大纲可以写清终局，但正文前期不能朝终局明示，而要朝当前矛盾和当前误判推进。

- 作者知道的答案，只负责控制方向。
- 角色当前相信的误判，负责驱动行动。
- 读者当前看到的异常，负责制造追读。
- 正文每章确立一个主导可感知问题；复杂章节可以推进多个支持问题，但要有清晰层级，且不提前发放未获权限的最终答案。

从大纲生成正文时，必须先把大纲节点拆成“当前事件、当前阻力、当前误判、当前代价、当前允许异常”。如果大纲节点包含终局结果、最终反转或世界观答案，正文只能提取其中的情绪压力、行动目标和局部异常，不能提取终局解释。

## 自检新增项

所有长篇正文、续写、扩写和开局样章在输出前，必须新增以下自检：

| 自检项 | 合格标准 |
|---|---|
| 终局泄露检查 | 本章没有提前明示或半明示终局结果、最终反派、世界规则真相。 |
| 信息权限检查 | 正文只使用本章允许的 C级信息；B级以上信息未越权。 |
| 重要信息登场检查 | 本章涉及的 S/A/B 级信息均符合该作品的 `重要信息登场账本`；首次登场有场景承载，未把首次登场写成完整解释。 |
| 伏笔显影检查 | 前期伏笔以异常和误判呈现，不以答案和解释呈现。 |
| 读者知识检查 | 叙述没有把读者未知信息当作已知事实处理。 |
| 悬念寿命检查 | 本章揭示后，主线仍有可持续升级空间。 |

如果任一项不合格，先选择降级显影、恢复证据、改写台词、调整信息次序或推迟揭示中的最小有效方案；修改后按 [[神思-正文质量净增益与防退化规则]] 检查理解成本、人物动机、因果桥和悬念强度，不能为了“隐藏”把文本改得不可理解。
