# 神思-非常规大纲执行卡

显示名称：特殊叙事大纲落地

状态：正式生效。

用途：当章纲、大纲或用户设想包含梦境、幻觉、象征、怪异规则、非线性叙事、错位记忆、民俗异象、意识流、诗性意象、现实与幻想交叠、非常规世界观时，把“难直接执行的大纲”转译成“可写正文的执行方案”。

本文不是某个作品专属规则。它适用于《幻烬》这类幻象设定，也适用于后续任何审美特殊、设定陌生、意象密集、容易被 AI 普通化的作品。

## 触发条件

命中以下任一情况时，正文生成前先使用本文：

- 大纲中有梦、幻觉、幻境、记忆错位、时间错位、身份错位。
- 大纲中有象征物、反复意象、神话化画面、民俗异象或诗性场景。
- 大纲不是常规“目标 -> 阻力 -> 行动 -> 结果”，而是靠氛围、误判、隐喻、规则异常或感知异常推进。
- 用户反馈“按大纲写出来没味道”“太普通”“把特殊设定写成套路”“解释太多”“梦幻感没了”。
- 作品有专属审美，不希望被写成普通玄幻、普通悬疑、普通副本、普通都市异能或普通爽文。

## 不理解时的创作引导调度

执行器遇到无法准确理解的概念、设计或剧情问题时，先判断该不确定点是否会影响正文方向。不会影响正文方向的，写成“临时倾向”并继续推进；会影响正文方向的，按 [[神思-非常规概念引导规则]] 调度 [[创作引导]] 做定向问答。

触发情形：

- 不确定某个概念是字面设定、象征、误判、伏笔还是终局规则。
- 不确定某个怪异画面应该被解释、保留暧昧，还是只作为氛围存在。
- 不确定某个剧情节点的真实功能：爽点、压迫、悬疑、关系变化、人物弧线、世界规则验证或信息误导。
- 不确定用户想要的气质：梦幻、诡异、荒诞、恐怖、浪漫、神圣、滑稽、残酷、宿命或现实锚定。
- 大纲中的陌生设计如果直接执行，会被写成普通套路，且会改变本章目标效果、信息释放、人物行动或章尾钩子。

调度方式：

1. 先用一句话复述执行器当前理解。
2. 指出最多 3 个不确定点。
3. 用 [[神思-非常规概念引导规则]] 和 [[创作引导]] 的顾问式节奏提问，每轮只问 1 个核心问题。
4. 用户回答后，整理为“已确认 / 倾向 / 待确认 / 禁区 / 下一步”。
5. 将已确认与倾向回填到本文“转译字段”和创作意图状态，再由 [[神思-记忆核运行卡]] 编译动态创作胶囊，进入 [[神思-创作核运行卡]]。

不得把用户未确认的解释写成 canon；用户只表达口味倾向时，标为“倾向”或“待确认”。涉及 canon、终局真相、核心设定、人物命运或重大关系转向时，必须停下确认；其他可合理推断内容可先作为临时倾向推进。

## 与双核的区别

[[神思-创作核运行卡]] 负责通用人物模拟、候选竞争、正文生成和效果复核；[[神思-记忆核运行卡]] 负责把本文的转译结果与作品事实合并。

本文负责把非常规大纲翻译成可执行正文方案。

执行顺序：

```text
非常规大纲 / 章纲
-> [[神思-非常规大纲执行卡]]
-> [[神思-记忆核运行卡]] 编译动态创作胶囊
-> [[神思-创作核运行卡]]
-> [[神思-正文写作规则]]
-> 正文生成
-> 双核检查与必要返修
```

若大纲普通、任务清楚、没有特殊审美风险，可以跳过本文，直接进入神思双核正文链。

## 转译字段

使用本文时，先生成以下执行卡，再写正文：

```text
非常规大纲执行卡：
- 表层事件：这一章表面发生什么。
- 真实情绪：这一章真正要制造的读者感受。
- 类型防偏：不能被写成哪种常见套路。
- 异常机制：本章怪异、梦幻、象征或规则异常如何运作。
- 现实锚点：哪些具体物件、身体反应、社会反应、时间、伤口、道具或代价证明事件有重量。
- 意象清单：本章反复出现或必须保留的意象。
- 意象功能：每个意象承担什么功能，不能只是装饰。
- 读者必须看懂：为了跟上剧情，本章必须明确的信息。
- 读者应该困惑：本章故意留下的疑问、误判或暧昧感。
- 不能解释的信息：本章不得讲透的真相、规则、身份、终局或象征含义。
- 人物行动锚点：主角或关键人物在迷离场景中做出的具体判断、选择或动作。
- 任务完成：本章给读者的可确认进展、后果、关系位移、认知校准或阶段闭合。
- 结束功能：结尾承担的具体问题、异常、代价、画面、余波、选择或闭合；不默认必须未解。
- 引导确认结果：来自 [[创作引导]] 的已确认 / 倾向 / 待确认 / 禁区。
```

## 转译原则

1. 不把意象当装饰。每个意象必须承担信息、情绪、关系、伏笔、误判或代价功能。
2. 不把迷离写成混乱。读者可以困惑，但必须知道人物当下在怕什么、想要什么、失去什么。
3. 不把怪异解释成说明书。规则优先通过后果、道具变化、身体反应、环境变化和旁证呈现。
4. 不把特殊设定普通化。遇到陌生设定时，先保留它的审美逻辑，不急着套入常见类型模板。
5. 不让主角在梦幻场景中失去行动。越迷离，越需要具体判断、试探、选择或代价。
6. 不提前破译象征。象征可以被看见、误解、反复出现、造成后果，但不必立刻解释含义。
7. 不牺牲可读性。非常规呈现必须提供足够的认知锚点，并让读者确认本章完成了什么；锚点和完成可以来自物件、身体、社会反应、时间、关系、信息、选择、余波或闭合，不按章固定塞一个现实物件和一个爽点。

## 写后检查

非常规章节写完后，除正常自检外，额外检查：

- 是否把特殊设定写成常见套路。
- 是否用解释替代了场面。
- 是否只有氛围，没有行动和代价。
- 是否只有意象堆叠，没有信息功能。
- 是否过早解释象征、规则或真相。
- 是否没有现实锚点，导致读者无法判断事件重量。
- 是否没有可确认的任务完成或变化，只留下无证据的模糊感。

若命中多项，先返修执行卡，再返修正文。
