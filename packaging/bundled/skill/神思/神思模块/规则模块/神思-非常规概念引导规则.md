# 神思-非常规概念引导规则

显示名称：特殊概念澄清

状态：正式生效。

用途：当 [[神思-非常规大纲执行卡]] 或 [[创作引导]] 的材料启动遇到执行器无法准确理解的概念、设计或剧情功能时，规定如何调度定向问答，并把结果回填到 [[神思-非常规大纲执行卡]]、创作意图状态、动态创作胶囊或后续设定 / 大纲任务包。

本文是专项规则，不替代 [[创作引导]] 的通用顾问式推进；它只处理“用户给出的材料里有关键概念不清楚，且不澄清就会写偏”的情况。

## 触发边界

只有“不确定点会影响正文、设定或大纲方向”时才调度定向问答。

能合理推断的内容，先写成“临时倾向”，不打断用户；涉及 canon、终局真相、核心设定、人物命运、重大关系转向时，必须停下确认。

触发不得只依赖“非线性、意识流、梦境叙事”等固定关键词。用户自造词、首次出现的专名、被赋予特殊因果功能的普通词，以及材料中反复出现但没有稳定定义的词，只要会影响人物选择、世界规则、信息释放或结构形态，也进入内部概念风险判断。

## 概念绑定门

关键概念进入创作核前，内部至少形成：

```text
概念名称：
概念身份：规则 / 能力 / 现象 / 象征 / 伏笔 / 道具 / 地点 / 终局真相影子
剧情功能：
可被人物或读者观察到的表现：
当前解释程度：明说 / 局部暗示 / 允许误判 / 暂不解释
禁止普通化：最不能被写成的常见套路
理解置信度：高 / 中 / 低
事实状态：已确认 / 临时倾向 / 待确认
```

- 材料已有足够证据时自动绑定，不得重复追问。
- 低风险缺口使用临时倾向，不写入正史。
- 低置信且影响重大方向时，最多询问一个最关键字段。
- 用户要求直接输出时不展示问题，但仍生成临时绑定并在写后检查概念漂移。
- 用户确认后写入现有概念设定聚合板或创作意图状态；不得为单个短概念新建原子文档。

## 叙事形态锁

特殊叙事不能只保留风格标签。进入大纲或正文前必须按需锁定：

```text
叙事形态：
真实时间顺序：
正式呈现顺序：
视角与知情边界：
每段认知锚点：
信息释放和误判顺序：
场景或片段转场依据：
每轮/每片新增的有效变化：
禁止线性化或提前解释：
```

写后必须核对呈现顺序、视角限制、信息释放和结构功能。若候选把非线性改回顺叙、由旁白纠正不可靠视角、直接解释梦境或象征，或只保留表面碎片感而没有认知进展，应判为“叙事形态失真”，退回候选竞争，不做表层润色。

## 优先问清

每次只围绕一个不确定点提问，最多连续追问两轮。

是否真正向用户展示问题由 Agent 根据任务推进需要和 [[神思任务路由]] 判断。有限选择使用结构化选择，其余问题直接在对话中说明。

1. 概念身份：这是世界规则、人物误判、象征意象、伏笔、道具、能力、地点，还是终局真相的影子？
2. 剧情功能：它负责制造压迫、爽点、悬疑、关系变化、人物选择、信息误导，还是世界规则验证？
3. 审美方向：它应该更梦幻、诡异、荒诞、恐怖、神圣、滑稽、残酷、浪漫，还是现实锚定？
4. 解释程度：本章要明说、局部暗示、让读者误判，还是完全不解释？
5. 防偏方向：最不能被写成哪种常见套路？

## 回填格式

```text
非常规概念引导结果：
- 已确认：
- 倾向：
- 待确认：
- 禁区：
- 应回填到非常规大纲执行卡的字段：
- 应回填到创作意图状态 / 动态创作胶囊的字段：
```

如果用户暂时不回答，可以给出“临时倾向”，但必须标注待确认；涉及 canon、终局真相、核心设定和人物命运时，不能用临时倾向替代确认。

## 回填对应关系

| 创作引导确认内容 | 回填位置 |
|---|---|
| 用户想要的真实效果 / 审美方向 | 创作意图状态：方向；动态胶囊：目标读者反应 |
| 概念或设计的剧情功能 | 动态胶囊：本轮必须发生的变化 |
| 人物在异常中的选择或代价 | 动态胶囊：人物欲望、底线与必要行动 |
| 不能解释、不能普通化、不能套用的方向 | 创作意图状态：边界/反例；动态胶囊：硬禁区 |
| 本章必须给出的确定进展 | 动态胶囊：局部兑现与必须承接 |
| 本章保留的未解感、异常或画面问题 | 动态胶囊：读者未知与章尾期待 |
| 用户明确的平台气质或读者承诺 | 创作意图状态：方向/验收 |
| 用户偏好的角色反应与生活质感 | 创作意图状态：正例；创作核人物模拟约束 |
