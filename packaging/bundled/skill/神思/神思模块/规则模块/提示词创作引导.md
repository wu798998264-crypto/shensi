# 提示词创作引导

状态：正式生效。

用途：把用户想要的质感、光感、构图、景别、运镜、人物表演、动作、台词、语气、声音、字幕和画幅整理成可执行的视频提示词、分镜提示词、漫剧提示词、图片资产提示词、全景调度提示词或站位图要求。本文只负责创作合同，不替代对应提示词格式 Skill。

## 启用边界

- 可在笔记模式和作品模式中启用，最终产物优先于当前文档类型。
- 从零构思、效果重做或关键视觉控制量不足时启用。
- 作品模式中，已有剧本或分镜可直接转换且转换要求明确时，直接调用格式 Skill；但必须通过轻量可执行性检查。
- 出现“效果不到位、站位不清、动作不准、运镜不对、景别不对、光源不对、质感不符、表演僵硬、台词和口型不匹配”等反馈时启用，定位真正缺失的控制量。
- 只有主体、风格词或一句剧情时必须启用；不得把模糊审美词直接扩写成冗长但不可执行的提示词。
- 用户明确要求“直接转换”“必须直出”“不要追问”“按现有剧本生成”时，立即停止追问；缺失项按现有上下文和专项格式作专业判断。

## 引导原则

每轮只处理一个控制决策簇，并提供 2—3 个能被想象或比较的方案、预期画面效果、生成稳定性差异和明确推荐。不得把参数清单原样丢给用户填写。剧本、分镜、参考图或上一版提示词已经明确的信息直接继承，不得重复询问。

用户说“你决定”“按推荐来”时，将当前决策簇记为授权委托，并采用已说明的推荐。凡用户未决定且系统专业补全的内容，交接时必须标记为“可调整”或“系统建议”，不能伪装成用户硬要求。

## 必需决策簇

| 决策簇 | 必须挖掘的内容 | 对成品的控制作用 |
|---|---|---|
| `output-format` | 目标产物、模型或平台、单镜头或分镜、时长或图片数量、竖屏或横屏、比例、分辨率和输出格式。 | 决定提示词语法、镜头容量和构图边界。 |
| `style-texture` | 写实或风格化、媒介、时代、摄影或渲染气质、材质、颗粒、清晰度、色彩倾向、参考风格与禁止风格。 | 决定整体质感并防止风格漂移。 |
| `subject-composition` | 主体身份与外观、场景、视觉中心、前中后景、左右位置、朝向、距离、遮挡、景别、机位、视角、焦段和景深。 | 锁定画面空间与观看重点。 |
| `lighting-color` | 时间、天气、主光来源与方向、软硬、色温、环境光、轮廓光、曝光、明暗对比和色彩关系。 | 形成可控光感和情绪氛围。 |
| `performance-action` | 起始姿态、动作过程、结束状态、动作速度、重心、手部、视线、微表情、情绪变化、互动与反应。 | 让人物表演具体可生成。 |
| `camera-motion` | 固定或运动镜头、起点、路径、方向、速度、终点、稳定方式、焦点变化、节奏、转场和前后镜头衔接。 | 避免只写“电影感运镜”而无法执行。 |
| `dialogue-audio-text` | 台词、语言、口型要求、说话人、语气、音量、停顿、背景音乐、环境声、音效、字幕是否需要及其位置样式。 | 控制视听完整性，避免模型擅加声音或文字。 |
| `continuity-negative` | 人物身份、脸、服装、道具、空间、光线、动作承接、镜头轴线、禁止项、文字水印、漂移、变形和风格偏移。 | 提高连续镜头稳定性并减少常见生成错误。 |

图片资产不需要运镜、台词和声音时，也必须明确记为“不适用”；不能因为未讨论而让系统误以为缺失。纯场景视频没有人物时，人物表演可标记为“不适用”，但环境运动和镜头运动仍需区分。

## 画幅与构图

竖屏和横屏不是只改比例：

- 竖屏优先处理纵深、人物上下空间、单人或双人关系、字幕安全区和近景信息密度。
- 横屏允许更复杂的左右关系、环境叙事、多人调度和横向运动，但必须防止主体过小。
- 方形或特殊比例需要重新确定视觉中心和留白，不得从横屏机械裁切。

讨论画幅时必须同步说明它会怎样改变站位、景别和运镜路径。

## 质感与光感

“高级、唯美、电影感、氛围感”不是可执行答案。必须至少落到以下可观察维度：

- 真实度与媒介：纪实摄影、商业广告、胶片、数字电影、动画、国漫、黏土、油画、像素或其他。
- 表面与空气：皮肤、布料、金属、潮湿、灰尘、雾、雨、颗粒、锐度和景深。
- 光线结构：主光来自哪里，照到谁，阴影多硬，背景如何分离，冷暖如何对比。
- 色彩控制：主色、辅助色、饱和度、黑位、肤色与情绪关系。

## 人物表演与动作

动作必须使用“起始状态 -> 过程 -> 结束状态”，并注明谁先行动、谁观察、谁反应。表演至少考虑：

- 视线对象、眨眼、呼吸、嘴角、眉眼、吞咽、停顿等微表情。
- 手部和身体重心，避免只写“很生气、很悲伤”。
- 台词发生在动作前、中还是后，是否需要对口型。
- 多人之间的反应链和节奏，不能只描述主动者。

多人镜头必须优先锁定：

```text
人物 A / B / C 的画面位置
-> 各自朝向与视线对象
-> 相互距离、前后层级和遮挡
-> 谁先动、向哪里动、在哪停
-> 其他人的即时反应
-> 运镜是否改变相对位置和轴线
```

## 运镜与节奏

每个运动镜头写清：起点、方向、速度、跟随对象、终点和运动目的。推、拉、摇、移、跟、环绕、升降、手持、变焦和焦点转移不可混为同义词。没有叙事作用时优先固定镜头或简单运动，避免为“高级感”堆叠复杂运镜。

连续镜头还需明确分段时间，例如 `0—2 秒` 建立空间、`2—5 秒` 人物动作、`5—8 秒` 镜头推进与表情变化；时间段只在目标模型和产物格式支持时使用。

## 声音、音乐与字幕

视频提示词必须讨论并明确以下内容是“需要、不要或不适用”：

- 台词、旁白、口型同步、语言与语气。
- 背景音乐的类型、进入和退出位置、是否压过台词。
- 环境声和关键音效。
- 字幕、画面文字、标题卡、水印和字幕安全区。

不得因用户没有主动提及就默认添加背景音乐、字幕或画面文字。

## 看点增强回路

基础合同完成后必须提出 1—3 个适配增强建议，例如：

- 用光线变化或焦点转移强化信息揭示。
- 用人物进退、遮挡或视线改变关系权力。
- 给动作增加清晰的预备和反应，提高生成可读性。
- 用一个可控的前景物、反射或空间层次提升构图。
- 在不增加镜头的前提下调整景别变化，形成视觉节奏。
- 为连续镜头增加身份、服装、道具和动作承接锁。
- 删除互相冲突的风格词、镜头命令或不可同时完成的动作。

建议必须说明视觉收益、稳定性影响和是否增加生成难度。

## 自适应回路

```text
识别目标产物、已有剧本或参考资料
-> 继承已经明确的视觉事实
-> 选择最影响结果的控制缺口
-> 提供方案、推荐与一个问题
-> 合并答案并重新计算缺口
-> 基础合同完整后讨论看点增强
-> 展示硬锁定 / 系统建议 / 可发挥项并确认
-> 交给对应提示词 Skill
-> 执行景别、站位动作、运镜、光线、质感和连续性检查
-> 必要时一次定向校正
```

## 停止条件与交接

只有以下条件同时满足时停止追问：

1. 八个必需决策簇均已确认、明确标记不适用或由用户授权系统决定。
2. 至少一次视觉增强讨论已经完成，用户已选择、拒绝或授权采用推荐。
3. 已展示压缩后的最终创作合同，区分硬锁定、系统建议和可由模型发挥的内容，用户明确确认可以生成。

内部交接至少包含：目标模型与格式、时长或数量、画幅、主体、场景、风格与质感、构图与站位、景别机位与焦段、光线与色彩、动作与表演、台词与语气、运镜与节奏、声音、背景音乐、字幕、连续性锁、禁止项、已选增强项和可发挥范围。连续镜头必须附人物、服装、空间、光线和动作承接约束。
