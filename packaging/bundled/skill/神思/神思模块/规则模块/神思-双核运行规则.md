# 神思-双核运行规则

状态：正式生效，神思默认生产运行时。

用途：规定 [[神思]] 如何用创作核提升作品效果、用记忆核维持长篇稳定，并在不牺牲前两项的前提下连续生产。叙事产物同时受隐藏底层的 [[神思-正文质量净增益与防退化规则]] 裁决。本文负责运行编排，不替代题材、正文、设定、大纲、短剧或视觉资产的专项规则。

## 固定优先级

神思默认按以下顺序分配推理和检查资源：

```text
作品效果 > 长篇稳定 > 批量产能
人物真实 > 情节方便
情绪穿透 > 表面刺激
具体场面 > 作者解释
最小有效规则 > 全量规则加载
```

后项不得以效率、格式完整或流程方便为理由损害前项。批量任务可以连续执行，但每个单元都必须接收上一单元的记忆增量。

## 四个协作位置

| 位置 | 主要职责 | 不负责 |
|---|---|---|
| [[创作引导]] | 理解用户口味、识别真实目标、追问重大分叉、沉淀方向/边界/验收/取舍。 | 不主写正式产物，不维护 canon。 |
| [[神思-创作核运行卡]] | 进行人物心智模拟、候选方案竞争、场景构造、正式生成和效果返修。 | 不擅自改 canon，不承担长期状态维护。 |
| [[神思-记忆核运行卡]] | 写前编译动态创作胶囊，写后检查硬冲突、提取记忆增量和待确认项。 | 不替代主笔，不以保守建议压制正常创作。 |
| 专项模块 | 提供正文、设定、大纲、短剧、提示词、类型理论等领域规则。 | 不默认全部加载，不建立第二套总控。 |

双核指两个后台执行核心，不意味着只能保留两个模块。[[创作引导]] 是用户可见的总编台，专项模块是按需知识源。

## 默认运行链

正式生产默认执行：

```text
神思裁决任务与输出状态
-> 对应专项引导读取已有创作意图；仅在关键缺口存在时补齐
-> 可信内核冻结文体执行清单，并绑定关键自造概念与特殊叙事形态
-> 记忆核编译动态创作胶囊
-> 创作核进行候选竞争并生成产物
-> 创作核做效果复核
-> 记忆核检查硬冲突并提取记忆增量
-> 隐藏质量层检查任务适配、内容唯一性、关键过程和保护资产
-> 成品隔离门检查正式产物没有混入内部管理内容
-> 合并问题后由唯一责任方执行至多一次定向返修，并检查质量差值；无净增益则回退
-> 交付或按授权入库
```

默认不得在创作核起草前加载完整自检库、商业评分库、语言病灶库、结构化执行手册或兼容运行时 artifact。只有动态创作胶囊无法覆盖的专项风险，才读取对应规则。

闭环强度按 [[神思-分级闭环与规则包规则]] 裁决。轻链可以省略完整记忆增量和结构化自检协议；标准链执行本文默认双核短链；强闭环才强制阶段状态机、自检协议、返修再验收和必要证据记录。

## 创作意图状态

[[创作引导]] 应把用户在自然对话中确认的偏好沉淀为创作意图状态：

```text
方向：本轮最想产生的读者反应。
边界：不能写成什么、不能提前说什么。
验收：什么算通过、小修或打回。
取舍：多个方向中保留、删除或延后的内容。
正例：用户明确认可的表达、节奏或场面。
反例：用户明确否定的表达、节奏或场面。
```

创作意图状态属于协作偏好，不等同于作品 canon。已确认偏好可跨轮复用；临时口味和推断必须标为倾向，不得伪装成永久规则。

## 动态创作胶囊

记忆核每次只向创作核提供本轮真正需要的信息：

```text
任务与目标效果
当前场景或阶段位置
人物欲望、恐惧、误判、底线与关系位置
必须承接的事实和因果
读者当前已知、可疑、误判与未知
必须隐藏或禁止改动的信息
未兑现承诺、情绪债和伏笔压力
创作意图状态中的相关正例、反例与禁区
关键自造概念的身份、功能、表现、解释程度与防普通化边界
特殊叙事的真实时序、呈现顺序、视角边界、信息释放与禁止线性化项
本轮结束后必须发生的变化
本轮章节任务、叙事模式、结束功能与必须保护的有效资产
近期正文/场景/动作—台词链复用指纹
```

胶囊应短而足够。若某份资料与本轮人物、因果、信息权限或效果无关，不进入起草上下文。

## 候选竞争

下列情况必须由创作核在内部比较至少三种明显不同的走法：

- 开篇、前三章、高潮、关系转折、身份揭示、重大打脸、关键虐点和结局。
- 用户明确要求更狠、更爽、更意外、更自然或“不对味”。
- 现有方案结构正确但情绪、人物或追读效果偏弱。
- 一个决定会影响后续三章以上或改变人物关系位置。

候选至少覆盖：最符合人物本能的走法、效果最聚焦的走法、最意外但因果成立的走法。比较人物合理性、因果必然性、情绪强度、新鲜度、长线价值、最低必要强度和追读力，选出净增益最高的方案或有机组合；不得把“更吵、更狠、更快”自动当成效果更强。内部推演不得作为冗长思维过程展示给用户；只输出必要结论、取舍依据和最终产物。

普通过渡、小范围文字修正和确定性格式转换不强制生成三套候选，避免把算力浪费在低价值分支。

## 记忆核裁决边界

记忆核把问题分为三档：

| 等级 | 典型问题 | 处理方式 |
|---|---|---|
| 硬冲突 | 违反已确认 canon、人物不可能知道的信息、时间/地点矛盾、重大因果断裂、越权揭示。 | 阻止入库或要求定向返修。 |
| 软风险 | 情绪升级过快、人物反应偏整齐、旧承诺被忽略、关系变化缺少过渡。 | 提醒创作核比较更优方案，不直接封死创作。 |
| 创作选择 | 具体动作、措辞、场面调度、普通配角反应。 | 由创作核自主决定，记忆核不干预。 |

记忆核不得因为“资料没有写过”就否决合理的新细节；新细节先按 canon 状态进入已确认正文事实、待确认或草案。

## 连续多章与批量生产

多章正式生产仍按章节顺序执行，但不再要求每章等待用户确认，也不重复加载全量规则：

```text
第N章胶囊
-> 第N章候选竞争与正文
-> 第N章效果复核
-> 第N章记忆增量
-> 编译第N+1章胶囊
```

只有出现会改变主角命运、重大关系转向、核心真相、结局方向、已确认 canon 或用户明确禁区的分叉时，[[创作引导]] 才暂停并询问。普通细节由双核按既有意图自动推进。

## 专项规则触发

专项规则只在命中时读取：

- 小说正文：[[神思-正文写作规则]]、[[神思-正文质量净增益与防退化规则]]。
- 设定与人物：[[神思-设定生成规则]]。
- 全集大纲、卷纲、章纲：[[神思-大纲与章纲规则]]。
- 短剧叙事与视觉资产：[[神思-短剧与视觉资产规则]]；含剧情、动作或台词时同时读取 [[神思-正文质量净增益与防退化规则]]。
- 原创化重构：[[神思-原创化重构规则]]。
- 入库与目录维护：[[神思-结构化管理规则]]。
- 满血终稿、质量争议或专项诊断：读取对应自检与顾问规则。

类型理论、商业评分、AI 检测、语言病灶和框架健康检查均为触发式后置工具，不作为普通起草默认前置。

## 兼容适配层

[[神思-webnovel-writer运行边界规则]]、[[神思-webnovel同步适配规则]] 和 [[神思-本章创作合同模板]] 保留为可选兼容适配层。只有用户明确要求使用 webnovel-writer、现有作品已经依赖其 commit/projection，或外部运行时确实可用时才启用。

未启用兼容适配层时，不得把缺少 reviewer artifact、chapter-commit 或 projection 当作神思原生生产失败。

## 完成标准

一次标准正式生产完成，至少满足：

1. 创作意图与本轮目标清楚。
2. 创作核完成对应产物，并通过效果复核。
3. 记忆核未发现未处理的硬冲突。
4. 无内容复用、槽位换皮、关键过程跳过或内部产物污染；任何修改均有可说明的净增益，保护资产没有实质下降。
5. 已生成记忆增量或待回写清单。
6. 需要入库时，canon 状态与目标路径明确。

外部兼容运行时的 artifact 只在该适配层被明确启用时进入完成判定。
