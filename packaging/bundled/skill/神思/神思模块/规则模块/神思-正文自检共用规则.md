# 神思-正文自检共用规则

状态：正式生效。

用途：承接 [[强剧情自检]] 与 [[常规推进自检]] 共同使用的自检标准，避免两份自检文档重复维护。所有诊断与返修必须服从 [[神思-正文质量净增益与防退化规则]]。

执行边界：本文承担写后自检共用层职责，不接管写前起草清单。正文写前按 [[神思-正文写作规则]] 锁定输出模式、canon、章节任务、叙事模式、质量保护项、信息权限、结束功能和篇幅要求，同时常驻执行 [[神思-正文高频表达限制与语境裁决规则]] 的轻量硬边界；正文成稿后，再按本文集中检查文字、人物、信息权限、内容唯一性、质量差值、压缩初稿和商业增强项。

## 满血 / 局部自检编排

用户要求“全量自检、满血自检、全面自检、完整自检、所有因素都检查、不要漏项、终稿自检、投稿前自检、发布前自检”时，必须先读取 [[神思-正文满血自检编排规则]]，按其 0-16 号板块输出覆盖矩阵。不得只检查最近提到的禁用词、字数、节奏、钩子或任一单项。

用户明确说“只检查某一项”时，执行局部自检；局部自检必须声明未检查板块，不得输出“全文通过”“满血通过”“终稿通过”。

## 共用检查

| 检查项 | 执行规则 |
|---|---|
| 质量净增益 | 所有正式正文、改写和自动返修无条件读取 [[神思-正文质量净增益与防退化规则]]。先判章节任务与叙事模式，再区分硬故障、语境风险和意图性表达；修改前列保护资产，修改后做质量差值检查。指标改善但人物、因果、关系、情绪、信息梯度、声音、类型承诺或后续空间下降时必须回退。 |
| 商业增强 | 当任务涉及开局、样章、强追读、章节评分、读者模拟、自动审稿、商业判断、平台投稿或追读复盘时，读取 [[神思-商业判断与自动审稿增强规则]]。商业评分、硬性失败项、读者模拟和自动审稿建议的详细标准只在该规则中维护；硬性失败项未清零时不得通过。 |
| 高频表达与模板复用 | 所有正式正文无条件读取 [[神思-正文高频表达限制与语境裁决规则]]，先按三层修改标准归类，再依次检查开头零容忍、固定模板、词族计数、逐条语境、条件上限、前 20 篇段落复用与批量模板坍缩。第一层重写结构、第二层举证功能、第三层调节密度，三层都不得用近义词轮换冒充修复。它不是满血模式才启用的可选项。 |
| 文字质量 | 连词、关联词、否定解释句式及其变体、重复词、重复信息、比喻密度、画面感、可拍边界和情绪载体统一按 [[神思-正文语言质量规则]]；人味与反工整质量闸门按 [[神思-正文质量规则]]。计数只触发复检，是否返修由实际功能、聚集程度、章节任务和净增益决定。 |
| 人物一致性 | 人物行动、对白、口吻差异、人物私心、生活毛刺、性格变化、第二人格、黑化或觉醒，按 [[神思-正文质量规则]] 与 [[神思-结构化管理规则]] 的人物状态回写边界检查。 |
| 信息权限 | 终局泄露、信息权限、重要信息登场、伏笔显影、读者知识和悬念寿命统一按 [[神思-正文信息权限规则]]。 |
| 压缩初稿 | 信息密度闸门统一按 [[神思-正文质量规则]]。动作链、场景锚点、人物变化、信息释放、伏笔状态、局部兑现或扩写锚点缺失时，不得判定合格。 |

## 多章轮询共用规则

多章正式正文必须逐章执行：

```text
生成本章 -> 对应自检 -> 返修 -> 复检 -> 通过后进入下一章
```

硬规则：

1. 不得等多章全部写完后再统一粗检。
2. 自检不通过时，必须返回正文主笔修改本章。
3. 本章任务、必要兑现、人物一致性、对白差异、结束功能、内容唯一性、文字质量、信息权限、质量守恒和上下文衔接全部通过后，才能进入下一章；人物毛刺等增强项只在有功能时检查，不设按章配额。
4. 不得用章节数量、节省 token、赶进度或批量生产作为跳过返修的理由。
5. 上下文预算不足时，停在已通过章节后生成下一章接续上下文包，不输出未达标章节。
6. 每章进入下一章前必须完成近期复用检查；3 章以上同骨架或未登记的精确 / 近似段落复用直接阻断批量流程。
7. 各自检器先汇总、去重并形成一张返修单，再由正文主笔统一修改；禁止多个检查器依次重写全文导致语义和声音逐轮流失。
8. 返修后必须核对目标缺陷的改善证据与质量保护资产。收益不确定或出现实质退化时回退，不得用总分提升抵消。

## 输出格式

用于审稿时，结论分五类：

- 必须修正：硬故障，或有证据证明会破坏章节任务的人物、因果、设定、时间线、信息权限、模板复用和正式产物污染问题。
- 增益机会：有明确预期读者收益但不阻断交付的优化点，同时说明修改风险。
- 明确保留：承担必要情绪缓冲、内心矛盾、关系推进、后果消化、信息沉淀、作者声音或结构回声的内容。
- 不建议改动：收益不确定，或会伤及人物、因果、情绪、信息梯度、声音和类型承诺的内容。
- 资料缺失：缺少 canon、前后章、章节任务、类型或平台目标而无法可靠判断的内容。

执行了自动返修时，必须内部附上目标缺陷、修改层级、预期读者收益、保护资产、实际改善证据、退化检查和采用/回退裁决；未实际修改时不伪造质量差值。

高频表达边界：全量与标准自检都必须按 [[神思-正文高频表达限制与语境裁决规则]] 输出或内部形成三层归类、词族计数和逐条裁决。“不是”及其他受控词符合允许功能、具有相邻证据、删除会损失实际叙事功能且未越过配额时才可保留；对白不自动豁免。时间领句必须先按 [[神思-开场钩子与时间叙述控制规则]] 分为模板报时、叙事性时间锚点或因果性时间锚点，并完成删除、换时、承接和频率测试；不得把全部时间开场并入硬禁。近期连续或同构高频使用只触发重点复核：比较非时间入口后，若时间仍承担不可替代的因果、连续性、制度、异常或人物压力功能则可保留；模板化、无信息增量、无后续承接或可无损替换时才判返修。经分类确认的模板报时、其他固定模板、条件上限和未登记跨篇复用不接受语境豁免。

启用 [[神思-商业判断与自动审稿增强规则]] 时，还必须补充：

- 硬性失败项：0 项 / N 项。
- 章节评分：总分与主要扣分项。
- 读者模拟反馈：最想追的点、最想弃的点、下一章期待。
- 平台适配判断：目标平台 / 目标读者是否匹配，理解成本和情绪直给程度是否合适。
- AI 痕迹风险：只评估过度工整、同质化、功能化风险，不判定作者或生成来源。
- 自动审稿建议：需要脚本或人工复核的重复词、信息越权、连续性、主角能动性问题。
