# 神思-长篇结构自检规则

本文件是 [[神思]] 的长篇结构自检模块。适用：全集大纲、卷纲、阶段规划、整卷正文复盘、整本小说复盘、完稿前结构审查和长篇连载中期体检。

边界：只检查大纲时不套用正文词频；一旦检查整卷 / 整本正文或引用正文样段，必须同时执行 [[神思-正文高频表达限制与语境裁决规则]] 和 [[神思-正文质量净增益与防退化规则]]，重点统计开头同构、固定模板、跨章段落/场景骨架/动作—台词链复用、批量模板坍缩和修改退化。结构合格不能覆盖内容复用或质量守恒硬失败。

## 依据来源

本模块吸收外部长篇结构研究，但不把外部术语直接写入正文。外部资料只转化为检查项。

参考来源：

- K.M. Weiland 的故事结构系列强调 Hook、Inciting Event、First Plot Point、Midpoint、Third Plot Point、Climax、Resolution 等关键结构节点，以及 Hook 与 Resolution、Inciting Event 与 Climactic Moment 的呼应关系。
- Reedsy 的三幕结构说明把故事拆为 Setup、Confrontation、Resolution，并强调开端建立人物和赌注，中段防止动力塌陷，结局兑现承诺、收束松散线索并强化主题。
- 长篇商业连载需要在上述通用结构之外，额外检查卷内承诺、阶段局部兑现、爽点/信息/伏笔分布和连续追读钩子。

## 定位

[[强剧情自检]] 和 [[常规推进自检]] 主要检查单章或少量连续章节。[[神思-长篇结构自检规则]] 检查更高层级：

- 全书是否有一个足以支撑长篇的核心承诺。
- 每卷是否有独立阶段目标、局部兑现和卷末新缺口。
- 中段是否塌陷、重复、跑偏或只堆设定。
- 主角成长线、势力升级线、信息释放线、伏笔回收线是否互相支撑。
- 结局是否兑现开篇承诺，而不是另起一个答案。
- 若作品追求商业连载，还要检查商业判断总纲、读者承诺、章节评分趋势、读者模拟反馈和追读风险；具体按 [[神思-商业判断与自动审稿增强规则]] 执行。

## 主笔与权限

- 正式全集大纲、卷纲、阶段规划由 Agent 选择适配的规划 Skill 完成；需要长期承接证据时按需使用 [[神思-记忆检查规则]] 提供旧承诺、人物状态、信息释放和 canon 边界。
- 本模块只负责自检、否决、返修建议和复盘报告，不接管大纲主笔。
- 理论顾问只在自检原因不清时作为顾问解释，不直接输出最终修改意见。
- 涉及 canon 修改、终局调整、人物核心身份改变、力量体系底层规则改变时，只能写入对应作品完整路径下的 `待确认事项`，等待用户确认。

## 分层自检入口

| 层级 | 检查对象 | 使用时机 | 输出 |
|---|---|---|---|
| 全集大纲自检 | 全书主线、主题、终局、分卷结构 | 生成或重修全集大纲后 | 全书结构体检报告 |
| 卷纲自检 | 单卷目标、压力、兑现、卷末钩子 | 每卷开写前或卷纲修订后 | 卷结构体检报告 |
| 阶段规划自检 | 3-10 章连续推进段 | 批量写作前、中段卡文时 | 阶段推进检查表 |
| 整卷正文复盘 | 已写完的一整卷正文 | 卷末、开下一卷前 | 整卷复盘报告 |
| 整本小说复盘 | 已完成或中后期全书稿 | 完稿前、中期大修前 | 全书复盘报告 |
| 商业追读复盘 | 开局、样章、阶段、整卷或连载数据 | 追读下降、读者反馈异常、商业目标不清时 | 商业判断与自动审稿增强报告 |

## 全集大纲自检

全集大纲必须通过以下检查，才可以作为正式长篇主控文件。

| 自检项 | 合格标准 | 风险表现 |
|---|---|---|
| 核心承诺 | 一句话能说清读者读完整本等待什么兑现。 | 只有设定概念，没有读者期待。 |
| 主角终极欲望 | 主角想要的东西能贯穿全书，并在终局被回答。 | 主角只是被事件推着走。 |
| 开端与终局呼应 | 开篇抛出的核心问题，在终局得到正面、反面或代价式回答。 | 结局解决的是后期新问题，开篇承诺落空。 |
| 分卷递进 | 每卷压力、敌人、地图、规则、关系或代价至少有一种升级。 | 每卷只是换地图重复同类事件。 |
| 中段动力 | 全书中段有明确转折，改变主角目标、策略、代价或对世界的解释，并产生不可逆选择。 | 中段只堆支线、设定、打怪和说明；或机械执行“被动转主动”。 |
| 反派/阻力线 | 核心阻力随主角成长同步升级，并逐步显露真实压迫。 | 反派只在需要冲突时出现。 |
| 人物成长线 | 主角每个阶段的认知、能力、关系和代价有不可逆变化。 | 主角升级但价值判断不变，关系线无后果。 |
| 信息释放线 | 世界真相、力量规则、身份秘密按阶段释放。 | 前期讲太多，后期只剩执行；或后期硬塞真相。 |
| 重要信息登场线 | S/A/B 级重要信息有首次登场、可疑推进、局部揭示、正式揭示和解释完成节点。 | 重要信息第一次出现就讲透，或正式揭示前没有可感知铺垫。 |
| 伏笔总账 | 主线伏笔有首次显影、推进、误判、回收和后果。 | 伏笔只埋不收，或回收时没有前文支撑。 |
| 主题证明 | 主题通过主角选择、代价和终局结果被证明。 | 主题只在旁白或设定里存在。 |
| 商业判断总纲 | 目标平台、类型承诺、主角欲望、情绪主轴、核心爽点模型和禁区清楚。 | 只有题材名，没有目标读者、追读承诺或作者取舍标准。 |

## 卷纲自检

卷纲不是全书大纲的缩写。每一卷都必须有自己的阶段承诺和卷末兑现。

| 自检项 | 合格标准 | 风险表现 |
|---|---|---|
| 本卷承诺 | 本卷开头能让读者知道这一卷等待什么结果。 | 卷首只接续日常，没有阶段目标。 |
| 卷内压力 | 压力随章节推进加重，且来自人物、规则、势力或资源限制。 | 压力靠作者临时加敌人。 |
| 局部兑现 | 卷末至少兑现一个阶段承诺。 | 卷末只抛更大坑，不给读者成果。 |
| 后续接口 | 非终卷且作品需要续读时，在兑现后保留自然生长的下一阶段压力、选择或问题；终卷允许真正闭合。 | 为留钩硬塞陌生敌人、突发秘密或与本卷无关的新坑。 |
| 中段转折 | 卷中有一次误判破裂、关系反转、代价显形或规则升级。 | 卷中连续推进但没有结构变化。 |
| 人物变化 | 本卷结束时，主角或关键配角不能回到原状态。 | 事件很多，人物没有变化。 |
| 设定负载 | 新设定数量服务本卷冲突，不压垮正文。 | 一卷内连续解释多个体系。 |
| 伏笔处理 | 本卷有新埋、推进、回收和延后四类伏笔安排。 | 只埋伏笔，不管理显影等级。 |
| 章节功能分布 | 强剧情章、推进章、后果章、关系章有节奏交替。 | 连续同质化追杀、解释或打脸。 |
| 追读曲线 | 卷内有压迫、小兑现、新缺口和阶段兑现的波动。 | 连续铺垫无兑现，或连续胜利导致世界失重。 |
| 章节差异与波形 | 相邻章节在任务、叙事模式、目标、阻力、策略、情绪和结束功能上有真实差异，并有强弱、快慢、外部/内在、兑现/余波交替。 | 换标题、人物或物件复用同一场景；每章都用同强度钩子和同节拍。 |

## 阶段规划自检

阶段规划通常覆盖 3-10 章，用于防止批量写作跑偏。

| 自检项 | 合格标准 |
|---|---|
| 阶段起点 | 明确从哪个未完成承诺或压力开始。 |
| 阶段终点 | 明确到哪个局部结果、反转或代价结束。 |
| 连续动作链 | 每章之间有因果，不只是并列事件。 |
| 期待循环 | 阶段内承诺、兑现、余波和新问题形成波形；不是每章机械配齐“小兑现 + 新缺口”。阶段末按作品进度完成大兑现、方向转换或闭合。 |
| 信息权限 | 每章只释放当前允许信息，不提前泄露卷末或全书真相。 |
| 重要信息登场 | 阶段内 S/A/B 级重要信息的首次登场、可疑推进、局部揭示或正式揭示有明确章节和承载方式。 |
| 人物状态 | 阶段末人物位置、目标、关系、伤势、持有物必须可更新。 |
| 商业增强 | 如启用商业判断，阶段内每章硬性失败项应为 0，并能看出章节评分或追读风险变化。 |
| 内容唯一性 | 各章的目标、阻力、策略、转折、代价、结果和结束功能不成套复用；无整段、整场或槽位换皮。 |

## 整卷正文复盘

整卷写完后，不能只看每章是否好看，还要检查整卷是否形成闭环。

| 自检项 | 合格标准 | 处理方式 |
|---|---|---|
| 卷首承诺兑现 | 卷首提出的主要问题在卷末有局部答案。 | 未兑现则补章节、改卷末或降级承诺。 |
| 中段塌陷 | 卷中没有连续多章目标模糊、重复追逐、重复解释。 | 删除重复章、合并同质冲突、补中段反转。 |
| 人物弧线 | 主角和关键配角在卷末有状态变化。 | 无变化则补代价、关系破裂或认知转折。 |
| 伏笔账本 | 本卷伏笔有状态：新埋、推进、回收、延后、废弃。 | 未登记则补入伏笔管理或待确认事项。 |
| 信息释放 | 读者知道的信息与本卷目标匹配，不多不少。 | 过量则后移解释；不足则补局部证据。 |
| 重要信息登场 | 本卷新增或推进的重要信息均有登场方式、读者状态和后续揭示计划。 | 缺失则补入该作品的 `重要信息登场账本` 或把无承载揭示列为修订建议。 |
| 爽点/压迫分布 | 局部胜利和压力升级交替出现。 | 连续压迫需补兑现，连续胜利需补代价。 |
| 卷末功能 | 按作品进度完成阶段兑现、余波、方向转换或终局闭合；仅在非终卷且确有后续因果时保留续读接口。 | 一律补钩导致本卷成果失重，或为续读强行重启冲突。 |
| 章节唯一性 | 无精确/近似正文复用、同场景骨架换槽位、固定动作—台词链和批量模板坍缩。 | 命中即停止继续批量写作，先重建差异。 |
| 张力波形 | 强剧情、关系、调查、后果、铺垫和收束章节比例服务本卷任务，峰值后有必要余波。 | 全卷持续同强度、同长度、同句法和同类结尾。 |
| 商业追读复盘 | 本卷读者承诺、局部兑现、爽点密度、压迫/补偿节奏和读者模拟反馈形成闭环。 | 单章看似合格，但整卷追读理由变弱、同质化或核心承诺漂移。 |

## 整本小说复盘

整本小说复盘用于完稿前或中后期大修。

| 自检项 | 合格标准 |
|---|---|
| 开篇承诺与终局兑现 | 终局回答开篇真正的问题。 |
| 主角成长闭环 | 主角最终选择与开篇缺陷、欲望和恐惧形成因果。 |
| 主题闭环 | 主题由剧情事件证明，而不是靠结尾解释。 |
| 世界规则一致 | 早期规则没有被后期爽点随意推翻。 |
| 终局反派/危机铺垫 | 最终阻力早有伏笔，中后期逐步显影。 |
| 重要信息登场闭环 | 影响主线理解的 S/A/B 级重要信息都有首次登场、局部揭示、正式揭示和解释完成记录。 |
| 分卷功能不重复 | 每卷承担不同功能：入局、扩张、反转、失落、反攻、终局等。 |
| 伏笔回收率 | 主线伏笔必须回收或明确废弃；支线伏笔不能影响主线理解。 |
| 人物去向 | 关键人物在终局有结局、代价或状态交代。 |
| 情绪收束 | 结局释放长期张力，留下明确的最终情绪。 |
| 质量守恒 | 大修没有用提速、反转或解释换掉人物驱动、因果桥、关系压力、信息梯度、作者声音与类型承诺。 |

## 输出格式

长篇结构自检报告必须按以下格式输出：

```text
长篇结构自检报告：
- 检查层级：全集大纲 / 卷纲 / 阶段规划 / 整卷正文 / 整本小说
- 检查对象：
- canon 状态：
- 总结论：通过 / 需小修 / 需大修 / 不建议入库
- 关键通过项：
- 必须修正项：
- 建议加强项：
- 明确保留 / 不建议改动：
- 质量差值与退化风险：
- 需要写入待确认事项：
- 是否需要理论顾问解释原因：是 / 否
```

## 与其他模块关系

- [[神思-大纲与章纲规则]] 负责大纲和章纲的生成标准；本模块负责生成后的结构自检。
- [[神思-正文写作规则]] 负责正文级单章写作和信息权限；本模块负责跨章、跨卷、全书复盘。
- [[神思-正文质量净增益与防退化规则]] 负责问题分级、任务适配、内容唯一性和修改前后质量守恒；本模块的一切返修建议必须服从该裁决。
- [[强剧情自检]] / [[常规推进自检]] 负责单章正文；本模块负责长篇结构层。
- [[神思-商业判断与自动审稿增强规则]] 负责商业判断、章节评分、读者模拟、自动审稿和追读复盘，只作为增强层，不替代本模块的结构自检结论。
- [[小说结构化文档管理]] 负责保存报告、更新伏笔账本、记录对应作品完整路径下的 `待确认事项`，不负责改写大纲内容。
