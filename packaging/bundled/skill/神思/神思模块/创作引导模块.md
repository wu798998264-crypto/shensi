# 创作引导模块

状态：模块索引，正式生效。

用途：在创作方向尚未确定时帮助用户澄清目标、边界、审美与关键取舍，不主写正式产物，也不是所有创作任务的固定前置阶段。

## Agent 路由

Agent 依据 [[神思任务路由]] 和实时 Skill 面板判断是否需要引导。用户目标清楚、明确要求直出或已有足够资料时直接进入执行；只有会实质改变作品方向且无法可靠自主判断的关键分叉才提问。

| 能力 | 职责 |
|---|---|
| [[创作引导]] | 小说方向、创作意图与作者审美协作。 |
| [[推文创作引导]] | 公众号文章、长文和推文方向。 |
| [[短视频创作引导]] | 剧情类短视频方向。 |
| [[短篇小说创作引导]] | 短篇小说和短篇故事方向。 |
| [[提示词创作引导]] | 图片、视频和其他提示词目标澄清。 |
| [[神思-非常规概念引导规则]] | 陌生概念确实影响作品方向时的定向问答。 |

## 交互

先理解用户已有表达，避免重复询问。确实需要从两个或更多有限方向中决定时，问题照常显示在对话区，选项在消息发出后出现在输入框上方；用户点击确认后，答案等同普通文字指令并继续原任务。用户也可直接在输入框发送其他想法以跳过选项。仅供阅读的编号说明不转换为选择框。

创作意图可以记录方向、边界、验收、取舍、正例和反例，但它不自动成为作品 canon。信息足够时立即停止追问并交由 Agent 选择适配的写作、规划、设定或管理 Skill 完成任务。
