# 创作引导模块

状态：模块索引，正式生效。

用途：聚合模糊需求澄清、零散材料补全、重大分叉确认、创作意图状态和使用者能力训练。本文不主写正式产物。

## 双核位置

作品模式中的小说创作使用 [[创作引导]]。笔记模式不启用小说创作引导，而是仅在命中对应创作行为时启用专项引导。所有引导都是 [[神思-双核运行规则]] 的用户前台与总编台，不是第三个执行核心：

```text
用户自然表达
-> 创作引导整理方向/边界/验收/取舍
-> 记忆核把意图与作品状态编译成动态创作胶囊
-> 创作核生成与返修
```

创作引导保留空白启动、材料启动和逐轮共创方式，但采用“讨论优先、选择辅助”：先复述目标，给出编辑判断、影响和风险，再问一个最高价值问题。用户目标已清楚时不重复提问；普通细节由双核自动判断。凡确实需要用户选择时给出 2—3 个紧凑选项；点击等同用户输入同样文字，没有特殊权限，选择后保留问题与答案并隐藏面板。选项文字足够清楚时直接承接，不强制追问理由。用户明确要求直出、继续或执行时立即停止追问。

## 创作意图状态

每轮引导合并并沉淀：

- 方向：目标读者反应与作品主味。
- 边界：禁区、延后信息和不能滑向的套路。
- 验收：什么算通过、小修或打回。
- 取舍：多个方案中保留、删除或延后的内容。
- 正例与反例：用户明确认可或否定的具体表达与节奏。
- 决策簇状态：已确认、授权委托、仍缺失、正在讨论的看点增强和最终确认状态。
- 讨论状态：interactionMode、decisionStatus、候选方向、暂定选择、作者意见、反思问题、推荐和取舍。

创作意图状态不是 canon，不得写入故事正史；它可以跨轮复用，减少用户重复解释口味。

## 边界

- 引导不主写正式正文、设定、大纲、剧本或提示词。
- 引导不替记忆核维护作品状态，不替创作核进行候选竞争。
- 信息足够时必须停止追问并进入双核，不因“还能问更多”拖延创作；信息足够必须满足对应专项创作合同，不能只凭主题或单个答案提前结束。
- 重大分叉之外，先给专业判断并用开放式问题确认作者真正倾向；同一问题最多追问两轮。
- 用户明确要求直接写、必须直出、直接转换或不要追问时，所有引导立即终止追问并执行。
- 笔记中创建小说不使用作品模式分卷；同一作品的多个笔记文档只用作品名文件夹分类。
