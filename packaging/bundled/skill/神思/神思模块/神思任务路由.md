# 神思任务路由

状态：Agent 内部路由合同。本文说明稳定机制；当前 Skill 面板的真实成员、位置、角色、启用状态、能力和适用场景由可信内核每次运行时生成的实时路由快照提供。

## 路由顺序

1. 读取用户完整意图、交付物、阶段、工作区和本轮明确引用。
2. 使用当前面板快照确定可自动路由的模板、模组、模块、插槽和 Skill。
3. 只读取完成当前阶段真正需要的 Skill 与资料；预计读取、空文档和未实际加载的内容不算证据。
4. 运行中根据实际读取和生成结果复核路线；发现新的真实缺口时补读或改道，不为了旧流程补齐无关资料。
5. 由神思运行规范决定读写、历史、交付和失败处理；本文件不替代运行事务。

关键词只能用于搜索、标签和兼容元数据，不能单独决定任务类型、资料范围、写入目标或 Skill。任务路由输出的是可执行能力边界，不是僵化的线性脚本。

## 面板关系

面板由模板、模组、模块和插槽组成，当前真实顺序决定角色：

| 关系 | 角色 | 路由含义 |
| --- | --- | --- |
| 并行 | 并行 | 同级能力按任务需要独立或同时调用。 |
| 主次 | 主要、次要 | 第一项是主要；语义明确命中次要时精确替代主要，不自动叠加。 |
| 组织 | 上位、下位 | 第一项是上位；命中下位时自动加载完成任务所需的上位能力。 |

拖拽、交换、排序和关系切换后的面板顺序必须直接进入下一轮路由。任何旧文件名、旧标签或缓存快照都不能覆盖当前拓扑。

## 面板功能与场景

| 面板能力 | 适用场景 | 交互结果 |
| --- | --- | --- |
| 创作引导 | 最终产物或关键决策仍不明确 | 只追问当前最有影响的一个决策；用户明确直出时可跳过。 |
| 规划/设定 | 大纲、卷纲、章纲、人物、世界观、规则和事实链 | 生成规划或设定候选；正式入库由管理能力和运行规范完成。 |
| 正文/剧本主笔 | 小说、短篇、公众号、短剧、短视频和提示词等明确交付物 | 生成对应正式内容或多候选，不询问主笔数量。 |
| 理论顾问 | 题材、类型、赛道或结构方法需要解释 | 顾问提供判断依据，不覆盖用户审美和可信内核。 |
| 自检/效果检查 | 生成后质量、格式、连续性或专项风险检查 | 产出最小返修单；报告任务按要求保存到编译报告集合。 |
| 记忆与经验 | 需要召回作品事实、经验或生成后增量 | 只处理记忆/经验数据，不把偏好自动升级为硬规则。 |
| 结构化管理 | 建档、索引、移动、复制、重命名、删除、恢复和落盘 | 调用原子结构或文档事务，保留历史和真实回执。 |
| 图片/视频提示词 | 用户要分镜、镜头、站位、图片资产或媒体提示词 | 按面板中的提示词 Skill 和关系加载，不扩大媒体配置。 |
| 明确引用的面板外 Skill | 用户明确写出 Skill 名称或 `@Skill` | 仅本轮临时加载；不会进入普通语义自动候选。 |

## Skill 边界

- 面板内、启用、可达且通过测试的 Skill 才能被普通任务语义自动路由。
- 面板外 Skill 不通过任务路由自动导航；只有用户明确提及或 `@` 引用才允许本轮调用。
- 禁用、失效、未绑定和不可达 Skill 不得自动调用；明确引用也必须先经过能力与安全兼容检查。
- 同一 Skill 出现在多个位置时使用实时 `placementId`，不能混用另一位置的关系角色。

## 更新与历史

每次保存 Skill 面板、模组、模块、插槽或 Skill 启停状态后，可信内核递增路由版本，重算拓扑哈希，重新编译当前全文路由快照，并把位置变化、启用 Skill、能力覆盖审计和快照写入任务路由历史。校验失败时继续使用上一个通过版本，不覆盖可恢复历史。
