# 设定模块

状态：模块索引，正式生效。

用途：聚合设定生成、命名约束和设定落盘边界相关规则。本文不新增设定字段标准。

## 活动规则

| 文件 | 路径 | 职责 |
|---|---|---|
| 实时面板中的设定 Skill | 由 Agent 按完整意图选择，生成并比较设定方案的剧情功能、代价和人物压力。 |
| [[神思-记忆检查规则]] | `skill/神思/神思模块/规则模块/神思-记忆检查规则.md` | 本轮需要时检查既有 canon、来源、冲突和待确认状态。 |
| [[神思-设定生成规则]] | `skill/神思/神思模块/规则模块/神思-设定生成规则.md` | 角色、世界观、地图、力量体系、规则、势力、物品、术语和事实链。 |
| [[神思-命名去污染规则]] | `skill/神思/神思模块/规则模块/神思-命名去污染规则.md` | 原创姓名去污染、候选生成和命名自检。 |
| [[神思-结构化管理规则]] | `skill/神思/神思模块/规则模块/神思-结构化管理规则.md` | 设定 canon 状态、来源、待确认和入库边界。 |

## 边界

- 从零原型设定和正式结构化补设定所需能力，由 [[神思任务路由]] 结合当前阶段与面板选择。
- 正式设定由 Agent 选择适配的设定 Skill 执行；需要承接既有事实时组合记忆检查，管理流程只入库有充分来源的事实。
- 命名去污染只约束原创命名；已有资料或 canon 明确姓名时必须承接。
- 正式设定在用户未明确要求不落盘时直接写入正确文档；探讨、未采用方案和明确草案默认不进入正史，用户要求保存时写入指定位置。
