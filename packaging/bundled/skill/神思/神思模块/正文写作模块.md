# 正文写作模块

状态：模块索引，正式生效。

用途：聚合小说正文相关活动规则。默认运行时为 [[神思-双核运行规则]]，本文只列小说正文需要的专项入口，不建立第二套生产链。

## 默认运行入口

| 文件 | 职责 |
|---|---|
| [[神思-双核运行规则]] | 编排创作引导、创作核和记忆核。 |
| [[神思-创作核运行卡]] | 人物心智模拟、候选竞争、正文生成与效果复核。 |
| [[神思-记忆核运行卡]] | 写前动态创作胶囊、写后硬冲突与记忆增量。 |
| [[神思-正文写作规则]] | 小说正文专项边界、写中要求和完成标准。 |
| [[神思-正文生产流程]] | 单章、续写和多章连续生产的短流程。 |

## 按需专项规则

| 文件 | 触发条件 |
|---|---|
| [[神思-正文信息权限规则]] | 本章涉及秘密、误判、伏笔显影、身份或终局信息。 |
| [[神思-正文质量规则]] | 正式终稿、字数争议、信息团、场景密度或可发布判断。 |
| [[神思-正文语言质量规则]] | 语言机械、重复、比喻、总结式旁白或人味问题。 |
| [[强剧情自检]] | 开局、前三章、高潮、强反转、重大虐点、打脸或追读压力章节。 |
| [[常规推进自检]] | 关系推进、后果消化、过渡章出现功能不足。 |
| [[神思-商业判断与自动审稿增强规则]] | 用户要求商业评分、平台适配、读者模拟或市场判断。 |
| [[神思-作者化与AI检测风险控制规则]] | 用户明确提到 AI 味、机器味、朱雀检测或作者化。 |
| [[神思-非常规大纲执行卡]] | 梦境、幻觉、象征、怪异规则、非线性或错位记忆。 |
| [[神思-原创化重构规则]] | 借鉴型改写、素材重构、洗稿风险或同源文本重写。 |
| [[神思-正文创作核心卡]] | 兼容旧调用；其有效要求已由创作核和动态胶囊吸收。 |

## 兼容适配层

| 文件 | 当前定位 |
|---|---|
| [[神思-本章创作合同模板]] | 仅在外部运行时需要固定字段输入时使用。 |
| [[神思-webnovel-writer运行边界规则]] | 仅在明确启用 webnovel-writer 时使用。 |
| [[神思-webnovel同步适配规则]] | 仅同步已启用的 webnovel-writer 运行记录。 |
| [[神思-创作效果验收规则]] | 满血终稿、质量争议或需要正式验收报告时使用；普通章节由双核短检完成。 |

## 边界

- 小说正文默认从动态创作胶囊进入创作核，不再强制生成独立本章合同。
- 创作核起草前不加载完整自检库；专项规则只把命中的少量硬约束注入胶囊。
- 多章正式正文按章节顺序连续执行，每章完成记忆增量后立即编译下一章。
- [[创作引导]] 保留原触发方式；方向清楚时不重复追问，重大分叉时才暂停。
- 正式正文继续遵守单章单文件和单正文源规则。
