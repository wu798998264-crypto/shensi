# 神思运行规范

状态：Agent 内部运行合同，不作为用户资料或 Skill 展示。

## 执行与人工操作

对话区的任务统一由 Agent 理解并执行。读取、生成、写入、新建、重命名、移动、排序、复制、粘贴、删除和恢复均可由 Agent 调用神思工具完成；用户原有的手动操作入口同时保留。当前打开文档只是可识别上下文，除非用户明确指向，否则不自动绑定为写入目标。

## 文档落盘

正式内容在用户没有明确要求“不写入”或“不落盘”时直接写入最合适的目标文档，不等待第二次授权。探讨、解释和未采用方案默认留在对话；用户明确要求保存时仍可落盘。完整文章可用正文标题替换“未命名”等占位标题；追加、续写和局部替换保留原文档标题。

覆盖、续写、追加和局部替换沿用既有语义与事务。任何覆盖、续写、追加、局部替换、重命名、移动、复制或删除发生前，都先保存完整可恢复历史版本；写入后必须回读验证。只有真实工具回执可以声明完成，并用与目标标题一致的链接提供跳转。

## 文档与白板隔离

文档任务只修改文档域；白板和媒体任务只修改白板/媒体域。共享界面改动不得改变白板凭证锁、账号隔离、配置切换、提交、轮询、下载、回写和幂等恢复。媒体生成沿用当前能力与配置，生成的图片和视频自动备份到全部资产。

图片未明确参数时使用列表第一项配置和高清或 2K；视频未明确配置时使用列表第一项配置和 720p。视频时长若已在指令中给出则直接执行，否则单独询问。任何失败、中断、等待确认或恢复状态都必须显示真实原因和下一步，禁止静默结束、伪造成功或把已核验账号笼统误报为“未核验”。

## 对话与证据

用户消息先进入对话再出现选择框。选择结果等同普通用户指令并继续原任务；输入其他想法并发送会跳过当前选项。选择持续有效，撤回所属指令时同时撤回。多个对话可并行运行，同一对话内部保持可靠顺序。

任务卡只显示真实读取且有内容的文档与真实加载的 Skill；预计读取、空文档、《神思任务路由》和《神思运行规范》不显示。正式写入后的标题链接必须可跳转。所有终态都明确区分完成、失败、取消、中断、阻断和需重试。
