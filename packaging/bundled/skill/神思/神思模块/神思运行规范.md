# 神思运行规范

状态：Agent 内部运行合同，供所有运行器遵守；用户手动操作入口同时保留。

## 执行边界

读取、生成、写入、新建、重命名、移动、复制、粘贴、排序、删除和恢复可以由 Agent 调用神思工具完成，也可以由用户手动完成。当前打开文档只是可识别上下文，除非用户明确指向，否则不是默认写入目标。文档与白板/媒体域隔离，修改文档规则不得改变白板、媒体生成、即梦锁和受保护生图链路。

## 正式内容与落盘

正式内容在用户没有明确要求“不写入”或“不落盘”时直接写入最合适的目标文档；探讨、解释、未采用方案和普通候选默认留在对话。用户明确要求保存时，非正式内容也可以落盘。覆盖、续写、追加、局部替换沿用既有语义，完整文章可用真实标题替换“未命名”等占位标题。

## 历史版本与备份层级

每一次 AI 正式写入和每一次用户手动保存，在改变既有文档前必须建立修改前的完整可恢复版本。服务端保存事务会生成完整正文写前快照，写入前回读快照并校验完整性；校验失败就阻止修改，不能口头宣称完成。

备份范围按真实影响自动确定：

| 修改范围 | 写入前备份 |
| --- | --- |
| 单篇正文或单个文档 | 该文档完整正文、标题和连续性字段。 |
| 同一卷/文件夹内多篇文档 | 每篇文档完整版本，并建立卷级结构快照。 |
| 同一分类/视图内多篇文档 | 每篇文档完整版本，并建立分类级结构快照。 |
| 同一模块内多篇文档或结构调整 | 每篇文档完整版本，并建立模块级结构快照。 |
| 跨模块、全作品或作品结构调整 | 每篇受影响文档完整版本，并建立作品级快照。 |
| 新建空文档且没有可恢复前文 | 不伪造正文历史；结构变化仍由相应层级快照、事务日志和回读校验覆盖。 |

层级快照只覆盖本次真实受影响的节点和文档，不把无关板块伪装成已读取或已修改。历史版本、差异、来源操作和完整性校验均可恢复；保存成功必须以真实工具回执和磁盘回读为准。

## 交互、资料与交付

用户消息先进入对话，再显示动态选择框；选择结果等同普通用户指令继续任务，输入其他想法并发送则跳过当前选项。撤回所属指令时同步撤回选择框，选择不会因等待时间自动失效。任务卡只显示真实读取且有内容的文档与真实加载的 Skill；任务路由和运行规范本身不显示为资料证据。

正式文档交付必须给出真实目标 ID、完成写入并回读验证，再提供与标题一致且可跳转的链接。完成、失败、取消、中断、阻断和需重试必须分别显示真实原因与下一步。

## 媒体与并行

图片和视频使用现有媒体服务与配置；失败必须显示厂商或本地真实原因，不能静默结束、伪造成功、重复付费提交或把已核验账号笼统报成未核验。多个对话可以并行运行，同一对话内部保持可靠顺序。图片和视频结果在下载验收后自动备份到全部资产。
