# 公众号文章创作理论

显示名称：公众号文章通用理论与细分类路由

## 定位

[[公众号文章创作理论]] 是神思公众号文章理论顾问组的通用上位，与 [[小说类型理论研究]] 同级。它负责公众号文章共用的内容方向、读者承诺、选题价值、证据边界、内容组织和传播机制，再按需加载对应的细分 Skill。

本文不直接替代 [[公众号模块]]、[[神思-公众号去AI味规则]] 或任何细分类型 Skill。命中细分品类时，本文作为上位理论与一个主细分 Skill 共同生效；后续新增的公众号文章方向统一收录在本目录中。

## 总原则

1. 公众号创作任务先识别内容类型，再决定结构、证据、语言和传播方式。
2. 一个任务可以包含多个方向，但必须确定主类型；辅助类型只能补充，不能争夺文章中心。
3. 类型理论负责选题、内容组织、读者价值和风险边界；去 AI 味负责表达返修，二者不得混为一套规则。
4. 事实型文章必须区分事实、推断、假设和比喻。高时效或高风险信息必须核对当前权威来源。
5. 未命中已接入类型时，只使用本文与 [[公众号模块]] 的通用流程，不得强行套用另类科普。
6. [[skill/神思/公众号文章创作理论/public-account-humanizer/SKILL|公众号文章人味优化 Skill]] 只在用户要求去 AI 味、自然表达、人味优化或 AIV 风险诊断时启用；普通类型识别不自动加载完整返修能力。

## 新方向接入标准

新增方向必须满足：

1. 使用独立 Skill 目录，至少包含 `SKILL.md` 和必要的 `references/`。
2. 在本页登记触发关键词、读取入口、适用范围和禁止套用范围。
3. 明确事实核验要求、内容风险和平台边界。
4. 说明与已有方向的主辅关系，避免多个 Skill 同时争夺主笔权。
5. 通过 Skill 基础校验后，才允许写入 [[公众号模块]] 的活动入口。

## 调用流程

```text
公众号任务
-> 读取 [[公众号模块]]
-> 读取 [[公众号文章创作理论]] 作为通用上位并做轻量类型识别
-> 命中细分方向后加载一个主下位 Skill，与当前上位共同生效
-> 完成选题、证据、结构和传播设计
-> 按需执行事实核验与风险审查
-> 仅在用户明确调用时追加第三方去 AI 味 Skill
-> 交付或返修
```
