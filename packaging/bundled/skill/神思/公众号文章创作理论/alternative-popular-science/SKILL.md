# 另类科普写作理论

## 定位

把“介绍一个知识”改造成“用一个奇怪但真实的问题，带读者完成一次认知升级”。核心公式：

```text
普通问题
× 认知冲突
× 故事化因果链
× 证据可信度
× 人类相关性
× 情绪记忆点
= 可传播的另类科普
```

本 Skill 归属 [[公众号文章创作理论]]，由 [[公众号模块]] 路由。它提供科普内容类型理论，不替代事实核验、平台规则或 [[神思-公众号去AI味规则]]。用户明确要求完整创作、全量诊断或高风险事实审查时，再读取 [[skill/神思/公众号文章创作理论/alternative-popular-science/references/theory|另类科普写作理论详版]]。

## 任务模式

- 选题：从普通现象中提炼反常识问题和核心谜题。
- 创作：完成标题、开头、解释链、认知升级、结尾和视觉建议。
- 改写：把知识罗列稿改成问题驱动、故事化而不失真的科普稿。
- 诊断：检查事实边界、标题承诺、故事因果、理解成本和传播价值。
- 栏目规划：设计可持续栏目和选题组合，不用单篇爆款替代长期信任。

## 固定工作流

### 1. 锁定读者问题

先写清：目标读者是谁、他为什么关心、读完应改变哪个旧认知。不要从“我想介绍什么知识”开局，要从“读者正在误解什么、害怕什么或好奇什么”开局。

### 2. 建立证据账本

把材料分为四层：

| 层级 | 写法 |
|---|---|
| 已确认事实 | 可直接陈述，并保留来源、时间和适用条件。 |
| 有证据的推断 | 明示“这意味着 / 研究者推测 / 一种解释是”。 |
| 思想实验 | 明示“如果 / 假设 / 在这个模型下”，不得伪装成预测。 |
| 比喻 | 只降低理解成本，不能代替机制、数量级和限制。 |

医学、健康、法律、财经、灾难风险、平台政策和最新研究必须核对当前权威来源。无法确认时缩小断言，不编造确定性。

### 3. 选择一个问题发动机

只选一个主发动机，必要时加一个辅助发动机：

| 发动机 | 核心问法 | 适用 |
|---|---|---|
| 假设型 | 如果 X 发生，会怎样？ | 宇宙、灾难、未来、生态和技术。 |
| 逆向型 | 如果我们不再需要 X，世界会更好吗？ | 睡眠、疼痛、遗忘、衰老和制度。 |
| 尺度型 | 放大、缩小或拉长时间后，会看到什么？ | 微观生命、地质、宇宙和人体。 |
| 文明型 | 为什么不同文明都出现了某种结构？ | 城市、农业、文字、能源和组织。 |
| 黑暗型 | 危险、灭绝和未知如何真实运作？ | 深海、病毒、灾难、宇宙终局；必须避免恐慌。 |

### 4. 设计认知冲突开头

在前 10% 完成三件事：给出读者熟悉的旧认知，提供一个可验证的异常，再留下明确谜题。优先使用反常识、生活切入、尺度换算或真实风险，不使用与正文无关的惊吓。

开头公式：

```text
你以为【常识】
但【异常事实 / 现象】
真正的问题是【核心谜题】
```

### 5. 用事件链解释机制

不要按百科顺序罗列“是什么、特点、作用”。把知识组织成可追踪的变化：

```text
起始条件
-> 第一处变化
-> 连锁反应
-> 反馈或失控
-> 对生命 / 社会 / 文明的结果
-> 机制解释与证据回扣
```

故事性来自因果和处境，不来自捏造人物、伪造实验或给自然现象强加人类动机。

### 6. 降低理解成本

每出现一个专业概念，至少提供一种理解支架：日常映射、数量级换算、步骤图、对比、时间轴或剖面图。比喻后补一句“它不像什么”或“比喻在哪一步失效”，防止读者把映射当机制。

### 7. 完成认知升级

结尾前回答：读者原先把什么看小了、看反了或看简单了？使用“真正改变的不是……而是……”完成升维，但必须由前文证据推出，不写脱离主题的哲学金句。

### 8. 设计标题与传播句

标题只承诺正文确实回答的内容。可以使用“为什么”“如果”“你以为……其实……”“一个 X 如何改变 Y”，但“科学家至今无法解释”“致命”“颠覆认知”等措辞必须有真实依据。

传播句用于压缩认知，不用于替代结论。它应代表读者愿意转发的观点，同时保留科学边界。

### 9. 进行发布前审查

检查事实、标题、因果、数量级、比喻、恐慌风险、图像准确性、段落节奏和来源。发现核心事实不稳时先缩小题目或补证，不用更强情绪掩盖证据缺口。

## 推荐结构

```text
认知冲突（约 10%）
-> 核心谜题（约 10%）
-> 故事化解释与证据回扣（约 55%）
-> 认知升级（约 15%）
-> 传播记忆点与余韵（约 10%）
```

比例是诊断基线，不是固定模板。复杂选题可以增加解释篇幅，但不能拖延核心答案到读者已经失去问题意识。

## 硬规则

- 科学正确性优先于戏剧性，不能为反转改写事实。
- 反常识必须反读者误解，不得反科学共识。
- 标题承诺必须在正文中明确兑现。
- 故事化不得伪造人物、数据、实验、引语或历史现场。
- 比喻不得偷换机制；数量换算必须核对单位、尺度和前提。
- 思想实验必须标注假设条件，不能冒充未来预测。
- 黑暗科普不得制造无依据恐慌，不给高风险行为提供可操作伤害指南。
- 医学健康内容不得替代诊断和治疗建议；争议信息必须说明证据等级和不确定性。
- 图片不是装饰，必须服务于比较、过程、结构或尺度理解，并检查版权和科学准确性。
- 不把“一屏一个重点”误解成一句一段；段落长短服从阅读节奏和完整表达。
- 不为传播强行升华。前文没有推出的宏大观点必须删除。

## 最小自检

- 删除知识机制后，文章是否仍只是一个猎奇故事？若是，科普失效。
- 删除故事包装后，是否仍有清楚、准确、可追踪的解释链？若否，事实基础不足。
- 开头制造的谜题是否在正文中真正回答？
- 每个反常识断言是否有来源、条件或明确假设标记？
- 比喻、数字换算和图像是否降低理解成本而没有制造新误解？
- 读者能否用一句话说出自己改变了哪个认知？
- 标题是否比正文结论更夸张？若是，先降标题。
- 结尾是否由证据自然推出，而不是突然升华？

核心项失败时，优先返修问题、证据账本和因果链，不靠增加惊叹号、危险感或金句补救。

- [[神思-公众号去AI味规则]] 管公众号文本的作者化与 AIV 风险，不决定科学结论。

- 涉及实时事实、最新研究、健康医学、法律、财经或平台政策时，必须另行核验当前来源。
