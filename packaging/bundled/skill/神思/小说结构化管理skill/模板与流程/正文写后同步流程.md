# 正文写后同步流程

用途：正式正文、续写、改写、压缩初稿写后同步。

## 同步档位

| 档位 | 处理方式 |
|---|---|
| 轻量诊断 | 只输出待回写清单，不强制落盘。 |
| 正式生产 | 生成结构化更新包，列出应更新文件和条目。 |
| 入库维护 | 实际写入完整路径文件，并记录更新日志。 |

## 每章必须提取

- 本章事件摘要。
- 章尾状态和下一章直接承诺。
- 人物地点、身份、目标、情绪、已知信息、能力、伤势、持有物和关系变化。
- 新埋、推进、回收、延后或废弃的伏笔。
- 本章揭示、局部揭示、误导或必须继续隐藏的信息。
- 重要信息首次登场、推进可疑、维持误判、局部揭示、正式揭示或解释完成状态。
- 新增设定、事件、时间线、术语、物品、地点、规则和势力。
- 冲突、模糊事实、需要用户补充和待确认事项。

## 同步位置

| 内容 | 位置 |
|---|---|
| 章 / 集后台连续性增量 | 随对应 `04_正文/` 单元保存摘要与下一单元必须承接项，不创建独立 Markdown |
| 人物、关系、地点、势力、物品当前状态 | `03_状态快照/当前状态.md`，按完整 `[STATE:id]` 当前视图更新 |
| 伏笔状态 | `01_剧情控制/伏笔管理/伏笔总表.md`，按稳定伏笔 ID 更新 |
| 信息释放 | `01_剧情控制/信息释放表.md` |
| 重要信息登场 | `01_剧情控制/重要信息登场账本.md` |
| 读者知识 | `01_剧情控制/读者当前知识库.md` |
| 章节目标 | `01_剧情控制/章节目标队列.md` |
| 待确认 | `09_索引/待确认事项.md` |
| 更新记录 | `09_索引/更新日志.md` |

有状态变化时更新完整当前状态集合；无状态变化时保留原快照。动态上下文在每次任务前由运行时根据剧情控制、当前状态、最近正文、后台单元增量和相关账本临时编译，用完即丢弃，禁止创建上下文包文档。

## 压缩初稿同步

压缩初稿必须额外记录：

- 可扩写场景锚点。
- 动作链、局部兑现、章尾钩子。
- 正式扩写时需补强的关系戏、对白、物件和情绪后果。
- 已揭示、仅作为扩写锚点、必须继续隐藏的信息。

未通过压缩初稿信息密度闸门的内容，只能保留在候选稿、临时草案包或进入 `01_剧情控制/章纲/`，不得写入 `04_正文/` 冒充章节草稿。只有用户明确要求长期保留并行版本时，才可进入按需创建的 `08_资料库/备选方案/`。
