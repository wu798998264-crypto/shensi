# 设定拆分与入库流程

用途：把新增设定、补设定和正文反推事实拆入结构化目录。

## 入库判断

| 状态 | 位置 | 是否可当 canon |
|---|---|---|
| 用户确认或正文明确写出 | `02_正史设定/`、`03_状态快照/`、对应正文单元的后台连续性增量 | 是 |
| 用户未确认、AI 首轮生成、正文反推核心事实 | `09_索引/待确认事项.md` | 否 |
| 草案、试作 | 候选稿、临时草案包或 `09_索引/待确认事项.md` | 否；默认不自动落盘。 |
| 用户明确要求长期保留的并行方案 | 按需创建的 `08_资料库/备选方案/` | 否 |
| 与既有 canon 冲突 | `09_索引/待确认事项.md` | 否 |

## 设定分类

`02_正史设定/` 优先使用分类聚合板：

- `世界观.md`
- `地图设定.md`
- `基础设定.md`
- `人物设定.md`
- `人物关系.md`
- `势力设定.md`
- `物品设定.md`
- `种族设定.md`
- `力量体系.md`
- `概念设定.md`
- `规则设定.md`
- `特殊设定.md`
- `衍生设定.md`
- `事件.md`
- `时间线.md`

每个实体使用二级标题和稳定 ID 管理，作品内链接采用“作品 / 作品名 / 02_正史设定 / 人物设定#角色名”的项目路径模板。不得仅因实体名称不同就创建单独文件。只有用户明确要求，或单个实体内容已长到无法在聚合板中维护、拥有独立版本周期和大量专属子结构时，才允许独立文档；独立化必须记录理由和来源链接。

## 单实体召回与虚拟档案

单实体任务不改变入库粒度。系统应按以下方式读取：

- 只需要稳定设定：读取聚合板中该实体标题/稳定 ID 对应的完整分节。
- 需要当前状态：追加 `03_状态快照/当前状态.md` 中对应 `[STATE:id]`。
- 需要关系、知情、伏笔或近期承接：只追加直接命中的关系条目、信息 ID、伏笔 ID 和最近必要记忆。
- 将上述内容临时编译为虚拟档案，记录来源与截取状态，但不保存为新的实体 Markdown。
- 没有命中的来源直接省略，禁止扫描式加载整板或用无关条目补足篇幅。

如果独立实体文档确有必要，迁出动作必须满足独立建档门槛，并在原聚合板保留摘要、稳定 ID、正式链接、迁出原因和生效时间；独立文档成为唯一正文源，原分节不得继续保留重复详情。

## 实体分节最低字段

- 名称。
- canon 状态。
- 来源。
- 首次正文出场或待出场状态。
- 具体内容。
- 与人物、势力、地点、规则、物品或事件的关系。
- 信息权限：读者已知、读者可疑、读者未知但作者已知。
- 待确认缺口。

## 出场记录

重磅设定应记录：

- 首次伏笔章节。
- 首次登场章节。
- 局部揭示章节。
- 正式揭示章节。
- 解释完成章节。
- 当前允许写法和禁写方式。

主角身世、核心世界规则、力量体系真相、关键人物真实身份、组织真实目的、重大旧案和终局反转必须进入该作品的 `重要信息登场账本`。
