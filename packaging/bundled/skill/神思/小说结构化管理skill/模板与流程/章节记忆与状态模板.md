# 后台连续性增量与状态模板

用途：给随正文单元保存的后台连续性增量、人物状态、伏笔、信息释放和读者知识提供最小字段。文件名保留为兼容入口，不代表继续创建章节记忆文档。

## 章 / 集后台连续性增量

```text
所属正文单元：第XXX章 / 第XXX集
单元结果摘要：
下一单元必须承接：
提取时间：
同步状态：已同步 / 待同步
```

该增量作为对应正文文档的后台元数据保存，不创建 `章节记忆.md`、`分集记忆.md` 或独立目录。详细状态、伏笔和信息变化分别回写下列正式账本，避免在单元增量中复制第二套事实。

## 当前状态快照

```markdown
## [STATE:稳定ID] 状态对象或维度

- 当前状态：
- 依据与细节：
- 最后更新来源：
```

同一 `03_状态快照/当前状态.md` 同时保存人物、关系、地点、势力和物品的唯一完整当前视图，不按对象建立独立文件。

## 伏笔管理

```markdown
## [FORESHADOW:稳定ID] 伏笔名

- 类型：主线 / 人物 / 世界观 / 情感 / 细节
- 首次出现：
- 表面作用：
- 真实作用：
- 当前状态：未埋 / 已埋 / 伏笔中 / 局部揭示 / 已回收 / 延后 / 废弃
- 显影等级：弱显影 / 中显影 / 强显影
- 当前允许写法：
- 回收节点：
- 回收记录：
```

