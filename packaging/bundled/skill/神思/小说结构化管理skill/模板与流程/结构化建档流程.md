# 结构化建档流程

用途：新建作品、迁移旧目录、补建结构化目录。

## 建档前确认

1. 作品名。
2. 作品根路径。
3. 当前阶段：临时上下文、轻量结构化、完整结构化、强制结构化。
4. canon 状态：已确认、待确认、草案、废弃冲突、不涉及。
5. 是否允许实际落盘；不允许时只输出待确认建档包。

## 多媒介建档

当作品需要管理短剧剧本、视频提示词、图片资产提示词或站位线稿图时，在 `04_正文/短剧/` 下补建对应子目录：

| 子目录 | 用途 |
|---|---|
| `短剧剧本/` | 剧集大纲、改编取舍表、分集剧本。 |
| `视频提示词/` | 视频提示词、分镜提示词、漫剧提示词。 |
| `图片资产提示词/` | 角色、场景、道具、风格和复用资产提示词。 |
| `站位线稿图/` | 多人物站位、空间调度、视频人物位置固定。 |

这些目录只保存本作品的多媒介表达层产物；不得把多个作品的正式剧本或提示词混放到作品外公共目录。

## 其他与编译报告建档

| 目录 / 文件 | 用途 |
|---|---|
| `10_其他/` | 创作者查阅型、辅助型、非 canon 汇总视图，例如当前正式可用章节、当前分卷结构。 |
| `07_编译报告/小说自检.md` | 小说正文、连续性、商业追读、禁用词、信息权限、OOC、伏笔风险等聚合报告。 |
| `07_编译报告/剧本自检.md` | 短剧剧本、剧集大纲、漫剧前置剧本等聚合报告。 |

不得把预计外 Markdown 放在作品根目录；不得在 `07_编译报告/` 下按单项无限新建报告目录。

## 旧目录迁移

- 发现旧根目录 `剧情控制/`、`设定/`、`正文/`、`资料库/`、`索引/` 时，先迁移到标准目录，再停用旧目录。
- 旧目录不得继续作为事实源；迁移后在 `09_索引/更新日志.md` 记录来源、目标和状态。
- 无法判断 canon 状态的旧资料，进入 `08_资料库/原始混合文档/` 或 `09_索引/待确认事项.md`。

## 建档输出

建档完成后输出：

```text
- 作品名：

- 创建目录：
- 创建文件：
- 未确认内容：
- 需要用户确认：
- 更新日志位置：
```
