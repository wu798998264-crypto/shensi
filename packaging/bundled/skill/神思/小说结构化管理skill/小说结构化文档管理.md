# 小说结构化文档管理

显示名称：作品结构管理

状态：结构化管理执行手册入口。

用途：给小说作品建立和维护结构化资料库。本文只保留执行入口、阶段判断和最小闭环；具体建档、同步、设定拆分、链接和日志模板下沉到 `模板与流程/`。

## 读取顺序

执行结构化任务时先读本文，再按任务类型读取对应子文档：

| 任务 | 必读子文档 |
|---|---|
| 新建作品、迁移旧目录、创建标准目录 | [[结构化建档流程]] |
| 正文写后同步、后台连续性增量、人物状态、伏笔和信息释放更新 | [[正文写后同步流程]] |
| 设定拆分、补设定入库、事实提取、出场记录 | [[设定拆分与入库流程]] |
| 链接消歧、更新日志、待确认事项、冲突记录 | [[链接与日志模板]] |
| 后台连续性增量、人物状态、伏笔、信息释放、读者知识字段模板 | [[章节记忆与状态模板]] |

## 标准作品结构

正式长篇统一采用 [[神思-结构化管理规则]] 中定义的标准作品结构：

```text
作品/作品名/
  00_入口/
  01_剧情控制/
  02_正史设定/
  03_状态快照/
  04_正文/
    小说/
      第001卷-卷名/
    短剧/
      短剧剧本/
      视频提示词/
      图片资产提示词/
      站位线稿图/
  07_编译报告/
    小说自检.md
    剧本自检.md
  08_资料库/
  09_索引/
  10_其他/
```

旧结构目录 `剧情控制/`、`设定/`、`正文/`、`资料库/`、`索引/` 不再作为新建、测试、样板或补档任务的落盘位置。正文卷目录不得直接放在 `04_正文/` 根下，必须进入 `04_正文/小说/`。

多媒介作品不另建作品外公共剧本库。新增短剧剧本、视频提示词、图片资产提示词和站位线稿图时，统一在具体作品 `04_正文/短剧/` 下建立对应子目录；跨媒介变更记录到 `09_索引/更新日志.md`，未确认事实记录到 `09_索引/待确认事项.md`。
正文源文件粒度：小说正文一章一个 Markdown 文档，短剧剧本一集一个 Markdown 文档。多章 / 多集汇总文件只允许作为索引、总控、大纲或临时编译视图，不能替代正式正文源文件。拆分、搬运和链接修复时，必须优先保持单章 / 单集文档可独立打开、独立自检、独立回写。

预计外文档不得自动落在作品根目录。`当前正式可用章节.md`、`当前分卷结构.md`、临时阅读清单和创作者查阅型汇总视图，统一放入 `10_其他/`；如果某文件实际承担剧情控制、状态、索引、正文源或编译报告职责，必须放入对应标准目录。

`07_编译报告/` 只维护聚合报告：`小说自检.md` 和 `剧本自检.md`。连续性检查、商业追读评分、禁用词检查、短剧逐集自检等都写入对应聚合报告，不按项目无限新建报告目录。

## 阶段触发

| 阶段 | 触发条件 | 管理动作 |
|---|---|---|
| 临时上下文阶段 | 灵感、点子、大纲、样章、第 1-3 章 | 不强制建完整目录；输出可迁移的临时结构化更新包。 |
| 轻量结构化阶段 | 准备写第 4 章、样章通过后继续连载、用户要求继续多章 | 建议或建立轻量作品结构，至少维护随正文保存的后台连续性增量、伏笔、信息释放和读者知识。 |
| 完整结构化阶段 | 准备写第 10 章、确认写成长篇、出现多卷规划或复杂设定 | 升级为完整作品结构，正式维护 canon、状态和索引。 |
| 强制结构化阶段 | 第 20 章以后、批量续写、连续生产、长篇质量审查 | 缺结构文件时先补建或输出迁移包，不直接批量写正文。 |

章数识别优先级：正文文件名或章节标题、正文目录中的最新编号、章节目标队列、用户明确说明、运行时临时上下文抽取。

## 执行边界

- 管理流程只负责建档、拆分、搬运、链接修复、日志记录和结构一致性检查。
- 管理流程不得替代 [[神思-创作核运行卡]] 的设定、规划或正文主笔模式，也不得替代 [[神思-记忆核运行卡]] 的事实检查与记忆增量。
- 未确认、冲突、正文反推核心事实和理论建议进入 `09_索引/待确认事项.md` 或临时结构化更新包。
- 具体作品内同名结构文档必须使用完整路径 + 显示别名。
- 正文写后同步按 [[神思-结构化管理规则]] 的轻量诊断、正式生产、入库维护三档执行。

## 快速流程

新建作品：

1. 确认作品名和作品根路径。
2. 按 [[结构化建档流程]] 创建标准目录。
3. 只写入作者已提供或已确认的信息。
4. 在 `09_索引/更新日志.md` 记录创建时间和创建内容。

正文更新后：

1. 读取新增或修改的正文。
2. 提取明确事实、可靠推断、待确认事实、幕后/未揭示内容和伏笔状态。
3. 按 [[正文写后同步流程]] 生成随正文保存的后台连续性增量、状态变化、伏笔变化、信息释放变化和待确认更新。
4. 如涉及新设定，按 [[设定拆分与入库流程]] 拆入 `02_正史设定/`。
5. 按 [[链接与日志模板]] 维护 `09_索引/更新日志.md` 和 `09_索引/待确认事项.md`。
