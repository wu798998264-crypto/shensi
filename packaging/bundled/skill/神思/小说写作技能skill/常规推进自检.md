# 常规推进自检

关联：[[神思]]、[[强剧情自检]]、[[神思-正文自检共用规则]]、[[神思-正文质量净增益与防退化规则]]、[[神思-正文质量规则]]、[[神思-正文高频表达限制与语境裁决规则]]、[[神思-开场钩子与时间叙述控制规则]]

## 定位

常规推进版用于正式连载中的普通章节、关系推进、信息沉淀、后果消化和过渡章。它要求章节任务成立、阅读节奏合适、结束功能具体，但不强制每章都有大反转或悬念式钩子。

适用场景：

- 正式连载中段。
- 人物关系推进。
- 信息消化与后果处理。
- 从一个事件过渡到下一个事件。
- 需要稳住人物逻辑而不是强行制造爆点的章节。

## 章节基本要求

一章至少完成一个小闭环：

1. 开头明确本章目标、问题、压力或待处理后果。
2. 中段让人物行动，并通过对话、冲突、误判或选择推进信息。
3. 后段兑现一个局部结果，让局势发生变化。
4. 结尾完成与章节任务相符的结束功能；承担连载接力时形成下一章需求，后果、关系或收束章可用余波、关系位移、阶段兑现或闭合成立。

常规推进不等于无效。即使没有大反转，也要有可说明的贡献：关系/信息/风险/承诺/选择发生变化，或情绪余波、认知校准、必要定向与对比蓄力真正成立。

正式正文还必须通过篇幅闸门：

- 优先检查用户本轮要求、项目创作合同或章纲中的篇幅变量；未指定时 `2000-2800` 只作常规连载参考，以任务、必要场景、因果桥和余波是否完成判断，不为下限注水。
- 信息团数量由章节复杂度决定；应有一个主导问题，支持信息需带走信息、关系、资源、风险、情绪或承诺上的实际作用。
- 关键选择、关系变化和后果不能被摘要替代；重复劳动、行程和已建立的日常可以压缩，不把“摘要”一律判错。



## 商业开局专项自检

本节详细标准统一读取 [[神思-正文质量规则]] 的商业开局自检标准。本自检只负责根据当前章节类型裁决是否通过；任一关键项不合格时，必须返回正文主笔返修。

## 核心自检

| 维度 | 自检问题 | 不合格表现 |
|---|---|---|
| 章节目标 | 本章要推进什么：事件、关系、设定、情绪还是后果？ | 写完后局势没有变化。 |
| 人物能动性 | 人物是否以符合本章任务的方式行动、拒绝、隐瞒、等待、改变解释或承担后果？ | 关键节点被作者便利推动，人物没有自己的选择。 |
| 节奏紧凑 | 是否删掉了不推动人物、关系、冲突、伏笔的信息？ | 场景松散，信息重复。 |
| 信息团 | 本章信息团是否有清晰核心信息，并与前后信息团因果衔接？ | 一章里反复讲同一件事，或切换信息没有原因。 |
| 正文篇幅 | 是否符合明确规格，并完整保留必要过程与余波？ | 只覆盖剧情打点，或为字数加入无后果内容。 |
| 修辞密度 | 比喻、拟人、抽象修辞是否符合叙事模式、人物视角和场景速度，并产生认知增量？ | 同效修辞聚集、抢走场景焦点或打断必要过程。 |
| 否定解释句式 | “不是 A，而是 B / 不像 A，更像 B / 不是因为 A，而是因为 B”等句式是否符合当前场景功能，并且整章不过密？“不是”逐条进行语境裁决。 | 用否定定义解释关系、心理、规则或意象，且不承担角色否认、撒谎、反击、排除误判或主题排比功能。 |
| 场景承载 | 信息沉淀是否通过人物行动、对话、环境压力和后果消化完成？ | 大段说明，缺少具体场面和人物反应。 |
| 时间叙述 | 时间开场属于模板报时、叙事性时间锚点还是因果性时间锚点；是否通过删除、换时、承接与频率测试；近期连续或同构高频时，非时间入口能否无损替代；全文非因果性报时是否在条件配额内？ | 把时间领句一律硬禁；或不检查跨章高频惯性；用“次日—随后—片刻后—到了晚上”串场，连续时间词领段形成日程流水账。 |
| 看点 | 本章是否至少有一个可记住的场面、对话、发现或选择？ | 读完没有记忆点。 |
| 承诺处理 | 本章是否兑现、推进或有充分理由延迟既有承诺？ | 长期只铺垫不兑现，或为配额强行给答案。 |
| 结束功能 | 结尾是否完成后续需求、后果、关系位移、余波、阶段兑现或闭合中的适配功能？ | 结尾没有功能，或临时塞危机冒充钩子。 |
| 循环推进 | 本章是否让核心剧情循环向前走了一步？ | 过渡内容和主循环脱节，像可删番外。 |
| 人物性格一致性 | 行动、对白和反应是否符合既有人设、利益、情绪状态、关系压力和已发生事件？ | 为推进剧情突然 OOC、变脸、降智，或所有角色说话方式趋同。 |
| 伏笔维护 | 当前章节若涉及既有伏笔/承诺，是否按计划推进、回收或合理延迟？ | 伏笔长期悬空；或为每章配额无意义新增伏笔。 |

## 商业评分增强

商业评分、硬性失败项、读者模拟和自动审稿统一按 [[神思-正文自检共用规则]] 与 [[神思-商业判断与自动审稿增强规则]] 执行。常规推进章评分重点优先看章节目标、人物行动、局部兑现、后续期待、信息控制、连续性和语言流畅度。

## 调动后续期待感

常规推进章的期待感不靠强反转，而靠“连续推进感”：

- 让读者看到一个问题正在逼近答案。
- 让读者知道角色下一步必须处理什么。
- 让一个关系变化带来新的行动后果。
- 让一个已解决的小问题暴露更大的结构性问题。
- 让主角获得新资源，同时带来新限制。

需要形成连载接力时，结尾可留下以下一种；关系、后果和收束任务也可用具体余波、站位变化、阶段兑现或闭合完成：

- 下一步任务。
- 未解释线索。
- 即将兑现的承诺。
- 新出现的风险。
- 人物关系的新裂缝或新绑定。
- 某个选择造成的后果。

## 适度原则

常规推进版允许：

- 情绪缓冲。
- 关系铺垫。
- 设定沉淀。
- 后果消化。
- 日常场景中的暗线推进。

这些内容必须服务当前章节任务或后续剧情。不能只是“让人物聊一聊”“让世界观展示一下”“让读者休息一下”；但场景价值可以是外部变化，也可以是情绪余波、关系重定位、认知校准、必要定向或对比蓄力。

如判断不清，先按 [[神思-正文自检共用规则]] 与 [[神思-正文质量规则]] 拆信息团，确认每个场景带走的信息、关系、资源、风险或承诺变化。

## 文字层面强制自检

文字清理、连词 / 关联词、重复信息、比喻密度和画面感边界按 [[神思-正文自检共用规则]] 与 [[神思-正文质量规则]] 执行。高频表达必须完整执行 [[神思-正文高频表达限制与语境裁决规则]]：先查开头零容忍和固定模板，再报词族计数、逐条功能证据、条件上限与近期跨章复用。任一阻断项命中，本章不得通过常规推进自检。

## 人物性格一致性强制自检

人物行动、对白、性格变化、第二人格、黑化或觉醒的检查统一按 [[神思-正文自检共用规则]] 执行。出现无法由人物卡、状态快照、关系压力或已发生事件解释的突变时，判定为 OOC，必须修正文段，不得用事后补设定迁就正文。

## 长篇信息权限专项自检

终局泄露、信息权限、重要信息登场、伏笔显影、读者知识和悬念寿命统一按 [[神思-正文自检共用规则]] 与 [[神思-正文信息权限规则]] 执行。任一信息越权、首次登场无承载或提前讲透重磅信息时，本章不得通过。

## 多章正文轮询自检与上下文衔接

常规推进任务涉及多章生成时，自检文档必须逐章检查，不能把多章当作一段长摘要处理。每一章都要在“推进是否成立”和“上下文是否衔接”两条线上达标后，才能进入下一章。

执行硬规则统一按 [[神思-正文自检共用规则]] 的多章轮询共用规则；常规推进章节额外要求章节任务、承诺处理、结束功能、内容唯一性和质量净增益通过后才能进入下一章。

过渡章尤其不得批量复用“看一眼—沉默—慢慢—这句话意味着”的低熵反应链；同批次 3 章以上同构时按模板坍缩中止生成。

上下文衔接自检：

| 自检项 | 合格标准 | 不合格表现 |
|---|---|---|
| 前章问题承接 | 上一章留下的任务、危险、线索、关系变化或后果，在本章得到处理。 | 上章问题悬空，本章另开新话题。 |
| 人物状态延续 | 人物目标、伤势、情绪、持有物、关系距离和信息差保持连续。 | 人物状态被重置，前章代价消失。 |
| 场景与时间衔接 | 地点转换、时间流逝和行动路径有清楚交代。 | 角色无解释换地点、跳时间、跳过后果。 |
| 信息团衔接 | 本章信息团接在前章已知或可疑信息上，逐步推进。 | 信息团并列堆放，缺少因果。 |
| 重要信息登场衔接 | 本章重要信息的首次登场、推进、局部揭示或正式揭示接在前文已知、可疑或误判之上。 | 重要信息突然正式揭示，前文没有可感知异常、场景承载或读者可疑状态。 |
| 伏笔账衔接 | 新埋、推进、回收、延后的伏笔状态清楚，并与 `作品/作品名/01_剧情控制/伏笔管理/伏笔总表|伏笔总表` 一致。 | 伏笔遗忘、重复埋、突然回收。 |
| 下一章接力 | 本章结尾产生明确的下一步任务、风险、关系后果或信息缺口。 | 结尾收平，下一章只能硬开。 |

任一项不合格时，本章不得通过常规推进自检。
## 禁止项

- 把过渡章写成纯说明文。
- 用长段旁白替代人物行动。
- 因为不追求强反转就让结尾失去具体功能；也禁止给余波章和结局强塞假钩子。
- 为了稳而让章节没有目标、没有变化、没有期待。
- 为了铺垫连续多章不兑现任何信息。
- 为了批量生成，把正式正文压缩成剧情节点清单。
- 明显未完成仍作为正式正文提交；也禁止只因低于历史参考值就机械扩写。
- 为了让过渡章“有文采”，连续堆比喻、拟人和抽象句，导致人物行动、关系变化和信息推进变慢。
- 为了交代信息或推动过渡，让人物 OOC、降智、突然变脸，或让人物性格服务说明而不服务自身逻辑。
- 出现性格变化、第二人格、人格切换、黑化、觉醒后，不更新对应人物设定。
- 用“看着 / 沉默 / 没有立刻 / 慢慢”等占位词冒充后果消化，实际没有人物化动作、关系变化或新信息。
- 为让节奏、钩子或语言指标更漂亮，删掉必要因果桥、内心矛盾、关系余波或作者声音；返修必须通过质量差值检查。

## 输出要求

审稿输出格式统一按 [[神思-正文自检共用规则]]。用户要求“全量 / 满血 / 全面 / 完整 / 所有因素”自检时，必须先按 [[神思-正文满血自检编排规则]] 输出覆盖矩阵；常规推进自检额外标明：章节目标、局部兑现、后续期待和常规推进变化是否通过。

如果用户只要求检查禁用词、剧情节奏、字数、钩子、人物或其他单项，只输出局部自检结论，并明确“本轮未检查满血矩阵的其他板块，不代表全文通过”。

## 压缩初稿信息密度自检

压缩初稿的信息密度闸门统一按 [[神思-正文自检共用规则]] 与 [[神思-正文质量规则]] 执行。若动作链、场景锚点、人物变化、信息释放、重要信息登场、伏笔状态、局部兑现或扩写锚点缺失，不得判定为压缩初稿合格。
