# Chapter Pacing And Information Groups

## Information Group

An information group is a cluster of content around one core information point, often several hundred to two thousand Chinese characters.

Examples:

- 主角穿越。
- 主角面临麻烦。
- 金手指出现。
- 反派误判。
- 情报揭示。
- 关系变化。
- 收获盘点。
- 新危机出现。

## Chapter Shape

Use 2-4 information groups:

1. 承接上章钩子。
2. 展开本章冲突。
3. 推出核心变化或兑现。
4. 抛出新钩子。

For 爽点 or 反杀 scenes, apply [[crossbow-theory]]:

1. 画靶子：确认本段局部目标、承上信息和启下信息。
2. 拉弦：用敌人、旁观者、主角限制制造情绪势能。
3. 卡弦：判断铺垫是否到释放阈值。
4. 扣扳机：给主角无法继续回避的触发点。
5. 放箭：兑现爽点，并命中伏笔回收、情报推进或人物选择。

For revised chapters, apply [[revision-fusion]] before accepting the new version:

- Use the new version to improve causality, pressure, information order, and setup.
- Preserve the old version's strongest humor, intimacy, visual scale, reversal, and final payoff.
- If the new version is clearer but the chapter ending is smaller, flatter, or more explanatory, redesign or restore the larger payoff.

## Formal Chapter Length Gate

For formal novel prose, do not treat chapter structure as complete only because the hook/payoff points are covered.

- Treat chapter length as a resolved project variable: the current user request overrides the project contract and chapter outline. When none specifies a length, accept 2000-2800 Chinese characters and choose a stable, non-boundary target that varies naturally between chapters.
- Minimum 2000 Chinese characters for publishable prose; below this is a compressed draft or plot draft.
- A formal chapter should usually contain 3-5 information groups, not only one scene plus one hook.
- Each information group must be carried by concrete scene work: character action, dialogue, sensory detail, emotional reaction, rule cost, relationship change, or consequence.
- If a chapter only lists plot beats, reveals one rule, and ends on a hook, mark it as draft-level and expand before final submission.

## Group Fields

- 核心信息。
- 读者期待。
- 情绪方向。
- 承载场景。
- 与前后信息团的因果连接。
- 本信息团是否处于拉弦、卡弦、扣扳机、放箭中的哪一步。
- 是否存在设定说明感；若是，改用 [[lore-to-prose]] 以现象、行动、后果承载信息。
- 可删闲笔。

## Cliffhanger

Best positions:

- 新信息团刚抛出。
- 旧期待即将兑现。
- 角色做出不可逆选择。
- 局势刚变复杂。
- 主角完成身份、权柄、底线或能力亮牌。

Avoid ending a chapter on rules explanation when a stronger emotional or visual payoff is available.
