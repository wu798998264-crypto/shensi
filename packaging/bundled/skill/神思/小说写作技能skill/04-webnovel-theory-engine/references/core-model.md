# Core Model

## Chain

`核心卖点 -> 核心期待 -> 剧情循环 -> 故事层级 -> 信息团 -> 场景分镜 -> 正文表达`

## Core Rules

- 网文第一任务是制造并维持期待。
- 爽点是期待被准确兑现，不是孤立刺激。
- 结构服务期待分层；文笔服务信息落地。
- 长篇必须有可重复剧情循环。
- 每一章必须改变至少一项：信息、关系、资源、地位、危机、情绪、目标。

## Diagnostic Questions

- 读者为什么点开？
- 主角为什么持续行动？
- 每轮行动遇到什么阻力？
- 每轮行动得到什么收益？
- 当前钩子何时兑现？
- 章尾留下了什么新问题？
