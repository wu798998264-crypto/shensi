# Character And Network

## Rule

人设 = 性格点 + 行为选择 + 剧情后果 + 读者期待。

Labels are not enough.

## Protagonist

Check:

- 行动逻辑合理。
- 欲望与经历统一。
- 有记忆点。
- 有普通人共鸣点。
- 有非凡之处。
- 成长幅度不破坏读者预期。

## Character Use

- 性格导致剧情产生。
- 性格导致剧情结束。
- 性格通过递进式铺垫被证明。

## Relationship Network

有效关系变化 should create visible changes:

- 地位提升。
- 资源开放。
- 情报增加。
- 新地图资格。
- 新冲突。

Avoid relationships that only state “they know each other”.
