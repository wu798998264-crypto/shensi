# Prose And Scene

## Priority

流畅 is primary. Literary polish only matters after the story moves.

## Formula

`行文 = 叙事 + 旁白`

`叙事 = 场景 + 分镜 + 对白 + 心理/感受`

## Scene Fields

- 时间。
- 地点。
- 出场人物。
- 当前目标。
- 当前阻力。
- 场景结果。

## Shot Fields

- 主体。
- 陪体。
- 环境。
- 动作。

## Prose Rules

- Use narration before abstract explanation when possible.
- Use specific actions and reactions to prove information.
- Description must serve character, atmosphere, emotion, conflict, or expectation.
- Delete dialogue that only repeats known information.
- Formal prose must not keep knowledge-base double-link syntax; write the concept naturally or delay naming.
- Lore terms should enter through phenomenon, character reaction, consequence, then naming. See [[lore-to-prose]].
- Do not use a concept name as a substitute for scene work.
