# Expectation And Plot Loop

## Hook And Payoff

- 抛钩：制造期待。
- 收钩：满足期待。
- 爽点：收钩产生的情绪释放。
- 手弩理论：爽点桥段可拆成弩弦蓄力、卡扣到点、扳机释放、弩箭命中目标。

Rule: 抛钩与收钩必须一一对应。

## Expectation Types

- 近期待：1-3 章内兑现。
- 远期待：跨阶段兑现，必须反复提醒。
- 小期待：小反派、小资源、小误会、小互动。
- 大期待：复仇、升阶、身份揭露、关系确认、终极真相。

## Plot Loop Formula

`题材 + 金手指 + 主角身份 = 剧情循环`

Examples:

- 案件 -> 解谜 -> 局部真相 -> 更大谜团。
- 资源 -> 技能 -> 实力 -> 更高级资源。
- 误判 -> 主角亮牌 -> 认知刷新 -> 更大误判。

## Checks

- 远期待是否定期点火。
- 近期待是否拖太长。
- 同类爽点是否疲劳。
- 情绪是否已经积累到卡扣阈值，还是过早释放或迟迟不释放。
- 爽点是否命中明确剧情目标，而不是无用装逼。
- 修订稿是否保留原稿最强的情绪兑现，不因解释更清楚而削弱爽感。
- 章末是否落在爆点、反转、亮牌或新期待上，而不是落在设定说明上。
- 卷末是否留下下一阶段承诺。
