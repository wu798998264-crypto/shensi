# Learning And AI Workflow

## Theory Learning

Use theory as a diagnostic lens, not as rigid formula.

Process:

1. Learn concept.
2. Verify in successful works.
3. Extract reusable pattern.
4. Rewrite with own topic.
5. Review results.

## Book Dissection Levels

- 核心梗。
- 剧情循环。
- 故事结构。
- 信息团。
- 场景表达。

## Material Card

For each useful material, record:

- 内容。
- 可触发欲望。
- 可触发恐惧。
- 可制造冲突。
- 可承载人设。
- 适用题材。
- 可变桥段。

## AI Uses

AI can classify, extract, generate options, check expectation chains, draft outlines, and review consistency. Do not let AI silently decide core taste, value stance, major character fate, or canon-breaking changes.
