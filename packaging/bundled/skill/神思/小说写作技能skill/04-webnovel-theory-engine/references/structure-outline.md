# Structure And Outline

## Levels

- 大故事：全书或整卷承诺。
- 中故事：阶段目标，数章到数十章。
- 小故事：一个完整情节闭环。
- 故事卡：能制造戏剧性、冲突、反转、爽点或情绪的素材。

## 一级结构 Formula

`目标产生 -> 追求目标 -> 阻碍出现 -> 解决阻碍/新阻碍 -> 目标实现 -> 收获/新钩子`

## Outline Fields

- 核心卖点。
- 主角目标。
- 剧情循环。
- 大阶段。
- 卷级承诺。
- 卷级危机递增。
- 中段反转。
- 卷末兑现。
- 下一卷钩子。

## Failure Modes

- 只有大事件，没有小闭环。
- 只有小爽点，没有大承诺。
- 节点之间没有因果。
- 同类型节点连续重复导致期待疲劳。
