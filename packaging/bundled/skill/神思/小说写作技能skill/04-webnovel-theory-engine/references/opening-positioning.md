# Opening And Positioning

## Opening Jobs

- Let readers know what this book is about.
- Put the protagonist into a concrete problem.
- Show the core promise quickly.
- Trigger a next-chapter question.

## Standard Opening Information Groups

1. 主角进入特殊处境。
2. 主角面对具体麻烦。
3. 金手指、核心梗或关键反差露头。

## Topic Choice

题材 is a reader expectation template. Check:

- What does this audience expect by default?
- What is the genre loop?
- Can the author produce enough scenes for this loop?
- Does the innovation still satisfy the base promise?

## Core Hook

A usable core hook must be:

- Clear in one sentence.
- Visual.
- Repeatable into many payoffs.
- Bound to protagonist identity.
- Demonstrable in the opening.
