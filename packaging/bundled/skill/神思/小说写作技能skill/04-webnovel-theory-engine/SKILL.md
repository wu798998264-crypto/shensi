# 网文通用理论顾问

## Role

Use this skill as the theory layer for [[神思]]. It does not replace [[创作引导]], [[强剧情自检]], [[常规推进自检]], the prototype-writing flow, or the prose-writing flow. It supplies the underlying webnovel logic those flows should apply.

Core chain:

`核心卖点 -> 核心期待 -> 剧情循环 -> 故事层级 -> 信息团 -> 场景分镜 -> 正文表达`

## Default Workflow

1. Identify the task stage: idea, title/intro, outline, volume plan, chapter plan, opening, drafting, revision, review, or learning.
2. Load only the relevant reference file listed below.
3. Convert theory into executable output: checklist, diagnosis, outline fields, chapter plan, scene plan, or revision notes.
4. Preserve canon. If a theory-based suggestion conflicts with established files, write it as a proposal or the current work's `待确认事项`, not as fact.

## Output Contracts

### Diagnosis

When diagnosing an idea or draft, report:

- 核心期待是否清楚。
- 剧情循环是否能长期运转。
- 抛钩与收钩是否对应。
- 爽点是否完成“情绪蓄力 -> 到点 -> 释放 -> 命中目标”的闭环。
- 当前章节是否有有效信息团。
- 设定、术语和能力规则是否已经小说化入文，正式正文是否残留 Obsidian 双链语法。
- 修订稿是否保留原稿最强的幽默、亲近感、爽感和章末爆点。
- 人物行动是否由欲望、恐惧、关系或代价驱动。
- 哪些内容是无用段落、重复解释或无期待信息。

### Outline

When building an outline, include:

- 核心卖点。
- 核心期待。
- 剧情循环公式。
- 大故事 / 中故事 / 小故事层级。
- 每个一级结构的目标、阻碍、解决、收获、新钩子。
- 近期待与远期待分布。

### Chapter Plan

When building a chapter plan, include:

- 本章目标、阻力、代价、局部兑现。
- 2-4 个信息团。
- 每个信息团的核心信息、读者期待、承载场景、衔接方式。
- 本章收钩与章尾新钩。
- 本章禁区。

### Revision

When revising, remove or compress:

- 不服务期待、冲突、人设、氛围或信息释放的段落。
- 重复解释同一信息团的句段。
- 没有行动承载的设定说明。
- 正文中的知识库链接语法和过早术语化表达。
- 与核心承诺错位的爽点。

Then strengthen:

- 具体欲望。
- 具体阻力。
- 可见代价。
- 明确读者期待。
- 对应兑现。
- 原稿中不可降级的亲近感、幽默、爽感和场面资产。

## Integration With Shensi

- [[创作引导]] should use this skill to clarify author intent and choose the correct theory lens.
- `webnovel-plan` and prose-related review flows should use this skill for core expectation, plot loop, story hierarchy, and information-group chapter plans when the route calls for theory diagnosis.
- [[强剧情自检]] should use this skill to test hook/payoff, pressure, reversal, and follow-up expectation.
- [[常规推进自检]] should use this skill to test information-group freshness, relationship progress, consequence digestion, and next promise.
- [[小说结构化文档管理]] should store outputs, not override canon with theory suggestions.
