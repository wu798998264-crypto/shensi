# 04-webnovel-theory-engine

定位：[[神思]] 的网文理论引擎，经过整理归纳的可执行创作方法。

正式 skill 文件：[SKILL](SKILL.md)

## 核心链条

`核心卖点 -> 核心期待 -> 剧情循环 -> 故事层级 -> 信息团 -> 场景分镜 -> 正文表达`

## 主要用途

- 诊断脑洞、题材、开头和核心梗是否有追读。
- 辅助大纲、卷纲、章纲和细纲生成。
- 检查抛钩/收钩、剧情循环、故事层级和信息团。
- 优化人物、人设、爱情线、类型桥段和正文表达。
- 删除无用段落，提高信息密度。
