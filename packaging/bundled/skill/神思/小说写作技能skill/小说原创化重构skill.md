# 原创化重构顾问

关联规则：[[神思-原创化重构规则]]

关联正文：[[神思-正文写作规则]]、[[神思-正文语言质量规则]]

关联改编：[[小说改编短剧剧本skill]]、[[神思-短剧与视觉资产规则]]

## 定位

本 skill 用于处理小说改写、素材重构、借鉴型创作、去 AI 味重写、小说改剧本前的素材功能拆解。

它不是同义替换工具，不负责把原文换名换句后冒充新作品。它负责把输入素材拆成“功能层、情绪层、表达层”，再输出可交给正文或剧本主笔的原创化重构卡。

## 工作流程

1. 读取输入素材，提取核心吸引力。
2. 按 [[神思-原创化重构规则]] 拆出功能层、情绪层、表达层。
3. 列出高相似风险：人物关系、事件顺序、标志性场景、台词、道具、独特设定、意象和节奏模板。
4. 重建新人物、新动机、新场景、新压力、新事件顺序、新道具承载和新钩子。
5. 输出原创化重构卡。
6. 根据最终产物交给 [[神思-正文写作规则]] 或 [[小说改编短剧剧本skill]]。

## 输出格式

```text
原创化重构卡：
- 输入素材核心吸引力：
- 要保留的读者反应：
- 可继承的功能层：
- 必须剥离的相似风险：
- 新人物 / 新关系：
- 新场景 / 新压力：
- 新事件顺序：
- 新道具 / 新信息承载：
- 新章尾或集尾钩子：
- 禁止保留的表达：
- 后续交给：
```

## 禁止项

- 禁止只换人名、地名、门派名、公司名。
- 禁止保留原文事件顺序后只改句子。
- 禁止保留标志性台词、独特名场面和独特设定机制。
- 禁止把原文角色关系组合原样搬到新项目。
- 禁止把素材拆解结果直接当正文交付。
