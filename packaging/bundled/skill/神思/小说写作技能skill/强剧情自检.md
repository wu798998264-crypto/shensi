# 强剧情自检

关联：[[神思]]、[[常规推进自检]]、[[神思-正文自检共用规则]]、[[神思-正文质量净增益与防退化规则]]、[[神思-正文质量规则]]、[[神思-正文高频表达限制与语境裁决规则]]、[[神思-开场钩子与时间叙述控制规则]]、[[小说类型理论研究]]

## 定位

强剧情版用于开局、样章、前三章、核心卖点验证和强类型商业化章节。它的目标是让读者持续产生“下一章必须看”的冲动。

适用场景：

- 开局钩子设计。
- 入局压力设计。
- 前 3-10 章样章验证。
- 重要章节及剧情高潮位置。
- 强反转、强压迫、强悬念章节。
- 判断一个脑洞是否有长篇连载潜力。
## 类型研究顾问触发边界

[[小说类型理论研究]] 是本自检可按需使用的类型能力索引，不是默认前置文档或门禁。Agent 结合完整任务意图、作品核心承诺、当前阶段和自检问题判断是否需要具体类型理论；题材表达只用于理解与搜索，不能由单个关键词直接决定读取。

未命中已接入类型板块时，强剧情自检只按本文件、[[常规推进自检]]、[[神思-正文质量规则]] 和信息权限规则执行，不把其他类型作品强行套入男频爽文标准。

## 章节硬要求

强剧情章必须完成下列功能，但不得把它们写成固定段落顺序或批量模板：

- 起：开头立刻抛出问题、压力、异常、目标或承诺。
- 承：主角采取行动，读者看清他为什么必须这么做。
- 转：局势出现误判、阻力升级、信息反转、代价显形或更大危险。
- 合：兑现本章局部结果，同时留下下一章钩子。

结尾必须形成与前文有因果的具体后续需求。它不一定是爆炸式反转，可以是新压力、选择、后果、关系位移、阶段兑现后的更深问题或未完成承诺。

正式正文还必须通过篇幅闸门：

- 优先检查用户本轮要求、项目创作合同或章纲中的篇幅变量；未指定时 `2000-2800` 只作常规连载参考，以强剧情任务、必要过程、因果桥和情绪余波是否完整判断，不为下限注水。
- 信息团数量由事件复杂度决定；必须有一个主导读者问题，支持信息由场景、行动、对话、心理、规则代价或关系变化中的合适载体承接。
- 不能只完成“开头异常 -> 信息揭示 -> 章尾钩子”的骨架；强剧情也需要足够铺垫、误判、阻力升级和情绪反应。



## 商业开局专项自检

本节详细标准统一读取 [[神思-正文质量规则]] 的商业开局自检标准。本自检只负责根据当前章节类型裁决是否通过；任一关键项不合格时，必须返回正文主笔返修。

## 核心自检

| 维度 | 自检问题 | 不合格表现 |
|---|---|---|
| 开局钩子 | 是否按 [[神思-开场钩子与时间叙述控制规则]] 从人物问题和章节任务选择一个主钩，必要时最多一个辅钩，并留下可复述的未完成问题？ | 只铺背景；机械套灾难、死亡、未来预告或倒计时；多个钩子信号争抢注意力。 |
| 入局压力 | 主角是否被迫行动，且不行动会付出代价？ | 主角只是旁观，剧情靠别人推动。 |
| 期待感 | 本章是否让读者想知道下一步会怎样？ | 只有信息，没有未完成问题。 |
| 抛钩/收钩 | 本章制造的期待是否被局部兑现，章尾是否抛出新期待？ | 抛出 A 期待，却用 B 爽点收尾；或只吊不收。 |
| 信息组织 | 是否有主导问题，支持信息层级清楚且相互有因果？ | 同一信息反复解释，或多个问题争抢注意力。 |
| 正文篇幅 | 是否符合明确规格，并完整展开不可压缩的选择、对抗、证据和后果？ | 只有剧情打点，或为字数填充无后果细节。 |
| 修辞密度 | 比喻、拟人、抽象修辞是否符合人物视角、类型与场景速度，并产生认知增量？ | 同效修辞聚集，用比喻补情绪或打断关键动作链。 |
| 否定解释句式 | “不是 A，而是 B / 不像 A，更像 B / 不是因为 A，而是因为 B”等句式是否符合当前场景功能，并且整章不过密？“不是”逐条进行语境裁决。 | 用否定定义解释心理、规则、意象或情绪，且不承担角色否认、撒谎、反击、排除误判或主题排比功能。 |
| 场景承载 | 每个关键设定/反转/代价是否通过场景发生？ | 用旁白概述替代对抗、选择、行动和后果。 |
| 剧情循环 | 本章是否展示或推进本书的核心剧情循环？ | 开头热闹但和核心卖点、题材循环无关。 |
| 代入感 | 主角目标、恐惧、判断和选择是否具体可信？ | 主角动机空泛，行动像作者安排。 |
| 人物性格一致性 | 本章人物言行是否符合既有人物设定、当前状态、关系压力和已发生事件？ | 为了强剧情让角色突然 OOC、降智、变脸、说出不符合其身份和性格的话。 |
| 紧迫感 | 是否有时间、敌人、规则、资源或后果压力？ | 危机可以无限拖延，没有逼近感。 |
| 时间叙述 | 时间开场是否先区分模板报时、叙事性时间锚点与因果性时间锚点；是否提供不可替代功能、信息增量和后续张力；近期是否连续或同构高频使用；高频时是否与非时间入口做过净增益比较？倒计时是否真的改变选择与代价？ | 把时间领句一律硬禁；或反过来忽略跨章高频惯性；用生僻计时词冒充高级感；用精确报时冒充紧迫感，或按“次日—随后—片刻后”流水推进。 |
| 伏笔设计 | 伏笔当下是否有作用，后续是否可回收？ | 只摆神秘物件，不参与当前冲突。 |
| 局部兑现 | 本章是否至少解决一个小问题或给出一条线索？ | 一章只吊胃口，没有推进。 |
| 结尾钩子 | 结尾是否出现新问题、新压力、新选择或新后果？ | 结尾回到原点，读者没有继续看的理由。 |

## 商业评分增强

商业评分、硬性失败项、读者模拟和自动审稿统一按 [[神思-正文自检共用规则]] 与 [[神思-商业判断与自动审稿增强规则]] 执行。强剧情章节评分重点优先看开篇吸引力、本章冲突强度、主角能动性、爽点 / 局部兑现、信息控制和章末钩子。

## 强化期待感的方法

使用“承诺 - 阻断 - 小兑现 - 新缺口”的循环：

1. 承诺：告诉读者接下来会有一个重要结果。
2. 阻断：让主角遇到具体阻力。
3. 小兑现：给出部分答案或局部胜利。
4. 新缺口：暴露更大危险、真相、代价或选择。

期待感来自未完成，但不能只吊着不兑现。强剧情章应给出与承诺相称的进展，并形成有因果的后续需求；阶段高潮可以先充分兑现，再由真实后果打开下一步。

如判断不清，先按 [[神思-正文自检共用规则]] 与 [[神思-正文质量规则]] 拆出本章抛钩、收钩、局部兑现和信息团，再做强剧情判断。

## 结尾钩子类型

- 新危险：更强敌人、更坏规则、更近的期限出现。
- 新真相：已有认知被部分推翻。
- 新选择：主角必须在两个坏选项之间取舍。
- 新后果：本章行动造成不可逆变化。
- 新承诺：下一章会看到试炼、对决、揭露、救援、逃亡或交易。
- 新关系张力：信任破裂、利益绑定、误会升级、亲密关系被危险牵连。

## 文字层面强制自检

文字清理、连词 / 关联词、重复信息、比喻密度和画面感边界按 [[神思-正文自检共用规则]] 与 [[神思-正文质量规则]] 执行。高频表达必须完整执行 [[神思-正文高频表达限制与语境裁决规则]]：先查开头零容忍和固定模板，再报词族计数、逐条功能证据、条件上限与近期跨章复用。任一阻断项命中，本章不得通过强剧情自检。

## 人物性格一致性强制自检

人物行动、对白、性格变化、第二人格、黑化或觉醒的检查统一按 [[神思-正文自检共用规则]] 执行。出现无法由人物卡、状态快照、关系压力或已发生事件解释的突变时，判定为 OOC，必须修正文段，不得用事后补设定迁就正文。

## 长篇信息权限专项自检

终局泄露、信息权限、重要信息登场、伏笔显影、读者知识和悬念寿命统一按 [[神思-正文自检共用规则]] 与 [[神思-正文信息权限规则]] 执行。任一信息越权、首次登场无承载或提前讲透重磅信息时，本章不得通过。

## 多章正文轮询自检与上下文衔接

强剧情任务涉及多章生成时，自检文档不得只检查单章爆点。每一章必须先通过本章强剧情自检，再通过上下文衔接自检，才能允许进入下一章。

执行硬规则统一按 [[神思-正文自检共用规则]] 的多章轮询共用规则；强剧情章节额外要求章尾后续需求、内容唯一性和质量净增益通过后才能进入下一章。

批量强剧情不得复用同一种“异常开头—否定解释—意义总结—更大威胁”骨架；同批次 3 章以上同构时按模板坍缩中止生成。

上下文衔接自检：

| 自检项 | 合格标准 | 不合格表现 |
|---|---|---|
| 前章钩子承接 | 上一章结尾的新危险、新真相、新选择、新后果或新承诺，在本章开头或前段产生实质影响。 | 上章钩子被遗忘，本章另起事件。 |
| 情绪余波 | 上章造成的恐惧、愤怒、怀疑、信任变化或代价，在本章人物反应中可见。 | 人物像重置状态，情绪和关系没有后果。 |
| 行动因果 | 本章目标由上一章结果自然推出。 | 本章任务突然出现，缺少因果桥。 |
| 信息连续 | 本章只承接读者已知和可疑信息，不把幕后真相当作已知。 | 角色或旁白默认知道上一章没有揭示的信息。 |
| 重要信息登场连续 | 本章重要信息的首次登场、推进、局部揭示或正式揭示接在前文已知、可疑或误判之上。 | 重要信息突然正式揭示，前文没有可感知异常、场景承载或读者可疑状态。 |
| 伏笔连续 | 本章对关键伏笔的处理与 `作品/作品名/01_剧情控制/伏笔管理/伏笔总表|伏笔总表`、`作品/作品名/01_剧情控制/信息释放表|信息释放表` 一致；执行具体作品时替换为真实作品名和完整 wikilink。 | 伏笔显影等级跳跃，提前揭答案。 |
| 章尾递进 | 本章结尾在上一章压力基础上升级，而非简单重复同类钩子。 | 连续多章用同一种假悬念拖延。 |

任一项不合格时，本章不得通过强剧情自检。
## 禁止项

- 为了强剧情让每章都硬塞大反转。
- 为了钩子制造假悬念。
- 为了爽点让人物突然降智。
- 为了冲突擅自增加重大设定，如背叛、死亡、隐藏血脉、隐藏身份。
- 为了强剧情让人物 OOC、降智、突然变脸，或让人物性格服务剧情而不服务自身逻辑。
- 出现性格变化、人格切换、第二人格、黑化、觉醒后，不更新对应人物设定。
- 为了节奏删除必要的情绪缓冲、关系铺垫和后果消化。
- 为了批量覆盖章节，把正式正文压缩成 500-1500 字的剧情梗概。
- 用设定解释、信息罗列或细纲复述替代正文场景。
- 用连续比喻、拟人、抽象文学句替代动作、对白、物件和身体反应。
- 在逃跑、搏斗、谈判、追查等强行动场景中，让比喻连续打断节奏。
- 用“立刻 / 猛地 / 突然”等速度词冒充强度，或用“真正 / 终于明白 / 不是 A 而是 B”替代爆点发生后的具体后果。
- 为提高冲突、钩子或商业评分，删掉必要因果桥、人物矛盾、关系余波或独特声音；任何返修都必须通过质量差值检查。

## 输出要求

审稿输出格式统一按 [[神思-正文自检共用规则]]。用户要求“全量 / 满血 / 全面 / 完整 / 所有因素”自检时，必须先按 [[神思-正文满血自检编排规则]] 输出覆盖矩阵；强剧情自检额外标明：开局钩子、入局压力、局部兑现和章尾追读是否通过。

如果用户只要求检查禁用词、剧情节奏、字数、钩子、人物或其他单项，只输出局部自检结论，并明确“本轮未检查满血矩阵的其他板块，不代表全文通过”。

## 压缩初稿信息密度自检

压缩初稿的信息密度闸门统一按 [[神思-正文自检共用规则]] 与 [[神思-正文质量规则]] 执行。若动作链、场景锚点、人物变化、信息释放、重要信息登场、伏笔状态、局部兑现或扩写锚点缺失，不得判定为压缩初稿合格。
