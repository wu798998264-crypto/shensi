# 神思

神思 Windows 桌面版安装包与更新发布仓库。

## 下载与更新

- 前往 [Releases](https://github.com/wu798998264-crypto/shensi/releases/latest) 下载最新 Windows x64 安装包。
- 软件中的“检查更新”读取本仓库 Releases 的版本、安装包与签名更新清单。
- 每次发布包含安装包、`SHA256SUMS.txt` 和 `update-manifest.json`。软件校验清单签名、安装包哈希与发布者后才允许更新。
- 升级保留本机用户作品、笔记和历史版本。本仓库不包含用户数据或开发者测试作品。
