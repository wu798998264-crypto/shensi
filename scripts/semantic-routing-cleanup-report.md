## 删除的运行规则

- 删除 `classifyRequestMode`、`shouldUseGeneralChat`，及仅供旧分类器使用的函数和关键词表。
- 删除“没有 Agent 决策就按关键词回退”的入口。无决策时保留通用 Agent 执行，不预先推断文档修改或交付类型。
- 删除写入授权中的关键词推断和“落盘意图不明确就强制生成候选”规则。Agent 的写入计划、任务合同和用户手动操作提供执行依据。
- 删除“创作说明必须覆盖固定关键词组才能开始”的资料充分性门槛。经验、记忆、设定和大纲不再作为默认必读列表。
- 删除创作编排、读取规则包和 Skill 选择中的关键词回退。使用明确的任务阶段、产物类型、能力和任务特征。
- 删除闲置的普通文字探测、旧工作区操作计划请求、旧资料门禁重试解析、双模式设置控件及无运行调用方的模式能力模块。
- 删除普通文档任务进入白板执行入口的可能性；白板任务的输出说明限定为白板卡片。
- 配置升级读取旧指针后清除旧字段，保留用户选择、模型、地址与凭证。更新测试/辅助脚本，不再写出独立 Chat 或双模式配置。
